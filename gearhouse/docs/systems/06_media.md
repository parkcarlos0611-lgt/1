# 시스템 설계 06 — 신문과 잡지

수직 슬라이스(소규모 공방, 미국, 1930~1935) 기준이다. 슬라이스에는 지역 신문 1종과 자동차 잡지 1종이 들어간다. 라디오와 다른 매체는 뒤 단계다.

## 1. 목적

- 미디어는 세상을 아는 창이자, 광고·구인·공급사·평판이 오가는 통로다. 읽지 않으면 기회를 놓친다.
- 읽는 것 자체가 재미여야 한다. 시대의 큰 사건과 동네의 자잘한 일이 한 지면에 섞인다.
- 쌓이고 낡는다. 오래된 신문은 회사의 기록이 된다.

## 2. 매체 (슬라이스)

| 매체 | 발행 | 값 | 지면 | 모양 |
|---|---|---|---|---|
| 지역 신문(가상의 소도시 주간지) | 매주 목요일 | 구독 연 $2 | 4면 | 거친 갱지, 흑백, 작은 사진 1~2장, 촘촘한 단 |
| 자동차 잡지(가상의 전국 월간지) | 매달 1일 | 권당 25센트 | 16면 중 읽을 수 있는 8면 | 매끈한 종이, 흑백 사진 다수, 표지 2색 |

- 매체 이름, 제호 글씨, 지면 틀은 가상으로 만든다.
- 뒤 단계에서 광역지, 전국지, 경제지(일간)와 성격이 다른 잡지(고급차, 레이싱, 상용차)를 더한다. 종이 질, 사진 해상도, 색(흑백 → 초기 컬러 → 풀컬러)은 매체 등급과 연도가 정한다.

## 3. 신문의 구성

한 호는 지면 틀에 기사와 광고를 채워 만든다.

| 면 | 들어가는 것 |
|---|---|
| 1면 | 머리기사(가장 중요한 기사), 2~3번째 기사, 날씨, 사진 |
| 2면 | 지역 소식, 사건·사고, 부고, 사교란(결혼, 방문, 파티) |
| 3면 | 경제(물가, 농산물 시세, 은행, 공장), 광고 |
| 4면 | 안내 광고(구인, 구직, 매매, 공급사), 만화 한 칸, 연재물 |

### 기사의 종류

| 종류 | 내용 | 만드는 방법 | 비율 |
|---|---|---|---|
| 역사 기사 | 실제 사건(대공황 진행, 선거, 금주법 폐지, 해외 정세). 실존 인물은 실명 | 날짜가 정해진 데이터. 직접 쓴다 | 호당 1~3건 |
| 시대 기사 | 그 무렵 있을 법한 일(은행 파산, 농산물 값, 먼지 폭풍, 신기록, 영화 개봉) | 연도 범위와 조건이 붙은 틀 + 00 문서 방식 | 2~4건 |
| 지역 기사 | 동네의 자잘한 일(화재, 품평회, 교회 행사, 도난, 날씨 피해) | 무작위 틀 + 동네 인물·장소 이름 | 4~8건 |
| 회사 기사 | 플레이어의 공방(개업, 새 차, 유명 고객, 사고, 해고) | 게임 이벤트가 일으킨다 | 있을 때 |
| 업계 기사 | 가상 경쟁사와 공급사(신차, 가격 인하, 폐업) | 게임 상태가 일으킨다 | 0~2건 |

- **중요도**가 지면을 정한다. 중요도가 가장 높은 기사가 1면 머리에 가고, 제목 크기도 커진다.
- 역사 기사는 그 신문의 눈높이로 쓴다. 소도시 주간지는 큰 사건을 짧게 전하고 "우리 군에는 어떤 영향이"를 덧붙인다.
- 나치 상징은 그림과 사진에 넣지 않는다.

### 기사가 게임에 주는 것

| 기사 | 효과 |
|---|---|
| 은행 파산 | 그 은행 고객의 지불 불능 사건, 대출 조건 악화 |
| 원자재 값 변동 | 공급사 가격 인상·인하의 예고 |
| 도로 포장 계획 | 그 지역 수요 증가의 예고 |
| 공장 폐쇄 | 숙련공 지원자 증가 |
| 품평회·레이스 예고 | 참가 기회(뒤 단계) |
| 부유한 인물의 이사·사업 성공 | 잠재 고객 등장 |

- 기사에는 눈에 띄는 표시가 없다. 읽고 알아채는 것이 플레이다. 놓친 기회는 일지에 나중에 "그때 신문에 났었다"로 남는다.

## 4. 광고와 안내란

- **플레이어의 광고**: 크기(안내 광고 한 줄, 8분의 1면, 4분의 1면)와 기간을 고르고 문구를 정한다. 문구는 몇 가지 강조점(값, 품질, 맞춤, 속도) 중에서 고른다. 다음 호부터 실제 지면에 실린다.
- 광고료 시작값: 안내 광고 주 $0.50, 8분의 1면 주 $4, 4분의 1면 주 $8. (당시 자료를 찾지 못한 값이다.)
- **구인란**: 플레이어의 구인 광고가 실린다(05 문서). 다른 업체의 구인도 실려 시세를 알 수 있다.
- **공급사 광고**: 읽으면 그 공급사가 주소록에 생긴다(03 문서).
- **매매란**: 중고 공구, 중고차, 폐업 정리 물건. 싸게 살 기회다.
- **구직란**: 일자리를 찾는 사람. 먼저 연락할 수 있다.

## 5. 잡지의 구성

| 꼭지 | 내용 |
|---|---|
| 표지 | 그달의 차 그림(가상 차 또는 플레이어의 차) |
| 신차 소개 | 가상 경쟁사와 플레이어의 새 설계. 사양표 |
| 시승기 | 차 한 대의 평가. 수치와 글 |
| 기술 해설 | 그 무렵의 새 기술(유압 브레이크, 독립 서스펜션). 연구 트리의 예고 |
| 레이스·기록 | 대회 결과 |
| 독자 편지 | 차 주인의 칭찬과 불만. 플레이어 고객의 편지가 실릴 수 있다 |
| 광고 | 부품 제조사, 공구, 다른 제작사 |

### 시승기

- 대상이 되는 조건: 전국 인지도가 일정 값 이상이거나, 플레이어가 시승차를 보낸다(차를 한 달 내주고 운송비를 낸다).
- 평가는 계산 물리 수치에서 나온다.

| 항목 | 근거 |
|---|---|
| 가속, 최고 속도 | 계산 엔진 |
| 제동 | 정지 거리, 페이드 |
| 조향·코너링 | 횡가속, 언더스티어 정도 |
| 승차감 | 승차 진동수, 감쇠 |
| 만듦새 | 그 차의 보이는 품질과 결함 |
| 멋 | 차체 설계의 시대 적합도와 비례 점수 |
| 값어치 | 가격 대 같은 급 차 |

- 잡지 성격이 가중치를 정한다. 슬라이스의 잡지는 대중지 성격이다(값어치와 만듦새를 무겁게 본다).
- 기자마다 취향이 있다(성능파, 실용파). 같은 차도 기자에 따라 글이 다르다.
- 글은 00 문서 방식으로 만든다. 수치의 좋고 나쁨에 따라 문장 조각이 달라진다.
- 결과: 평판 5분야의 변화, 전국 인지도 상승, 다음 달 문의 증가. 나쁜 평은 그 반대다.

## 6. 보관과 낡음

- 도착한 신문·잡지는 책상에 놓인다. 읽은 뒤 **버리기 / 서랍에 넣기 / 책장에 꽂기**를 고른다.
- 책상에는 5부, 서랍에는 60부, 책장에는 칸마다 한도가 있다. 넘치면 쌓여서 책상이 어지러워진다.
- 낡음은 나이로 계산해 그릴 때 덧입힌다(그림을 다시 만들지 않는다).

| 나이 | 모양 |
|---|---|
| 1년 미만 | 새것 |
| 1~5년 | 누렇게 바램 |
| 5~15년 | 모서리 접힘, 구김 |
| 15년 이상 | 갈색, 가장자리 삭음, 찢어짐 |

- 서랍이나 책장에 둔 것은 덜 낡는다. 창가 책상에 둔 것은 빨리 바랜다.
- 회사 기사, 시승기, 플레이어 광고가 실린 호는 자동으로 표시된다. 보관해 두면 뒤 단계의 **회사 연대기**에서 찾아볼 수 있다.
- 기사를 오려 **스크랩북**에 붙일 수 있다.

## 7. 읽는 화면

- 신문을 집으면 지면이 화면 가득 펼쳐진다. 면을 넘기고, 기사를 누르면 확대된다.
- 글자는 실제로 읽을 수 있는 크기여야 한다. 지면 그림은 작은 글씨 질감으로 그리고, 누른 기사만 읽기용 글자로 띄운다.
- 광고·구인란·공급사 광고는 눌러서 바로 행동할 수 있다(주소록에 추가, 편지 쓰기).
- UI 품질 기준(글자 넘침, 창 겹침, 누름 영역)을 따른다.

## 8. 상태 데이터

```
Publication { id, kind, name, schedule, pages, style }
Issue       { pubId, date, articles: [{ slot, kind, importance, headline, body, facts, effects }], ads: [...], classifieds: [...] }
Copy        { issueId, place: desk | drawer | shelf | scrapbook | gone, read, marked }
PlayerAd    { pubId, size, weeks, startDate, emphasis }
ReviewRequest { pubId, carId, sentDate, returnDate }
```

## 9. 하루 틱에서 하는 일

1. 발행일이면 그 호를 만든다.
   - 날짜에 걸린 역사 기사를 넣는다.
   - 지난 호 이후의 게임 이벤트에서 회사·업계 기사를 만든다.
   - 조건에 맞는 시대 기사와 지역 기사를 뽑아 남은 칸을 채운다.
   - 중요도 순으로 지면에 놓는다.
   - 광고와 안내란을 채운다(플레이어 광고, 공급사, 구인·구직, 매매).
2. 아침에 구독 중인 매체가 도착한다(`newspaper_published`).
3. 기사의 효과를 건다(예고된 변화는 며칠~몇 주 뒤에 일어난다).

## 10. 이벤트

| 이벤트 | 보내는 내용 | 듣는 시스템 |
|---|---|---|
| `newspaper_published` / `magazine_published` | 호 | UI, 시간(알림), 공급(광고), 인사(구인란) |
| `article_about_company` | 기사, 논조 | 평판, 인지도 |
| `review_published` | 차, 점수, 글 | 평판, 인지도, 판매(문의 증가) |
| `ad_ran` | 광고, 호 | 판매(문의 발생), 재무 |
| `copy_archived` / `copy_discarded` | 사본 | 연대기 |

듣는 이벤트: `car_delivered`, `order_placed`(유명 고객이면 기사), `employee_fired`, `supplier_closed`, `economy_changed`, `design_finalized`(신차 소개), `test_drive_done`, `person_died`(부고).

## 11. 분량 (슬라이스 5년)

| 종류 | 필요한 양 |
|---|---|
| 신문 호 | 약 260호 |
| 역사 기사 | 약 300건 (1930~1935, 직접 쓴다) |
| 시대 기사 틀 | 약 80종 |
| 지역 기사 틀 | 약 150종 (조합으로 수천 건) |
| 잡지 호 | 60호 |
| 시승기 문장 조각 | 약 400개 |

- 역사 기사는 사실 확인이 필요하다. 사건마다 날짜와 출처를 데이터에 함께 적는다.

## 12. 결정 (2026-11-19)

1. 기사에 "게임에 영향 있음" 표시를 넣지 않는다. 난이도 설정으로 표시를 켤 수 있다.
2. 무대는 미국 중서부의 가상 소도시다(미시간·오하이오·인디애나 부근).
3. 신문 한 호는 4면이다.

## 13. 기사 분류 체계 (기획자 지시 2026-11-19, 구현됨)

기사는 출처, 중요도, 게임과의 관계 세 가지로 분류한다.

| 출처 | 중요도 | 게임과의 관계 |
|---|---|---|
| 가상 | 1~6단계 | 필수 / 관련 / 배경 / 무관 |
| 현실 | 중요한 사건 / 매우 중요한 사건 / 역사적 사건 | 필수 / 관련 / 배경 / 무관 |

| 관계 | 뜻 | 예 |
|---|---|---|
| 필수 | 몇 주 뒤 게임 수치를 바꾼다 | 자재 값 변동, 도로 포장, 공장 감원, 은행 불안, 풍작, 새 공급사, 자동차 품평회 |
| 관련 | 자동차 업계와 그 고객의 일 | 경쟁사 신차와 폐업, 경주, 도로 사고, 휘발유 값, 등록 대수, 교통 규칙 |
| 배경 | 시대와 지역 경제 | 곡물 시세, 군 예산, 철도, 가게, 일자리, 날씨, 선거, 은행 결산 |
| 무관 | 동네 살림 | 화재, 교회와 모임, 운동 경기, 도둑, 날씨 사고, 품평회, 경조사, 별난 일 |

### 가상 기사
- 주제 32개가 관계별로 8개씩 있다. 주제마다 중요도 낮음(1~2), 중간(3~4), 높음(5~6) 세 구간의 문장 틀을 따로 갖는다. 같은 화재도 1단계는 헛간의 작은 불이고 6단계는 중심가 대화재다.
- 문장 틀의 빈칸은 낱말 목록에서 채운다. 숫자·금액·비율 목록은 중요도마다 다르다.
- 제목 뒤에 꼬리말(관계자 한마디, 주민 반응, 때와 장소)이 붙을 수 있다. 관계자 한마디는 3단계 이상, 무관 기사가 아닌 것에만 붙는다.
- 호마다 싣는 수: 1단계 2~3건, 2단계 2~3건, 3단계 1~2건, 4단계는 두 호에 한 번꼴, 5단계는 여덟 호에 한 번꼴, 6단계는 서른 호에 한 번꼴이다.
- 필수 기사는 효과를 갖는다. 신문에 난 뒤 1~10주 사이에 실제로 일어난다: 문의 수 배수(일정 기간), 특정 공급사의 값 배수(일정 기간), 새 공급사 알려짐, 동네 인지도.

### 현실 기사
- 날짜가 걸린 사건 43건(해마다 돌아오는 행사 4건 포함)이다. 사건마다 제목이 3가지이고, 관계별 지역 반응 문장 6가지 중 하나가 붙는다.
- 실존 자동차 회사 이름이 들어가는 사건은 싣지 않는다.
- 날짜와 사실은 기억으로 적은 것이라 출시 전에 출처로 검증해야 한다.

### 확인한 수치 (`tools/newsCheck.ts`, 5년 × 10판)
- 가상 기사가 낼 수 있는 서로 다른 제목은 칸(중요도 × 관계)마다 12만~320만 가지다(사람·공급사 이름은 세지 않음).
- 현실 기사의 표현은 774가지다(제목 × 지역 반응).
- 한 호에 평균 7.4건이 실린다. 5년 한 판에서 같은 가상 제목이 다시 나오는 비율은 약 3%다.

### 남은 문제
- 제목만 있고 본문이 없다.
- 꼬리말이 제목과 어울리지 않는 경우가 있다(예: 별난 일 기사에 모임의 반응).
- 사람 이름과 공급사 이름이 영문 그대로 들어간다. 한글 표기 규칙이 필요하다.
