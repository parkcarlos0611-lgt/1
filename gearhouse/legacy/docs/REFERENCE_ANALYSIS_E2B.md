## 2. 섀시·프레임

| 자료 | 패턴 | 반영 |
|---|---|---|
| X멤버 프레임 실물 사진 (구형) vs 현대식 래더 | 구형: 두 레일 가운데에서 X자로 교차, 앞 횡판 스프링, 뒤 토크튜브. 현대식: 평행 레일 + 사다리 크로스멤버 | 하부 평면 뷰 `frame.type: 'x_member'` (1942 세단) / `ladder` (군용·트럭) |
| 1948 스텝다운 세단 브로슈어 3장 (빨간 투시 구조도) | 외곽(페리미터) 프레임이 **뒷바퀴 바깥**으로 돌아감 → 바닥이 레일 사이로 내려앉음(스텝다운), 박스 단면 거더가 승객실을 감쌈, 반일체(세미 유니) 차체. 웹 확인: 휠베이스 124in, 1948년형 L헤드 직렬8 254.5ci 128hp, 3단 수동 | 섀시 형식 `perimeter_stepdown` 데이터 근거. 다음 단계에서 1948 스텝다운 세단 복제 + 하부 뷰 (뒷바퀴 바깥 레일 → 펜더 스커트 필수 규칙) |
| 1951형 스텝다운 쿠페 모형 안내서 (엔진룸 위, 실내, 섀시 하면, 대시, 엔진 양측) | 하면: 레일이 바닥을 둘러싸고 구동축이 크로스멤버 구멍을 통과, 배기관이 오른쪽으로 우회, 뒤 연료탱크. 엔진: 직렬6 + 2연 기화기, 흡·배기 매니폴드 같은 쪽 | 하부 뷰 재질 구분(무광·반광·녹), 직렬6 고출력 변형 근거 |

## 3. 엔진룸·엔진 (8장)

| 엔진 | 판독한 형태 특징 | 생성기 반영 (`engine40.mjs`) |
|---|---|---|
| L헤드 V8 (1942~48 좌측 라벨 도면, 1948~51 337ci 좌·우 분해도, 사진 1장) | 헤드 윗면에 **스터드 너트 3열 약 24개**, 헤드 앞쪽 물 출구 + 상부 호스, 뱅크마다 앞 아래쪽 워터펌프, 앞 중앙 팬, 위 앞쪽 발전기 + 오일필터 캔, 중앙 다운드래프트 기화기 + 오일배스 에어클리너, 뒤쪽 높은 브리더·오일 주입구, 블록 아래쪽 배기 매니폴드, 깊은 오일팬 | `flatheadV8()`: 스터드 24개(빛·그림자 2픽셀), 냉각 리브, 4개 배기 포트, 337ci는 보어·스트로크 비례로 길고 높게 |
| L헤드 V8 단면도 (90°, 밸브축 45°, 캠 기어 42T / 크랭크 21T) | 뱅크각 90°, 밸브가 실린더 옆에 서는 L헤드 구조, 캠이 V 사이 중앙 | 정면 단면 스프라이트 및 엔진 폭 계산 근거 (다음 단계) |
| OHV 직렬6 3장 (주황 승용, 회색 + 4단 트럭, 회색 + 긴 레버) | 긴 블록, 로커커버, **푸시로드 측판 2장(창 모양 구멍)**, 디스트리뷰터·코일, 오일필터 캔, 연료펌프, 오일 주입관, 가로형 오일배스 클리너, 바닥 변속 레버 | `ohvI6()`: 6x6 트럭(270ci, 회색)과 승용(216ci, 주황) |
| OHV 직렬6 신형 (1952형) | 흡기 위·배기 아래 매니폴드, 둥근 클리너 | 1950년대(E3) 엔진 자료로 보관 |

## 4. 변속기 (유체 커플링 4단 자동 컷어웨이)
토러스(유체 커플링) → 프런트 유닛 유성기어 → 리어 유닛 유성기어 → 리버스 유성기어, 클러치 팩, 하부 오일팬과 펌프. → `fluidAuto()` 컷어웨이 스프라이트로 제작. 변속기 설계 화면의 "투시" 표시에 사용.
