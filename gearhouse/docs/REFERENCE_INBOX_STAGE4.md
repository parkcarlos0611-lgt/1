# 4단계 자료 수신함 (제작 전 수집 단계)

> 사용자 지시: **모든 사진 자료를 받은 뒤 제작 시작.** 이 문서는 받은 자료의 판독 메모와 남은 요청 목록이다. 이미지 원본은 저장소에 넣지 않는다.

### 주의: 이 4장은 AI로 만든 홍보용 인포그래픽으로 보임
- **근거**: 같은 워터마크, 스튜디오 렌더 질감, 카드끼리 같은 차의 제원이 다름(예: 1930 V16 토크 300 lb-ft vs 446 Nm), 사실 오류(1930 V16을 "L-Head"로 표기 — 실제는 45° OHV).
- **원칙(자료 우선, AI 성향 배제)**:
  - 이 이미지의 **형태·비율은 템플릿 실측에 쓰지 않는다**. 같은 차의 도면이나 실제 사진을 찾아 대체한다.

**공통 판독 (시대 묘사 규칙)**: 작업복·작업모, 높은 창의 톱니 지붕 채광, 천장 트러스와 레일, 매달린 갓등, 나무 받침대·양동이. 1930년대 사진은 흑백이므로 색은 당시 컬러 자료(엽서·카탈로그)와 재질 기준으로 정한다.
**출처 표기**: 일부는 스톡 사진 워터마크(Alamy, Granger)가 있다. 구조·배치 판독에만 쓰고 이미지를 따라 그리지 않는다.

## 4차 수신 (3장): 시험 주행장

| 자료 | 시대 | 판독 → 시험 주행장(§4 직접 운전, §5 장소) |
|---|---|---|
| 회사 홍보물의 시험장 사진 (세피아 인쇄) | 1930년대 초 | 경사가 급한 **콘크리트 뱅크 오벌**, 노면에 그은 주행선 여러 줄, 바깥 둑 위 울타리, 뒤쪽 나무 띠, 박스형 세단 8대가 줄지어 고속 주행 |
| 같은 종류의 시험장 흑백 사진 | 1930년대 | 뱅크 위쪽으로 갈수록 차가 기울어 보이는 각도, 안쪽 흙 갓길, 마른 겨울 나무, 흐린 하늘 |
| 기록 영상 한 장면 | 1940년 전후 | 평지 직선 포장로, 넓은 잔디 갓길, 낮은 수평선의 나무·건물, 세단 3대 일정 간격 주행 → 측면 스크롤 시험 주행의 기본 구도 |

→ 시험 주행장 구성: **평지 직선(가속·최고속 측정)** + **뱅크 오벌(고속 내구)** + 1930년대 비포장 언덕길(등판)·군용 험로는 자료 추가 시. 측면 스크롤 화면에서 뱅크 구간은 노면이 기울고 차가 위쪽 차선으로 올라가는 연출. 사진이 흑백·세피아라 색은 당시 컬러 자료 기준.
