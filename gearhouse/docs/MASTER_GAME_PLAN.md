# GEARHOUSE 본격 게임 시스템 구상안 (마스터 계획서)

> 상태: **계획 보고 단계 → 보고 후 1단계부터 착수.**
> 참고 게임: *Automation*(엔진·차체 설계 깊이, 실제 개발 순서), *GearCity*(경영·딜러·경쟁사·연표), *Car Mechanic Simulator*(부품 단위 조립 상호작용), *Game Dev Tycoon*(출시 행사·리뷰 점수 연출).
> 구조와 검증된 흐름만 참고한다. 명칭·UI·수치·그림은 모두 이 프로젝트 고유로 만든다.
> 원칙: ① 자료(실측·사진)가 항상 그림 스타일보다 우선 ② 실제 개발 순서와 공정 ③ 높은 설계 자유도 ④ 모든 단계에 손으로 만지는 상호작용과 보상 연출 ⑤ 결과는 장소·인쇄물·숫자로 사실적으로 남는다.

| 지적 | 방향 |

| 연구가 목록뿐 | §9 테크트리(선행 관계 그래프 + 짧은 설명 + 픽셀 그림) |

## 1. 차량 개발 파이프라인 (실제 순서)
각 단계는 **설계실 장소**의 다른 자리(제도대, 엔진 시험실, 목업실, 시험장)에서 일어나고, 단계마다 기간·비용·담당 인력이 든다. 앞 단계로 돌아가 수정하면 뒤 단계 비용이 다시 든다(실제 개발처럼).

| 단계 | 내용 | 결과물·연출 |
|---|---|---|
| 1 기획서 | 목표 세그먼트·가격·연간 생산량·시장(국가). 시장 조사 보고서(경쟁차 표) | 타자기로 찍히는 기획서 문서 |
| 2 플랫폼(섀시) | 프레임 형식(래더·X멤버·페리미터·유니바디), 강재 등급·두께, 휠베이스·트레드, 앞뒤 서스펜션, 브레이크, 타이어 규격, 조향 | 제도대 위 **프레임 청사진**. 무게·강성·원가 계산, 강성 부족 부위가 붉게 표시 |
| 3 엔진 | §2 엔진 설계기 (패밀리 → 변형) | 엔진 시험실: 조립 애니메이션, 다이노, 내구 시험 |
| 4 구동계 | 변속기 형식·단수·기어비, 종감속, 차동 | 기어 맞물림 단면 |
| 5 차체 설계 | §3 파라메트릭 차체 설계기 (측면·정면·후면·평면) | **청사진**: 수정할 때마다 새 청사진이 스캔되어 나오는 장면 (광원 막대가 지나가며 선이 인쇄됨) |
| 6 목업 | 1930년대 목재 목업, 1940년대 실물 크기 클레이 모형. 조명 아래 360° 회전, 경영진 품평회 | 목업실 장면, 품평 점수와 수정 요청 |
| 7 상세 설계 | 실내(좌석·계기판), 편의 장비, 안전 장비, 트림 등급, 도장 옵션 | 계기판·실내 단면 미리보기 |
| 8 시제품·시험 | 시제품 제작(조립 9단계 연출), **시험장 직접 운전**, 내구 주행, 결함 발견과 수정 | 결함 리포트(신뢰성↑ vs 출시 지연) |
| 9 생산 준비 | 공장 라인 배치, 강판·자재 조달, 설비(프레스 금형) 제작 | 도색 안 된 프레임이 라인에 걸리는 장면 |

## 2. 엔진 설계기 (부품 단위)
| 부품 그룹 | 설계 항목 (시대 해금) | 영향 |
|---|---|---|
| 블록 | 배열(직렬 3~8, V6~V16, 수평대향), 뱅크각, 재질(주철·알루미늄), 실린더 간격, 최대 보어·스트로크 | 길이·폭·무게·진동·원가 |
| 헤드 | 사이드밸브 / F헤드 / OHV / SOHC / DOHC, 실린더당 밸브 수, 연소실 형상, 재질 | 체적효율 상한, 회전 한계, 압축비 한계 |
| 하체 | 크랭크(주조·단조, 메인 베어링 수), 커넥팅로드(재질), 피스톤(주철·알루미늄) | 회전 한계, 신뢰성, 진동 |
| 밸브계 | 캠 프로파일(토크형 ↔ 고회전형), 밸브 스프링 강도 | 토크 곡선 모양, 밸브 서징 |
| 흡기 | 기화기 형식(업드래프트·다운드래프트·사이드), 개수·구경, 흡기 매니폴드 | 고회전 출력, 연비 |
| 연료·점화 | 압축비(시대 옥탄 한계), 점화 시기 | 출력·노킹·신뢰성 |
| 배기 | 매니폴드, 단일·듀얼, 머플러 | 출력, 소음(사운드에 반영) |
| 냉각·윤활 | 라디에이터 크기, 오일 용량 | 신뢰성, 무게 |
| 공정 등급 | 부품 그룹마다 −3~+3 | 원가·개발기간 ↔ 성능·신뢰성 |

- **엔진 그림**: 설계값으로 블록·헤드·크랭크·피스톤·매니폴드·기화기·발전기·팬을 **부품별 스프라이트로 조립**한다. 외관, 투시도, 분해도 3가지로 보여 준다. 투시도는 점화 순서대로 움직인다.
- **시험**: 다이노(곡선이 그려짐), 내구 시험(시간 가속, 고장 부품 표시), 엔진음.
- **엔진 조립 연출**: 블록 → 크랭크 → 피스톤 → 헤드 → 매니폴드 → 보기류.

## 3. 파라메트릭 차체 설계기 (가장 큰 작업)
**혼합 대신 직접 설계.** 실측 차량은 허용 범위와 시작 프리셋으로만 쓴다.

### 3-1. 설계 계층 (아래에서 위로)
| 계층 | 조절 (모두 mm, 실측 범위 + 시대 한계) |
|---|---|
| 프레임·섀시 | §1-2에서 설계한 플랫폼 그대로. 차체는 프레임 위에 얹힌다 |
| 차체 구조 | 목골조+강판 / 전강철 / 일체형, 강판 등급·두께(성형 한계 → 곡률 한계) |
| 측면 윤곽 | **제어점 편집**: 범퍼선, 후드선, 카울, 앞유리 기울기, 루프선, C필러, 트렁크·꼬리, 로커선. 점을 끌어 옮기고 곡률 손잡이를 조절. 각 점은 실측 범위 밖으로 못 나감 |
| 펜더 | 분리형(앞·뒤 모양 곡선), 밸런스형, 반폰툰, 폰툰. 앞펜더 꼬리 길이, 크라운 높이, 스커트 |
| 캐빈·창 | 문 개수·문 길이·경첩 형식, A·B·C 필러 위치와 두께, 창 개수·위아래 선, 환기창, 앞유리(1장·2분할), 뒷창 크기, 지붕 형식(고정·컨버터블·랜도) |
| 정면 | 그릴(모양·패턴·크기·높이), **헤드램프 좌우 대칭 배치**(간격·높이·형식: 스탠천·포드·펜더 매립, 크기), 범퍼(바 수·가드·높이), 보조등, 후드 장식, 번호판 |
| 후면 | 트렁크/뒤 스페어, 테일램프(대칭 배치), 뒷창, 범퍼, 번호판, 연료 주입구 |
| 장식 | 몰딩·스피어·핀스트라이프·루버·엠블럼을 측면·정면에 배치 (그리드 스냅, 좌우 대칭 복사) |
| 도장 | 단색·투톤·펜더색·핀스트라이프 색, 시대 색표 |

### 3-2. 편집 기능 (실용)
- **대칭 모드**: 정면·후면의 램프·범퍼 가드·보조등을 한쪽에 놓으면 반대쪽에 거울 배치.
- **편집 보조**: 그리드 스냅, 실행 취소·다시 실행, 수치 직접 입력, 부품 복사.
- **비교**: 실측 범위 표시선, 경쟁차 실루엣을 겹쳐 보기.
- **5뷰 동기화**: 측면에서 바꾼 높이·길이가 정면·후면·평면에 즉시 반영. 폭·높이가 어긋나면 자동 경고.
- **기존 모델에서 시작**: 연식 변경(페이스리프트)용으로 지난 모델을 불러와 일부만 수정.

### 3-3. 질리지 않게
- **시대 유행 지수**: 해마다 인기 형태(그릴 모양·펜더 형식·투톤 등)가 바뀌어 같은 디자인의 평가가 달라짐.
- **디자이너 인력**: 숙련도가 허용 곡률·부품 수·개발기간에 영향, 각자 성향(보수·전위).
- **영감 스케치**: 디자이너가 가끔 콘셉트 스케치를 가져옴(새 부품·형태 해금).
- **도전 과제 기획서**: 예) "1936년, $600 이하 4도어로 연비 25mpg".
- **콘셉트카**: 판매하지 않는 쇼카로 평판을 올린다.
- **부품 카탈로그**: 해마다 새 프롭 추가(이미 224종 + 1940년대 배치 예정).

### 3-4. 청사진·목업 연출
- **청사진**: 설계 변경 → 제도대 위 청사진 롤이 스캐너를 통과하며 선이 한 줄씩 인쇄되는 장면. 치수선·주석 포함.
- **목업**: 실물 크기 목재·클레이 모형이 목업실 조명 아래 놓이고, 360° 회전과 품평회 의견 말풍선이 나옴.

### 3-5. 품질 (v2 렌더 품질 향상 동시 진행)
- **부품 라이브러리**: 두툼한 실부품으로 바꾼다. 범퍼 단면·브래킷·볼트, 램프 버킷·크롬 림, 그릴 셸·바 단면, 교차 스포크 휠, 경첩·핸들.
- **명암 v2**: 곡률 기반 반사띠, 디더는 경계에만, 재질별 명암 곡선.
- **하부 자동 생성**: 프레임·서스펜션·구동계·배기·탱크가 섀시 설계값에서 나온다.

## 5. 장소 (도시 지도에서 이동)
| 장소 | 그래픽·상호작용 |
|---|---|
| 회사 전경 | 공장동·사무동·급수탑·굴뚝, **출고 야적장에 줄지어 선 신차**(실제 재고 수에 비례), 직원 주차장. 규모·시대에 따라 확장 |
| 본사 사무실 | 책상·타자기·전화·지도. 비서 안내, 보고서 서류 |
| 설계실 | 제도대(청사진), 목업실, 엔진 시험실 |
| 공장 내부 | 라인, 프레스, 도장 부스. 기계·인원 클릭 시 정보 |
| 시험장 | 직선로·뱅크 오벌·비포장 언덕. 직접 운전 |
| 딜러십 | 지역별 매장(1930s 상가 → 1940s 쇼룸 → 1949 스트림라인), 진열된 내 차, 손님 |
| 행사장 | §7 발표회 장소들 |
| 재고 방치 | 야적장·쇼룸에 오래 팔리지 않은 차에 **먼지가 쌓이고 색이 바래는 표시**, 가격 인하 필요 |

## 6. 신차 발표회와 언론
| 규모 | 장소 | 비용·효과 |
|---|---|---|
| 소 | 딜러 쇼룸 | 지역 신문 단신 |
| 중 | 호텔 연회장 | 지역·전국 신문 |
| 대 | 본사 대강당·전용 행사장 | 잡지 표지 기회 |
| 특대 | 자동차 박람회·만국박람회 부스 | 해외 시장 인지도 |
- **연출**: 커튼이 걷히며 차가 공개되고 플래시가 터진다. 그 장면이 **흑백 신문 사진**(디더 흑백 + 망점 질감)으로 인쇄된다.
- **신문 기사**: 헤드라인, 사진, 본문은 제원·가격과 기자 한마디.
- **잡지**: 로드 테스트 기사(측정값 표, 장단점, 별점). 매체마다 성향이 다르다(스포츠지·가정지·업계지).

## 7. 출시 후 평가와 판매
- **판매**: 월별·지역별·세그먼트별 판매량, 경쟁차 대비 점유율 그래프, 딜러 재고.
- **전문가 평가**: 출시 리뷰 + 연례 비교 시험, 수상(올해의 차 등 가상 상).

## 12. A단계 재정비 — 실측 렌더를 설계기의 바탕으로

**지적:**
- v3 설계기가 기존 실측 렌더(측면 14대, 정면·후면 5세트, 군용)를 쓰지 않고 도형부터 새로 그려 품질이 떨어졌다.
- 정면 앞유리 아래 양옆이 비는 문제(예전 군용차와 같은 문제)가 다시 생겼다.

**바로 고친 것:** 정면·후면에서 차체 옆면(카울·문)이 벨트라인부터 문턱까지 전폭으로 내려가도록 수정했다. 펜더는 그 앞에 그려진다.

**원칙:** 기존 실측 렌더는 삭제하지 않고 설계기의 **바탕 차체**로 쓴다. 새 도형은 실측 자료가 없는 곳에만 쓴다.

| 순서 | 내용 |
|---|---|
| 1 | **바탕 차량 선택**: 설계를 시작할 때 시대에 맞는 실측 차체 14대 중 하나를 고른다(연도로 잠금). 측면은 실측 사양 그대로 출발한다 |
| 2 | **치수 조절 = 구간 변형**: 휠베이스, 앞뒤 오버행, 지붕·벨트·후드 높이, 전폭을 실측 사양의 구간 변형으로 적용한다(캐빈 고정 원칙 유지). 기존 warpSpec을 오버행·후드·벨트까지 확장한다 |
| 3 | **부품 교체 = 실측 부품 라이브러리**: 그릴, 헤드램프, 범퍼, 테일램프, 휠, 스페어를 실측 차에서 부품 단위로 떼어 라이브러리로 만든다. 다른 실측 차의 부품을 같은 기준점(그릴 중심, 펜더 정점, 범퍼 높이)에 맞춰 바탕 차에 끼운다 |
| 4 | **정면·후면도 실측 바탕**: 실측 정면·후면이 있는 차(1930 세단, 1934 타운카, 1934 에어플로형, 1937 유선형, 군용)는 그대로 쓰고 같은 치수 변형을 적용한다. 정면·후면이 없는 1940년대 8대는 받은 정면·후면 사진 16장으로 **실측 정면·후면을 새로 제작**한다 |
| 5 | **v3 매개변수 체계 유지**: 조작 항목, 시대 한계, 대칭 배치, 청사진 스캔은 그대로 두고 그리는 쪽만 실측 바탕으로 바꾼다. 실측 바탕이 없는 조합에만 v3 도형을 쓴다 |
| 6 | **품질**: 범퍼 단면·브래킷, 램프 버킷·크롬 림, 그릴 바 단면을 실측 부품 기준으로 다듬는다 |

**진행 결과 (12장 1차):** 바탕 차량 14대 선택, 구간 변형(앞·뒤 오버행, 휠베이스, 차체 높이, 지붕 높이, 전폭), 부품 교체(휠, 헤드램프, 그릴, 범퍼, 테일램프)를 테스트판에 반영했다. 실측 정면·후면 5세트는 치수에 맞춰 다시 맞추고, 1940년대 8대의 정면·후면은 측면 실측 높이와 정면·후면 사진으로 만들었다. 자유 설계(v3)는 선택 항목으로 남겼다.

## 13. 추가 요청 3건 — 계획서 반영 여부 점검과 보강안

| 요청 | 기존 계획서 | 빠진 부분 |
|---|---|---|
| 실제 기반 프레임·플랫폼(모노코크) 제작 | §1-2 플랫폼 단계(래더·X멤버·페리미터·유니바디 선택, 강재, 휠베이스·트레드), B단계 섀시 화면, 조립 9단계의 1단계 프레임 | 실측 프레임 자료를 바탕으로 쓰는 방식이 없음. 모노코크는 선택지 이름뿐이고 구조(바닥판·사이드실·필러·격벽)와 제작 공정이 없음 |
| 실측 차체에서 길이를 포함한 전체 형상 조절 | 12장(이번에 구현): 길이·높이·폭 조절만 | 지붕선, 트렁크·꼬리, 앞코, 펜더 형상 같은 **모양** 조절이 실측 차체에는 없음(자유 설계에만 있음) |

### 13-1. 실측 기반 프레임·플랫폼
- **바탕 프레임**: 바탕 차량마다 실제 프레임 형식과 치수를 기본값으로 둔다. 1930년대 초는 채널 단면 래더와 뒤차축 위 킥업, 1930년대 중반부터 X멤버, 1940년대 박스 단면 레일. 휠베이스를 바꾸면 사이드 레일이 늘어난다.
- **모노코크(유니바디)**: 연구로 해금한다(1930년대 중반 실차 사례 기준). 바닥판, 사이드실, 터널, A·B·C 필러, 루프 레일, 앞 격벽을 부재 단위로 표시하고, 무게·강성·금형비·수리비가 프레임식과 달라진다.
- **설계 화면**: 평면도와 측면도를 함께 보여 준다. 도색 안 된 강재 색에 리벳·용접 표시를 넣고 청사진 스캔을 쓴다. 조절 항목은 레일 단면 높이·두께, 강재 등급, 크로스멤버 수, 킥업 높이다.
- **생산 연결**: 조립 1단계에서 설계한 프레임이 그대로 나온다. 모노코크는 프레임 단계와 차체 얹기 단계 대신 용접 지그에서 차체가 짜이는 장면으로 바뀐다.
- **필요 자료**: 1930~49년 프레임 평면도(래더·X멤버), 초기 모노코크 절개도.

### 13-2. 실측 차체 형상 조절
- **조절점**: 실측 윤곽 위에 지붕 앞끝, 지붕 정점, 뒷창 경사, 트렁크 길이·높이(패스트백 경사), 앞코·그릴 경사, 앞펜더 꼬리 길이·정점, 벨트선 기울기, 앞유리 경사를 둔다.
- **변형 방식**: 각 조절점 주변만 부드럽게 변형하고 캐빈 문짝은 고정한다. 범위는 같은 시대 실측 차들 사이로 제한한다.
- **조작**: 측면 미리보기에서 끌기와 수치 입력을 모두 지원하고, 실행 취소를 넣는다. 정면·후면은 같은 높이를 공유해 자동으로 따라간다.

### 13-3. 부품 장착 연출
- **설계 화면**: 그릴·램프·범퍼·장식·휠을 바꾸면 화면 전체를 다시 스캔하지 않는다. 바뀐 부품만 다음 순서로 연출한다.
  1. 옛 부품이 떨어진다.
  2. 새 부품이 장착 위치로 내려와 맞물린다.
  3. 볼트 조임 반짝임 2~3번.
  4. 크롬에 빛이 한 번 훑고 지나간다.
  5. 효과음(렌치, 래칫, 쿵)과 장식 장착 시 작은 '딸깍'.
- **조립 화면**: 8단계 마감에서 그릴, 헤드램프, 범퍼, 장식, 휠캡을 하나씩 단다.
- **구현 기반**: 부품이 사양에 따로 들어 있어서, 부품을 뺀 차체와 부품을 따로 그려 겹치는 방식으로 만든다.

**진행 결과 (13장 1차, 3 → 2 → 1 순서):**
- **13-3 장착 연출:** 설계 화면에서 그릴, 램프, 범퍼, 가드, 장식, 안개등, 휠을 바꾸면 그 부품만 연출한다. 옛 부품이 떨어지고, 새 부품이 내려와 맞물리고, 볼트 반짝임과 크롬 빛이 지나가며, 쿵·래칫·딸깍 소리가 난다. 조립 8단계에서는 범퍼 → 램프 → 그릴·크롬 순서로 하나씩 단다.
- **13-2 형상 조절:** 형상 탭을 추가했다. 실측 윤곽 위 조절점 7개(앞유리 윗선, 지붕 정점, 뒷창 윗선, 트렁크 높이, 앞코 경사, 앞펜더 꼬리, 앞펜더 높이)를 끌거나 슬라이더로 움직이며, 바탕 차마다 범위가 정해져 있다. 되돌리기·다시하기는 모든 탭에 적용된다.
- **13-1 프레임·플랫폼:** 프레임 탭을 추가했다.
  - 바탕 차마다 실제 형식을 기본값으로 둔다: 채널 래더, 래더 + X멤버, 박스 레일 + X멤버, 일체형 차체(연구 해금).
  - 조절 항목: 레일 높이·두께, 크로스멤버 수, 킥업, 강재 등급(연강, 중탄소강, 고장력강).
  - 이 값으로 무게·강성·강도 여유·원가를 계산해 성능(무게), 승차감(강성), 신뢰성(강도 부족 시 균열), 원가, 현대성에 반영한다.
  - 조립 장면은 설계한 프레임(도색 안 된 강재)을 쓰고, 일체형 차체는 지그 용접 → 서스펜션 장착 → … 순서로 진행한다.
- **13-1 보강 (7차 자료):** 일체형 차체를 1934년 셸 사진 기준으로 다시 그렸다(격벽, 뿔 레일, 문·창 개구부, 일체 휠하우스, 평평한 리브 바닥). 조립 장면도 셸 → 서스펜션 → 파워트레인 → 펜더·보닛 결합 순서로 바뀐다. 1938년 하부 사진으로 '중앙 튜브 플랫폼' 형식을 추가했다.
