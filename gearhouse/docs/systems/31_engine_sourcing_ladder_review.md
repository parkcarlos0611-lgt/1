# 검토 31 — 엔진 조달 사다리 (회사 규모별)

(대화에서 제안한 것을 옮겨 적고 결정을 더함. 원래 제안: docs/decisions.md 2026-11-20 "review 31, proposal")

## 지금 상태
- 새 설계(검토 03): 1930~35 조각에서는 엔진·변속기·클러치를 공급사에서 산다. 제조사는 평판과 실적이 있는 가게에만 판다.
- 1차판: 회사 규모 프리셋(차고, 작은 공장, 엔진 공장이 있는 중견, 대기업)과 연구원, 연구 시설 등급, 부품별 엔진 설계(계열 → 변형), 엔진 시험실(legacy/docs/GDD.md 3.2, legacy/docs/MASTER_GAME_PLAN.md 15).
- 섀시 시트로 만든 섀시는 시험(맞춤 검사, 시험 주행)과 배치 참고용. 주행 장치 부품(엔진, 변속기, 차축, 스프링, 완충기, 탱크, 프레임)은 부품 그림마다 따로 만들어 배치에 놓는다.

## 사다리
| 단계 | 하는 일 | 여는 조건 |
|---|---|---|
| 1. 완성 엔진 구매 | 공급사 카탈로그에서 엔진을 사서 단다 | 처음부터 |
| 2. 구매 후 개조 | 산 엔진의 헤드·카뷰레터·배기 등을 바꿔 성능·소리·신뢰성을 조정 | 정비 기술, 작업장 공구 |
| 3. 라이선스 생산 | 다른 회사 설계를 사용료를 내고 직접 만든다 | 주조·기계 가공 설비, 계약 |
| 4. 자체 변형 | 기존 계열에서 배기량·실린더 수를 바꾼 변형 | 설계 부서, 엔진 시험실 |
| 5. 자체 계열 개발 | 블록부터 새 계열, 엔진 공장과 연구 시설 | 대기업, 연구 시설 등급 |

## 결정 (2026-11-20, 추천안 채택)
- 1930~35 세로 조각은 1단계와 2단계만 연다. 3~5단계는 회사가 커지는 뒤 단계(단계 3~4)에서 연다.
- 단계는 회사 규모와 설비(작업장 공구, 엔진 시험실, 연구 시설 등급)로 열리며, 도면 화면의 회사 규모(도면 종류)와 같은 규모 값을 쓴다.
- 견적서에 엔진 줄이 생기는 것은 계산 물리(시제품 ②)를 옮긴 뒤.
