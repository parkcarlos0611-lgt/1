# GEARHOUSE — 게임 디자인 문서 (GDD v0.1)

- 장르: 자동차 회사 경영 + 차량 엔지니어링/디자인 시뮬레이션
- 시점/그래픽: 2D 정사영 (좌측면 · 우측면 · 탑 · 프론트 · 리어), 플랫 일러스트 + 선택적 픽셀 모드
- 플랫폼: 웹(HTML5 Canvas) 우선 → 데스크톱 래핑(Electron/Tauri) 확장 가능
- 플레이 기간: 시작 1930~2000년 중 선택, 기본 종료 2010년 (옵션: 무한 모드)
- 참고: 엔지니어링 시뮬레이션 장르(*Automation* 등)의 설계 깊이. 시스템·명칭·아트는 독자 구성

## 1. 핵심 게임 루프

```
 ┌──────────────── 연구 (기술 해금 / 기술 성숙도) ◄──────────────┐
 │                                                               │
 ▼                                                               │
 플랫폼 개발 ──► 엔진 개발 ──► 파워트레인 구성 ──► 바디 디자인       │
 (섀시·서스)    (패밀리/변형)   (변속기·구동)     (실루엣→강판→부품) │
 │                                                               │
 ▼                                                               │
 테스트 트랙 / 통계 산출 ──► 트림·가격 결정 ──► 공장 툴링·생산      │
                                                 │               │
                                                 ▼               │
                         시장 판매 (세그먼트 수요·경쟁사·경제) ──► 수익·명성 ┘
```

- **단기 루프 (분 단위)**: 부품 배치 → 통계 변화 즉시 확인 → 조정.
- **중기 루프 (게임 내 1~3년)**: 모델 개발 → 출시 → 판매 데이터 → 페이스리프트.
- **장기 루프 (수십 년)**: 시대 변화(규제·유가·취향)에 맞춰 플랫폼·엔진 세대 교체, 브랜드 포지셔닝.

### 2.1 저장/불러오기

- 수동 슬롯 20개 + 자동저장 3개(롤링, 매 게임 내 분기 또는 출시 이벤트 시).
- 저장소: IndexedDB (브라우저) / 파일 시스템 (데스크톱 빌드).
- **내보내기/가져오기**: 세이브 전체 `.ghsave`(압축 JSON), 차량 단일 `.ghcar`, 엔진 단일 `.gheng` — 커뮤니티 공유용.
- 세이브 포맷에 `schemaVersion` 필드, 로드시 마이그레이션 함수 체인 적용.
- 시뮬레이션은 시드 기반 결정론적 RNG → 세이브에 RNG 상태 포함.

## 3. 새 게임 설정

### 3.1 화면 1 — 국가 & 연도

- **시작 연도**: 1930~2000 (연 단위 슬라이더). 선택 즉시 해당 연도의 대표 실루엣·뉴스 헤드라인 미리보기.
- **본사 국가**: 국가마다 아래 파라미터가 다르다.

| 파라미터 | 설명 | 예 |
|---|---|---|
| 인건비 지수 | 생산비·연구원 급여 | 시대별로 변동 (예: 일본/한국은 초반 저가→후반 상승) |
| 연료 가격 지수 | 시장의 연비 민감도 | 유럽 높음, 미국 낮음 |
| 세제 | 배기량세·마력세 | 일본(소형차 규격), 프랑스(세제 마력), 이탈리아(배기량 구간) |
| 도로 상태 | 승차감·내구성 가중치 | 비포장 비율이 높은 시장은 서스펜션·내구성 중시 |
| 관세/수출 | 자국 시장 보호, 수출 장벽 | |
| 소비자 취향 | 세그먼트별 선호 | 미국: 대형·고배기량 / 유럽: 소형·핸들링 / 일본: 신뢰성·경제성 |
| 역사 이벤트 | 해당 국가가 받는 영향 | 전쟁, 경제 위기, 규제 도입 연도 |
| 진출 가능 연도 | 해당 국가 자동차 산업 시작 가능 시점 | 일부 국가는 1950년 이후 선택 가능 |

국가 초기 목록(10~14개, 실제 국가명 사용·특정 기업 미등장): 미국, 영국, 독일, 프랑스, 이탈리아, 스웨덴, 체코슬로바키아, 소련/러시아, 일본, 한국, 브라질, 인도, 호주.
→ 1990년 등 국경 변화는 이벤트로 처리.

### 3.2 화면 2 — 회사 규모

| 프리셋 | 초기 자본 | 공장 | 연구원 | 브랜드 명성 | 난이도 체감 |
|---|---|---|---|---|---|
| 차고 창업 | 매우 적음 | 없음(외주 조립) | 3 | 0 | 매우 어려움 |
| 소형 제작소 | 적음 | 소형 라인 1 | 10 | 낮음 | 어려움 |
| 중견 기업 | 보통 | 중형 라인 1 + 엔진 공장 | 40 | 보통 | 보통 |
| 대기업 계열 | 많음 | 대형 라인 2 | 120 | 보통 | 쉬움 |
| 커스텀 | 자유 입력 | 선택 | 자유 | 자유 | — |

- 자본 금액은 연도별 물가 지수로 환산(1930년 vs 2000년 화폐가치)되어 표시.
- **연구 규모** 별도 설정:
  - 연구원 수 (위 프리셋 기본값에서 조정)
  - 초기 기술 수준: 시대 평균 대비 -1세대 / 평균 / +1세대 (예: 1955 시작 + "+1세대" → OHV V8, 독립 앞서스 해금 상태)
  - 연구 시설 등급 (1~5): 동시 연구 프로젝트 수, 연구 속도

### 3.3 화면 3 — 회사 정체성 & 규칙

- 회사명, 창업자명, **로고 에디터** (엠블럼 프레임 + 심볼 + 문자 조합, 스프라이트 시스템 재사용 → 차량 엠블럼 슬롯에 그대로 부착).
- 브랜드 컬러 (UI 테마 및 기본 도색 제안).
- 경쟁사 AI 수 (0~12), AI 성향(공격적/보수적).
- 경제 변동성 (낮음/역사적/높음), 역사 이벤트 (실제 연표/무작위/끔).
- 종료 연도 (2000~2010, 무한).
- 철인 모드 (자동저장 1슬롯, 되돌리기 불가).

## 4. 시대(Era) 구분

| Era | 기간 | 디자인 언어 | 대표 기술 해금 | 시장 이슈 |
|---|---|---|---|---|
| E1 | 1930–1939 | 독립 펜더, 러닝보드, 세로형 그릴, 스페어 타이어 외부 장착, 유선형(후기) | 사이드밸브, 래더 프레임, 기계식 브레이크→유압, 싱크로메시(후기) | 대공황, 고급차 몰락, 저가차 수요 |
| E2 | 1940–1949 | 펜더 일체화 시작, 폰툰 바디 등장 | OHV 보급, 전시 기술(4WD·고옥탄) 민간 이전 | 전쟁 중 민수 생산 중단(국가별), 군납 계약, 전후 물자 부족 |
| E3 | 1950–1959 | 크롬, 테일핀, 투톤, 랩어라운드 유리 / 유럽 소형차 | V8 OHV 대중화, 자동변속기, 파워스티어링, 모노코크 확산, FRP 바디 | 교외화, 고속도로, 마력 경쟁 |
| E4 | 1960–1969 | 직선적·롱후드, 쿠페 패스트백, 소형 해치 | 디스크 브레이크, 맥퍼슨, 기계식 연료분사, 로터리(실험), 안전벨트 | 안전 규제 시작, 머슬/스포츠 붐 |
| E5 | 1970–1979 | 웨지 쉐이프, 5mph 대형 범퍼, 사각 헤드램프, 비닐 루프 | 촉매, 터보 초기, FF 횡치 대중화, 래디얼 타이어 표준 | 오일쇼크 ×2, 배기가스 규제, 소형차 전환 |
| E6 | 1980–1989 | 박스형, 플러시 글라스, 팝업 램프, 공력 디자인 | 멀티포인트 EFI, DOHC 4밸브 대중화, ABS, 전자제어 4WD, 아연도금 | 일본차 확산, 품질 경쟁, 유가 안정 |
| E7 | 1990–2000 | 바이오 디자인(곡면), 프로젝터 램프, 대형 범퍼 일체형 | 에어백 표준, 가변밸브, 알루미늄 바디, CVT, 차체 안정제어(후기), 하이브리드(실험) | 환경 규제 강화, SUV 붐, 외환위기 등 |

Era는 **콘텐츠 태그**로 사용된다: 실루엣·부품·소재·도색 팔레트·기술은 `eraFrom`~`eraTo`(연 단위)를 가진다. 시대가 지난 부품도 사용은 가능하지만 "구식" 디자인 페널티를 받고, 일부는 레트로 보너스(예: E7의 원형 헤드램프 레트로 스포츠카)를 받을 수 있다.

## 5. 차량 개발 파이프라인

개발은 4개 설계실로 나뉘고, 결과물은 서로를 참조한다.

```
 플랫폼(섀시) ──┐
               ├──► 모델(Model) = 플랫폼 + 바디(실루엣) ──► 트림(Trim) = 모델 + 엔진 변형 + 변속기 + 옵션
 엔진 패밀리 ───┤
   └ 엔진 변형 ─┘
```

- **공유 구조**: 하나의 플랫폼에 여러 바디(세단/왜건/쿠페), 하나의 엔진 패밀리에 여러 변형(1.6/1.8/2.0, 터보). 공유할수록 툴링 비용·개발 기간 감소, 대신 차별성(디자인 점수 다양성) 감소.
- 모든 설계는 **엔지니어링 시간(인·월)** 과 **툴링 비용**을 소모하며, 설계 완료 후 공장 라인에 할당돼야 생산 가능.

### 5.1 플랫폼(섀시) 개발

| 항목 | 선택지 (시대 해금) | 영향 |
|---|---|---|
| 섀시 구조 | 래더 프레임, X-프레임, 페리미터 프레임, 백본, 모노코크, 세미 모노코크, 튜블러 스페이스프레임 | 무게, 강성(핸들링·안전), 생산비, 수리성, 오프로드 |
| 섀시 소재 | 일반강, 아연도금강, 고장력강, 알루미늄, (E7) 알루미늄 압출+주조 | 무게, 비용, 부식 |
| 엔진 배치 | 프론트 종치, 프론트 횡치, 프론트 미드, 미드, 리어 | 무게 배분, 실내공간, 엔진베이 크기 |
| 구동 | FR, FF, RR, MR, 4WD(파트타임/풀타임/전자제어) | 트랙션, 핸들링, 실내공간, 비용 |
| 앞 서스펜션 | 솔리드 액슬(리프), 트윈 I빔, 더블 위시본, 맥퍼슨, 트레일링 암 | 승차감, 핸들링, 비용, 공간 |
| 뒤 서스펜션 | 솔리드 액슬(리프/코일), 스윙 액슬, 드디옹, 토션빔, 세미 트레일링, 멀티링크 | 〃 |
| 치수 | 휠베이스, 앞/뒤 트랙 폭 (실루엣 호환 범위와 연동) | 실내공간, 안정성, 회전반경 |
| 품질 투자 | -15 ~ +15 (각 하위 시스템별) | 신뢰성·성능 ↑ / 비용·엔지니어링 시간 ↑ |

**호환성 규칙**: 바디 실루엣은 `wheelbaseRange`, `trackRange`, `engineLayoutAllowed`를 가진다. 플랫폼 치수가 범위를 벗어나면 해당 실루엣을 선택할 수 없다 (미리보기에서 회색 처리).

### 5.2 엔진 개발 (패밀리 → 변형)

**엔진 패밀리** (블록 단위, 변경 시 새 툴링 필요)

| 항목 | 선택지 |
|---|---|
| 실린더 레이아웃 | 직렬 2/3/4/5/6/8, V6/V8/V10/V12/V16, 수평대향 2/4/6, (E4~) 로터리 1~3로터 |
| V각 | 45/60/72/90/120° (레이아웃별 제한) — 밸런스·폭에 영향 |
| 블록 소재 | 주철, 알루미늄+주철 라이너, (E6~) 전 알루미늄 |
| 헤드 형식 | 사이드밸브(플랫헤드) → OHV → SOHC → DOHC |
| 헤드 소재 | 주철 / 알루미늄 |
| 밸브 수 | 2 / 3 / 4 / 5 (헤드 형식별 제한) |
| 최대 보어/스트로크 | 패밀리 내 변형이 가질 수 있는 상한 |

**엔진 변형** (같은 블록에서 파생)

| 항목 | 선택지 / 범위 |
|---|---|
| 보어 × 스트로크 | 배기량 = 실린더수 × π/4 × 보어² × 스트로크 |
| 크랭크 / 콘로드 / 피스톤 | 주철·단조강·빌렛 / 강·티타늄 / 주조·단조 알루미늄 |
| 압축비 | 연료 옥탄가와 노킹 한계로 제약 |
| 캠 프로파일 | 0~100 (저회전 토크 ↔ 고회전 출력) |
| 연료 공급 | 단일 캐브 → 2/4배럴 캐브 → 다중 캐브 → 기계식 분사 → 싱글포인트 EFI → 멀티포인트 EFI → (E7) 직분사(실험) |
| 과급 | 자연흡기, 슈퍼차저(루츠/원심), 터보(싱글/트윈, E5~) + 인터쿨러 |
| 배기 | 단일/듀얼, 매니폴드 형식(주철/헤더 4-1, 4-2-1), 촉매(E5~), 머플러 등급 |
| 연료 | 레귤러/고급, 유연/무연 (시대·국가별 공급), 디젤 |
| 튜닝 | 공연비, 점화 시기, 레드라인 RPM |
| 품질 투자 | 블록·헤드·연료·배기 하위별 -15 ~ +15 |

**엔진 출력 통계**: 출력/토크 곡선, 최고출력·최대토크 RPM, 연비(BSFC 맵), 배출가스 등급, 소음, 진동/스무스니스, 신뢰성, 무게, **물리 크기(길이·폭·높이 mm)**, 생산비, 정비비, 엔지니어링 시간.

> 엔진 물리 크기는 스프라이트 조립 결과의 바운딩 박스와 같은 값이다 (→ SPRITE_SYSTEM §6). 엔진베이에 들어가지 않으면 장착 불가.

### 5.4 바디 디자인 (디자인 스튜디오)

사용자가 요구한 순서를 그대로 단계(Step)로 만든다. 각 단계는 탭으로 오가며 언제든 되돌아갈 수 있다.

| Step | 작업 | 산출 |
|---|---|---|
| ① 실루엣 선택 | 시대·차종 필터로 실루엣 선택, 허용 범위 내 모프(길이/폭/높이/루프라인 등) | 차체 외곽·패널 영역·슬롯 |
| ② 강판(패널) 소재 | 패널 영역별(루프·후드·도어·펜더·트렁크) 소재 등급 지정 | 무게, 비용, 부식, 패널 품질, 안전 |
| ③ 기계 레이아웃 (X-ray) | 차체가 반투명 처리되고 엔진·변속기·구동축·연료탱크·라디에이터·배기·배터리·스페어 타이어 배치 | 무게 배분, 실내/트렁크 공간, 충돌 안전, 패키징 충돌 검사 |
| ④ 외장 부품 | 헤드램프, 그릴, 범퍼, 테일램프, 창문/유리 프레임, 미러, 도어핸들, 크롬 몰딩, 엠블럼, 테일핀, 스포일러 등 | 디자인 점수, 공력, 안전(램프·범퍼), 비용 |
| ⑤ 도색 & 장식 | 단색/투톤/스트라이프, 메탈릭/펄, 데칼, 화이트월 타이어 | 시장 매력도, 비용 |
| ⑥ 인테리어 & 편의 | 시트·내장 등급, 라디오, 히터/에어컨, 전동창, 안전장비(벨트/에어백) | 승차감, 프레스티지, 안전, 비용 |

자세한 레이어·배치·스프라이트 규칙은 **SPRITE_SYSTEM.md** 참조.

### 5.5 테스트 & 통계

테스트 트랙 화면: 사이드뷰 차량이 스크롤되는 트랙 위를 달리는 애니메이션(휠 회전, 서스펜션 바운스, 가속 시 피칭) + 그래프.

| 통계 | 계산 근거 |
|---|---|
| 0→100 km/h, 1/4마일 | 토크 곡선, 기어비, 무게, 트랙션(구동방식·무게배분·타이어) |
| 최고속도 | 출력 vs (공기저항 ½ρCdAv² + 구름저항) 교차점, 레드라인 제한 |
| 전면 투영 면적 A | **프론트 뷰 최종 마스크 픽셀 수 × (mm/px)²** |
| 공기저항 계수 Cd | 실루엣 기본 Cd + 부품 보정(돌출 램프·미러·스포일러·범퍼 형상) |
| 연비 | BSFC 맵 × 표준 주행 사이클 시뮬레이션 |
| 제동거리 | 브레이크·타이어·무게 |
| 핸들링 / 그립 | 서스 형식·품질, 무게배분, 트랙/휠베이스, 타이어, 무게중심(부품 Z좌표 가중평균) |
| 승차감 | 서스 형식, 휠베이스, 타이어 편평비, 시트/내장 |
| 실용성 | 실내 공간(실루엣 캐빈 박스 - 기계부품 침범), 트렁크(트렁크 박스 - 탱크/스페어 침범), 좌석 수 |
| 안전 | 섀시 구조, 강판 crash, 크럼플 존 길이(범퍼→캐빈 거리), 안전장비, 연료탱크 위치 |
| 신뢰성 | 각 하위 시스템 품질투자 + 기술 성숙도 + 소재 부식 |
| 디자인 점수 | 비례(휠베이스·오버행·높이 비), 시대 트렌드 일치, 부품 스타일 조화(태그 매칭), 대칭/정렬, 패널 품질, 색상 트렌드 |
| 프레스티지 | 디자인, 소재, 인테리어, 엔진 실린더 수·출력, 브랜드 명성 |
| 생산비 / 생산 시간 / 정비비 | 모든 부품·소재 합 + 공장 자동화 수준 |

## 6. 연구 시스템

- **기술 트리**: 분야별 (엔진 / 연료·과급 / 섀시·서스 / 구동·변속 / 바디·소재 / 전장·안전 / 생산기술) 노드. 노드는 `yearAvailable`(역사적 등장 연도)을 가지며, 그 이전에 연구하면 비용·기간이 급증("선행 연구").
- **기술 성숙도**: 새로 해금된 기술은 성숙도 0%에서 시작 → 신뢰성·비용 페널티. 연구 투자와 **실제 생산 사용량**으로 성숙. 업계 전체 보급도(경쟁사 사용)도 성숙도에 반영.
- **연구원 배치**: 연구원 = 슬롯. 시설 등급이 동시 프로젝트 수를 결정. 연구원은 분야 숙련도(경험치)를 쌓는다.
- **특허/라이선스 (확장)**: 경쟁사 기술을 라이선스 구매하거나 판매.

## 7. 경영 시스템

### 7.1 시간 진행
- 기본 단위: 1틱 = 1주, UI는 월 단위 리포트. 일시정지 / 1x / 2x / 4x 속도.
- 개발·연구·툴링은 주 단위로 진척. 시장 판매는 월 단위 정산.

### 7.2 공장
- 라인 크기(소/중/대), **자동화 수준**(인력 ↔ 설비 투자), 품질 관리 등급.
- 툴링: 모델(바디)·엔진 패밀리·플랫폼 별 1회성 비용. 공유 시 할인.
- 라인 전환(모델 교체) 시 다운타임.
- 생산 능력·재고·출고 관리. 과잉 재고는 할인 판매/보관비.

### 7.3 시장
- **구매자 집단** (각자 통계 가중치·가격 민감도·브랜드 충성도 보유):
  서민 실용, 가족, 중산층, 부유층, 상류층(럭셔리), 스포츠 매니아, 상업/영업용(트럭·밴), 관용·택시, 오프로드/농업.
- 집단 규모는 국가·연도별 인구·소득 곡선으로 변화 (예: 1950년대 미국 중산층 팽창, 1970년대 연비 가중치 급증).
- 각 트림은 집단별 **매력 점수**를 받는다 = Σ(통계 × 가중치) × 가격 적합도 × 브랜드 명성 × 딜러 커버리지 × 마케팅.
- 같은 세그먼트 경쟁 차량 간 점유율 분배 (로짓 모델).
- 수출: 국가별 관세·딜러망 구축 필요, 좌/우핸들 대응(우측면/좌측면 뷰의 스티어링 위치가 실제로 바뀜).

### 7.4 판매·마케팅
- 가격 책정(권장가 대비), 딜러 네트워크 투자(지역별), 광고 캠페인(신문→라디오→TV→인터넷 순으로 매체 해금).
- 신차 발표회 이벤트: 쇼룸 일러스트 + 차량 5뷰 회전 연출.

### 7.5 재무
- 손익계산서, 대차대조표, 현금흐름. 은행 대출(신용등급), 증자/상장, 배당.
- 파산 조건: 현금 음수 + 대출 불가 상태 N개월.

### 7.6 명성 & 사건
- 브랜드 명성: 세그먼트별(럭셔리 명성 ≠ 경제차 명성).
- 신뢰성 이슈 → 리콜 이벤트(비용·명성 손실), 언론 리뷰 점수.
- 역사 이벤트: 대공황, 전쟁(민수 생산 중단, 군수 계약: 트럭/소형 4WD 개발 의뢰), 오일쇼크, 배기·안전 규제(기한 내 대응 못하면 판매 금지), 외환/금융 위기.

### 7.7 경쟁사 AI
- AI 회사도 동일 시스템으로 차를 설계(파라미터 공간 탐색 + 템플릿)하고, 동일 스프라이트 시스템으로 외형이 생성된다.
- 성향: 볼륨형 / 럭셔리형 / 스포츠형 / 상용차형.
- 인수합병 (확장): 파산 직전 AI 인수, 플레이어 회사 인수 제의.

### 7.8 모터스포츠 (확장)
- 랠리/투어링/레이스 참가 → 명성·기술 성숙도 보너스. 레이스 결과는 사이드뷰 시뮬레이션.

## 9. 밸런스 원칙

1. 같은 시대 안에서 "만능 정답"이 없도록 트레이드오프를 설계: 고급 소재 = 무게↓·품질↑ 이지만 비용·생산시간↑.
2. 시대 변화가 기존 정답을 무너뜨린다: 오일쇼크로 대배기량 V8 수요 급감, 규제로 무거운 범퍼·촉매 의무화.
3. 공유(플랫폼·엔진)와 차별화(디자인 점수) 사이의 긴장.
4. 디자인 점수는 플레이어 미적 취향을 강제하지 않도록 "규칙 기반 + 시대 트렌드" 위주, 비중은 전체 매력도의 15~25%로 제한.
5. 자동 밸런스 벤치(헤드리스 시뮬레이션): AI 회사 N개로 1930→2010을 수백 회 돌려 파산률·점유율 분포 검사 (cage 프로젝트의 `simbench` 방식).
