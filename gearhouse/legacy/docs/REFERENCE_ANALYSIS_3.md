# 레퍼런스 분석 3차 — 정면 타이어, 유선형 2종, 엔진룸, 하부 구조

입력: 사용자 제공 19장 (엔진룸 3, 하부 4, 프레임 1, 섀시 평면 + 측면 1, 유선형 4면도·사진 5, 기존 스포츠·고급 5).

## 1. 정면 타이어가 얇아 보이던 문제

| 원인 | 수정 |
|---|---|
| 정면 타이어를 단순 직사각형(폭 120mm, 공칭 단면폭 그대로)으로 그림 | 타이어 규격에서 단면폭을 가져와 **공기압 부풂 ×1.28** 적용 (4.75-19 → 약 155mm) |
| 형상이 기둥 같음 | 타이어를 정면에서 본 실제 실루엣인 **알약형(stadium)**: 모서리 R = 폭 × 0.48 |
| 음영이 단조로움 | 가운데 트레드 크라운은 밝게 + 3px 간격 트레드 줄무늬, 옆벽은 바깥으로 갈수록 어둡게, 좌측 옆벽 볼록 하이라이트 |
| 바퀴 위치가 임의값 | 트레드(차축 폭) 1422mm 기준 중심 ±711 |
| 허브가 안 보임 | 바깥쪽으로 돌출된 크롬 허브캡 |

## 2. 유선형 측정

| 항목 | 1934 에어플로형 세단 | 1937 V 그릴 패스트백 쿠페 |
|---|---|---|
| 축척 근거 | 블루프린트 WB 표기 3251 → 13.6mm/px | 사진, WB 122in(3099) → 9.48mm/px |
| 타이어 | 6.50-16 화이트월, 차체색 휠 + 허브캡 | 7.00-16 **와이드 화이트월** (OD 755 실측 일치) |
| 전장 / 전고 | 약 4,910 / 1,520 | 약 4,930 / 1,690 |
| 노즈 | 둥근 폭포형 그릴, 헤드램프가 노즈 측면에 매립 | 뱃머리형 V 그릴, 램프가 펜더 앞에 매립 |
| 앞유리 | 약 45° 경사, 카울 = 앞차축 + 0.26WB | 약 32° |
| 창 | 앞 모서리가 A필러와 평행, 뒤 창은 루프를 따라 둥글게 | **D자형 단일 창** (3창 쿠페) |
| 펜더 | 앞펜더는 차체와 통합(아치만 뚫림), 뒤는 **스커트** | 큰 앞펜더가 길게 흘러 러닝보드로, 뒤 펜더는 독립 |
| 범퍼 | **3단 가는 바** + 클램프 | 단일 블레이드 + 오버라이더 |
| 장식 | 후드 옆 가로 루버 5줄(앞쪽이 짧음), 벨트 이중 크롬 라인, 트렁크 사선 스피어 | 노즈 측면 그릴 바 래핑, 카울 스피어, 보드 몰딩, 후드 오너먼트 |

## 3. 엔진룸 사진 → 사이드밸브 직렬4 디테일 (5mm/px)

| 관찰 | 반영 |
|---|---|
| 평평한 헤드, 볼트 2열 | 헤드 슬랩 + 볼트 9개 × 2열 |
| 헤드 위 점화플러그 4개 + 배선, 앞 디스트리뷰터 | 플러그(자기 절연체 흰색) + 검은 배선 → 디스트리뷰터 캡 |
| 헤드 앞 물 배출구, 굵은 상부 호스, 워터펌프·팬 | 배출구 주물 + 고무 호스 + 팬(옆에서 본 모습) |
| 블록 옆 녹슨 배기 매니폴드, 그 위 아치형 흡기 매니폴드, 아래 업드래프트 캐브 | 배기 로그(녹 색) + 포트 3개, 흡기 아치 → 황동 캐브 + 하부 흡입구, 동관 연료라인 |
| 발전기, 오일 필러 캡, 스타터, 벨하우징 | 각 부품 |
| 블록 색: 녹회색 도장, 주물 거친 표면 | 엔진그린 램프 + 주물 반점 + 그라데이션 |

## 4. 하부·프레임·섀시 사진 (X-ray와 하부 뷰에 쓸 패턴)

| 구성 | 관찰 (1930 소형차 하부 사진 4장 + 프레임 사진 1장) |
|---|---|
| 프레임 | 채널 단면 사다리 2레일, 앞은 좁고 뒤는 넓음(테이퍼), 뒤차축 위 킥업, 크로스멤버 3~4개 |
| 앞 | 빔 액슬 위 횡치 리프, **V자 래디어스 로드("위시본")**가 변속기 뒤 볼 조인트로 모임, 드래그 링크·타이로드 |
| 가운데 | 토크튜브(중앙 굵은 관), 브레이크 로드가 프레임을 따라 뒤로, 바닥판 |
| 뒤 | 디퍼렌셜(호박형) + 액슬 튜브, 액슬 위 횡치 리프, 뒤 래디어스 로드가 토크튜브 앞쪽으로 모임 |
| 배기 | 머플러가 프레임 한쪽에 평행, 테일파이프는 뒤로 |
| 유럽 소형차 섀시 평면도 | X멤버 프레임, 배터리 박스, 뒤 연료탱크, 오픈 프로펠러 샤프트 (호치키스) |

→ X-ray(측면)는 이미 반영(프레임 킥업, 스프링, 래디어스 로드, 토크튜브). **하부 평면 뷰(차를 아래에서 본 모습)**는 디자인 스튜디오의 "하부" 탭용으로 다음 단계에서 생성.
