# E2 (1940년대) 제작 계획서

## 0. 시대 개요
| 구간 | 디자인 | 게임 처리 |
|---|---|---|
| 1940–42 전전 | 앞펜더가 문까지 흐르는 유선형, 펜더 매립 실드빔 램프, 러닝보드 소멸, 와이드 가로 그릴 | `stream` 연장, 그릴 `wide` 해금 |
| 1942–45 전시 | 미국·유럽 민수 승용차 생산 중단, 군용 4x4·트럭·지휘차 | 민수 판매 중단 이벤트, **군납 계약 세그먼트**(경 4x4, 1.5~2.5t 트럭, 지휘차), 공장 전환 |
| 1946–48 전후 | 전전 모델 재생산 + 신형 등장 | 전전 설계 재사용(개발비 할인), 자재 부족 이벤트 |
| 1946–49 풀 폰툰 | 펜더가 차체에 통합된 슬래브 사이드, 수평 벨트라인, 노치백 | **새 디자인 언어 `pontoon`** (1946+) |

## 1. 차체 생성기 연도별 한계 (구현 완료: `gen/bodygen.mjs`)
| 항목 | 박스 1946 / 1949 | 유선 1942 / 1949 | **폰툰 1946 / 1949** |
|---|---|---|---|
| 앞유리 경사(°) | 10–26 / 14–30 | 26–44 / 28–46 | 30–42 / 34–46 |
| 전고/WB | 0.52–0.58 | 0.45–0.53 / 0.46–0.54 | 0.50–0.56 / 0.50–0.55 |
| 후드/WB | 0.40–0.52 / 0.40–0.50 | 0.42–0.55 / 0.40–0.52 | 0.36–0.46 / 0.34–0.44 |
| 펜더 | 폰툰형 앞펜더 | 폰툰 앞펜더, 스커트 | **통합(슬래브)**: 아치만 뚫림, 뒤 아치는 아래쪽만 |
| 꼬리 | 트렁크, 버슬 | 패스트백, 버슬 | **노치백 트렁크**, 패스트백 |
| 그릴 | 와이드, V | 와이드, 폭포 | 와이드 |
- 폰툰 비율 근거: 1949 4도어 세단 블루프린트 실측 (WB 2896, 전장 4999, 전폭 1821 표기 → 5.7mm/px). 전고 0.53WB, 벨트라인 0.67H(후드~트렁크 수평), 앞유리 약 45°.
- 1946년 이전 폰툰 요청 → 유선형으로 대체 (미리보기 1945 사례).
- 미리보기: `samples/e2_generator_preview.png` (레퍼런스 반영 전). **알려진 문제**: 폰툰 노즈가 높고 뭉툭함 → 복제 단계에서 후드 길이·노즈 높이 보정.

## 2. 기술 해금 (E2)
실드빔 헤드램프(1940), 칼럼 시프트, 완전 자동변속기(1940), 유체 커플링, 오버드라이브 보급, 독립 앞서스 표준화, 유니바디(1941~, 1948 스텝다운 구조), 고압축 OHV V8(1949), 15인치 저압 타이어(6.70-15, 1949), 2분할 곡면 앞유리 → 1분할 곡면(1950s 예고), 전시 기술 이전(4WD, 고옥탄 연료).
