# MotorWorks — 설계 문서 & 로드맵 (v0.2)

2D 사이드뷰/탑뷰 자동차 회사 경영 시뮬레이션. 실행: `motorworks/index.html` (빌드 없음).
밸런스 점검: `node motorworks/tools/simcheck.js [년수] [rich]` — 1946→2035 전체 경제를 1~2초에 돌립니다.

### 2. 렌더러 (`src/render/carRender.js`)
스튜디오 촬영 방식의 셰이딩: 지붕·어깨선은 하늘 반사, 도어 중간의 수평선 반사, 하부는 바닥 반사, 평면도 곡률로 앞뒤 끝이 어두워짐.
휠 아치는 차체에서 실제로 잘라내고, 램프·범퍼·휠·몰딩·사이드미러·도어 핸들·실내 시트가 설계 연도(또는 지정한 디자인 연대)를 따릅니다.
강판 텍스처(절차 생성 또는 업로드)를 삼각형 메시로 차체 곡면에 맞춰 변형하고, 패널별 소재가 다르면 원소재 보기에서 패널마다 다른 강판이 보입니다.
결과는 설계별로 캐시합니다.

### 3. 새 시스템
- **플랫폼**: 공유 하부(프레임, 서스펜션, 구동, 휠베이스·전폭 범위, 엔진룸). 플랫폼 위 차량은 개발비 55%·기간 70%·차체 금형 60%. 공장별 하부 금형 공유, 누적 생산 학습곡선.
- **패널별 강판(테일러드 블랭크)**: 7개 패널마다 소재·등급. 패널별 성형 깊이 vs 소재 성형 한계 → 스크랩률이 원가에 반영.
- **전동화**: BEV/HEV/PHEV. 셀 화학(NiMH·NMC·LFP·전고체), BloombergNEF 팩 가격 시계열($1,200/kWh 2010 → $108 2025), 에너지밀도, 모터·인버터, 주행거리, kWh/100km, CO₂.
- **생산**: 라인 밸런싱(병목 공정이 라인 능력 결정), 1~3교대, 모델별 학습곡선, 부품 내재화/외주(협력사 공급 차질), 노조(3년 단체협약·파업).
- **판매**: 트림, 리베이트, 플릿 판매, 3년 잔존가치, EV 보조금·충전 인프라에 따른 수용도, 관세.
- **규제**: 미국 CAFE(1978~), EU·동아시아 CO₂ 함대 평균 — 연말 벌금.
- **언론**: 출시 시 3개 매체 평가 + 같은 세그먼트 경쟁차와 비교 테스트, 올해의 차(경쟁사 포함), 1980년부터 브랜드 신뢰성 조사, 충돌 별점.
- **자본시장**: IPO(3년 연속 흑자·자기자본 조건), 주가(PER×이익), 배당, 유상증자, 자사주 매입, 경쟁사 인수.

### 4. 유기적 경쟁 (`src/sim/rivals.js`)
경쟁사는 플레이어와 같은 엔진·차량 물리 모델로 실제 차를 설계(`src/sim/autodesign.js`)하고 같은 시장에서 경쟁합니다.
각 회사는 현금·생산능력·평판·수출망을 가지며 매년: 노후 모델 교체, 유망 세그먼트 진출, 전동화, 증설/감산, 수출 확대, 현지 공장 건설을 결정합니다.
초과 수요 시 가격 인상·증설, 적자 누적 시 매각 공고 → 다른 회사(또는 플레이어)가 인수, 아니면 청산. 신규 진입사(EV 스타트업 포함)가 시대별로 등장합니다.
기본 시드로 돌린 결과: 일본형 품질 메이커가 오일쇼크 이후 1위, 한국형 메이커 성장, 2003년 EV 스타트업이 2030년대 점유율 6%, 2015년 진입한 유럽 EV 스타트업은 적자로 피인수.

### 5. 인터페이스
엔지니어링 워크스테이션 구조: 작업공간 메뉴 / 프로젝트 탐색기 / 문서(스튜디오 뷰포트·표) / 속성 인스펙터 / 상태 표시줄(시간·현금·이벤트).

## 남은 것 (정직한 목록)
- 경쟁사는 플랫폼·트림을 따로 운용하지 않고 모델 단위로만 설계합니다.
- 공기역학은 형상 지표 기반 근사이며 패널법(포텐셜 유동) 계산이 아닙니다. 충돌은 점수 모델이며 FEM이 아닙니다.
- 서스펜션 하드포인트·Pacejka 타이어·랩타임, 3/4 뷰 렌더는 아직 없습니다.
- 지도 기반 딜러 입지, 캡티브 파이낸스(할부·리스), 환율, 모터스포츠, 광고 매체 믹스는 아직 없습니다.
- 플레이어 기준 1946→2035 장기 밸런스는 경쟁 경제만큼 다듬지 않았습니다.
