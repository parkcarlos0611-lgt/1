# 120 · 엔진을 단계별로 조립하며 개발하기 (검토)

> 2026-11-25. **검토만 했다. 구현하지 않았다.**
> - 사용자 제안: 엔진 개발에서 단계마다 부품이 하나씩 붙게 하면 실제로 만드는 느낌이 난다. 분해도도 이미 있으니 Automation 같은 느낌으로.
> - 근거: 엔진 공방(`ui/shell/engine.ts`), 엔진 받침대 모델(`render/car/powertrain/stand.ts`, 분해도 `exploded`, 부품 고르기 `pickPart`), 동력계 메시(`render/car/powertrain/*`).

## 1. 지금
- 엔진 공방은 계열·변형, 부품 품질, 다이노, 소리, 분해도, 절단 보기(피스톤·점화 순서), 보관함이 있다.
- 받침대 위 엔진은 **처음부터 완성된 모습**이다. 고른 값이 바뀌면 조금 뒤에 전체를 다시 짓는다.
- 분해도는 부품을 정해진 방향으로 펼친다. 부품마다 이름과 설명이 있다(`PART_INFO`).

## 2. 제안: 조립 단계 = 개발 단계
| 단계 | 정하는 것 | 화면에 붙는 부품 |
|---|---|---|
| ① 블록 | 배열(직렬·V·수평대향), 기통 수, 보어·행정(배기량), 블록 소재 | 빈 블록, 오일 팬 |
| ② 아래쪽 | 크랭크, 커넥팅 로드, 피스톤(단조·주조), 압축비 | 크랭크축, 피스톤과 로드(블록 위로 내려앉음) |
| ③ 헤드 | 밸브 수, 캠 방식(SOHC·DOHC), 가변 캠, 캠 프로필 | 헤드, 캠축, 캠 덮개 |
| ④ 흡기 | 자연흡기·터보(0~4)·과급기, 인터쿨러, 스로틀 | 흡기 매니폴드, 터보, 인터쿨러 관 |
| ⑤ 연료·점화 | 카뷰레터·분사, 점화 방식 | 연료 레일·인젝터, 점화 코일 |
| ⑥ 배기 | 매니폴드·헤더, 촉매, 머플러 | 배기 매니폴드, 관 |
| ⑦ 보조기기 | 알터네이터, 벨트, 냉각 펌프, 윤활 방식 | 풀리와 벨트, 펌프 |
| ⑧ 마무리 | 엔진 커버 디자인·색 | 커버 |
- **부품이 붙는 연출:** 새 단계의 부품이 분해도의 자리에서 날아와 제자리에 앉는다(0.4~0.6초, 분해도의 펼침 방향을 거꾸로 씀). 소리도 짧게 낸다(조임, 딸깍).
- **다이노는 단계가 갖춰질 때 열린다:** ③ 헤드까지 끝나면 처음 시동을 걸어 볼 수 있고, 뒤 단계가 끝날 때마다 출력 곡선이 늘고 바뀐다. "처음 시동" 순간을 작은 연출로 둔다.
- **언제든 앞 단계로 돌아갈 수 있다.** 돌아가서 바꾸면 그 뒤 부품이 잠깐 떨어졌다가 다시 붙는다.
- **이미 만든 엔진**(보관함, 순정 엔진)은 완성 상태로 열린다. "조립 다시 보기" 단추로 처음부터 볼 수 있다.
- 각 단계 화면은 G4의 부품 카드와 수치 막대를 쓴다. 단계 레일은 빌더처럼 왼쪽 아이콘 탭이다.

## 3. Automation과 비교
- 같은 점: 계열(블록·보어·행정)과 변형(아래쪽, 헤드, 흡기, 연료, 배기)을 나누어 정하는 흐름.
- 다른 점(우리 쪽 보탬): 정할 때마다 3D 받침대에서 부품이 실제로 조립된다. 분해도·절단 보기와 이어진다. 그래서 "설계표를 채운다"보다 "엔진을 만든다"에 가깝다.

## 4. 필요한 일
- 받침대 모델을 **단계별 부품 묶음**으로 나눈다. 분해도가 이미 부품을 나누고 있어 대부분 다시 쓴다.
- 단계 상태(어디까지 정했는지)를 엔진 설계에 저장한다. 옛 엔진은 "완성"으로 읽는다.
- 붙는 연출(경로 보간, 짧은 소리), 처음 시동 연출, 단계별 다이노 열림.
- 화면: 단계 레일, 단계별 선택 칸 정리(지금 공방의 선택지를 단계로 나눠 옮김).
- 차급 상한(C1)은 단계마다 그대로 적용한다(넘는 선택지는 잠그고 이유 표시).

## 5. 비용과 순서
- 약 15~25만 토큰(구조 위주, 부품 겉모습 다듬기는 따로).
- 엔진·부품 겉 디테일을 Automation급으로 올리는 일(STATUS 5절, 스타일 결정 필요)과 함께 하면 효과가 크다. 다만 그 결정 없이도 지금 외형으로 먼저 할 수 있다.

## 6. 검토받을 것
1. 단계 나누기(①~⑧)가 맞는지, 줄이거나 합칠 단계가 있는지
2. 다이노를 ③ 헤드 뒤 "처음 시동"부터 열지, 끝까지 조립한 뒤에만 열지
3. 붙는 연출의 길이와 소리
4. 순서: 언제 할지(제안: 운전석·운전자 계획(문서 118) 뒤, 크렘린 앞)
