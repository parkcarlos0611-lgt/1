# 검토 23 — 공통 하체(프레임·파워트레인·타이어), 물리로 움직이는 서스펜션, 실차 조사, 차량 제작 체계

기획자 지적(2026-11-19):
- 앞 범퍼가 허공에 떠 있다.
- 옆 휠하우스 그림자가 페인트통으로 부은 것 같고 잡티가 남아 있다.
- 앞·뒤에서 본 타이어와 파워트레인이 어색하고, 앞뒤 크기와 모양이 서로 다르다.
- 서스펜션과 엔진이 없다.

검토할 것:
1. 차급별 공통 하체와 타이어 모델
2. 물리엔진과 연결된 서스펜션
3. 실차 조사로 세부를 보완하는 방법
4. 이를 묶은 제작 체계

## 0. 바로 고친 것

- **앞 범퍼:** 프레임 끝(혼)과 범퍼 뒤 받침판을 넣어 차체에 붙였다(옆·앞 보기).
- **휠하우스:** 검은 그림자 덩어리를 없앴다. 대신 아치 안쪽 판을 개구부보다 조금 크게 그려 가장자리 틈(흰 점)이 생기지 않게 했다.

## 1. 왜 앞뒤가 어긋났나

지금은 보기마다 하체를 따로 손으로 그린다. 옆에서 쓴 타이어 폭, 차축 높이, 디퍼렌셜 크기를 앞·뒤 보기에서 다시 적으니 서로 맞을 이유가 없다. 차체는 원본에 맞추지만, 원본 시트의 하체는 생성 그림의 추정이라 맞출 기준도 못 된다.

**해결 원칙:** 하체는 보기마다 그리지 않는다. **한 번, 세 방향 치수(앞뒤 x, 좌우 y, 높이 z)로 정의하고 각 보기로 투영한다.** 이렇게 하면 앞·뒤·옆·위·아래가 구조상 어긋날 수 없다.

## 2. 공통 하체(롤링 섀시) 모델 — 타당하다

### 구성
하체 부품은 단순한 입체(막대, 원통, 상자, 판)라 세 방향 정의와 투영이 쉽다.

| 묶음 | 부품 |
|---|---|
| 프레임 | 세로 레일 2개, 가로 멤버, 앞뒤 혼, 범퍼 받침 |
| 앞 차축 | I빔 일체차축, 너클, 드럼, 타이로드, 드래그 링크 |
| 뒤 차축 | 일체 구동축, 디퍼렌셜 통, 드럼 |
| 스프링 | 판스프링(반타원·가로·4분타원), 섀클, 댐퍼(마찰식·레버식) |
| 파워트레인 | 엔진 블록·오일팬, 벨하우징, 변속기, 프로펠러 샤프트(또는 토크 튜브), 배기관·소음기, 연료 탱크, 라디에이터 |
| 타이어 | 아래 2-3 |

### 차급(공통 모델 6종 제안)
| 차급 | 축간 | 예 |
|---|---|---|
| 경차 | 1.9~2.4 m | 소형·초소형 |
| 대중차 | 2.5~2.8 m | 대중 세단·투어링 |
| 중형 | 2.8~3.2 m | 중형·상급 세단 |
| 대형·고급 | 3.2~3.9 m | 리무진, 고급 컨버터블 |
| 스포츠 | 낮은 프레임 | 로드스터, 경주차 |
| 상용·다목적 | 높은 프레임, 굵은 차축 | 1톤 트럭, 4륜구동 |

차마다 조정하는 값은 축간, 윤거, 프레임 높이, 타이어 규격, 엔진 길이(기통 수)뿐이다. 나머지는 차급 모델이 정한다. 이것이 요청하신 "크기만 조금 맞춰 쓰는 범용 모델"이다.

### 타이어 모델
- 단면 폭, 림 지름, 트레드 종류(세로 줄, 블록, 오프로드)로 정의한다. 당시 규격 표기(예: 4.75-19, 6.00-16)를 그대로 받는다.
- 옆면(원)과 정면(세운 타원형 단면)을 같은 단면과 같은 트레드 간격에서 그린다. 그래서 앞뒤 보기의 타이어 폭과 높이가 옆과 반드시 같다.
- 휠(림, 살, 캡)은 별도 부품으로 타이어 안에 끼운다.

### 근거와 비용
- 1차판에 하체 그리기(`legacy/game/chassdraw.mjs`)와 하체 수치(`legacy/sim/chassis.mjs`)가 있어 출발점이 있다.
- 추정: 투영 기반 도구 1회, 차급 모델 하나에 1~2시간.
- 한계: 옆 보기에서 하체는 대부분 차체에 가려 휠 아치와 문턱 아래로만 보인다. 품질 차이가 크게 드러나는 곳은 앞·뒤·아래 보기와 차체를 벗긴 섀시 화면(조립, 정비, 컷신)이다.

## 3. 물리와 연결된 서스펜션 — 타당하다, 단계로 나눈다

### 이미 있는 것
1차판 `legacy/sim/dyn.mjs`에 축약 다물체 모델이 있다.
- 차체: 상하, 롤, 피치
- 일체차축: 상하와 기울기
- 타이어, 구동계, 1kHz 고정 스텝

물리 계산은 옮겨 오면 된다. 없는 것은 **그 상태를 그림에 연결하는 부분**이다.

### 연결 방법
Z 방식은 모든 부품이 장착점을 가진 따로 선 모양이다. 그래서 실차처럼 묶을 수 있다.

| 물리 상태 | 그림에서 움직이는 것 |
|---|---|
| 차축 상하·기울기 | 차축, 드럼, 타이어가 함께 움직인다. 타이어는 땅에 닿아 있다 |
| 스프링 변위 | 판스프링의 휨(호의 높이)이 바뀌고 섀클이 흔들린다 |
| 차체 상하·피치(옆), 롤(앞뒤) | 프레임과 차체 전체가 움직인다 |
| 구동 | 프로펠러 샤프트 각도, 바퀴 회전 |
| 조향 | 앞바퀴 각도(앞·위 보기), 타이로드 |

### 시대에 맞는 형식(먼저 만들 순서)
1. 일체차축 + 반타원 판스프링 (앞뒤, 가장 흔함)
2. 가로 판스프링 (대중차 일부)
3. 4분타원 판스프링 (경차 일부)
4. 독립 앞 현가 (1934년 무렵부터, 뒤 시기)

구동은 토크 튜브와 개방형(호치키스) 두 가지다.

### 걸림돌
- **그리기 속도:** 지금 한 대 그리는 데 80~250ms라 매 프레임 다시 그릴 수 없다. 차체·프레임 묶음은 한 번 그려 두고 위치와 작은 기울기만 바꾼다. 스프링처럼 모양이 변하는 부품만 다시 그린다.
- **기울기:** 10mm/px에서 롤 3~5°를 픽셀 그림으로 돌리면 선이 깨진다. 작은 각도는 줄 단위 밀기로 처리하고, 큰 각도는 몇 단계 자세를 미리 그려 둔다.
- **이전 결정과의 관계:** "바퀴는 일단 고정"(검토 17)을 이 단계에서 푼다.

### 단계
1. 정지 자세: 짐과 승객 무게로 가라앉은 높이. 그림 한 장으로 끝나 싸다.
2. 느린 장면: 인도 컷신, 시험대.
3. 주행: 길거리, 시험 주행.

## 4. 실차 조사로 세부 보완 — 사실에는 효과가 있고, 모양에는 효과가 없다

| 효과 있음 (사실) | 효과 없음 |
|---|---|
| 치수(길이, 축간, 윤거, 높이, 무게) | 패널 곡선 같은 모양 자체 |
| 타이어 규격, 휠 종류 | 그림을 대신 그려 주는 것 |
| 엔진 배치와 기통 수, 현가 형식, 제동 형식 | |
| 특징(예비 바퀴 위치, 문 여는 방향, 루버 개수, 판매된 차체 종류와 색) | |

쓰임:
- 차급 모델과 수치를 정한다.
- 시트의 오류를 걸러낸다. 시트 하체는 추정 생성이라 바퀴가 6개인 것도 있었다.
- 게임 수치(무게, 성능)의 근거가 된다.

한계:
- 이 환경의 네트워크 정책이 일부 사이트(위키백과 등)를 막고 있었다. 조사를 하려면 허용 사이트를 정해야 한다.
- 제 기억으로 적는 값은 확신도(H/M/L)를 붙인다.
- 드문 차는 자료가 얇다.
- 가져오는 것은 사실뿐이고, 사진이나 도면은 쓰지 않는다.

**제안:** 차마다 "제원표" 한 장(값, 출처, 확신도). 1대 10분 안팎.

## 5. 종합: 차량 제작 체계 — 세울 수 있다

| 단계 | 내용 | 자동/손 |
|---|---|---|
| 0. 제원표 | 실차 조사로 치수, 타이어, 현가, 엔진, 특징을 적는다 | 손 (조사) |
| 1. 하체 | 차급 모델에 제원을 넣어 프레임, 파워트레인, 현가, 타이어를 다섯 방향 + 아래로 만든다 | 자동 |
| 2. 차체 부품 | Z 방식: 부품을 손으로 쓰고 원본 선에 맞춘다. 장착 기준은 하체가 준다 | 손 + 자동 맞춤 |
| 3. 자동 검사 | 아래 표 | 자동 |
| 4. 눈 검토 | 원본과 나란히, 다섯 방향 한 장 | 기획자 |
| 5. 물리 연결 | 장착점에 서스펜션 모델을 묶어 자세와 움직임을 준다 | 자동 |

자동 검사 항목(이번 지적을 기계가 먼저 잡도록):
| 검사 | 잡는 문제 |
|---|---|
| 연결 | 모든 부품이 지정된 부모 부품에 닿아 있는지 (떠 있는 범퍼) |
| 틈 | 차 안쪽에 배경이 비치는 픽셀이 없는지 (휠하우스의 점) |
| 보기 간 일치 | 같은 부품의 폭·높이·위치가 보기마다 같은지 (앞뒤 타이어) |
| 잡티 | 홀로 떨어진 픽셀이 없는지 |

### 제안 순서
1. 투영 기반 하체 도구와 타이어 모델. 상용·다목적 차급 하나를 만들어 이번 차에 끼운다. 자동 검사 4종도 함께.
2. 대중차 차급. 1920년대 시트를 받으면 그 첫 차에 쓴다.
3. 반타원 판스프링 현가를 물리와 묶어 정지 자세와 느린 장면까지.
4. 제원표 양식과 조사. 허용 사이트가 정해지는 대로.
5. 나머지 차급과 현가 형식, 주행.

차체도 같은 원칙(주요 단면 치수를 한 번 정하고 보기마다 공유)을 적용하면 앞·뒤·위 보기의 차체 치수 어긋남도 줄어든다. 하체에서 방식이 검증되면 차체로 넓힌다.

## 6. 정할 것
1. 하체를 세 방향으로 한 번 정의해 투영하는 공통 모델로 간다 (추천).
2. 차급 6종 구성이 맞는지, 먼저 만들 차급.
3. 서스펜션 물리 연결의 범위: 정지 자세와 느린 장면까지 먼저 (추천), 주행은 뒤.
4. 실차 조사: 허용할 사이트를 정하거나, 기억 + 확신도 표기로 먼저 시작.
5. 위 제안 순서대로 진행할지.
