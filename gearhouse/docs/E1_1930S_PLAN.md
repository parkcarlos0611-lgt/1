# E1 (1930년대) 제작 계획서 — 실차 복제 차량 · 게임용 차량 데이터 · 외장 프롭 100+

## 0. 요청 정리 & 결정 사항

| 요청 | 결정 |
|---|---|
| 휠이 너무 큼 | 당시 **타이어 규격 코드**(예: `4.75-19`)로 외경·림 지름을 계산해서 그린다. 실측 블루프린트와 대조한 결과 림 지름은 외경의 약 0.62~0.67이 맞는데, 이전 렌더는 0.76이라 휠이 커 보였다. |
| 실차 블루프린트 복제 + 디테일 강화 | 제공 블루프린트(측면·정면·후면·평면) + 웹 검색 제원으로 **형상과 제원을 실차대로 복제**한다. **상표명·엠블럼·마스코트·배지 문자는 전부 제거**하고, 게임 내 명칭은 일반명(예: "1930 4도어 타운 세단")을 쓴다. |
| 엔진·파워트레인·프레임까지 갖춘 게임용 차량 | 차량 = **VehicleDef**(플랫폼/프레임 + 서스펜션 + 엔진 + 변속·구동 + 바디 + 외장 부품 슬롯). X-ray 렌더로 프레임과 기계 부품을 보여준다. |
| 시대별 외장 프롭 100개 이상 | 1930년대 카탈로그 **31개 분류, 224종** (§5). 이후 시대도 같은 방식으로 Era당 100종 이상. |

> 법적 메모: 상표(이름·로고·마스코트)는 제거하더라도, 실차 외형을 그대로 복제하면 상업 출시 때 트레이드 드레스(디자인 권리) 문제가 생길 수 있다.
> 그래서 코드상 실차 복제본은 `replica` 플래그로 관리하고, 출시 전에 **비율 유지 + 세부 변형** 버전으로 바꿀 수 있게 만든다.

## 2. 타이어/휠 규격 시스템

- 입력: 바이어스 타이어 코드 `W-D` (W = 단면폭 in, D = 림 지름 in).
- 외경 `OD = (D + 2 × 0.98 × W) × 25.4 mm`, 림 시각 지름 = `D × 25.4 + 플랜지 24mm`.
- 렌더: 타이어 두께 = (OD − 림)/2. 휠 스타일(와이어/아틸러리/디스크/허브캡)은 림 안쪽에만 그린다.

| 코드 | 사용 시기 | 외경(mm) | 림(mm) |
|---|---|---|---|
| 4.50-21 | 1928–29 소형 | 757 | 533 |
| 4.75-19 | 1930–31 소형 | 719 | 483 |
| 5.25-18 | 1932–33 | 718 | 457 |
| 5.50-17 | 1934–36 | 706 | 432 |
| 6.00-16 | 1935–40 | 705 | 406 |
| 6.50-16 | 1936–40 중형 | 730 | 406 |
| 7.00-17 | 1930s 고급차 | 780 | 432 |
| 6.50-20 | 1920s말 대형 스포츠 | 832 | 508 |

## 3. 게임용 차량 데이터 구조 (VehicleDef)

```js
{
  id: 'v30_town_sedan', year: 1930, replica: true, name: '1930 4도어 타운 세단',
  platform: {                    // 여러 바디가 공유하는 플랫폼
    wheelbase: 2629, track: [1422, 1422], frame: { type: 'ladder_channel', depth: 100, kickupRear: 120, crossmembers: 4 },
    front: { type: 'beam_transverse_leaf' }, rear: { type: 'beam_transverse_leaf', axle: 'torque_tube' },
    brakes: 'mech_drum', steering: 'worm_sector', tire: '4.75-19', wheel: 'wire_30' },
  engine: { layout: 'inline', cyl: 4, bore: 98.4, stroke: 108, head: 'sv', fuel: 'carb1_updraft', cooling: 'thermo_pump', hp: 40, mount: 'front_long' },
  drivetrain: { layout: 'FR', gearbox: 'manual3_sliding', drive: 'torque_tube', diff: 'open' },
  fuel: { litres: 38, tank: 'cowl' },                 // 위치가 무게배분·안전 통계에 반영
  body: { silhouette: 'sil_E1_sedan4d_town', panel: 'steel_g2', paint: [...], parts: { headlamp: 'hl_drum_E1_a', grille: 'gr_shell_dip', ... } }
}
```

- **X-ray 렌더**: 바디는 외곽선만 남은 블루프린트 고스트로 그리고, 그 위에 프레임 레일(킥업 포함), 크로스멤버, 액슬·스프링, 엔진(모듈 조립), 변속기, 토크튜브/프로펠러 샤프트, 디퍼렌셜, 라디에이터, 연료탱크, 배기·머플러, 스티어링을 컬러로 그린다.
- 엔진·변속기·섀시 부품은 이미 만든 **모듈 생성기를 차량 스케일(25mm/px)로 재사용**한다.
- FF(전륜구동) 차량은 변속기를 엔진 앞(차축 앞)에 배치하고 구동축을 앞바퀴로 연결한다.
