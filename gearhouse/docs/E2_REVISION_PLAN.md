## A. 지적 사항 진단 & 수정 계획

### A-1. 창문 (민수·군용 공통)

| 진단 (현재 결과물) | 원인 | 수정 |
|---|---|---|
| 창이 모두 비슷한 둥근 사각형이라 "붙여 넣은" 느낌 | 창 형상을 차마다 손으로 둥근 사각형으로만 지정 | **창 시스템 v2**: 창마다 (앞 모서리 = A필러 각도, 위 모서리 = 루프선과 일정 간격, 뒤 모서리 = C필러·패스트백 곡선)를 루프·필러 선에서 **자동 유도** |
| 창 위쪽과 루프 사이 간격이 뒤로 갈수록 벌어짐 | 루프가 패스트백으로 내려가도 창 위변은 수평 | 창 위변을 루프 오프셋 곡선으로 (드립레일 폭 40~60mm 유지) |
| 필러가 얇고 일정함 | 필러 폭을 따로 정의하지 않음 | 시대별 필러 폭: A 70~90, B 90~120(1940s 4도어), C 패스트백은 넓은 쿼터 패널 |
| 1940년대 특징이 없음 | — | **삼각 환기창(벤트 윙)**: 1937년 이후 앞문 앞부분에 세로 분할선 + 별도 크롬 프레임 |
| 유리 질감이 진한 파랑, 실내가 비어 보임 | 유리 램프 채도 높음, 실내 실루엣이 거의 없음 | 유리 램프 채도 ↓(청회색), 위쪽 하늘 반사 → 아래쪽 어두운 실내. 시트 등받이·헤드레스트·스티어링 휠·대시 상단·반대편 창의 밝은 면이 비치게 |
| 창틀 재질이 한 가지 | — | 크롬 몰딩 / 차체색 리빌 / 고무 개스킷(트럭·군용) 3종을 차종별로 지정 |
| 군용 유리가 사선 줄무늬 | 군용 생성기가 별도 유리 처리를 씀 | **군용도 민수와 같은 시대 유리 질감** 사용 + 캔버스 창(셀룰로이드, 탁한 반투명) 추가 |

검증: 블루프린트 위에 창 외곽을 빨간 선으로 겹쳐 대조 (1930년대와 같은 방식).

### A-2. 픽업·트럭 적재함

| 진단 | 수정 (적재함 모듈 `bedgen`) |
|---|---|
| 픽업 적재함이 캡 높이의 빨간 상자 하나 | **스텝사이드 구조**: 캡보다 좁고 낮은 적재함 상자(상단 레일 + 스테이크 포켓 3~4개), 바깥으로 튀어나온 뒤펜더, 캡~뒤펜더 사이 러닝보드, 테일게이트 + 체인, 적재함 바닥 목재(측면에서 끝단 보임) |
| 트럭 짐칸이 프레임 위에 떠 보이고 판자만 있음 | **플랫폼 구조**: 길이 방향 실(sill) 2줄 + 가로 크로스실 → 바닥판 → 드롭사이드 판자(경첩·걸쇠) → 헤드보드(캡 뒤 보호판) → 스테이크 포켓, 흙받이(머드가드), 공구함, 스페어 캐리어 |
| 비율 | 레퍼런스 실측: 적재함 바닥 높이, 측판 높이(픽업 약 380mm, 트럭 약 500mm), 캡과의 간격 |
| 군용 화물 | 같은 모듈의 군용 변형: 강판/목재 측판, 접이 벤치(트룹 시트), 활대(bows) + 캔버스 |

### A-3. 군용 (비율·디자인·빈 구조·재질 명암) — 추가 자료 반영

**레퍼런스 갱신**: 4x4 치수 표기(전장 3327, 휠베이스 2032, 전폭 1575, 전고 1321/1829, 중량 1040kg) + 4x4 실내 평면도·섀시 상하면도·프레임 측면도 + 6x6 오픈캡·캔버스캡·장비 탑재 변형 + 6x6 4면도 3종.

| 진단 | 수정 |
|---|---|
| 4x4: 후드가 길고 낮아 차체가 길쭉함 | 치수 표기 도면으로 재측정: 후드 길이, 그릴~카울, 바퀴 지름/휠베이스(≈0.37), 터브 높이·측면 컷아웃 위치를 오버레이로 맞춤 |
| 4x4: 펜더·터브 형태 | 평평한 앞펜더(후드보다 약 150mm 낮음, 앞끝이 그릴면에서 꺾임), 뒤 바퀴 아치는 위가 평평한 사다리꼴 |
| 4x4: 구조가 비어 보임 | 실내 레이어 추가: 대시 패널(계기 4개), 앞시트 2 + 뒷시트(캔버스 쿠션), 변속·트랜스퍼 레버, 손잡이, 앞유리 프레임 + 유리 2장 + 와이퍼, 터브 안쪽 벽(측면 컷아웃으로 보이는 어두운 면), 시트 아래 연료탱크, 접이 탑 활대 |
| 6x6: 후드 앞이 낮고 펜더가 평평함 | 후드 높이·길이 재측정, 앞펜더는 민수형 곡면(단 무광 재질), 묵직한 C채널 범퍼 + 견인 고리, 윈치 옵션 |
| 6x6: 적재함 슬랫이 두껍고 규칙적 | 실측 판자 폭·간격, 스테이크 + 상단 레일, 트룹 시트, 활대 5개 |
| 6x6 변형 | **캡 2종**(밀폐 강판 / 오픈캡 + 캔버스 지붕), **적재 모듈**(화물·캔버스·컴프레서·로켓 발사대 등 장비)을 공통 섀시에 교체 장착 |
| 재질을 고려한 명암 | 군용 재질 4종 셰이더: **도장 강판**(무광: 면 단위 부드러운 수직 그라데이션 + 패널 모서리 하이라이트 + 모서리 도장 마모), **캔버스**(주름·처짐·봉제선·바랜 상단), **고무**(NDT 블록 + 사이드월 볼록), **목재**(판자 결·끝단 그림자). 유리는 민수와 공용 |

## B. 1940년대 파워트레인·엔진·프레임·섀시 + 완성 차체 결합 계획

### B-1. 목표
각 차량을 **차체 + 섀시 + 파워트레인이 맞물린 하나의 구조**로 만든다. 측면 X-ray(차체 유령선 + 컬러 기계부), 하부 평면 뷰, 엔진 디테일 스프라이트, 그리고 게임 데이터(VehicleDef)를 같은 좌표계로 정렬한다.

### B-2. 차량별 기계 구성 (1차 정리 — 자료로 검증 예정)
| 차량 | 프레임 | 앞/뒤 서스 | 엔진 | 변속·구동 |
|---|---|---|---|---|
| 1941 V8 고급 세단 | X멤버 래더 | 코일 독립 / 리프 빔 | L헤드 V8 346ci | 3단 칼럼 시프트 또는 4단 자동, 호치키스 |
| 1940 V12 컨티넨탈형 | 래더(차체 일부 일체) | 횡치 리프 빔 / 횡치 리프 | L헤드 V12 292ci | 3단 + 오버드라이브, 토크튜브 |
| 1942 4도어 세단·1940 쿠페·우디·픽업 | 래더(X멤버) | 횡치 리프 빔 / 횡치 리프 | 플랫헤드 V8 221/239ci (6기통 옵션) | 3단, 토크튜브 |
| 1946 소형 4도어 | **유니바디** | 독립(소형 트레일링/더보네) / 리프 | 직렬4 L헤드 약 1.1L | 3단 |
| 1940 3톤 트럭 | 채널 래더(중량) | 반타원 리프 빔 / 리프 빔 | 플랫헤드 V8 (트럭) | 4단 + 2단 디퍼렌셜 |
| 1/4톤 4x4 (군용) | 채널 래더 | 반타원 리프 + 구동 빔 액슬 앞뒤 | 직렬4 L헤드 134ci 60hp | 3단 + **2단 트랜스퍼(4x4)** |
| 2.5톤 6x6 (군용) | 중량 채널 래더 | 리프 빔 / **워킹빔 탠덤** | 직렬6 OHV 270ci | 5단 + 2단 트랜스퍼(6x6), 프로펠러 샤프트 3개 |

### B-3. 결합 방식
1. 섀시 기준점: 차축 위치·프레임 높이·엔진 크랭크 높이를 각 차체 실측값에 맞춤 (차체가 섀시에 "얹히는" 좌표 통일)
2. 엔진 모듈 생성기 확장: L헤드 V8(플랫헤드: 헤드 2개, 워터펌프 2개, 가운데 디스트리뷰터), V12, OHV 직렬6, 소형 직렬4 — 엔진룸 사진 기반 디테일 (5mm/px) + 차량 축척 버전
3. 구동계: 토크튜브 / 호치키스 / 4x4·6x6 트랜스퍼 + 프로펠러 샤프트 다중
4. 출력: 측면 X-ray, 하부 평면 뷰, 차체 + 섀시 분해도(차체를 위로 띄운 익스플로드 뷰), VehicleDef 데이터
5. 검증: 제공 도면(4x4 섀시 상하면도·프레임 측면도 등)에 오버레이

### B-4. 자료 제공 요청 (B 진행에 필요)
| 우선 | 자료 |
|---|---|
| ★★★ | **엔진룸 사진**: 플랫헤드 V8(221/239), 캐딜락급 L헤드 V8, V12, OHV 직렬6(트럭·6x6), 소형 직렬4, 4x4용 직렬4 |
| ★★★ | **섀시·프레임 도면 또는 사진**: X멤버 래더(승용), 트럭 채널 프레임, 6x6 섀시(워킹빔 탠덤·트랜스퍼), 유니바디 소형차 하부 |
| ★★ | **팬텀(투시) 단면도·카탈로그 컷어웨이**: 1940년대 승용차·트럭 (엔진·변속기·구동축 배치를 한 장에서 확인) |
| ★★ | 변속기·트랜스퍼 케이스·디퍼렌셜 사진(특히 4x4·6x6) |
| ★ | 서비스 매뉴얼의 섀시 윤활도·배치도 (부품 위치 확인용) |
(4x4는 이번에 받은 섀시 상하면도·프레임 측면도로 바로 시작 가능)

## C. 진행 순서 (승인 후)
1. A-1 창 시스템 v2 → 민수 8종 + 군용 재적용, 오버레이 검증
2. A-2 적재함 모듈 → 픽업·트럭·6x6
3. A-3 군용 v2 (재측정, 실내·레이어, 재질 셰이더, 변형)
4. B 섀시·파워트레인 결합 (4x4 → 6x6 → 승용 순, 자료 도착 순서에 맞춤)
5. 보고 → 1940년대 프롭 배치 → 조립 테스트
