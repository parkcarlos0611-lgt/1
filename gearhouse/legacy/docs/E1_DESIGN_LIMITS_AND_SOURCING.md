# E1 디자인 언어 제한 & 자료 수급 보고서

## Part A. 박스형 / 유선형 선택 + 시대 한계 + 비율 강제

구현: `tools/pixel/gen/bodygen.mjs` (`limits()`, `clampParams()`, `genBody()`), 데모 `samples/e1_design_language_x3.png`.

### A-1. 플레이어 입력

| 입력 | 형식 | 설명 |
|---|---|---|
| 디자인 언어 | `box` / `stream` | 박스형(업라이트) / 유선형 |
| 차종 | sedan4d, coupe2d … | 캐빈 길이·창 수·도어 수 결정 |
| 휠베이스·타이어 | 플랫폼에서 상속 | 타이어 규격 코드로 바퀴 크기 확정 |
| 슬라이더 | 0~1 | 전고, 후드 길이, 벨트라인, 노즈 돌출, 앞유리 경사, 루프 곡률, 노즈 곡률, 차체 곡률 |
| 선택지 | 목록 | 꼬리 형태(업라이트/트렁크/버슬/패스트백), 펜더(분리/밸런스/폰툰/스커트), 그릴(평면/V/폭포/루버) |

슬라이더 0~1은 **그 해 · 그 디자인 언어가 허용하는 범위**에 매핑된다. 범위 밖 값을 넣어도 경계값으로 잘리고(clamp), UI에 이유가 빨간 글씨로 표시된다.

### A-2. 연도별 한계 (주요 연도 사이는 선형 보간)

| 항목 | 박스 1930 | 박스 1935 | 박스 1939 | 유선 1933 | 유선 1936 | 유선 1939 |
|---|---|---|---|---|---|---|
| 앞유리 경사(°) | 0–6 | 0–14 | 6–22 | 14–26 | 20–36 | 24–42 |
| 루프 모서리 R(mm) | 60–220 | 100–320 | 160–420 | 200–420 | 260–520 | 300–600 |
| 노즈 R | 20–60 | 40–160 | 80–260 | 120–300 | 160–380 | 200–460 |
| 차체 R | 40–160 | 80–260 | 120–340 | 160–360 | 220–460 | 260–520 |
| 전고/WB | 0.60–0.67 | 0.55–0.63 | 0.52–0.60 | 0.50–0.58 | 0.46–0.55 | 0.45–0.53 |
| 후드/WB | 0.38–0.48 | 0.38–0.52 | 0.40–0.55 | 0.40–0.50 | 0.42–0.52 | 0.42–0.55 |
| 꼬리 | 업라이트, 트렁크 | +버슬 | 트렁크, 버슬 | 패스트백, 버슬 | 동일 | 동일 |
| 펜더 | 분리 | 분리, 밸런스 | 밸런스, 폰툰(앞) | 밸런스, 폰툰 | 폰툰, 스커트 | 폰툰, 스커트 |
| 그릴 | 평면 | 평면, V | V, 폭포 | V, 폭포 | 폭포, 루버 | 폭포, 루버 |

- **유선형은 1933년 이전에는 선택할 수 없다** (요청하면 박스형으로 바꾸고 이유를 표시).
- 근거: 레퍼런스 실측(REFERENCE_ANALYSIS.md) + 당시 기술 제약. 딥드로잉 프레스(일체형 스틸 루프는 1935년 이후), 평판 유리만 존재(경사가 크면 V 분할 유리), 노즈·펜더 곡률은 프레스 성형 한계를 따른다.
- **연구 연동(게임 규칙)**: "프레스 성형" 등의 기술을 연구하면 한계가 최대 1~2년 앞당겨진다. 시대를 앞서면 디자인 점수 보너스, 대신 생산비와 신뢰성 페널티.

### A-3. 스타일과 무관한 공학 규칙 (항상 강제)

| 규칙 | 값 |
|---|---|
| 좌석 쿠션 위 루프까지 최소 높이 | 1000mm |
| 타이어와 펜더 최소 간격 | 45mm |
| 차체 하단 최저 지상고 | 180mm |
| 평판 유리 최대 경사 | 42° (28° 이상이면 V 분할) |
| 캐빈 길이 | 차종별 고정값, 뒤차축 + 200mm를 넘지 않게 |

### A-4. 데모 결과 요약

- 1931 박스형 / 1931 유선형 요청 → 박스형으로 대체 (`STREAM NOT AVAILABLE IN 1931`)
- 1935 박스형(밸런스 펜더·트렁크) vs 1935 유선형(폰툰·패스트백, V 그릴은 1935년에 불가 → 폭포형)
- 1939 박스형(폰툰 앞펜더) vs 1939 유선형(스커트·루버 그릴)
- 1939 슬라이더 극단값(전부 −5 / 전부 +9) → 둘 다 그 해 정상 범위 안의 차로 나옴
- 1935 박스형 + 스커트 + 패스트백 요청 → 허용 목록 밖이라 업라이트·분리 펜더로 대체

## Part B. 청사진을 매번 제공받아야 하나, 직접 찾아 만들 수 있나?

### B-1. 결론

**시대별로 모든 청사진을 제공하실 필요는 없습니다.** 제가 직접 검색해서 자료를 모으고, 측정·생성·오버레이 검수까지 할 수 있습니다.
다만 아래 경우에는 직접 제공해 주시는 편이 빠르고 정확합니다.
1. 꼭 넣고 싶은 특정 모델이 있을 때
2. 공개 자료가 적은 지역·차종 (1930년대 소련·체코·일본 등)
3. 블루프린트 판매 사이트나 서적의 고품질 4면도 (제가 받아 올 수 없거나 재배포가 안 되는 자료)

### B-2. 이번에 실제로 해 본 테스트

| 테스트 | 결과 |
|---|---|
| 제원 웹 검색 (휠베이스, 전장, 타이어, 엔진, 변속기, 서스펜션) | 성공. 4종 교차 확인 (출처 불일치는 블루프린트 실측으로 보정) |
| 미국 디자인 특허 도면 다운로드 | 성공. **1934년 자동차 디자인 특허 Des. 93,451 원본 도면(2320×3408)** 확보 |
| 네트워크 | 처음에는 차단 → 환경 허용 목록에 4개 호스트 추가 후 성공: patents.google.com, patentimages.storage.googleapis.com, upload.wikimedia.org, commons.wikimedia.org |

### B-3. 자료 종류별 수급 방법

| 필요한 자료 | 직접 수급 | 출처 | 비고 |
|---|---|---|---|
| 차량 제원 | ✅ | 웹 검색 (위키, 제조사 아카이브, 박물관, 클래식카 DB) | 2개 이상 교차 확인 |
| 차량 외형 (측·정·후·평면) | ✅ 부분 | **미국 디자인 특허(퍼블릭 도메인)**, Wikimedia Commons | 특허 도면은 투시도인 경우가 많아, 제원(WB·전장·전고)으로 정사영 비율을 보정. 4면도는 일부만 있음 |
| 부품 외형 (램프·그릴·범퍼·마스코트·휠) | ✅ | 부품 디자인 특허, 사진 | 1930년대 램프·그릴 특허가 많음 |
| 엔진·변속기·서스펜션 구조 | ✅ | 유틸리티 특허 단면도, 기술 문헌 | 화면에는 **모듈 생성기**로 그리므로 차량별 도면은 불필요. 시대별 형식 카탈로그(배열, 밸브 형식, 보어·스트로크 범위)만 있으면 됨 |
| 세그먼트별 대표 차종 선정 | ✅ | 판매·역사 자료 | 아래 B-4 |
| 블루프린트 사이트·서적 스캔 | ⚠️ | 사용자 제공 | 측정 참고용으로만 쓰고 저장소에는 넣지 않음 |

### B-5. 한계와 주의점

- 이미지 측정 오차는 약 ±2~3%입니다. 투시도뿐인 자료는 오차가 더 커서 제원 수치로 보정합니다.
- 허용 목록에 없는 사이트는 막혀 있습니다. 새 출처가 필요하면 호스트 추가를 다시 요청드립니다.
- 저작권: 미국 특허 도면과 퍼블릭 도메인 사진만 저장소에 참조 정보로 남기고, 블루프린트 판매 사이트나 서적 이미지는 측정에만 씁니다.
- 실차 외형 복제는 상업 출시 시 트레이드 드레스 위험이 있습니다 (`replica` 플래그로 관리, E1_1930S_PLAN 참고).

### B-6. 제안 작업 흐름 (시대마다 반복)

1. 세그먼트별 대표 차종 목록 → 사용자 확인
2. 제원 검색 + 특허·퍼블릭 도메인 도면 수집
3. 측정 → 비율 규칙과 연도별 한계표 갱신
4. 복제 차량 생성 + 블루프린트 오버레이 검수
5. 사용자 승인
