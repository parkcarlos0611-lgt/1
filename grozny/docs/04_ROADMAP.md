# 04. 로드맵과 Claude Code 작업 티켓

각 티켓은 **Claude Code 한 세션 분량**이고 **완료 기준**이 있다. 순서대로 진행한다.

## M0. 프로젝트 기반 (1주)
| # | 티켓 | 완료 기준 |
|---|---|---|
| T01 | Vite + TS(strict) + Vitest + Playwright 세팅, `npm run dev/test/e2e` | 세 명령이 모두 통과 |
| T02 | `sim/` 고정 틱 루프, 시드 난수, Command 큐 | 같은 시드 + 같은 입력 → 같은 상태 해시 (테스트) |
| T03 | JSON 데이터 로더 + 스키마 검증 (`data/weapons.json`, `wounds.json`) | 잘못된 JSON이면 테스트 실패 |

## M1. 프로토타입: "한 발에 죽는 긴장감" 검증 (4~6주)
| # | 티켓 | 완료 기준 |
|---|---|---|
| T04 | 타일 월드 (층, 벽 재질, 문, 창문) + 테스트 맵 1개 (아파트 1동 3층) | sim 테스트: 벽·문 충돌 |
| T05 | Three.js 쿼터뷰 렌더 (정사영, 4방향 회전), 박스 지오메트리 | 스크린샷 `docs/shots/t05.png` |
| T06 | 플레이어 이동, 자세(서기/앉기/엎드림), 마우스 조준 | e2e: 키 입력 후 좌표 변화 |
| T07 | 시야 원뿔 + 벽 차단 + 화면 마스크 | 단위 테스트(벽 뒤 안 보임) + 스크린샷 |
| T08 | 건물 컷어웨이 (현재 층보다 위 숨김, 앞벽 반투명) | 스크린샷 비교 |
| T09 | 사격: 투사체, 확산, 벽 관통 | simrun: 재질별 관통률 통계 출력 |
| T10 | 부상 시스템 v1: 부위·출혈·혈액량·사망 | 단위 테스트(동맥 손상 → 2분 내 사망) |
| T11 | 의료 아이템: 지혈대, 붕대, 프로메돌 | 단위 테스트 |
| T12 | 적 AI v1: 순찰 → 소리 감지 → 교전 → 엄폐 | simrun: 1:1 교전 1000회 승률 출력 |
| T13 | 소리 시스템 + 방향 표시 UI | e2e 스크린샷 |
| T14 | HUD v1: 부상 실루엣, 탄약, 공포 (숫자 없이 시각 표현) | 스크린샷 |
| **검증** | **사람이 직접 10판 플레이 → 긴장감·재미 평가 메모** | `docs/playtest/m1.md` |

## M2. 버티컬 슬라이스: 챕터 1의 한 구역 (3~4개월)
- 분대원 3명 + 일시정지 명령 시스템
- 심리 시스템 (공포, 피로)
- 기차역 일대 맵 1개 (수작업), 야간, 포격 이벤트
- 민간인 조우 이벤트 3개 (지하실)
- 거점 화면 (하루 단위, 자원, 대원 카드, 사망자 기록)
- 사운드 1차, 아트 1차 (박스 → 저폴리곤 모델)
- **성능 측정 → 엔진 재검토 판단** (02_TECH.md 5절)

## M3. 얼리 액세스 (+6~12개월)
