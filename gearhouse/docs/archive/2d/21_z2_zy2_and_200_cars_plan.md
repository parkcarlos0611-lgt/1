# 검토 21 — Z2와 ZY2 비교, 200대 작업량과 계획

기획자 지시(2026-11-19): Z 방식을 강화하는 쪽을 검토하고, ZY에 개선안을 넣은 ZY2를 만들어 둘을 비교한 뒤, 작업량을 재고 계획을 세운다.

## 1. 두 방식

공통 바탕은 같다.
- 요소 구조: 후드, 카울, 문, 문턱, 뒤 차체, 트렁크, 지붕, 펜더, 부품. 각 요소는 mm 단위의 온전한 모양이다.
- 원본에서 읽은 세부: 재질과 명암 단계.
- 색은 원본 색이 아니라 **게임 팔레트의 단계**다.

차이는 세부를 담는 그릇이다.

| | ZY2 | Z2 |
|---|---|---|
| 세부를 담는 방식 | 요소마다 칸(10mm 격자), 칸마다 재질과 명암 단계 | 요소마다 영역(재질·단계가 같은 덩어리)의 외곽선, mm 단위 |
| 원본 픽셀 저장 | 없음. 게임 팔레트 단계로 바뀐 칸만 | 없음. 모양만 |
| 크기를 바꿔 그릴 때 | 칸을 늘려 찍는다 | 외곽선을 새로 그린다 |
| 만드는 법 | `capture.py` → `skin.py --common --fill --clean` | 같은 skin에서 `decals.py` 한 번 더 |

ZY2에 넣은 개선(검토 20 이후 제안 2·3·4·8번):
- **공통 팔레트:** 원본의 각 명암을 밝기가 가장 가까운 게임 단계로 옮긴다. 모든 차가 같은 크롬·유리·고무 색을 쓰고, 어떤 도장색이든 받는다.
- **가려진 부분 채우기:** 칠은 보이는 명암을 매끄럽게 이어서 채우고(Telea 보간), 나머지 재질은 가장 가까운 칸으로 채운다. 스커트나 펜더에 가려진 바퀴는 잘 보이는 쪽 바퀴의 세부를 받는다.
- **정리:** 이웃 넷과 모두 다른 칸은 이웃의 다수값으로 바꾼다.
- **휠캡 로고 제거:** 캡 안의 글자와 배지는 주변 크롬으로 덮고, 둥근 빛만 남긴다.

캡처도 함께 고쳤다.
- 채도가 낮은 도장(베이지)에서 크롬 배기관이 칠로 분류되던 문제.
- 바퀴 아치 안이 칠로 번지던 문제.
- 두 번째 색(가죽 등)이 차체색으로 덮이던 문제.

## 2. 세 견본 결과

색 차이는 원본 대비 0~255 평균이다. 공통 팔레트로 옮긴 만큼 ZY(6.2)보다 커지는 것이 정상이다.

| 차 | ZY2 색 차이 | Z2 색 차이 | 색 수 (ZY2 / Z2) | 홀로 떨어진 픽셀 | 저장 (gzip) |
|---|---|---|---|---|---|
| 세단 1936 | 11.1 | 11.2 | 32 / 30 | 1.1% / 0.6% | 15 KB / 47 KB |
| 스피드스터 1935 | 17.5 | 17.7 | 41 / 40 | 0.7% / 0.7% | 13 KB / 37 KB |
| 픽업 1948 | 13.4 | 13.5 | 37 / 37 | 0.6% / 0.5% | 13 KB / 41 KB |

참고로 원본을 같은 크기로 줄이면 색 수 22,604, 홀로 떨어진 픽셀 84.5%다. 이전 방식은 Y 5.6, ZY 6.2, Z 24.4였다.

변형 7가지를 세 차 모두에 적용했다. 두 방식 모두 통과했다.

| 변형 | 결과 |
|---|---|
| 원본대로 | 둘 다 정상 |
| 길이 +465mm | 둘 다 정상 |
| 색 변경 | 둘 다 정상 |
| 다른 차의 전조등·휠을 세부째 교체 | 둘 다 정상. 교체 부품도 같은 화풍 |
| 요소 분해 | 둘 다 구멍 없음. 가려졌던 칠은 매끄럽게 이어짐 |
| 7mm/px (크게) | 둘 다 정상 |
| 15mm/px (작게) | 둘 다 정상 |

**결론:** 눈으로 보면 ZY2와 Z2는 거의 같다.
- ZY2가 나은 점: 파일이 3배 작고, 만들기가 한 단계 짧고, 테두리 빈틈 같은 사고가 적다.
- Z2가 나은 점: 원본에서 온 것이 모양뿐이라는 점이 더 분명하고, 사람이 벡터 도구로 고치기 쉽다.
- Z2는 ZY2에서 0.4초 만에 자동으로 만들 수 있다.

**추천:** 원본 데이터는 **ZY2**로 둔다. Z2는 크게 그려야 할 때나 사람이 손볼 때 그 자리에서 만들어 쓴다.

남은 결함(견본 3대):
- 스피드스터 배기관 모양이 원본과 조금 다르다. 손으로 쓴 차체의 관 위치 문제다.
- 스피드스터 가죽색이 원본보다 어둡다.
- 픽업 적재함 난간 끝이 조금 튀어나온다.
- 세단 휠 림의 녹색이 고무로 분류된다. 어두운 도장의 채도 기준 문제다.
- 차를 늘리면 문손잡이 같은 작은 세부도 같이 늘어난다(개선 5번, 미착수).

## 3. 작업량 측정

견본 3대에서 잰 값이다. 시간은 이 세션의 작업 시간(커밋 시각 기준)이고, 기획자가 확인하는 시간은 빠져 있다.

| 단계 | 사람 손 | 세단 / 스피드스터 / 픽업 | 차 1대 시간 |
|---|---|---|---|
| 1. 시트에서 옆모습 잘라내기 (`trace.py`) | 없음 | 자동 | 수 초 |
| 2. 차체 직접 쓰기 (패널, 펜더, 유리, 부품, 선) | 있음 | 61 / 45 / 46줄 | 약 15분 (3대에 약 50분) |
| 3. 맞춤 목록과 자르는 선 | 있음 | 39(교정 포함) / 9 / 12줄 | 5분 |
| 4. 캡처 → 스킨 → (데칼) | 없음 | 1대 2초 미만 | 수 초 |
| 5. 결과 확인과 교정 (부품 모양, 층 순서) | 있음 | 차마다 0~4건 | 5~10분 |
| 합계 | | | **25~30분** |

- 198대를 지금 방식으로 하면 약 80~100시간이다.
- 저장 용량은 옆모습 198대 기준 약 3MB(gzip)다.
- 가장 큰 비용은 2번(차체 직접 쓰기)이다. 3번의 자르는 선도 차마다 손이 간다. 4번은 무시할 만하다.

## 4. 줄이는 방법: 차종 틀

카탈로그 198대의 차종은 약 70가지로 적혀 있지만, 차체 모양으로 묶으면 10가지 안팎이다.

| 틀 | 해당 (예) | 대략 대수 |
|---|---|---|
| 세단 (2·4도어) | popular / mid / small / upper sedan, saloon, taxi | 약 60 |
| 쿠페·패스트백 | coupe, fastback, business coupe | 약 20 |
| 유선형 | streamlined sedan / luxury | 약 10 |
| 로드스터·컨버터블 | sports, light sports, convertible, roadster, tourer | 약 35 |
| 경주차 (바퀴 노출) | grand prix, sports racer, single-seat, record | 약 20 |
| 소형·초소형 | small car, microcar, 삼륜 | 약 30 |
| 리무진 | limousine, luxury saloon | 약 10 |
| 상용·다목적 | pickup, wagon, van, utility 4x4, 삼륜 화물 | 약 10 |

틀마다 할 일:
- 패널 구성, 자르는 선, 부품 자리를 한 번만 정한다.
- 차마다 바퀴 위치와 높이로 틀을 먼저 늘린다(`edit.ts`의 비례 변경과 같은 원리).
- 그다음 원본 선에 맞춘다(`zkit.fit_closed`, 맞춤 범위를 지금보다 넓게).

예상: 차 1대 10~15분, 198대 약 35~50시간. 틀 8개 만드는 데 약 4~6시간. 이 숫자는 아직 추정이라, 아래 2단계의 시험 묶음에서 실제로 잰다.

## 5. 계획

| 단계 | 내용 | 예상 |
|---|---|---|
| 1 | ZY2를 원본 형식으로 확정, 남은 결함 정리, 늘릴 때 작은 세부 보존 | 1회 |
| 2 | 차종 틀 2개(세단, 로드스터)와 일괄 실행기, 확인용 모음 페이지. 슬라이스 차 10대로 시험해 **실제 1대 시간을 잰다** | 1~2회 |
| 3 | 나머지 틀. 1930년대 약 90대를 20대씩 묶어 진행, 묶음마다 확인 페이지를 받아 수정 | 3~5회 |
| 4 | 1940년대 약 98대, 같은 방식 | 3~5회 |
| 5 | 정면·후면·위 보기: 차체 껍데기로 쓰는 차만 (같은 ZY2 방식, 보기마다 틀) | 껍데기 수에 따라 |
| 6 | 게임 연결: 역할(껍데기 / 경쟁 모델 / 도로 차), 제조사별 스타일, 무작위 생성(부품 교체) | 1~2회 |

## 6. 정할 것

1. 원본 형식: ZY2(추천) 또는 Z2.
2. 진행 방식: 차종 틀을 먼저 만든다(추천) 또는 지금처럼 차마다 직접 쓴다.
3. 네 방향을 다 만드는 차의 범위: 차체 껍데기로 쓰는 차만(추천) 또는 전부. 껍데기로 쓸 차의 수.
4. 확인 방식: 20대씩 모음 페이지로 확인(추천) 또는 다른 단위.
