# 검토 19 — 정면도와 후면도

기획자 지시(2026-11-19)에 대한 검토다. 적용한 것은 없다. 맨 끝의 결정 사항에 답을 받으면 시작한다.

지시: 정면과 후면도 차종과 치수에 맞추어 만드는 것을 검토한다.

## 1. 어디에 쓰나

| 장면 | 쓰는 그림 |
|---|---|
| 배달 컷신 도착, 손님이 찾으러 옴 | 정면 |
| 공방 앞에 선 차, 품평회 줄 | 정면, 비스듬히 선 측면 |
| 떠나는 손님, 드래그 레이스 출발선 뒤 | 후면 |
| 카탈로그, 잡지, 설계 화면의 3면도 | 측면 + 정면 + 후면 |
| 탑뷰 주행(뒤 단계) | 평면과 높이별 단면. 정면·후면의 폭 윤곽이 바탕이 된다 |

## 2. 데이터: 한 설계에서 세 그림

차 한 대의 데이터에 정면·후면을 더한다. 측면과 따로 노는 그림이 아니라 같은 치수를 나눠 쓴다.

| 정면·후면이 측면에서 가져오는 것 | 정면·후면이 따로 갖는 것 |
|---|---|
| 지붕, 허리선, 보닛 위, 펜더 등성이, 범퍼, 전조등·미등의 높이 | 전폭, 윤거, 차체 단면의 폭(지붕 폭, 허리 폭, 보닛 폭) |
| 바퀴 반지름, 타이어 폭 | 펜더가 차체 밖으로 나온 정도 |
| 칠 색, 낡음, 부품 형식 | 앞유리·뒷창의 모양, 그릴 면의 모양 |

- 정면과 후면은 좌우가 같으므로 반쪽 윤곽만 적고 뒤집어 붙인다(1차 판 `front.mjs`의 방식).
- 단면 몇 개로 이룬다: 객실 단면(지붕과 옆창이 안으로 기우는 정도), 보닛 단면, 펜더 단면(보닛 옆의 둥근 덩어리), 발판, 바퀴.
- 플레이어가 비례를 고치면: 차폭과 높이를 바꾸는 편집은 정면·후면에도 들어가고, 길이를 바꾸는 편집은 들어가지 않는다.

## 3. 치수와 차종

| 값 | 어디서 |
|---|---|
| 전폭 | 참고 차 목록표의 제원(아직 확인 전). 없으면 차급의 기준 축간거리에서 정한다(1차 판 `dims.mjs`: 축간거리 2,300 mm에서 약 1,450 mm, 3,900 mm에서 약 2,070 mm) |
| 윤거 | 전폭 − 약 290 mm(1차 판 규칙), 차종마다 조정 |
| 전고, 각 높이 | 측면 데이터 |
| 모양 | 참고 시트의 정면·후면을 같은 방법(격자 실측, 분석 도구)으로 잰다. 시트의 정면·후면은 측면과 배율이 달라서, 측면의 높이에 맞춰 배율을 정한 뒤 잰다 |

차종마다 다른 점(목록표의 차종 구분):

| 차종 | 정면의 특징 |
|---|---|
| 대중 세단·쿠페 | 좁은 그릴, 떨어진 펜더, 높은 객실 |
| 고급 세단·리무진 | 넓고 높은 그릴, 큰 전조등, 넓은 차폭 |
| 스포츠·로드스터 | 낮고 좁은 객실(없음), 낮은 앞창, 넓은 윤거에 비해 좁은 차체 |
| 픽업·상용 | 높은 차체, 좁은 객실과 넓은 짐칸(후면), 큰 바퀴 |
| 유선형 | 펜더와 차체가 하나로 이어진 넓은 덩어리 |

## 4. 부품 라이브러리에 정면·후면 형식 더하기

| 부품 | 측면 형식(있음) | 정면·후면 형식(더할 것) |
|---|---|---|
| 그릴 | 띠(옆에서 본 그릴) | 그릴 면: 방패형, 폭포형(세로 살), 하트형, V형, 가로 살 / 살의 수와 간격 |
| 전조등 | 포드, 탄환, 매립 | 둥근 렌즈와 테, 받침대, 매립 고리 |
| 범퍼 | 막대 끝, 가드 | 차폭에 걸친 막대, 가드 두 개의 자리, 번호판 받침 |
| 미등 | 받침대 위, 매립 | 둥근 렌즈, 번호판 등 |
| 바퀴 | 바퀴와 휠캡 | 앞에서 본 타이어(둥근 모서리의 세로 띠), 휠 안쪽 |
| 예비 바퀴 | — | 뒤에 단 예비 바퀴(덮개, 끈) |

부품의 세 형식은 같은 값(지름, 높이, 살 간격)을 나눠 쓴다. 측면에서 고른 전조등이 정면에서도 같은 전조등이 된다.

## 5. 그리기

- A 방식 그대로: 7단계 칠, 외곽선, 반사띠, 겹침 그림자.
- 정면은 빛이 위에서 온다. 좌우로 밝기가 같고 위가 밝다(1차 판 정면 음영). 둥근 덩어리(펜더, 전조등, 지붕)는 가운데가 밝고 가장자리가 어둡다.
- 축척은 측면과 같다(10 mm/px). 정면 한 장은 폭 약 150~200px, 높이 약 150~200px이다.

## 6. 품

- 그리기: 정면 단면 그리기와 정면·후면 부품 형식. 한 번 만드는 일이다.
- 차 한 대: 반쪽 윤곽 단면 4~6개와 부품 자리. 측면 작성의 절반 정도가 더 든다.
- 견본 3종으로 먼저 하고, 시트의 정면·후면과 겹쳐 오차를 잰다.

## 7. 결정이 필요한 것

1. 한 설계에서 측면·정면·후면을 함께 만드는 방식(반쪽 윤곽 단면 + 부품의 세 형식)으로 갈지. (추천: 그렇게)
2. 전폭은 목록표 제원을 쓰고, 없으면 차급 규칙으로 정할지. (추천: 그렇게. 제원 확인은 따로)
3. 후면도 모든 차에 만들지, 장면에 필요한 차종부터 만들지. (추천: 견본 3종은 모두, 그 뒤는 정면 먼저)
4. 순서: 측면 디테일(부품 라이브러리 마무리, 분석 도구, 부품 단위 맞추기) 다음에 할지, 함께 할지. (추천: 다음에. 부품의 측면 형식이 자리 잡은 뒤에 정면 형식을 더하는 것이 덜 꼬인다)

## 8. 결정 (2026-11-19)
