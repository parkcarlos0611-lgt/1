# 1940년대 레퍼런스 분석 & 제작 1차 (E2)

입력: 사용자 제공 20장 (고급 세단·쿠페 5, 중형 4, 소형 2, 픽업 2, 트럭 3, 우디 웨건 2, 군용 지프 2, 군용 6x6 1) + 웹 제원 검색.
모든 차량은 상표·엠블럼·문자를 제거한 일반명으로 제작한다.

## 2. 군용차 모델링 원칙 (민수용과 분리, `gen/military.mjs`)

| 항목 | 민수 (`buildCar`) | 군용 (`buildMil`) |
|---|---|---|
| 형상 단위 | 스플라인·필렛 곡면 차체 | **평면 패널 조립** (패널마다 고정 명도, 모서리 R 거의 없음) |
| 음영 | 그라데이션 + 수평선 반사 띠 + 크롬 | **무광**: 면 고정 명도, 위 모서리 1px 베벨, 아래 모서리 어둡게, 리벳 열 |
| 팔레트 | 시대 도색 (최대 명도 사용) | 올리브 드랩 전용 램프(명도 범위 압축, 흰 하이라이트 없음), 캔버스 OD |
| 크롬 | 범퍼·그릴·트림 | 없음 (도장 철제) |
| 하부 | 대부분 차체에 가려짐 | **노출**: 프레임, 판스프링, 디퍼렌셜, 트랜스퍼 케이스, 워킹빔 |
| 타이어·휠 | 화이트월, 허브캡 | **NDT 블록 트레드**(실루엣까지 요철), 분할 림 + 러그 너트 |
| 부속 | 장식 | 등화관제 램프, 견인 고리·핀틀 훅, 연료통, 삽·도끼, 스페어 |
| 표식 | 엠블럼(일반 문양) | 스텐실: 원 안의 별, 의미 없는 블록 문자열 |
| 덮개 | 루프 | 캔버스(250mm 간격 주름, 처진 아래단), 슬랫·스테이크 적재함 |
