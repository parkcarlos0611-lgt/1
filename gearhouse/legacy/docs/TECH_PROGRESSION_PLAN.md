# 기술 계승 & 노후화 평가 계획 (전 시대 공통)

> 상태: **계획 보고 단계 — 승인 후 구현.**
> 목표: ① 시대가 넘어가도 이전 시대 기술·설계를 자연스럽게, 점점 더 싸고 쉽게 쓸 수 있게 한다. ② 대신 뒤처진 기술·구조는 평가에서 손해를 보고, 그 손해가 **최근으로 올수록 커지게** 한다 (실제 역사의 기술 교체 속도 가속을 반영).

---

## 1. 기술 데이터 모델

모든 기술·구조·부품(엔진 헤드 형식, 프레임 형식, 변속기, 브레이크, 서스펜션, 램프, 차체 디자인 언어, 프롭)은 다음 연표 값을 가진다.

| 필드 | 의미 | 예: 유압 브레이크 |
|---|---|---|
| `invented` | 처음 등장 (연구 가능 시점) | 1921 |
| `mainstream` | 시장의 다수가 채택한 해 (평가 기준점) | 1936 |
| `obsolete` | 대체 기술이 주류가 된 해 (이후 "구식") | 1960 (디스크 보급 시작) |
| `successor` | 대체 기술 | disc_brake |
| `segmentBias` | 세그먼트별 민감도 보정 | 고급 +, 상용·군용 − |

## 2. 계승 — 이전 기술을 쉽게 쓰기

| 장치 | 규칙 |
|---|---|
| **지식 보존** | 한 번 연구한 기술은 시대가 바뀌어도 사라지지 않는다. 시대 경계에서 리셋 없음 |
| **업계 확산** | `mainstream`이 지난 기술은 연구하지 않았어도 연구비가 연 단위로 하락 (확산 할인). `obsolete` 이후에는 거의 무료로 해금 (라이선스·공용 지식) |
| **성숙도** | 오래 쓴 기술일수록 신뢰성↑·생산비↓ (기존 성숙도 시스템 유지). 구식 기술은 "싸고 믿을 만하지만 낡은" 선택지가 됨 |
| **설계 재사용** | 이전 시대 플랫폼·엔진 패밀리·프롭을 새 시대 차량에 그대로 쓸 수 있음. 툴링 재사용 할인 (전후 1946~48 전전 설계 재생산이 대표 사례) |
| **페이스리프트** | 구형 차체에 신형 프롭(그릴·램프·트림)만 교체하는 저비용 개발 경로 |
| **시대 전환 브리핑** | 새 시대 진입 시 "주류가 된 기술 / 구식이 된 기술" 목록을 뉴스로 알림 |

## 3. 노후화 — 뒤처질수록 평가 손해, 최근일수록 더 크게

### 3-1. 기술 하나의 "현대성" 점수
```
age   = 현재연도 − max(기술.mainstream, 차량 설계연도)      // 주류 이후 얼마나 지났나
lag   = 현재 프런티어 연도 − 기술.mainstream                 // 같은 분야 최신 주류 대비 뒤처짐
grace = 유예기간(현재연도)       // 이 기간 안에는 손해 없음
span  = 평판 하락 기간(현재연도)  // grace 이후 이 기간에 걸쳐 0까지 하락
modern = clamp(1 − max(0, lag − grace) / span, 0, 1)
```

### 3-2. 시대가 갈수록 엄격해지는 곡선 (역사 반영)
| 연대 | 유예 grace | 하락 기간 span | 시장 가중치 w_modern | 근거 (역사적 경향) |
|---|---|---|---|---|
| 1930s | 6년 | 14년 | 0.10 | 모델 수명이 길고 기술 확산이 느림, 대공황기 가격 우선 |
| 1940s | 5년 | 12년 | 0.12 | 전시 공백으로 전전 설계를 그대로 재생산해도 수용됨 (전후 수요 폭발) |
| 1950s | 4년 | 9년 | 0.18 | 연식 변경 경쟁, 마력 경쟁 — 구식이 빨리 드러남 |
| 1960s | 3.5년 | 8년 | 0.20 | 안전 규제 시작, 신기술 광고 경쟁 |
| 1970s | 3년 | 7년 | 0.22 | 배기가스·연비 규제로 구식 엔진은 **규제 탈락** 가능 |
| 1980s | 2.5년 | 6년 | 0.26 | 전자제어·품질 경쟁 |
| 1990s | 2년 | 5년 | 0.30 | 에어백·ABS 등 기대 장비화, 짧은 모델 주기 |

연도 사이는 보간한다. 결과적으로 **같은 10년 뒤처짐**이라도 1935년에는 가벼운 감점, 1995년에는 치명적인 감점이 된다.

### 3-3. 차량 전체에 적용
- 차량 현대성 = 구성 기술별 `modern`의 가중 평균 (엔진 0.25, 섀시·서스 0.20, 변속·구동 0.15, 브레이크·안전 0.15, 차체 구조 0.10, 디자인 언어 0.15)
- **구조도 대상**: 프레임 방식(예: 승용 래더 → 유니바디 주류화 이후 승용 래더는 감점, 트럭·군용은 예외), 펜더 분리형 차체(풀 폰툰 주류화 이후 감점) 등
- 시장 매력도 = 기존 점수 × (1 − w_modern) + 현대성 × w_modern, 세그먼트 민감도 보정:
  고급·스포츠 ×1.3, 패밀리 ×1.0, 경차 ×0.8, 상용 ×0.6, 군납 ×0.4 (군납은 신뢰성·정비성·표준화 가중이 높음)
- **규제 절벽**: 규제(안전·배기)를 만족하지 못하는 구식 기술은 감점이 아니라 해당 시장 **판매 불가**
- **레트로 예외**: 특정 시대 이후 고전 디자인 프롭은 "레트로" 태그로 스포츠·고급 일부 고객에게 가점 (1990s 레트로 붐 등)

### 3-4. 디자인 노후화 (기존 시스템과 연결)
- 프롭·디자인 언어의 `years` 범위 밖이면 이미 디자인 점수의 시대 적합도가 낮아진다 → 여기에 같은 grace/span 곡선을 적용해 **최근 시대일수록 유행 지난 디자인 감점이 커지게** 통일.

## 4. 게임 체감 예시
| 상황 | 결과 |
|---|---|
| 1946년, 1941년 설계 세단 재생산 | 유예 5년 안 → 감점 거의 없음, 툴링 재사용으로 이익 큼 (역사와 일치) |
| 1955년, 플랫헤드 V8 유지 | OHV V8 주류(1950s 초) 대비 뒤처짐 → 고급·스포츠에서 큰 감점, 경차·상용은 소폭 |
| 1975년, 배기 대응 없는 대배기량 엔진 | 규제 시장 판매 불가 + 현대성 감점 |
| 1995년, 1985년식 구조 그대로 | 10년 뒤처짐 → grace 2 + span 5 초과 → 현대성 0, 매력도 30% 하락 |

## 5. 구현 계획 (승인 후)
1. 기술·구조·프롭 데이터에 `invented / mainstream / obsolete / successor` 추가 (E1·E2 기존 데이터부터)
2. `progression.mjs`: 연도별 grace/span/w_modern 곡선, 확산 할인, 현대성 계산
3. 조립 테스트·시장 모듈에 연결 → 같은 차를 1935·1955·1975·1995년에 내놓았을 때 점수 변화 시뮬레이션 리포트
4. 밸런스: 헤드리스 시뮬레이션으로 "구형 재생산 전략"이 1940년대 후반에는 유효하고 1960년대 이후에는 빠르게 무너지는지 확인
