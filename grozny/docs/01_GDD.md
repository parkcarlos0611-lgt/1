# 01. 게임 기획서 (GDD)

## 1. 개요
| 항목 | 내용 |
|---|---|
| 가제 | GROZNY (Грозный) — 겨울의 끝 |
| 장르 | 쿼터뷰 전술 생존 + 소규모 분대 지휘 |
| 배경 | 1차 체첸 전쟁 (1994.12 ~ 1996.8), 중심은 그로즈니 시가전 |
| 플랫폼 | PC (Steam) + 모바일 (주 타깃 여부 결정 필요, 05_DECISIONS Q0-b) |
| 등급 목표 | 성인 (청소년이용불가) |
| 플레이 시간 | 캠페인 챕터당 2~4시간 + 엔드리스 생존 모드 |

**한 줄 소개:** 1994년 12월 31일, 준비되지 않은 사람들이 불타는 도시에서 하루 더 살아남으려는 이야기.

## 2. 디자인 원칙
1. **영웅은 없다.** 한 발에 죽을 수 있다. 플레이어 캐릭터는 평범한 사람이다.
2. **혼돈을 시스템으로.** 틀린 지도, 끊기는 무전, 오인 사격, 지연되는 명령.
3. **모두가 피해자.** 어느 쪽도 미화하거나 악마화하지 않는다.
4. **결과가 남는 잔혹함.** 고어 연출보다 "돌이킬 수 없음"으로 무게를 만든다.
5. **선택에 정답이 없다.** 도덕적 선택에 점수·보상을 붙이지 않는다.

## 3. 핵심 루프
```
[거점] 정비 · 치료 · 식량 배분 · 대원 상태 확인
   ↓
[출격] 임무(명령) 또는 수색(물자)
   ↓
[현장] 이동 · 시야 확보 · 교전/회피 · 민간인 조우 · 부상자 처리
   ↓
[귀환] 생존자/사망자 정리 · 트라우마 누적 · 다음 날
```
- **1회 출격:** 10~20분 실시간 (일시정지 가능)
- **하루 단위:** 낮 출격 1회 + 밤 이벤트(포격, 습격, 대화)

## 4. 시점과 조작
- **2D 탑뷰** (카메라 회전 없음, 북쪽 고정)
- 한 번에 **한 층만** 표시. 건물에 들어가면 지붕이 사라지고 실내가 보임. 계단으로 층 이동, 다른 층은 소리로만 인지
- 높이감은 그림자 방향, 낙차 표시, 창문 너머 시야로 표현
- **시야 원뿔:** 캐릭터가 보는 방향만 밝게 보임. 소리는 위치 표시만(정확한 정보 아님)
- 조작: WASD 이동, 마우스 조준, 우클릭 견착, Space 일시정지(명령 입력), Tab 인벤토리
- 분대원: 일시정지 후 명령 (이동 / 엄호 / 진입 / 부상자 운반 / 후퇴 / 사격 중지)

## 5. 주요 시스템 (세부는 03_SYSTEMS.md)
| 시스템 | 요약 |
|---|---|
| 부상 | 부위별 상처(출혈, 골절, 파편, 화상, 동상), HP 바 없음 |
| 의료 | 지혈대, 붕대, 프로메돌(진통제), 부목. 항상 부족 |
| 심리 | 공포 · 피로 · 트라우마. 높으면 조준 흔들림, 명령 거부, 얼어붙음 |
| 사격·탄도 | 탄 관통(벽 재질별), 제압 효과, 탄약 무게 |
| 환경 | 겨울 추위, 밤 시야, 파괴된 건물, 화재 |
| 소리 | 총성·발소리가 AI를 끌어들임. 플레이어에게는 대략적 방향만 표시 |
| 무전·지휘 | 상급 부대 명령이 지연되거나 틀림. 지도가 실제와 다름 |
| 민간인 | 지하실 피난민. 식량 나눔, 동행, 의심 등 선택 |
| 분대 AI | 엄폐 찾기, 응사, 공포 반응, 부상자 구조 |
| 기록 | 사망한 대원의 이름, 나이, 남긴 편지가 기록에 남음 |

## 6. 캠페인 구조
| 챕터 | 주인공 | 시기 / 장소 | 주제 |
|---|---|---|---|
| 1. 새해 | 러시아 징집병 (19세, 가상 인물) | 1994.12.31~1995.1.2, 기차역 일대 | 준비 안 된 군대, 포위, 고립 |
| 2. 궁 | 체첸 민병 (동네 청년, 가상 인물) | 1995.1, 대통령궁 주변 | 자기 도시를 지키는 사람, 철수 |
| 3. 지하실 | 민간인 (러시아계 노인 + 체첸 소녀) | 1995.1~2, 포위된 시내 | 전쟁에 끼인 사람들, 탈출 |
| 4. 산 | (확장) | 1995~96, 산악 지대 | 매복, 끝나지 않는 전쟁 |
| 에필로그 | — | 1996.8 | 휴전과 남은 것들 |

- **실존 부대와 실존 인물은 직접 등장시키지 않는다.** 가상 부대에 실제 사건의 구조를 반영한다.
- 챕터 사이에 같은 장소와 같은 사건을 다른 시점에서 다시 보게 한다(교차 서사).

## 7. 모드
- **캠페인:** 위 구조. 수작업으로 만든 맵 + 일부 랜덤 요소
- **생존:** 랜덤 생성된 그로즈니 구역에서 며칠 버티는지. 영구 사망(퍼머데스)
- (확장) 시나리오 에디터: JSON 맵/이벤트 편집

## 8. 표현 수위
- 유혈, 시체, 부상 묘사는 **사실적이되 오래 남게** 한다(시체가 치워지지 않음, 부상자의 신음).
- 고어 옵션 3단계: 사실적 / 절제 / 최소화
- **절대 하지 않는 것:** 민간인 학살을 플레이어 보상으로 만들기, 고문 미니게임, 특정 민족을 비하하는 묘사

## 9. 아트·사운드 방향
- 회색, 갈색, 흰 눈 중심의 무채색. 불빛(화재, 조명탄)만 따뜻한 색
- 저폴리곤 + 거친 텍스처, 파괴된 소련식 아파트(흐루숍카), 철도, 공장
- UI는 군용 서류, 무전 메모 질감
- 사운드: 음악은 최소화. 무전 잡음, 멀리서 들리는 포격, 바람
