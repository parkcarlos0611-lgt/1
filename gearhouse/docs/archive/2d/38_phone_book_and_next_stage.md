# 검토 38 — 두툼한 전화번호부, 그리고 다음 단계

기획자 피드백(2026-11-20): 새 소리는 이전보다 낫다. 종이 마스킹은 보완하면 나중에 쓰일 기초 수준. 주방 · 전화 구도는 구상과 비슷하다. 전화번호부는 두툼한 책을 한 장씩 넘기며 빼곡히 적힌 번호를 찾는 재미가 있으면 좋겠다.

## 1. 두툼한 전화번호부 — 좋다, 단 "찾는 재미"가 "찾는 고역"이 되지 않게

### 1-1. 책의 모습
| 요소 | 내용 |
|---|---|
| 책 | 읍의 번호부 한 권(해마다 새 판). 표지, 앞부분 안내(교환 · 장거리 · 요금), 흰 페이지(사람 · 가게 가나다순), 노란 페이지(업종별), 뒷부분 광고 |
| 페이지 | 두 단, 한 쪽에 40~50줄. 이름 · 주소 · 번호가 점선으로 이어진 옛 번호부 모양. 굵은 글씨는 돈 낸 가게, 테두리 상자 광고 |
| 넘기기 | 모서리를 끌어 넘김(종이 휘는 그림 2~3장 + 넘기는 소리). 빨리 훑기는 엄지로 쭉(여러 장 촤르륵). 옆면의 색 띠(흰 · 노랑)와 꼭지 글자로 대략 어디인지 보인다 |
| 작은 글씨 | 돋보기로 확대해 읽는다(견본 B의 돋보기와 같은 도구) |

### 1-2. 내용은 세계에서 나온다
- 이름 자료가 이미 있다: 성 약 600, 이름 약 600(6계 출신). 사람 번호는 수백~천여 줄을 만들 수 있다.
- 가게 · 공장 · 은행 · 관공서는 마을 명부(core/register)에서: 은행 6, 공장 10, 경쟁 자동차 회사 10, 길 12, 관직 8. 명부의 상태가 바뀌면(은행 파산, 공장 폐업) **다음 해 판**에서 빠지고, **올해 책에는 아직 남아 있어** 걸면 "없어진 번호"가 나온다.
- 손님 · 직원 · 공급사(core의 사람과 공급사)도 실린다. 손님 집에 전화해 독촉 · 사과를 할 수 있다(판본에서 사건과 연결).
- 신문 광고 · 잡지 광고 · 손님 편지에 번호가 적혀 온다: 번호부를 뒤지지 않아도 되는 지름길.

### 1-3. 찾는 재미가 고역이 되지 않게 (꼭 함께)
| 장치 | 효과 |
|---|---|
| 업종별 노란 페이지 | "부품" 장에 가면 공업사가 모여 있다. 처음엔 여기서 찾는다 |
| 책갈피 · 접은 귀 · 연필 동그라미 | 한 번 찾은 곳은 표시해 두면 바로 펼쳐진다 |
| 전화기 옆 단골 쪽지 | 자주 거는 번호를 적어 두면 쪽지를 눌러 그 번호가 보인다(그래도 돌리는 건 손으로) |
| 교환원 "번호 안내" | 이름만 알면 교환원이 찾아 준다. 몇 센트와 시간이 든다(급할 때의 대가) |
| 광고 · 편지의 번호 | 신문 · 잡지를 오려 두면 번호가 따라온다 |
| 직원이 생기면 | 사무 직원에게 "주문해 줘"를 맡긴다(회사가 커질수록 손이 덜 간다) |

### 1-4. 숨은 재미
- 같은 품목을 여러 가게가 다른 값에 판다(번호부를 많이 뒤질수록 싸게).
- 옛 판의 번호, 오타, 동명이인 — 가끔 엉뚱한 집에 걸린다(짧은 우스운 대화).
- 귀한 부품(수입차 부품)은 노란 페이지에 없고, 광고 상자나 손님의 소개로만 알 수 있다.

### 1-5. 만드는 시기
판본에서 만든다(판본 반영 목록에 넣음). 견본 D의 다이얼 · 통화 · 주문 흐름은 그대로 쓰고, 번호부만 책 모양으로 바꾼다.

## 2. 지금까지 견본으로 확인한 것

| 견본 | 확인한 것 | 상태 |
|---|---|---|
| 제도판 | 선 도면, 빨간 수정, 도면 4종, 부품 조절, 앞 · 뒤 보기 | 방향 확정 |
| A 집 앞 | 구도, 시간 · 날씨 · 계절, 손님 도착 → 노크 → 맞이 | 구도 확정, 세부는 참고 이미지 대기 |
| B 차고 수리 | 층 구조, 손작업 순서, 돋보기, 종이 마스킹, 검사 | 기초 수준 도달 |
| C 주방 상담 | 질문 칸, 잡담, 차 · 커피 충전, 메모 | 구도 확정 |
| D 전화 | 다이얼, 통화, 주문 | 구도 확정, 번호부는 책으로(1장) |
| 시험 주행장 | 출렁이는 주행 장치 | 이전에 확인 |

아직 견본이 없는 핵심 장면: 공방 방(설계도 · 스탠드 · 책장 · 침대), 배달차 도착과 값 치르기, 예상도, 엔진 카탈로그와 조합, 차고에서 부품 떼고 끼우기, 인도와 결산표.

## 3. 다음 단계 제안: 판본 1단계 "세계의 뼈대"

견본은 손맛과 구도를 확인하는 데 충분히 썼다. 이제 견본을 더 늘리기보다, **견본의 장면들을 하나의 시간 · 하나의 저장으로 잇는 판본의 뼈대**를 만들 때다(검토 36의 원칙: 견본 코드는 옮기지 않고 규칙과 느낌을 옮긴다). 그림은 아직 임시 그림을 쓰고, 참고 이미지가 오는 대로 바꾼다.

| 순서 | 할 것 | 연결되는 것 |
|---|---|---|
| 1 | 코어에 분 단위 시계(평소 하루 60초, 사건 중 느림, 작업 20배, 상담 멈춤, 밤 넘기기) | core/sim의 하루 단위 위에 |
| 2 | 장소 장면 틀: 집 앞 · 집 안(주방) · 차고 · 공방 방, 문을 눌러 오간다(어두워졌다 밝아짐) | 장면 관리자(ui/shell) |
| 3 | 손님 흐름을 코어와 잇기: 판매 시스템의 문의 → 집 앞에 차가 와서 노크 → 주방 상담(코어의 상담 횟수 · 드러나는 예산과 필수 조건을 대화로) → 메모가 도면의 주문서가 된다 | core/sales, 견본 A · C, 제도판 |
| 4 | 전화와 번호부를 코어와 잇기: 공급사 · 식료품점이 번호부에, 주문 → 날짜 · 시간 맞춰 배달차가 집 앞에 → 값 치르기(돈이 없으면 평판) | core/supply, 마을 명부, 견본 D |
| 5 | 차의 부품별 상태를 저장: 수리 의뢰 차가 차고에 들어오면 부품마다 녹 · 칠 · 손상, 작업 결과가 남아 반년 뒤 사건으로 | 소재 · 칠 층 형식, 견본 B |
| 6 | 공방 방: 설계도 → 제도판, 침대 → 밤 넘기기(저장), 책장 → 잡지 · 카탈로그 | 제도판 |

1~4가 끝나면 "손님이 와서 상담하고, 전화로 재료를 시키고, 배달이 오는" 하루가 한 저장 안에서 돈다. 5 · 6까지면 수리 한 건이 처음부터 끝까지 돈다.

## 4. 기획자에게 필요한 것 (이 단계와 함께)

| 자료 | 쓰임 | 급한 정도 |
|---|---|---|
| 참고 이미지: 집 앞(정면), 주방, 차고 안, 공방 방 | 장소 그림을 다시 그릴 기준(깊이 축척표 기준) | 높음 |
| 사람 스프라이트(외부 도구): 손님 몇 몸, 4방향 걷기 · 앉기 · 노크 | 집 앞 · 주방 | 중간 |
| 새 차 시트(한 장에 한 대, 1500~2000 px): 손님 차 2~3종, 배달 밴, 평판 견인 트럭 | 수리 의뢰, 배달 | 중간 |
| 정할 것: 깊이 축척표(검토 36), 소재 · 칠 층 고증 자료를 누가 확인할지 | 그림 · 자료 기준 | 높음 |
