# 차체 생성기 v2 계획 (최우선 과제)

> 상태: 계획 보고 → 바로 착수. 사용자 지시: "현재보다 훨씬 높은 수준의 차체 생성기 시스템", "이미지 제작 스타일보다 자료를 항상 우선", "세부 요소를 두툼하고 실제 부품처럼".
> 진행 순서: **3 생성기 v2 (이 문서)** → 2 장소 → 1 시험 주행 → 4 사운드.

---

## 0. 휠베이스 = 휠 사이 차체만 (완료, 커밋됨)
- **캐빈 고정**: 문·창·지붕·필러는 절대 늘어나지 않는다.
- **늘어나는 구간**: 휠베이스 차이는 두 구간에만 들어간다.
  - (A) 앞바퀴와 앞유리 사이의 카울·후드 구간
  - (B) 뒷문 뒤 쿼터 패널. 이 패널이 없는 차체(뒷문이 휠아치에 걸린 경우)는 전부 (A)로 보낸다.
- **통째로 이동하는 부품**: 펜더, 지붕 투톤, 램프, 그릴 셸, 바이저는 늘이지 않는다.
- **최소 길이**: 후드 900mm, 쿼터 50mm보다 줄어들지 않는다.
- v2에서는 이 규칙을 "구간(Section)" 데이터로 일반화한다(§2).

## 1. 지금 생성기의 한계 (v2가 해결할 것)
| 한계 | 원인 |
|---|---|
| 실차처럼 보이지 않는 윤곽 | 윤곽을 둥근 모서리 몇 개의 다각형으로 만든다. 실제 차의 곡선(후드 크라운, 카울 꺾임, 트렁크 곡면)이 없다 |
| 비율이 실차 범위를 벗어남 | 높이·후드 등을 휠베이스 비율로 계산하고 연도 표를 보간한다. 실측 차량과 직접 연결되지 않는다 |
| 부품이 얇고 평평함 | 범퍼·램프·그릴·핸들이 1~2px 선과 평면 도형이다 |
| 하부가 빔 | 생성 차량에 섀시 데이터가 없다 |
| "AI 성향" | 모든 차가 같은 반사띠·디더·두께를 쓴다 |

## 2. 핵심 구조: 실측 템플릿 + 구간(Section) 모델

### 2-1. 참조 차량 라이브러리 (실측만)
- 지금까지 도면에서 실측한 차를 참조 차량으로 등록한다.
  - 1930년대: 1930 타운 세단, 1933 카브리올레, 1934 에어플로형, 1937 V 그릴 쿠페, 1934 V12 타운카, 1930~31 대중 쿠페(새 도면), 1930년대 초 영국 스포츠카(새 도면)
  - 1940년대: 민수 8종(1941 고급 V8, 1940 V12 쿠페, 1942 세단, 1940 쿠페, 1946 소형, 우디, 픽업, 트럭), 1948 리어엔진 세단, 1949~50 폰툰 쿠페(격자 도면)
- **기록 항목** (참조 차량마다):
  - 출처 도면, 연식, 실측 제원(휠베이스·전장·전고·타이어)
  - **랜드마크**: 의미가 같은 점에 같은 이름을 붙인다(§2-2)
  - **곡선 구간**: 랜드마크 사이의 실제 윤곽 점열
  - 부품 슬롯 위치(램프·그릴·범퍼·핸들·스페어)
  - 창 구성(필러 위치·벨트·드립)
- **검증**: 참조 차량을 그대로 재생성하면 원본 도면과의 평균 윤곽 오차 15mm 이하(픽셀 1개 미만)여야 한다. 실패하면 그 참조는 쓰지 않는다.

### 2-2. 랜드마크 (모든 차에 공통 이름)
| 영역 | 랜드마크 |
|---|---|
| 앞 | 범퍼 앞끝, 그릴 아래·위, 후드 앞 윗점, 앞펜더 앞끝·정점·뒤끝 |
| 후드·카울 | 후드 최고점, 카울(앞유리 아래), A필러 아래·위 |
| 캐빈 | 루프 앞·최고·뒤, 앞문 앞·뒤 선, B필러, 뒷문 앞·뒤 선, C필러 아래, 벨트라인 앞·뒤, 사이드실 |
| 뒤 | 트렁크 위 시작·끝, 꼬리 최후점, 뒤펜더 앞·정점·뒤, 뒤 범퍼 |
| 바퀴 | 앞·뒤 휠 중심, 타이어 반경, 아치 반경 |

### 2-3. 구간(Section) 모델
차는 앞에서 뒤로 **구간의 연속**이다. 각 구간은 길이와, 그 안의 곡선·부품을 가진다.
1. 앞 오버행 (범퍼 → 앞바퀴)
2. 후드 (그릴 → 카울) — **휠베이스 연장 구간 A**
3. 캐빈 (카울 → C필러) — **고정 구간**. 앞문·뒷문·창은 길이 조정 불가, 차급별로 실측 값을 쓴다
4. 쿼터 (C필러 → 뒷바퀴 앞) — **휠베이스 연장 구간 B**
5. 뒤 오버행 (뒷바퀴 → 꼬리)

- **조정 규칙**:
  - 휠베이스는 구간 2와 4만 바꾼다.
  - 전고는 캐빈 높이(그린하우스)와 차체 높이를 실측 비율 안에서 바꾼다.
  - 오버행·꼬리 형식은 참조 차량의 구간을 통째로 갈아 끼운다(예: 트렁크 꼬리 ↔ 패스트백 꼬리).
- **블렌딩**:
  - 같은 시대·차종의 참조 2~3대를 고르고, 구간마다 곡선을 같은 점 수로 재표본화해 가중 평균한다.
  - 가중치는 플레이어의 "디자인 성향" 슬라이더에서 나온다(예: 박스 ↔ 유선).
  - 결과는 항상 참조 차량들 사이(볼록 껍질 안)에 있어서 실차 범위를 벗어날 수 없다.

### 2-4. 연도 한계
- **연도별 참조 차량**: 그 연도까지 존재한 참조 차량만 섞을 수 있다. 1936년에 1938년 참조는 쓸 수 없다.
- **선행 디자인**: 연구로 "선행 디자인"을 해금하면 1~2년 앞선 참조를 쓸 수 있다. 이때는 비용과 위험이 올라간다.

## 3. 두툼한 실부품 라이브러리 (자료 실측)
| 부품 | 구조 | 실측 자료 |
|---|---|---|
| 범퍼 | 바 단면 3~5단 명암(위 하늘 반사, 가운데 지평선, 아래 땅 반사), 끝 곡면, 브래킷 2개가 프레임까지, 볼트, 가드 | 1940 고급차 실차, 카탈로그 |
| 헤드램프 | 버킷(깊이), 크롬 림 두께, 홈 무늬 렌즈, 스탠천 / 탄환형 포드 / 펜더 매립형 | 6차 클로즈업 2장 |
| 그릴 | 셸 두께와 테두리, 바 단면 2톤, 바 사이 라디에이터 코어 그림자 / 세로 이빨 / 가로 바 | 6차 클로즈업, 실차 |
| 휠 | 와이어(교차 스포크, 림 깊이), 포병식 목재(쐐기 스포크 12, 림 클램프), 디스크, 화이트월 폭 비율, 허브캡 돔 | 1차 휠 5장 |
| 문 | 경첩(노출형 1930s 초), 손잡이 받침, 열쇠 구멍, 문틀 단차 그림자 | 실차 사진 |
| 러닝보드 | 고무 매트 줄무늬, 크롬 테두리, 받침 브래킷 | 실차 사진 |
| 펜더 | 옆면 두께 띠, 안쪽 그림자, 크라운 하이라이트 | 실차 사진 |
| 스페어 | 사이드마운트(커버·노출·스트랩), 뒤 장착 | 실차 사진 |

부품은 슬롯 위치에서 **실측 mm 크기**로 그리고, 축척이 작아지면 부품 생성기가 디테일 단계를 줄인다(25mm/px: 3단, 12.5mm/px: 5단).

## 4. 하부 자동 생성
구간 모델의 휠·프레임 높이에서 섀시를 자동으로 만든다(이미 검증된 `mechview` 방식).
- **프레임**: 시대별 래더, X멤버, 페리미터
- **서스펜션**: 판스프링이나 횡치 스프링, 쇼크
- **구동계**: 차축과 디퍼렌셜, 추진축이나 토크튜브, 변속기 하단
- **배기·연료**: 배기관과 머플러, 연료탱크
- **차체 하부**: 스플래시 에이프런, 바닥판 가장자리

생성 차량의 측면 하부, 조립 연출, X-ray, 하부 평면 뷰가 모두 같은 데이터를 쓴다.

## 5. 명암·재질 (AI 성향 제거)
| 항목 | 규칙 |
|---|---|
| 반사띠 | 차체 곡률에서 계산. 수직 면은 지평선 띠가 진하고, 곡면은 띠가 휘고 흐려짐. 모든 차에 같은 띠 금지 |
| 디더 | 단계 경계 1~2px에만. 넓은 면은 단색 단계 |
| 재질 | 도장(광택 등급: 래커 → 에나멜), 크롬, 고무, 목재, 캔버스, 유리를 각각 다른 명암 곡선으로 |
| 부품 그림자 | 범퍼·램프·핸들 아래 1px 접촉 그림자, 펜더가 차체에 드리우는 그림자 |
| 검증 | 같은 각도의 실차 사진과 밝기 단계 수·위치를 비교하는 체크리스트 |

## 6. 플레이어 조작 (차 디자인 화면)
| 조작 | 효과 |
|---|---|
| 차종·차급 | 참조 후보군 결정 |
| 디자인 성향 (박스 ↔ 유선 ↔ 폰툰) | 참조 혼합 가중치 |
| 휠베이스 (mm) | 구간 2·4만 |
| 전고·전폭 (mm) | 실측 범위 안 |
| 앞·뒤 오버행, 꼬리 형식 | 구간 교체·조정 |
| 부품 선택 | 그릴·램프·범퍼·휠·스페어·트림을 시대 해금 목록에서 |
| 도장 | 단색·투톤·펜더색 |

## 7. 작업 단계
1. **랜드마크·구간 데이터 형식 + 편집 도구**: 참조 차량에 랜드마크를 찍고 구간 곡선을 뽑는 스크립트, 원본 도면 겹쳐 보기
2. **참조 등록**: 1930년대 7종 → 1940년대 11종. 각각 재생성 오차 리포트
3. **블렌딩 엔진**: 구간별 재표본화, 가중 평균, 연도 필터, 휠베이스·전고 조정
4. **부품 라이브러리 v2**: 범퍼 → 램프 → 그릴 → 휠 → 문·보드·스페어 (클로즈업 자료 실측)
5. **하부 자동 생성 + 명암 v2**
6. **게임 연결**: 차 디자인 화면 교체, 조립 연출·시험 주행·딜러십이 v2 차량을 사용
7. **검증 리포트**: 무작위 혼합 60대 + 참조 재생성 전부 → 겹쳐 보기 시트와 오차 표

## 8. (추가) 전면·후면 디자인 시스템

| 항목 | 내용 |
|---|---|
| 자료 | 실측 정면·후면이 있는 차: 1930 세단, 1934 에어플로형, 1937 유선형 쿠페, 1934 타운카 (+ 군용 4x4·6x6). 나머지는 측면 템플릿 + 실측 치수에서 단면을 만들고, 정면 자료가 오면 실측으로 교체 |
| 단면 형상 | 같은 mm 값을 공유한다: 전폭, 전고, 트레드, 타이어 폭, 벨트·루프 높이(측면 랜드마크), 후드 폭, 펜더 폭·정점 높이, 캐빈 폭. 실측 정면 템플릿은 폭·높이로 변형해 쓴다 |
| 부품 슬롯 (정면) | 그릴(모양·패턴, 시대 목록), 헤드램프(스탠천형 / 포드형 / 펜더 매립형, 실측 크기), 범퍼(바 수·단면·가드), 보조등, 엠블럼·후드 장식, 번호판 |
| 부품 슬롯 (후면) | 트렁크 또는 뒤 스페어, 테일램프, 뒷창, 범퍼, 번호판, 연료 주입구 |
| 일관성 | 측면에서 고른 그릴·램프가 정면에도 같은 부품으로, 5뷰의 폭·높이가 같은 mm로 맞는지 자동 검사 |
| 화면 | 차 디자인에 **측면 / 정면 / 후면** 탭(이후 평면 추가). 정면·후면 탭에서 부품을 고르면 즉시 반영 |
| 렌더 | 검증된 정면 렌더러(`front.mjs`)를 쓰고, 부품은 §3의 두툼한 부품 라이브러리로 교체 |

## 10. 진행 순서 (갱신)
1. 스와이프 스크롤 (§9) ← 먼저: 정면·후면 탭을 넣을 공간을 만든다
2. 정면·후면 디자인 시스템 (§8)
3. 템플릿 추가 → 실부품 라이브러리 → 하부·명암 v2 → 검증 리포트
