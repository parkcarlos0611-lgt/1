## 3. 차량 디자인 시스템 체계화

지금까지 차량은 두 경로로 만들어졌다. (a) 실측 복제 차량: 손으로 쓴 좌표, (b) 생성기: 파라미터. 이를 **한 체계**로 묶는다.

| 계층 | 내용 | 규칙 |
|---|---|---|
| 1 플랫폼 | 휠베이스, 트레드, 프레임(래더·X멤버·페리미터·유니바디), 레이아웃(FR·RR·4WD) | MechDef와 같은 데이터. 엔진 장착 검사의 기준 |
| 2 차체 셸 | 디자인 언어(박스·유선·폰툰) × 차종(세단·쿠페·왜건·픽업·트럭·군용) | 연도별 한계값 (`bodygen`), 비율 클램프 |
| 3 그린하우스 | 창 시스템 v2 파라미터(벨트, 드립, A/B/C 필러, 뒷창 컷, 환기창) | 차체 외곽에서 자동 유도 |
| 4 패널·펜더 | 분리 펜더 / 반폰툰 / 폰툰, 러닝보드, 스커트 | 시대 해금 |
| 5 프롭 슬롯 | 그릴, 램프, 범퍼, 트림, 휠, 마스코트 | 슬롯 호환 + 고립 요소 자동 연결 |
| 6 재질 | 강판 등급, 도장, 크롬, 목재, 캔버스, 군용 무광 | 재질 셰이더 |
| 7 기계 결합 | 엔진룸 상자, 터널, 탱크, 배기 | 장착 검사, X-ray·분해도·하부 |
| 8 출력 | 5뷰 + X-ray + 하부 + 게임 스프라이트(25 mm/px), 상세(12.5), 부품(5) | 같은 좌표계 |

**복제 차량 = 생성기 프리셋**: 실측 복제 차량을 위 파라미터 묶음으로 다시 기록해, 게임 안에서 경쟁사 차량·프리셋으로 쓰고 플레이어가 조정할 수 있게 한다. 손 좌표는 실측 검증용으로 남긴다.

**디테일 향상 목록**: 정면·후면 뷰 자동 생성(측면 데이터에서), 도어 핸들·키홀·배수구 같은 마이크로 디테일, 휠 스커트·스톤가드, 크롬 반사의 하늘·지평선 밴드 통일, 하부 그림자.

## 4. 1930~1949 테스트판

| 항목 | 내용 |
|---|---|
| 화면 | 480×270 픽셀 버퍼를 정수 배율로 확대. 모든 UI(창·버튼·슬라이더·선택기·그래프·커서)를 직접 픽셀로 그림: 호두나무 책상, 크림색 제도지, 황동 베벨, 옥스블러드 에나멜 제목판, 리벳 |
| 메인 메뉴 | 새 게임 / 이어하기(3슬롯) / 설정(배율, CRT 주사선) |
| 새 게임 | 회사명, 국가 6개(부·연료비·도로·임금·전쟁 기간이 다름), 시작 연도 1930~1945, 자본 3단계, 연구 규모 3단계 |
| 엔진 설계 | 배열·밸브기구(연구 해금)·보어·스트로크·압축비(시대 한계)·캠·기화기·공정 등급 → 토크/출력 곡선, 제원, 측면 스프라이트 미리보기 → 툴링 |
| 변속기 | 형식(시대·연구 해금)·단수·1단·최고단 → 기어비 사다리 |
| 차 디자인 | 디자인 언어(연도 한계)·차종·휠베이스·비율 슬라이더 → 실시간 픽셀 스프라이트, 엔진·변속기·종감속·트림·장비, 세그먼트·가격 → 성능·연비·등판·원가·장착 검사·매력도 → 출시(툴링·개발 기간) |
| 경영 | 월 단위: 생산 계획, 재고, 판매, 평판, 연구, 공장 확장. 대공황(1931~33), 1937 경기 후퇴, 국가별 전시 민수 생산 중단 → 군납 계약, 전후 수요 폭발 |
| 노후화 | 기술 계승·노후화 계획의 유예·하락 곡선(1930년대 6/14년, 1940년대 5/12년)으로 현대성 점수 반영 |
| 종료 | 1950년 1월 또는 파산 시 결산 화면 |
| 한계 | UI는 영문 픽셀 폰트(한글 픽셀 폰트는 다음 단계), 경쟁사는 시장 기준선 모델, 군납은 단순 계약 |
