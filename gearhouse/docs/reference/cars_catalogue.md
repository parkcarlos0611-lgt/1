# Reference cars — working catalogue

Real names are kept here only to check size and kind. They never appear in game data; the sheets themselves are not in the repository.

Length and wheelbase are from memory and are not checked against sources. 'Sure': H well-known figure, M about right, L a guess. Each is to be compared with the ratio measured on the sheet before use; width and height are taken from the sheet after scaling.
