# 100 · 1990년대 제작 공정 — 상세 검토 (검토 178)

사용자 요청: "1990년대용 제작 공정을 새로 정해 빌더와 연결할지 상세하게 검토". 이 문서는 검토와 제안만 담는다. 구현은 검토를 받은 뒤 한다.

> **상태 (2026-11-24, 사용자 결정):** 계획으로 남겨 둔다. 구현은 빌더를 먼저 확인한 뒤 정한다.

## 1. 지금 있는 제작 체계 (`core/build.ts`, `data/build/steps.json`)
1930년대 작은 공방 기준이다. 엔진은 그대로 쓸 수 있을 만큼 잘 짜여 있다.

| 요소 | 지금 방식 |
|---|---|
| 공정 | 9개: 차대 → (동력, 목재 골조) → 패널 → 접합 → 도장 → 내장 → 부착물 → 마무리 |
| 선후 관계 | 공정마다 `after`(앞 공정)가 있다. 앞 공정이 끝나고 재료가 창고에 있어야 시작한다 |
| 주문 종류 | 차체만(손님 차대) / 굴러가는 차대 구입 / 자체 차대 |
| 시간 | 공정별 기본 시간 × 차 크기(`sized`) × 반복 학습(1대째 1.0 → 5대째 0.75) |
| 품질 | 작업자 숙련 55 % + 재료 품질 30 % + 공구 수준 15 % ± 무작위. 보이는 품질과 숨은 품질로 나뉜다 |
| 결함 | 품질이 낮을수록 공정별 결함이 생길 확률이 높다(브레이크 쏠림, 프레임 균열, 과열, 오일 샘 등) |
| 날씨 | 도장은 비 오는 날 멈춘다 |
| 설계 | 설계 시간(비례·부품·패널 수로 계산), 첫 차는 목업(실물 모형) 40시간 |

**판단:** 공정 엔진(선후 관계, 재료, 숙련, 품질, 결함)은 시대와 상관없이 쓸 수 있다. **바꿀 것은 데이터(공정 목록)와 몇 가지 새 개념**(개발 단계, 시설, 생산 규모)이다.

## 2. 1990년대 차 만들기가 1930년대와 다른 점
| 항목 | 1930년대 공방 | 1990년대 소량 고성능차 |
|---|---|---|
| 차체 구조 | 사다리 프레임 위에 목재 골조, 그 위에 금속 패널 | 모노코크(차체 자체가 뼈대). 강철 점용접, 알루미늄 용접·접착(NSX), 탄소섬유 적층·경화(EB110, 맥라렌 F1) |
| 정밀도 | 손으로 맞춘다 | **지그**(고정 틀)가 필수다. 지그 없이는 치수가 맞지 않는다 |
| 첫 차 전 준비 | 목업 하나 | 시제차, 시험, **인증**(형식 승인, 충돌, 배출가스), 금형·몰드 |
| 엔진 | 사서 얹는다 | 사거나, 직접 조립해 **다이노**(엔진 시험대)에서 길들이고 측정한다 |
| 전기 | 램프와 점화 정도 | ECU(엔진 제어), ABS·TCS, 팝업 램프 모터, 배선 묶음. **전장 공정이 따로 필요하다** |
| 도장 | 붓·스프레이, 날씨 영향 | 도장 부스(먼지·온도 제어). 하도 → 중도 → 색 → 클리어 |
| 마무리 | 육안 검사 | 휠 정렬, 댐퍼 설정, 누수 시험, 시험 주행(셰이크다운) |
| 한 대 작업 시간 | 수백 시간 | 소량 수제 슈퍼카는 수백~수천 시간. 예: 맥라렌 F1은 한 대에 약 3,000시간이 들었다고 알려져 있다[~] |

## 3. 제안: 두 층으로 나눈다
### 3-1. 개발 단계 (설계 하나당 한 번)
빌더에서 설계를 마치면 생산 전에 아래를 거친다. 돈과 시간이 드는 "투자"다.

```
설계 확정 → 시제차 제작 → 개발 시험 → 인증 → 생산 준비 → (양산 시작)
```

| 단계 | 내용 | 게임에서 |
|---|---|---|
| 시제차 | 아래 제작 공정을 한 번 돈다. 시간은 1.5~2배다(처음이라 느리다) | 3D 시험 주행으로 직접 몰아 본다. 빌더의 시험 주행이 여기로 이어진다 |
| 개발 시험 | 고속, 냉각, 내구(수천 km), 브레이크 | 시험 항목을 골라 돌린다. 숨은 결함(과열, 진동)이 여기서 드러날 확률이 높다. 시간과 돈을 아끼면 결함이 손님에게 간다 |
| 인증 | 형식 승인, 충돌 시험(차 한 대를 부순다), 배출가스·소음 | 판매할 나라마다 비용이 있다. 인증 없이 팔 수 있는 것은 경주차뿐이다 |
| 생산 준비 | 지그, 패널 금형 또는 몰드, 부품 공급 계약 | **생산 규모(3-3)**에 따라 비용이 크게 다르다 |

- 1930년대 체계의 "설계 시간 + 목업"을 이 단계가 대신한다.
- 경주차는 인증이 없는 대신 **경주 규정 검사**(문서 99 3-4)를 거친다.

### 3-2. 제작 공정 (차 한 대마다)
```
               ┌─ ② 서스펜션·브레이크 ─┐
① 차체 골격 ───┼─ ③ 패널 맞춤 ─ ④ 도장 ┼─ ⑥ 결합 ─ ⑦ 전장 ─ ⑧ 내장 ─ ⑨ 유리·부착 ─ ⑩ 정렬·설정 ─ ⑪ 최종 검사·시험 주행
⑤ 엔진 조립·다이노(병행) ──────────────┘
```

| # | 공정 | 숙련 | 설계에서 영향 받는 것 | 결함 예 | 보이는/숨은 품질 |
|---|---|---|---|---|---|
| ① | 차체 골격 | 용접(강철·알루미늄) / 복합재(탄소섬유) | 구조 소재: 강철은 빠르고 싸다. 알루미늄은 용접과 접착이 까다롭다. 탄소섬유는 적층과 경화(오토클레이브)에 오래 걸린다. 휠베이스와 폭 | 치수 오차(정렬 불량으로 이어짐), 접합 불량(강성 저하, 소음) | 0 / 4 |
| ② | 서스펜션·브레이크 | 정비 | 댐퍼(가변식은 시간 +), ABS | 브레이크 쏠림, 소음 | 0 / 3 |
| ③ | 패널 맞춤 | 판금 | 패널 소재(FRP는 빠르고, 알루미늄·탄소는 느리다), 차체 형태 패널 수 | 단차·틈 불균일 | 3 / 1 |
| ④ | 도장 | 도장 | 칠 색, 광택(높은 광택은 연마 시간 +), 차 크기 | 흘러내림, 먼지 박힘, 색 차이 | 4 / 1 |
| ⑤ | 엔진 조립·다이노 | 엔진(새 숙련) | 개발 등급(경주 파생은 수작업 조립, 시간 ×2~3), 실린더 수, 터보 수 | 출력 부족, 오일 샘, 과열 | 0 / 4 |
| ⑥ | 결합(파워트레인 장착) | 정비 | 장착 검사의 "개조 장착" 항목은 여기서 **맞춤 제작 시간**이 붙는다 | 진동, 냉각 배관 누수 | 0 / 2 |
| ⑦ | 전장·배선 | 전장(새 숙련) | 장비 수(ABS, TCS, 가변 댐퍼, 능동 윙, 팝업 램프) | 전기 고장, 경고등, 팝업 램프 고장 | 1 / 3 |
| ⑧ | 내장 | 내장 | 실내 사양(경량 / 표준 / 고급: 가죽, 방음은 시간 ×2) | 잡소리, 마감 불량 | 3 / 1 |
| ⑨ | 유리·부착 | 정비 | 램프 종류(포켓 덮개 유리), 거울, 배지 | 누수, 바람 소리 | 2 / 1 |
| ⑩ | 정렬·설정 | 정비 | 서스펜션, 타이어 | 한쪽 쏠림, 편마모 | 0 / 2 |
| ⑪ | 최종 검사·시험 주행 | 정비 + 운전 | — | 결함을 **찾는** 공정이다(새로 만들지 않는다) | — |

- **병행:** ⑤ 엔진 조립은 ①~④와 동시에 진행한다. 작업자가 여럿이면 기간이 줄어든다.
- **⑪ 최종 검사:** 검사에 시간을 많이 쓸수록 숨은 결함을 더 찾는다. 찾은 결함은 해당 공정으로 돌아가 고친다. 못 찾은 결함은 손님에게 간다(보증 수리, 평판 하락, 심하면 리콜).
- **날씨:** 도장 부스가 있으면 비와 상관없다. 부스가 없으면(초기 공방) 지금처럼 비 오는 날 멈추고 먼지 결함이 는다.

### 3-3. 생산 규모
| 규모 | 준비 투자 | 한 대 시간 | 품질 편차 | 예 |
|---|---|---|---|---|
| 주문 제작(1대) | 지그만(작음) | 가장 김 | 큼(작업자 손에 달림) | 원오프, 경주차 |
| 소량 시리즈(10~300대) | 지그 + 간이 금형·FRP 몰드 | 반복 학습으로 줄어든다(지금의 반복 계수) | 중간 | EB110, 맥라렌 F1, XJ220 |
| 라인 생산(수천 대) | 프레스 금형, 라인 설비(매우 큼) | 짧음 | 작음 | NSX(전용 공장) |

- 알파는 **주문 제작과 소량 시리즈**까지만 한다. 라인 생산은 회사가 커진 뒤의 목표로 둔다.
- 반복 학습 계수는 지금 것(1.0 → 0.75)을 쓰되 소량 시리즈에서는 더 길게 이어지게 한다(예: 20대째 0.6).

## 5. 시설과 숙련
**시설** (지금은 공구 수준 하나뿐이다. 공정별 시설로 나눈다)

| 시설 | 쓰는 공정 | 없으면 |
|---|---|---|
| 차체 지그 | ① | 치수 오차 결함이 크게 는다 |
| 용접 설비(MIG·TIG, 점용접) | ① | 알루미늄을 못 쓴다 |
| 오토클레이브 | ① 탄소섬유 | 탄소섬유 구조를 못 쓴다(외주는 비싸다) |
| 도장 부스 | ④ | 비 오는 날 멈추고, 먼지 결함이 는다 |
| 엔진 다이노 | ⑤ | 4등급 이상 엔진을 못 만든다. 출력 편차가 커진다 |
| 휠 정렬기 | ⑩ | 쏠림 결함이 는다 |
| 시험로(또는 트랙 대여) | ⑪, 개발 시험 | 대여비를 낸다 |

**숙련** (지금: 정비, 목공, 판금, 용접, 도장, 내장 → 셋을 더한다)
- **복합재**(탄소섬유·FRP), **엔진**(조립·튜닝), **전장**(배선·ECU)
- 목공은 1930년대 리스토어에서 계속 쓴다.

## 6. 품질과 결함이 3D로 이어진다
공정 품질이 시험 주행과 손님의 차에 **실제 주행 특성**으로 나타나게 한다. 이 게임만의 강점이 된다.

| 결함·품질 | 주행 페이지에서 |
|---|---|
| 차체 치수 오차, 정렬 불량 | 직진에서 한쪽으로 쏠린다(조향 오프셋) |
| 엔진 조립 품질 | 출력이 설계값보다 −1~−8 % |
| 냉각 결함 | 고속 연속 주행에서 수온이 오르고 출력이 준다(지금 물리에 냉각 여유 값이 있다) |
| 브레이크 쏠림 | 제동할 때 한쪽으로 당긴다 |
| 접합 불량(강성 저하) | 롤 강성이 약간 줄어 코너에서 무디다 |
| 팝업 램프 고장 | 램프 한쪽이 안 올라온다(3D로 보인다) |
| 도장 결함 | 3D 차의 칠에 얼룩, 광택 저하(재질 값으로 표현) |

- ⑪ 최종 검사의 시험 주행은 실제로 3D에서 몰아 볼 수 있다. 쏠림이나 과열을 플레이어가 직접 느끼고 공정으로 돌려보낼 수 있다.

## 7. 공방 화면의 3D 표현
- 키트는 삼각형마다 "어느 패널·부품인지"를 기억한다(`role`, `panelOf`). 그래서 **공정 단계별로 차의 일부만 보여 줄 수 있다.**
  - ① 뒤: 골격만(맨 금속색), ③ 뒤: 패널(프라이머 회색), ④ 뒤: 칠, ⑤: 엔진이 따로 받침대 위에, ⑥ 뒤: 엔진이 들어감, ⑨ 뒤: 유리·램프·바퀴
- 나중에 3D 회사 허브(문서 98 7절)를 만들 때 차고에 만들고 있는 차가 이 상태로 서 있게 된다.

## 8. 1930년대 공정은 리스토어 공정으로
- 지금 9공정(목재 골조 포함)은 버리지 않는다. **클래식카 리스토어**(문서 98 7절)의 공정으로 바꾼다.
  - 분해 → 진단(녹, 부품 상태, 원형 여부) → 판금·녹 제거 → 목재 골조 수리 → 도장 → 재조립 → 시험 주행
- 진단에서 원래 부품이 남아 있는 정도가 **원형 보존 점수**가 된다. 현대 부품을 쓰면 빠르고 싸지만 점수가 내려간다.

|---|---|---|
| P1 | 1990년대 공정 데이터(`data/build/steps_1990.json`): 11공정, 새 숙련 3개, 공정별 결함. 공정 엔진이 시대별 공정 목록을 고를 수 있게 한다 | 10~15만 |
| P2 | 설계 → 공정 계산(시간, 숙련, 시설, BOM, 원가). 빌더에 "생산 계획" 화면을 붙인다. 원가 지수를 이것으로 바꾼다(B5) | 15~20만 |
| P3 | 개발 단계(시제차, 개발 시험, 인증, 생산 준비)와 생산 규모 | 15~20만 |
| P4 | 시설(공정별)과 결함 → 3D 주행 특성 연결 | 15~20만 |
| P5 | 공정 단계별 3D 표현(부분 조립 상태) | 10~15만 |
| P6 | 1930년대 공정을 리스토어 공정으로 전환 | 15만 |
- P1·P2가 먼저다. 빌더 원가가 실제 공정에서 나오게 되고, 경영 연결(B5)의 바탕이 된다.

## 10. 검토받을 것
1. **두 층 구조:** 개발 단계(설계당 한 번) + 제작 공정(차 한 대마다)으로 나눌지
2. **11공정 목록**과 병행(엔진 조립 동시 진행)
3. **생산 규모:** 알파는 주문 제작과 소량 시리즈까지만
4. **시설을 공정별로** 나누고 숙련 3개(복합재, 엔진, 전장)를 더할지
5. **결함이 3D 주행 특성으로 나타나는 것**(6절)
6. **순서:** P1·P2부터
