# 엔진·변속기·구동계 설계 시스템 계획 (검증된 시스템 참고)

> 상태: **계획 보고 단계 — 승인 후 구현.**
> 참고 대상: 이미 검증된 차량 설계 시뮬레이션 *Automation*의 엔진 디자이너·변속기 구조와, 경영 비중이 큰 *GearCity*의 부품별 설계 방식.
> 원칙: **구조(검증된 설계 흐름)는 참고하고, 수식·명칭·UI·수치 데이터는 이 프로젝트에서 새로 만든다.** 외부 게임 데이터는 쓰지 않는다. 검증은 실제 역사 차량 제원으로 한다.

---

## 1. 참고할 점 (검증된 구조) vs 우리 방식

| 검증된 시스템의 구조 | 왜 효과적인가 | GEARHOUSE 적용 |
|---|---|---|
| **엔진 패밀리 → 변형** 2단 구조 (블록·헤드 형식을 정한 "패밀리"에서 보어·스트로크·튜닝이 다른 "변형"을 파생) | 툴링 투자(패밀리)와 상품 다양화(변형)가 경영 판단으로 분리됨 | **패밀리 = 블록 금형 투자**(실린더 수·배열·뱅크각·헤드 형식·블록 재질·최대 보어/스트로크). **변형 = 배기량·압축비·캠·흡기·연료계·회전 한계**. 같은 패밀리 변형은 생산 라인 공유로 원가↓ |
| **부품별 품질 슬라이더** (개발 시간·원가 ↔ 성능·신뢰성 교환) | 단순한 선택지에 "얼마나 공들일지"라는 축을 추가 | **공정 등급** −3…+3 (부품 그룹별: 하체·헤드·흡배기·변속기). +는 개발기간·원가↑, 신뢰성·성능↑. `TECH_PROGRESSION_PLAN`의 성숙도와 합산 |
| **연도에 묶인 기술** | 시대감·연구 동기 | 기술 연표(`invented/mainstream/obsolete`)로 해금 + 노후화 평가 (기존 계획과 연결) |
| **물리 기반 출력** (토크 곡선, 연비, 신뢰성, 진동, 비용, 개발기간) | 숫자가 "그럴듯하게" 움직여 학습이 가능 | §3의 단순화 물리 모델 + 역사 차량 보정 |
| **변속기를 별도 부품으로 설계** (형식·단수·기어비·종감속) | 같은 엔진도 성격이 달라짐 | §4. 형식은 시대 해금, 단수·기어비는 자동 제안 + 수동 조정 |
| **엔진 → 차량 탑재 → 성능 시뮬** 순서 | 설계 결과를 바로 검증 | 엔진룸 **장착 검사**(우리 스프라이트·섀시 좌표계와 직결) → 주행 시뮬 |
| (GearCity) 차대·엔진·변속기 설계를 **각각 별도 제품**으로 관리하고 여러 차종에 재사용 | 플랫폼 전략·원가 경쟁이 경영 게임이 됨 | 엔진 패밀리·변속기·섀시를 회사 자산으로 보관, 차종 간 재사용 시 툴링 할인 (`TECH_PROGRESSION_PLAN` 설계 재사용과 동일 규칙) |

**참고하지 않는 것**: 외부 게임의 UI 배치, 명칭, 부품 목록 수치, 계산식 계수. 모두 아래 공식과 역사 제원 보정으로 새로 정한다.

## 2. 엔진 설계 데이터

### 2-1. 패밀리 (블록 = 툴링 투자)
| 항목 | 선택지 (시대 해금) | 영향 |
|---|---|---|
| 배열 | 직렬 3·4·5·6·8, V6·V8·V12·V16, 수평대향 2·4·6 | 길이·폭·진동·원가 |
| 뱅크각 | 60°/90° 등 (V 배열) | 폭·진동·크랭크 형식 |
| 밸브 기구 | 사이드밸브(L헤드), F헤드, OHV, SOHC, DOHC | 체적효율 상한, 회전 한계, 높이·원가 |
| 블록/헤드 재질 | 주철, 알루미늄 헤드, 알루미늄 블록 | 무게, 원가, 냉각 |
| 최대 보어·스트로크 | 블록 크기 | 변형 배기량 범위, 엔진 길이 |
| 냉각 | 수랭 / 공랭 | 무게, 소음, 기후 이벤트 |

### 2-2. 변형 (튜닝)
보어·스트로크 → 배기량 / 압축비(연료 옥탄 한계 안) / 캠 프로파일(토크형↔고회전형) / 흡기(기화기 수·구경, 다운드래프트·업드래프트) / 배기(단일·듀얼) / 회전 한계 / 크랭크·콘로드·피스톤 재질 / 공정 등급.

### 2-3. 스프라이트 연결 (이미 구현된 생성기와 연결)
엔진 데이터 → 생성기 파라미터: 실린더 피치 = 보어 + 벽두께 → 블록 길이, 스트로크 → 블록 높이, 헤드 형식 → 윗부분 모양 (L헤드: 스터드 헤드 / OHV: 로커커버 + 푸시로드 측판). 1940년대 생성기 `engine40.mjs`(플랫헤드 V8, OHV 직렬6, 변속기)와 `engineSV.mjs`(사이드밸브 직렬4)가 이미 이 방식이다. 같은 데이터가 **엔진룸 장착 검사**(라디에이터~방화벽 사이 길이, 후드 높이)에 쓰인다.

## 3. 엔진 출력 모델 (단순화 물리 + 역사 보정)

| 출력 | 계산 |
|---|---|
| 배기량 | D = π/4 · b² · s · n |
| 토크 곡선 | T(rpm) = (BMEP(rpm) − FMEP(rpm)) · D / 4π |
| BMEP | 열효율(압축비 기반 오토 효율 × 연소 계수) × 체적효율 VE(rpm) × 혼합기 에너지 |
| 체적효율 VE(rpm) | 헤드 형식별 최대값 (L헤드 낮음 → OHV → OHC → DOHC 높음), 캠 프로파일이 정점 rpm 이동, 흡기 유량 한계가 고회전에서 상한 |
| 마찰 FMEP | a + b·평균피스톤속도 + c·평균피스톤속도² (재질·공정 등급 보정) |
| 노킹 한계 | 시대 연료 옥탄 → 허용 압축비 (1930s 약 5.5~6.5 → 1950s 7.5~9 → 1960s 고옥탄) |
| 회전 한계 | min(밸브 서징 한계[헤드 형식], 평균 피스톤 속도 한계[재질·시대]) |
| 연비 | BSFC 맵(부하·rpm) → 차량 주행 사이클에서 적분 |
| 신뢰성 | 응력비(피스톤 속도, BMEP / 재질 한계) × 공정 등급 × 기술 성숙도 |
| 진동(부드러움) | 배열별 1차·2차 불평형 + 점화 간격 (직렬6·V12 최고, 직렬4 2차 진동, 90° V8 양호) |
| 무게·크기 | 실린더 수·피치·재질 → 생성기 치수와 동일 값 |
| 원가 / 개발기간 | 재료 × 무게 + 가공 복잡도(실린더·밸브 수·캠 수) + 패밀리 툴링 (변형은 소액) |

**보정 데이터 (역사 제원, 오차 목표 ±10%)** — 이번 1940년대 차량부터:
| 엔진 | 배기량 | 출력 | 토크 | 비고 |
|---|---|---|---|---|
| 4x4용 L헤드 I4 134ci | 79.4 × 111.1 mm | 60 hp / 4000 | 142 Nm | |
| 6x6용 OHV I6 270ci | 96 × 101.6 mm | 91.5 hp / 2750 | 약 293 Nm | 보어·스트로크·출력 웹 교차 확인 |
| L헤드 V8 221ci (1942 세단) | 77.8 × 95.25 mm | 90 hp / 3800 | 약 212 Nm | |
| L헤드 V8 239ci (1946~) | 81 × 95.25 mm | 100 hp | | |
| L헤드 I8 254.5ci (1948 스텝다운 세단) | | 128 hp | | 웹 확인 |

## 4. 변속기·구동계

### 4-1. 변속기 형식 (시대 해금)
| 형식 | 시대 | 특징 (게임 수치 방향) |
|---|---|---|
| 비동기 수동 (크래시 박스) | 1930 | 저렴, 변속 난이도 높음(편의성↓) |
| 싱크로메시 수동 3·4단 | 1930s~ | 표준. 칼럼 시프트(1939~)는 실내 공간↑ |
| 오버드라이브 부가 | 1930s 후반~ | 순항 연비↑ |
| 반자동·유체 클러치 | 1940s | 편의↑, 효율↓ |
| **유체 커플링 4단 자동** | 1940 | 토러스 + 프런트/리어/리버스 유성기어 3세트 (제공 컷어웨이 그대로 스프라이트화). 효율↓, 무게·원가↑, 편의 최고 |
| 토크컨버터 2·3단 자동 | 1948/50s~ | 부드러움↑, 효율↓ |
| 4단 자동 + 록업, 전자제어 | 1980s~ | 효율 회복 |
| CVT | 1980s 후반~ | 경차 우선 |

설계값: 단수, 1단·최고단 기어비(스프레드), 단 간격(등비/점진), 리버스, 종감속비, 공정 등급, 허용 토크(엔진 토크 이상이어야 장착 가능).
출력: 효율, 무게, 원가, 변속 시간·편의, 신뢰성, 최고속 기어링 적합성.

### 4-2. 구동계
- 배치: FR / FF / RR / MR / **4WD 파트타임(트랜스퍼 2단: 고·저속)** / 6x6 (프로펠러 샤프트 3개, 탠덤 보기).
- 차동: 오픈 → 제한슬립(1950s~).
- 후륜 구동 방식: **토크튜브**(1930~40s 일부) / **호치키스**(리프 스프링이 추진력 전달).
- 트랜스퍼 저속 기어비 → 오프로드·견인·군납 점수.

### 4-3. 주행 시뮬
타임스텝: 구동력 = T(rpm) · 기어비 · 종감속 · 효율 / 타이어 반경, 접지 한계(타이어 형식·하중 배분) 적용 → 구름저항(타이어 규격), 공기저항(차체 생성기의 정면적·형상 계수), 경사.
출력: 최고속, 0→60 mph, 최대 등판 능력, 견인력, 순항 연비. 군용은 등판·저속 견인·도섭이 주요 점수.

## 5. 기존 시스템과의 연결
1. **MechDef** (이번에 만든 `mech40.mjs`의 `spec` 블록): 엔진·변속기·트랜스퍼·종감속·질량이 이미 이 형식으로 기록되어 있다. 설계 결과가 그대로 이 블록을 채운다.
2. **장착 검사**: 엔진 길이·높이 vs 차체의 라디에이터~방화벽 거리와 후드 높이. 같은 mm 좌표라 바로 판정 가능 (실패 시 "후드 높이 부족" 등 안내).
3. **시장 평가**: 성능·연비·편의·신뢰성 → 세그먼트 점수 (`market.mjs`), 현대성 (`TECH_PROGRESSION_PLAN`).
4. **스프라이트**: 엔진·변속기 스프라이트가 데이터에서 생성 → X-ray·분해도·하부 뷰에 자동 배치.

## 6. 구현 순서 (승인 후)
1. `enginesim.mjs`: 패밀리·변형 데이터 구조 + 토크 곡선·회전 한계·진동·원가 계산.
2. 위 보정 표의 실차로 계수 맞춤 (오차 리포트 자동 생성).
3. `gearsim.mjs`: 변속기 형식·기어비 + 주행 시뮬 (최고속·가속·등판·연비).
4. 장착 검사 + 생성기 연결 (엔진 데이터 → 스프라이트 → MechDef).
5. 1930~40년대 차량 전체에 적용, 시대별 엔진 20종 시험 생성 리포트.
