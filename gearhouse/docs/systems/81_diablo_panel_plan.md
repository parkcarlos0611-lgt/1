# 81 · 람보르기니 디아블로 — 패널 분할 제작 계획 (검토 137)

계획만 세운다. 제작은 결정과 자료가 모인 뒤에 한다. EB110에서 배운 순서를 그대로 쓴다:
자료 → 치수·배치 시트 → 패널별 제작 → 겹쳐 보기 → 검수.

## 1. 어떤 디아블로인가
- **권장: 1990년 초기형(후륜구동).** 간디니의 쐐기형이 가장 순수하고, 팝업 헤드램프가 있다.
- 게임에서의 역할: EB110(4륜, 터보, ABS), XJ220(후륜, 터보, 그라운드 이펙트)과 대비되는 **자연흡기 V12 후륜, 전자 장치 없음**.
- 나중에 물리만 바꿔 VT(1993, 비스커스 4륜)를 파생할 수 있다. 차체는 거의 같다.
- 기억하는 제원(시트를 만들 때 자료로 다시 확인한다):

| 항목 | 값 |
|---|---|
| 전장 / 전폭 / 전고 | 약 4460 / 2040 / 1105 mm |
| 휠베이스 | 2650 mm |
| 윤거 앞 / 뒤 | 약 1540 / 1640 mm |
| 타이어 | 245/40 ZR17, 335/35 ZR17 |
| 엔진 | 5.7 L V12 자연흡기, 약 492마력 |
| 변속기 | 5단 수동 |
| 무게 | 약 1,580 kg |

## 2. 쐐기형 디자인 포인트 — 무엇을, 어떻게
EB110은 "둥근 덩어리가 날카로운 경계로 만나는" 차였다. 디아블로는 **평평한 면이 모서리로 만나는** 차다. 그래서 단면을 만드는 방법부터 다르다.

| 디자인 포인트 | 모델에서 만드는 방법 |
|---|---|
| **한 줄 쐐기선:** 코끝에서 지붕 꼭대기까지 거의 한 직선. 보닛과 앞유리의 각도 차이가 작다 | 옆모습 선을 직선 구간 몇 개로 잡고, 꺾이는 곳만 짧게 둥글린다 |
| **캡 포워드:** 앞유리 기슭이 앞 차축 가까이까지 나와 있다 | 시트에서 앞유리 기슭과 꼭대기의 x를 먼저 확정한다 |
| **평면과 모서리:** 보닛, 옆면, 지붕이 거의 평면이고 모서리는 좁게 깎여 있다 | 단면을 "직선 + 좁은 모깎기(2~3점)"로 만든다. 꺾임이 40°를 넘으면 렌더러가 날을 세우고, 모깎기 안쪽은 부드럽게 이어진다 |
| **뒤로 올라가는 벨트라인과 옆 유리 앞쪽의 꺾임** | 도어 패널 윗선을 꺾은선으로, 유리는 별도 패널로 만든다 |
| **뒷바퀴 아치:** 위가 납작하고 비스듬히 잘린 간디니식 아치 | 아치를 반원이 아니라 다각형 윤곽(사다리꼴에 모깎기)으로 자른다 |
| **넓은 뒤 어깨와 흡기구 두 쌍:** 도어 뒤 아래쪽(실 위)과 옆 유리 뒤 위쪽 | 뒤 쿼터를 별도 패널로 만들고, 흡기구는 실제로 파낸다 |
| **엔진 덮개:** 좌우 버트레스 사이의 낮은 골과 루버 | 버트레스와 덮개를 다른 패널로 만들어 골이 생기게 한다 |
| **잘린 꼬리:** 수직에 가까운 검은 램프 패널, 가운데 배기구 4개 | 테일 패널을 오목한 판으로 만들고, 램프는 형상으로 넣는다 |
| **팝업 헤드램프** | 덮개를 별도 패널로 만들고 `lamps` 값(0~1)으로 세운다. 주행 페이지의 램프 스위치와 야간에 연동한다 |
| **시저 도어** | 지금은 닫힌 상태만 만든다. 도어가 별도 패널이라 나중에 여는 동작을 붙일 수 있다 |

모델 규칙 127의 "단면은 곡선으로"는 둥근 차를 위한 규칙이다. 디아블로에는 "평면 + 모깎기" 예외를 규칙에 추가해야 한다.

## 3. 패널 분할 (15개)
1. **앞 범퍼와 코:** 낮은 쐐기 끝, 브레이크 덕트 2개, 방향지시등과 차폭등 띠, 안개등.
2. **보닛(앞 덮개):** 평면. 앞쪽 모서리에 팝업 램프 덮개 자리.
3. **팝업 램프 덮개 2개와 램프 유닛:** 올리면 사각 램프 2개가 보인다.
4. **앞 펜더:** 보닛과 만나는 모서리, 앞 아치.
5. **캐빈:** 크게 누운 앞유리, 지붕, 검은 테두리, 실내(대시보드, 시트 2개, 터널).
6. **도어 2개:** 꺾인 윗선, 옆 유리, 미러.
7. **실(사이드 스커트):** 도어 아래 선반과 아래쪽 흡기구 입구.
8. **뒤 쿼터 2개:** 가장 넓은 어깨, 위쪽 흡기구, 납작한 아치.
9. **버트레스 2개:** 지붕에서 꼬리로 내려가는 날개벽.
10. **엔진 덮개:** 루버가 있는 판.
11. **테일 패널:** 검은 램프 띠(램프는 형상), 배지.
12. **뒤 범퍼와 밸런스:** 그릴, 후진등과 안개등, 배기구 4개.
13. **바닥과 휠 하우스:** 어두운 안쪽 면.
14. **휠 4개:** OZ 5구멍 휠 17인치, 뒤가 훨씬 넓다.
15. **리어 윙(선택 사양):** 기본은 없음. 값으로 켠다.

- 패널 경계는 실차의 분할선을 따른다.
- 만나는 곳은 가장자리 점을 공유하거나 몇 mm 겹쳐서 틈이 없게 한다.
- 예산은 9,000~10,500 삼각형이다. 평면은 삼각형이 적게 드니, 남는 몫을 모서리 모깎기, 램프, 휠, 루버, 흡기구 안쪽에 쓴다.

## 4. 필요한 자료
EB110에서 가장 효과가 컸던 순서대로다.
1. **정사영 렌더 또는 블루프린트:** 옆, 정면, 후면, 평면. 가능하면 치수가 적힌 것.
2. **실차 사진:** 앞 3/4, 뒤 3/4, 팝업 램프를 올린 모습, 옆 흡기구, 엔진 덮개, 뒤 램프 클로즈업.
3. **공식 제원:** 오버행, 윤거, 타이어. 제가 검색해서 확인한다.

Sketchfab은 이 세션에서 열리지 않으니, 이미지는 EB110 때처럼 보내주는 것이 가장 빠르다.

## 5. 순서
1. 자료 수집과 제원 확인.
2. 치수·배치 시트 `data/cars/spec/diablo.json`: 전체 제원, 옆모습 꺾은선, 평면 반폭, 패널별 모서리선, 부품 약 35개.
3. 규칙 추가: 각진 차의 단면(평면 + 모깎기), 다각형 아치.
4. 패널별 제작: Fable 에이전트가 만들고, 옆·정면·후면·평면을 겹쳐 보며 반복한다.
5. 검수: 사진과 대조하고, 주행 화면에서 하이라이트가 모서리에서 직선으로 끊기는지 본다.
6. 게임 등록: 메시 등록, 물리 사양, 핸디캡 시간 측정, 테스트.

## 6. 물리 사양 초안 (6단계에서 확정)
- 후륜구동, 자연흡기 V12, 5단 수동, 뒤 LSD.
- ABS 없음, 파워 스티어링 없음(초기형).
- 앞뒤 더블 위시본.
- 넓은 뒤 타이어와 뒤쪽에 실린 무게 배분.

## 7. 결정이 필요한 것
- 연식: 1990 초기형(권장)인가, VT인가.
- 색: 빨강(권장: 파란 EB110, 은색 XJ220과 구분된다)인가, 노랑인가.
- 리어 윙: 기본으로 달 것인가(권장: 없음, 값으로 선택).
- 순서: EB110 패널 재제작이 통과한 뒤 시작할 것인가(권장: 같은 방식을 검증한 다음 쓴다).

## 8. 1차 제작 결과 (검토 141)
- **시트:** `data/cars/spec/diablo.json`. 부품 32개, 패널 15개, 값마다 근거와 오차를 적었다.
- **모델:** `render/car/mesh_diablo.ts`. 삼각형 9,649개(램프를 올리면 9,601, 윙을 달면 9,689). 아직 게임에 등록하지 않았다.
- **측정에서 확인한 것**
  - 키트 측면도는 가로세로 비율이 맞아서(타이어 318 mm, 실제 314) 옆모습 선에 썼다.
  - 블루프린트는 처음 생각과 달리 세로가 약 3 %만 눌려 있었다.
  - 키트 평면도는 비스듬히 찍힌 사진이라 가로와 세로 배율을 따로 적용했다.
- **옆모습:** 코끝에서 램프 덮개까지 28°, 보닛 12°, 앞유리 21°. 지붕 최고점은 x 2450에서 1105, 꼬리는 x 4384에서 600까지 뒤로 기운다.
- **확인 결과**
  - 측면: 키트에 ±25 mm 안에서 맞는다(앞뒤 범퍼는 GT용이라 다르다).
  - 평면: 블루프린트와 키트에 ±30 mm 안에서 맞는다.
  - 3ds 모델과 나란히 놓으면 사다리꼴 보닛, 팝업 램프, 도어, 흡기구, 쐐기 형태가 같게 읽힌다.
  - 화면: docs/reference/diablo_beside_3ds_141.png, diablo_contact_141.png.
- **남은 차이**
  - 뒤 범퍼가 각진 상자처럼 70 mm 튀어나와 있다.
  - 테일램프가 단순한 사각형이다.
  - 뒷바퀴 아치의 앞쪽 다리가 덜 기울었다.
  - 아래 흡기구가 작다.
  - 미러가 단순한 상자다.
  - 쿼터 유리와 휠 구멍은 뚫은 것이 아니라 덧댄 면이다.
- **자료 한계:** 참고 자료가 모두 GT, GTR, VT/SV다. 1990 초기형의 오버행, 범퍼, 테일램프는 1990년 차 사진으로 확인해야 한다.
