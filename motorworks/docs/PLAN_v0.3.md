# MotorWorks v0.3 계획 — 시작 설정 화면 · 직관적 차량 디자인

목표 두 가지:
1. 새 게임을 시작할 때 **시작 시점 · 본사 국가 · 기업**을 고르는 설정 화면.
2. 차량 디자인을 **기본 디자인 틀(실측 청사진) + 정해진 범위 안의 자유도**로 바꿔, 누구나 직관적으로 만들고 비정상적인 형상은 만들 수 없게.

---

## 1. 새 게임 설정 화면

### 1.1 흐름
`시작 시점 → 본사 국가 → 기업 → 난이도 → 확인(요약)` 4단계 마법사. 각 단계 오른쪽에 그 선택이 무엇을 바꾸는지 미리보기(시장 규모, 임금, 관세, 경쟁사, 대표 차량 실루엣)를 보여 줍니다.

### 1.2 시작 시점
| 시작 | 시대 상황 (게임에서 일어나는 일) |
|---|---|
| 1946 | 전후 공급 부족 시장, 래더 프레임·사이드밸브 시대 |
| 1955 | 미국 풀사이즈 전성기, 유럽 소형차 대중화 |
| 1965 | 머슬카·고속도로, 안전·배출 규제 직전 |
| 1973 | 오일쇼크 직전 — 소형·연비 경쟁 시작 |
| 1985 | FF·전자식 분사·로봇 생산, 아시아 업체 부상 |
| 1995 | SUV 붐, 에어백·ABS 보급, 하이브리드 직전 |
| 2008 | 금융위기 직전, 전기차 태동 |
| 2018 | 전동화 전환기 |

구현: 1946년부터 시작 연도까지 **경쟁 경제만 빠르게 시뮬레이션**(현재 89년에 약 1.7초)해서 그 시점의 경쟁사 라인업·점유율·기술 성숙도를 그대로 만든 뒤 플레이어를 넣습니다. 그래서 어느 연도에서 시작해도 세계가 자연스럽게 이어집니다.

### 1.3 본사 국가
기존 4개 시장권(북미·서유럽·동아시아·신흥시장)은 그대로 쓰고, 국가는 그 안의 **보정치 묶음**입니다.

| 국가 | 시장권 | 국가 특성 (예시) |
|---|---|---|
| 미국 | 북미 | 큰 내수, 높은 임금, 대형차 선호, CAFE 규제 |
| 독일 | 서유럽 | 고급·고속 주행 선호, 숙련 노동, 강한 노조 |
| 영국 | 서유럽 | 1970년대 노사 분규 위험 높음 |
| 프랑스·이탈리아 | 서유럽 | 소형차 선호, 높은 유류세 |
| 스웨덴 | 서유럽 | 안전 평판 보너스, 작은 내수 |
| 일본 | 동아시아 | 1950–70년대 수입 규제 보호, 품질관리(TQM) 조기 도입 |
| 한국 | 동아시아 | 1960–80년대 정부 육성(정책 금융·관세 보호), 낮은 초기 임금 |
| 중국 | 동아시아 | 1990년대 이후 거대 내수, 합작 투자 규제, 2010년대 EV 보조금 |
| 인도·브라질 | 신흥시장 | 저가 소형차 수요, 높은 수입 관세 |

국가별 데이터: 임금 곡선 보정, 내수 보호(국산차 관세 보호 기간), 정부 지원(정책 금리), 노조 강도, 유류세, 시작 평판, 국내 인지도, 사용 가능 연도(예: 한국 1955년 이전 불가, 중국 민간기업 1985년 이전 불가).

### 1.4 기업 선택
- **신생 기업**: 이름·로고 색 지정, 자본금은 난이도별. 전쟁 전 플랫폼 1개(1946) 또는 그 시대 기본 플랫폼 1개로 시작.
- **기존 기업 인수 플레이**: 그 연도까지 살아남은 경쟁사(Columbia, Halvorsen, Brandt, Volkstrom, Kitamura, Sungjin, Tarun …) 하나를 골라 그 회사의 라인업·공장·현금·평판 그대로 경영. 이미 있는 인수 기능(`S.acquireRival`)으로 전환합니다.
- **시나리오** (나중에): 1973 오일쇼크 소형차 회사, 1980 파산 직전 대형차 회사 회생, 2008 EV 스타트업 등.

### 1.5 난이도
자본금, 대출 가산 금리, 경쟁사 공격성(모델 교체 주기·가격 정책), 시장 반응 속도 4개 값의 묶음 (쉬움 / 보통 / 현실 / 하드코어).

## 2. 직관적 차량 디자인 — "틀 + 범위 안의 자유도"

### 2.1 원칙
- 디자인은 항상 **기본 틀(청사진에서 추적한 실제 차)에서 출발**합니다.
- 플레이어는 점을 마음대로 끄는 대신 **의미 있는 조절 항목**(후드 높이, 윈드실드 각도, 루프 높이 등)을 움직입니다.
- 모든 항목에 **현실적인 최소·최대 범위**가 있고, 그 밖으로는 움직이지 않습니다(값이 범위 끝에서 멈춤).
- 고급 사용자를 위해 직접 점 편집은 남기되, 각 점은 **원래 위치 주변 허용 상자 안**에서만 움직이고 순서가 뒤바뀌거나 선이 교차할 수 없습니다.

### 2.2 기본 틀 (템플릿)
청사진마다 **이름 붙은 기준점(랜드마크)** 을 둡니다:

`앞범퍼 하단 · 앞범퍼 상단 · 그릴 상단 · 후드 앞끝 · 후드 중간 · 카울(윈드실드 하단) · A필러 상단 · 루프 최고점 · 루프 뒤끝(C필러 상단) · C필러 하단/데크 시작 · 트렁크 끝 · 테일 상단 · 뒤범퍼 상단 · 뒤범퍼 하단`
+ 유리창(DLO): `A필러 하단 · A필러 상단 · 루프선 앞 · 루프선 뒤 · C필러 하단`
+ 평면: `앞끝 · 앞 휠 · 최대 폭 · 뒤 휠 · 뒤끝`

이 기준점이 모든 템플릿에 같은 의미로 있으므로, 템플릿끼리 섞기(예: 1975 세단 70% + 1985 세단 30%)와 조절 항목이 일관되게 동작합니다.

선택 순서: **차체 형식**(세단 · 해치백 · 왜건 · 쿠페 · 컨버터블 · SUV · 픽업 · 밴) → **시대 틀**(그 형식의 청사진 중 하나, 설계 연도에 맞는 것이 기본) → 조절.

### 2.3 조절 항목과 범위 (초안)
| 그룹 | 항목 | 범위 (기준 틀 대비) | 움직이는 기준점 |
|---|---|---|---|
| 크기 | 전장 | ±8% | 앞·뒤 오버행 중심 |
| | 휠베이스 | ±6% (플랫폼 범위 우선) | 휠 위치, 실내 길이 |
| | 전고 | ±6% | 루프·DLO |
| | 전폭 | ±5% (플랫폼 범위 우선) | 평면 윤곽 |
| 앞 | 노즈 높이 | ±80 mm | 그릴 상단·후드 앞끝 |
| | 후드 길이 | ±150 mm | 카울 위치 |
| | 후드 경사 | 0–8° | 후드 앞끝 |
| | 노즈 형상 | 각진 ↔ 둥근 (0–100) | 범퍼·그릴 곡률 |
| 캐빈 | 윈드실드 각도 | 시대별 범위 (예: 1950 30–45°, 2020 22–32° 수평 기준) | A필러 상단 |
| | 루프 높이 | ±60 mm | 루프점 |
| | 루프 곡률 | 평평 ↔ 둥근 | 루프 중간점 |
| | 루프 길이 | ±120 mm | C필러 상단 |
| 뒤 | 뒷유리 형태 | 노치백 ↔ 패스트백 (형식 범위 안) | C필러 하단·데크 |
| | 트렁크 높이 | ±70 mm | 데크·테일 |
| | 테일 형상 | 수직 ↔ 경사 | 테일 상단 |
| 측면 | 벨트라인 높이 | ±50 mm | DLO 하단 |
| | 캐릭터 라인 | 높이·유무 | (그리기만) |
| | 휠 아치 | 원형·각형·플레어, 틈 20–60 mm | 아치 |
| 스타일 부품 | 헤드램프·그릴·범퍼·테일램프·휠·미러·몰딩 | 시대별 카탈로그에서 선택 | (그리기만) |

각 항목은 해당 기준점들을 **부드러운 감쇠(falloff)** 로 함께 움직여서 곡면이 항상 매끄럽게 유지됩니다.

### 2.4 형상 검증 (자동으로 막거나 경고)
| 종류 | 규칙 |
|---|---|
| 기하 | 윤곽선 자기교차 금지, 점 순서 유지, 최소 곡률 반경, 날카로운 꺾임 각도 제한 |
| 패키징 | 앞좌석 머리 공간(H-포인트 기준 ≥ 900 mm), 엔진룸 길이·높이, 트렁크/적재 최소, 휠 스트로크 대비 아치 여유 |
| 시야 | 윈드실드 최소 높이, A필러 사각 각도 |
| 규제 | 범퍼 높이(1974년 이후 북미), 헤드램프 높이, 보행자 보호 후드 여유(2005년 이후 유럽) |
| 생산 | 패널 성형 깊이 vs 강판 성형 한계(이미 구현) |

막는 규칙은 값이 범위에서 멈추고, 경고 규칙은 설계는 허용하되 평가·원가에 반영합니다.

### 2.5 화면 구성
- 왼쪽: 템플릿 고르기(형식 → 시대 틀 썸네일).
- 가운데: 측면·평면 뷰포트. 조절 항목에 마우스를 올리면 영향을 받는 부위가 강조됩니다.
- 오른쪽: 조절 항목 슬라이더(그룹별) + 스타일 부품 선택 + 검증 결과.
- 되돌리기/다시하기, "기준 틀로 초기화", 경쟁차 실루엣 겹쳐 보기.
- 현재의 자유 점 편집은 "고급 편집" 토글 안으로 옮기고 허용 상자 제약을 적용.

## 3. 작업 순서
1. 랜드마크 형식 정의, 기존 16개 프리셋을 랜드마크 형식으로 변환.
2. 조절 항목 → 랜드마크 변형 엔진 (감쇠, 범위 고정, 검증).
3. 디자인 화면 개편 (템플릿 선택, 슬라이더, 고급 편집 제약).
4. 청사진이 들어오는 대로 추적 → 템플릿 추가/교체 (`docs/BLUEPRINTS.md` 목록 기준).
5. 국가·시작 연도 데이터, 경쟁 경제 선행 시뮬레이션, 새 게임 마법사.
6. 기존 기업으로 플레이, 난이도.
7. 밸런스 점검 (`tools/simcheck.js`를 시작 연도·국가별로 확장).
