# E2 (1940–1949) 제작 계획서 — 시대 특징(기술·디자인) · 자료 요청 · 진행 절차

> 진행 원칙 (사용자 지시): **① 시대 특징 계획 → ② 자료 제공 요청 → ③ 받은 자료 분석 + 추가 자료 탐색 → ④ 제작 착수.**
> 현재 단계: ①·② 완료, ③ 대기. 앞서 만든 1940년대 생성기 한계값과 미리보기(`samples/e2_generator_preview.png`)는 **임시값**이며 ③의 실측 결과로 다시 보정한다.

## 1. 시대 구분 (게임 연표)

| 구간 | 산업 상황 | 디자인 | 게임 처리 |
|---|---|---|---|
| **1940–41 전전 절정** | 생산 최대, 연식 변경 경쟁 | 앞펜더가 문으로 흐르기 시작, 펜더 매립 헤드램프, 러닝보드 소멸·은폐, 와이드 가로 그릴, 알리게이터 후드 | 1930s 말 스타일 연장 + 신기술 해금 집중 |
| **1942 단축 연식** | 1942년 2월 9~22일 사이 미국 민수 승용차 생산 중단 | 크롬 부족 → 도장 트림("블랙아웃" 모델), 문까지 이어지는 펜더 | 1942년 2월 이벤트: 민수 생산 중단, 재고 판매만 |
| **1942–45 전시** | 공장이 군수로 전환(항공기 엔진, 전차, 트럭, 경 4x4) | 기능 위주 군용 차체(평면 패널, 캔버스, 노출 섀시) | **군납 계약 세그먼트**(경 4x4·트럭·지휘차·앰뷸런스), 연구 가속(4WD, 고옥탄, 대량생산 기술), 민수 개발 동결 |
| **1945–48 전후 재개** | 1945년 10~11월 생산 재개, 전전 1942년형 재생산, 자재·철강 부족 | 1942년형 + 소폭 변경(그릴·트림) | 전전 설계 재사용(개발비 할인), 자재 부족으로 생산량 상한, 높은 수요 |
| **1947–49 신세대** | 1947년 첫 완전 신설계, 1948~49년 주요 회사 신형 | **풀 폰툰/슬래브 사이드**, 수평 벨트라인, 노치백, 2분할 앞유리, 테일핀 시작(1948) | 새 디자인 언어 `pontoon`, 프롭 대거 해금 |
| **유럽·일본 (참고)** | 전쟁 피해, 1945~49년 소형 국민차 중심 재건 | 소형 리어엔진·FF 이코노미카, 경량 로드스터 | 국가별 시장(연료비·세제)에 따라 소형차 수요 급증 |

## 2. 디자인 특징 → 생성기·프롭 반영 계획

| 특징 | 시기 | 반영 위치 |
|---|---|---|
| 펜더가 문 안까지 이어짐 (반폰툰) | 1941–48 | `stream` 펜더 `pontoonF` + **문 위로 이어지는 펜더 라인** 신규 |
| 풀 폰툰/슬래브 사이드 (펜더 완전 통합) | 1946/47–49 | `pontoon` 언어: 차체 아치만, 수평 벨트, 앞펜더 크리즈 |
| 러닝보드 소멸 → 문 아래 은폐 스텝 | 1940–42 | 보드 없음 + 로커 몰딩 |
| 펜더 매립 실드빔 헤드램프 | 1940+ | 헤드램프 프롭: 펜더 매립 원형(7in 표준), 크롬 링 |
| 알리게이터 후드 (앞쪽 경첩, 위로 열림) | 1940s | 후드 분할선이 측면에서 사라짐 → 측면 루버 감소 |
| 와이드 가로 그릴, 다층 바, 이빨형 그릴 | 1940–49 | 그릴 프롭 신규 세트 |
| 2분할 V 앞유리 (평판 2장) | 1940s 전반 | 앞유리 프롭 + 경사 한계 |
| 펜더 스커트, 크롬 스피어, 항공기 모티프 오너먼트 | 1940s | 스커트·트림·마스코트 신규 |
| 패스트백 "세다넷" / 노치백 세단 | 1941–49 | 꼬리 형태 `fastback` / `trunk(notch)` |
| 테일핀의 시작 (작은 리어펜더 핀) | 1948–49 | 고급 세그먼트 뒤펜더 옵션 |
| 우디 왜건 (목재 패널 바디) | 1940s | 왜건 차종 + 목재 패널 소재 |
| 군용: 평면 패널, 캔버스 탑, 노출 섀시, 무광 올리브 | 1941–45 | 군용 차종 템플릿 + 군용 팔레트 |

## 3. 기술 특징 → 연구·부품 카탈로그 반영 계획

| 기술 | 등장 (확인 상태) | 게임 반영 |
|---|---|---|

| 완전 자동변속기 (유체 커플링 + 유성기어) | 1940 (추가 확인 예정) | 변속기 `auto4_fluid`, 비용·연비 페널티, 편의 점수↑ |
| 반자동·유체 클러치, 오버드라이브 보급 | 1940s | 변속기 옵션 |
| 칼럼 시프트 | 1939–40 | 3인 벤치시트 → 실용성↑ |
| 미국 첫 양산 유니바디 | **1941 (확인)** | 섀시 `unibody` 해금 (무게↓, 강성↑, 툴링비↑) |

| 래디얼 타이어 | **1946 특허, 1949 판매 (확인)** | 타이어 `radial`(유럽 우선): 그립·수명↑, 승차감↓ |
| 15인치 저압 타이어 | 1949 전후 | 타이어 규격 `6.70-15` 등 → 차고 낮아짐 |
| 공조(에어컨) | 1940 전후 (추가 확인 예정) | 고급 옵션 |
| 전시 기술 이전: 4WD 트랜스퍼, 고옥탄, 대량생산 | 1941–45 | 군납 경험치 → 연구 보너스 |
| 독립 앞서스 표준화, 토션바(유럽) | 1940s | 서스 옵션 |
| 공랭 수평대향 리어엔진, FF 소형차 | 1940s 유럽 | 레이아웃 RR/FF 이코노미 |

## 6. 진행 절차 (③·④)

| 단계 | 내용 | 산출물 |
|---|---|---|
| ③-1 자료 분석 | 받은 자료를 격자로 측정, 비율 규칙과 디자인 패턴 정리 | `REFERENCE_ANALYSIS_E2.md` |
| ③-2 추가 탐색 | 부족한 세그먼트·부품을 허용 사이트에서 수집, 제원 교차 확인 | 측정표 갱신 |
| ③-3 한계값 보정 | 박스형·유선형·폰툰 연도별 한계를 실측값으로 교체 (현재 임시값) | `bodygen` 갱신 |
| ④-1 복제 차량 | 세그먼트당 1종 이상, 4면 + X-ray + 하부 | `samples/e2_*` |
| ④-2 프롭 배치 A·B | 약 220종 (§2 신규 프롭 + 군용 프롭) | 카탈로그 JSON |
| ④-3 조립 테스트 | 무작위 조합 20대 + 군납 차량, 고립 요소 자동 연결 검증 | 조립 리포트 |
| ④-4 시장·이벤트 | 전시 생산 중단·군납 세그먼트·전후 수요 급증 연결 | 시장 모듈 갱신 |
