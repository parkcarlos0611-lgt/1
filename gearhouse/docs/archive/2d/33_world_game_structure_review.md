# 검토 33 — 게임 전체 구조: 하나로 이어진 "세계"

기획자 구상(2026-11-20)을 검토한다. 요약하면:
- 전부 90년대풍 고품질 픽셀아트.
- 회사 앞(정면, 도로와 차고, 하늘, 계절과 날씨, 비 오면 물이 고이고 비침). 손님이 차를 타고 와 세우고 걸어와 노크한다. 받거나 안 받는다.
- 집 안(주방과 탁자). 대화 선택지로 상담하고, 차·커피를 내오면 선택지가 다시 찬다(최대 2번).
- 전화번호부와 다이얼 전화로 식료품점, 공업사, 기업사에 주문한다. 배달차가 온다. 돈이 없으면 평판이 깎인다.
- 차고(가장 작아도 2칸): 수리, 의뢰 제작, 자작. 부식을 철수세미로 긁고, 메우고, 칠한다. 마스킹 테이프. 부품 교체는 공업사를 뒤져 맞는 부품을 찾는다.
- 인도는 직접 몰고 가거나 컷신. 결산표.
- 공방 방(설계도, 스탠드, 책장, 창, 낡은 침대). 도면 → 자재 목록 → 전화 주문 → 예상도(콘셉트 그림) → 제작 → 도색 → 조립 → 시험 주행.
- 자작은 자유롭게(삼륜차에 V8, 안 들어가면 튀어나옴). 작은 사무실에서 시작해 지도에서 땅을 사 공업사로 커진다.

## 1. 결론

1. **좋은 방향이다. 지금까지의 게임보다 훨씬 팔릴 만한 모양이다.** 지금 만든 것은 "책상에서 서류로 하는 경영 게임"이고, 이 구상은 "손으로 만지는 1930년대 작업장 생활 게임"이다. 다이얼 전화, 부식 긁기, 마스킹 테이프처럼 손맛이 있는 동작이 게임의 얼굴이 된다.
2. **앞에서 말한 것과 대부분 맞고, 세 군데는 바뀐다**(3장). 바뀌는 것 중 가장 큰 것은 시간 속도다.
3. **구현은 모두 가능하다.** 가장 큰 위험은 코드가 아니라 그림(특히 사람 스프라이트)과 분량이다(4장).
4. **다 만들면 중상급 인디 게임의 깊이다.** 다만 전부를 한 번에 만들면 끝나지 않는다. "수리 한 건을 처음부터 끝까지" 도는 작은 고리부터 만들어야 한다(6장).

## 2. 왜 좋은가

| 구상 | 강점 | 비슷한 재미를 주는 게임 |
|---|---|---|
| 서류 대신 장소(집 앞, 주방, 차고, 공방) | 메뉴가 아니라 세계에 있는 느낌. 날씨와 시간이 눈에 보인다 | Stardew Valley, My Summer Car |
| 다이얼 전화와 전화번호부 | 한 번 보면 기억나는 장치. 광고·신문·명부 시스템이 모두 여기로 모인다 | My Summer Car(우편 주문), Strange Horticulture |
| 부식 긁기 → 메우기 → 칠하기 | 픽셀 단위로 결과가 남는 손작업. 대충 하면 반년 뒤 손님이 돌아온다 | PowerWash Simulator, Car Mechanic Simulator |
| 맞는 부품 찾아 발품 | 200종 부품 데이터가 "수집·탐색"의 재미가 된다 | Jalopy, Car Mechanic Simulator(폐차장) |
| 예상도를 손님에게 보내기 | 설계와 손님 반응 사이의 중간 확인. 만들기 전에 기대가 생긴다 | Automation(디자인) |
| 삼륜차에 V8 | 웃기고 자랑하고 싶은 결과물. 스크린샷이 퍼진다 | Automation, Kerbal |
| 작은 집에서 시작 | 모든 미니게임을 처음부터 직접 한다. 커지면 직원에게 맡긴다 | — |

시대 고증도 잘 맞는다: 마스킹 테이프는 1925년에 자동차 투톤 도장용으로 나온 물건이고, 당시 판금 메움은 납땜 메움(산성 플럭스 + 납), 도장은 스프레이건과 래커였다. 다이얼 전화는 1930년대 미국 도시에 있었다(작은 읍은 교환수 연결이 흔했으나, 게임에서는 다이얼로 둔다).

## 3. 지금까지의 방향과 맞는가

| 항목 | 지금까지 | 이번 구상 | 판단 |
|---|---|---|---|
| 화풍 | 시대 소품형 픽셀아트 UI(검토 27) | 화면 자체가 장소 | 맞음. 한 걸음 더 나아간 것 |
| 차 | 한 대 = 입체 부품 모델, 부품은 차마다 고유 | 부품별 수리·교체·탐색, 5면 도색 | 맞음. 부품 모델이 바로 이 용도 |
| 도면 화면 | 주문 체크리스트, 빨간 수정선 | 공방 방의 설계도를 눌러 진입, 의뢰/자작 선택 | 맞음. 이미 있음 |
| 외장 단계 | 도면 다음 "외장 설계"(검토 26) | 예상도(콘셉트 그림)에서 세부 선택 | 맞음. 외장 탭이 예상도가 됨 |
| 주행 | 옆에서 보는 출렁이는 주행(시험 주행장) | 차선 있는 사이드뷰 주행·배달 | 맞음. 계획의 "위에서 보는 주행"(시제품 ④)은 뺀다 |
| 경영 코어(주문, 공급사, 장부, 평판, 신문, 날씨) | 코드와 테스트 있음 | 전화, 배달, 평판, 날씨가 그대로 쓰임 | 맞음. 입구만 장소로 바뀜 |
| **시간** | 하루 8초(REBOOT_PLAN) | 천천히 흐르는 하루 | **바뀜** (5장 1번) |
| **제작** | 9공정이 시간 게이지로 찬다 | 손으로 하는 미니게임 | **바뀜**: 손작업 결과가 품질이 됨. 게이지는 직원에게 맡긴 일에 남긴다 |
| **시작** | 차체 주문 제작으로 시작, 수리점 시작은 단계 3 | 수리(싼 차)로 시작, 제작(비싼 차)은 그 위 | **바뀜**: 순서가 뒤집힘. 입문에는 이쪽이 낫다 |
| 가족과 승계, 큰 회사 "결정만" 화면 | 단계 4 | 언급 없음 | 유지 가능: 커지면 손작업을 직원에게 넘기는 흐름과 잘 맞는다 |

지난 통합 단계에서 만든 것은 그대로 쓴다. 장면 관리자는 "집 앞 → 집 안 → 차고 → 공방"을 오가는 바로 그 틀이고, 픽셀 책상의 목록·카드는 공방 책상 위의 편지함·장부가 된다.

## 4. 구현 가능성

| 요소 | 난이도 | 근거 |
|---|---|---|
| 집 앞 장면: 하늘, 계절, 시간대, 비·눈, 물 고임과 반사 | 중 | 날씨 계산은 이미 있다(core/weather). 비·물웅덩이·반사는 규칙으로 그리는 효과라 잘 맞는다 |
| 손님 차가 와서 서는 것 | 하 | 차 옆모습 렌더러와 주행 장치가 있다 |
| **사람 스프라이트(여러 방향 걷기, 손님 다양성)** | **상** | 규칙으로 그리는 방식이 가장 약한 곳. 5장 3번 |
| 집 안 상담: 대화 선택지, 차·커피로 충전 | 하~중 | 코어의 상담(횟수 제한, 예산·필수 조건 드러남)에 그대로 얹힌다 |
| 전화번호부, 다이얼, 주문, 배달차 | 중 | 마을 명부(core/register), 공급사, 광고가 있다. 다이얼·신호음·벨은 합성음으로 된다 |
| 부식 수리(긁기·메우기·칠하기·마스킹) | 중 | 부품마다 픽셀 층(철판, 부식 깊이, 메움 두께, 도막 색·두께, 마스킹)을 두면 된다. 부품 그림과 5면 보기가 이미 있다 |
| 부품 교체와 공업사 탐색 | 중 | 구조는 쉽다. 내용은 차종 수에 달렸다(지금 1대) |
| 예상도 | 하~중 | 같은 모델을 다른 화풍(굵은 선, 낮은 해상도, 깨끗한 종이)으로 그리는 렌더러 하나 |
| 엔진·변속기·구동계 카탈로그, 성능 | 중~상 | 계산 물리(시제품 ②)가 5%. 1차판 공식 이식이 먼저 |
| 자유 조합(안 들어가면 튀어나옴) | 중 | 부품 상자와 맞춤 검사가 있다. 안 맞는 부품을 차체 위에 그리면 된다 |
| 사이드뷰 월드 주행·배달 | 상 | 주행 장치는 있으나 마을(도로, 교차로, 차선, 다른 차)이 새로 필요. 컷신 먼저 |
| 지도, 땅 구매, 회사 확장과 외형 변화 | 중~상 | 뒤 단계 |
| 고품질 효과음 | 중 | 다이얼, 벨, 연필은 합성 가능. 테이프, 스프레이, 엔진의 질감은 녹음 음원(라이선스)이 낫다 |

**가장 큰 병목은 둘이다.**
1. **차종 수**: 부품 탐색과 "유선형 바디 A" 분류는 차가 많아야 산다. 지금은 1929 세단 한 대다. 첫 고리에는 3~5대면 된다.
2. **그림 분량**: 집 앞 한 장면만 해도 계절 4 × 날씨 3 × 시간대가 있다. 층(하늘, 건물, 땅, 효과)을 나누고 색과 효과로 바꾸면 그림 수를 줄일 수 있다.

## 5. 정해야 할 것과 위험

1. **시간 모델.** 하루 8초와 "천천히"는 함께 갈 수 없다. 추천:
   - 장면 안에서는 게임 1시간 ≈ 실제 30~40초(하루 약 6~8분).
   - 작업(긁기, 칠하기, 전화)이 게임 시간을 쓴다.
   - 침대 = 자고 다음 날로(저장). 할 일이 없는 날은 넘기기.
   - 5년 조각은 너무 길다. 첫 조각은 1930년 한 해로 줄인다.
2. **손작업과 능력치.** 코어에는 창업자 기술 수치가 있다. 추천: 결과는 플레이어의 손이 정하고, 기술은 도구의 너그러움(붓 크기, 허용 오차, 작업 시간)을 정한다. 직원에게 맡긴 일은 기술 수치와 시간 게이지로 한다.
3. **사람 그림.** 내가 코드로 그리는 사람은 "90년대 고품질" 기준에 못 미칠 가능성이 높다. 추천: 차 시트처럼 기획자가 사람 시트(앞·뒤·옆 걷기)를 주고, 몸 몇 벌에 옷·색을 바꿔 손님을 늘린다. 방향은 4방향(옆은 뒤집기)부터.
4. **반복 피로.** 긁기·칠하기·다이얼은 처음엔 재미있고 열 번째엔 일이다. 추천: 도구 업그레이드(전동 공구, 큰 스프레이건), 직원 위임, 단골 번호 메모(전화기 옆 쪽지를 누르면 바로 다이얼), 부품이 없을 때 "어디 가 보라"는 힌트.
5. **분량.** 서로 다른 시스템이 25개쯤이다. 한꺼번에 넓히면 지난번 지적하신 "붙여 나가는 낭비"가 다시 생긴다. 6장의 순서를 권한다.
6. **휴대폰.** 장소 화면은 큰 물건을 누르는 방식이라 지금의 작은 버튼 문제(UI 검사 경고)가 오히려 줄어든다. 미니게임(긁기, 테이프)은 터치와 잘 맞는다.

## 6. 추천하는 만드는 순서

먼저 위험이 가장 큰 두 가지를 작은 견본으로 확인한다. 둘 중 하나라도 기대에 못 미치면 구상을 고쳐야 하기 때문이다.

| 순서 | 만들 것 | 확인하는 것 |
|---|---|---|
| A | **집 앞 장면 견본**: 하늘·시간대·비와 물 고임, 손님 차가 와서 서고, 손님이 걸어와 노크, 받기/안 받기 | 그림 품질이 "90년대 고품질"에 닿는가 (가장 큰 위험) |
| B | **부식 수리 견본**: 1929 세단의 한 부품에서 긁기 → 메우기 → 마스킹 → 칠하기, 점수 | 손작업이 재미있는가 (게임의 핵심) |
| 1 | 수리 한 건 고리: 노크 → 주방 상담(차·커피) → 차고 수리 → 인도 컷신 → 결산표 | 첫 "한 바퀴" |
| 2 | 전화번호부·다이얼·배달차·부품 교체 | 세계가 이어지는가 |
| 3 | 공방 방 → 도면(있음) → 자재 목록 → 예상도 | 제작 의뢰 입구 |
| 4 | 제작 공정(철판, 엔진, 도색, 조립) → 시험 주행(있음) | 제작 한 바퀴 |
| 5 | 엔진 카탈로그와 성능 계산, 자유 조합 | 자작의 자유도 |
| 6 | 직원과 위임, 차고 확장, 지도와 땅 | 성장 |
| 7 | 사이드뷰 월드 주행·배달 | 세계 넓히기 |

직전에 추천했던 순서(견적 답장 → 공급사 주문 → 주간 계획 …)는 서류 화면 기준이라 이 구상과 맞지 않는다. 이 표로 바꾼다.

## 7. 다 만들면 어떤 게임인가

- **자유도**: 수리 방식(긁기/교체, 대충/꼼꼼), 설계(차체 형식, 치수, 부품), 구동계 조합, 외장, 회사 성장 경로. Automation의 설계 자유도보다는 얕고, 대신 손으로 만드는 과정과 생활이 있다.
- **깊이**: 대충 한 수리가 반년 뒤 돌아오는 것, 평판, 부품 탐색, 손님 요구 해석, 날씨 영향, 돈. 서로 영향을 주는 고리가 여럿이라 "세계"로 느껴질 만하다.
- **출시 가능성**: 가능하다. 1.0의 현실적인 크기는 마을 하나, 집과 확장 2단계, 차 20~30종, 미니게임 6~8개, 1930~35년 정도. 순서 1~4까지가 "앞서 해보기"로 낼 수 있는 최소 크기다.
- **차별점**: 1930년대, 픽셀아트, 다이얼 전화, 손으로 하는 판금·도장. 이 조합의 게임은 내가 아는 한 없다.
