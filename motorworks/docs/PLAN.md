# MotorWorks — 설계 문서 & 로드맵

2D 사이드뷰/탑뷰 자동차 회사 경영 시뮬레이션. 엔진·차량 설계의 깊이는 Automation 수준을 기준선으로 삼고, 그 위에 **생산 공정, 회사 경영, 판매망, 평가**를 같은 정밀도로 얹는 것이 목표다.

실행: `motorworks/index.html`을 브라우저로 열면 된다 (빌드 없음, 순수 JS + Canvas).

## 1. 지금 구현된 것 (v0.1)

### 1.1 시대 시스템 (1946 → 2035)

| 역사적 사건 | 한국전쟁 철강 통제, 1958 불황, 1·2차 오일쇼크, 아시아 외환위기, 2008 금융위기(신용경색), COVID, 반도체 부족 | 〃 |

### 1.2 엔진 설계 (`src/sim/engine.js`)
- 레이아웃: 직렬 1–8, V 2–16 (뱅크각 45/60/72/90/120°), 수평대향 2–12, W 8–16. 가솔린/디젤.
- 보어·스트로크 → 배기량, 피스톤 평균속도 한계, 밸브 서징 한계, 보텀엔드 한계로 최대 rpm 결정.
- 헤드: 사이드밸브 → OHV → SOHC → DOHC, 2/3/4/5밸브, 가변밸브(VVT·VVL·연속가변).
- 흡기: 1·2·4배럴 카뷰레터, 기통별 멀티 카뷰, 기계식 분사, TBI, MPFI, GDI, 디젤 IDI/TDI/커먼레일. **유량 한계(m³/s)** 로 카뷰레터 병목을 재현.
- 과급: 슈퍼차저(기생손실), 싱글/트윈/VGT 터보(스풀 rpm), 인터쿨러.
- 시대 옥탄가 기반 **노킹 한계 압축비** → 점화 지각 출력 손실 + 신뢰성 저하.
- VE 곡선 × BMEP × 오토사이클 효율 − FMEP(마찰) → 250rpm 간격 토크/출력 곡선.
- BSFC, 배출가스 지수(촉매 효율, 공연비), 밸런스(레이아웃·기통별 1·2차 진동표 + 밸런스 샤프트), 중량, 크기, 원가, 조립 공수, 신뢰성, 개발 기간·비용.

### 1.3 차량 설계 (`src/sim/car.js`)
- 차체 = 측면 상단 윤곽 스플라인 + 그린하우스(글라스) 다각형 + 평면도 반폭 스플라인. 11개 시대별 원형(펜더 세단, 테일핀, 박스, 에어로, 해치백, 왜건, 쿠페, 미드십, 픽업, SUV, 미니밴)에서 시작해 **점을 끌어 자유 변형**.
- 형상 해석: 윈드실드 경사, 노즈 높이, 노치/패스트백, 보트테일, 표면 굴곡 → **Cd**, 전면적, 실내 체적, 트렁크 용량, 패널 면적, 성형 난이도, 시야, 무게중심 높이.
- 강판 8종 × 가격 등급 3단계 (연강 0.7/0.9/1.1mm, 아연도금 편면/양면/GA, HSLA 340–590MPa, DP780–TRIP1180, 핫스탬핑 보론강, 알루미늄 5xxx/6xxx, FRP, CFRP). 밀도·두께로 패널 중량, kg당 단가, 가공 공수, 금형비, 방청, 강성, 충돌 성능이 갈린다.
- 프레임 5종, 앞/뒤 서스펜션 7/9종, 브레이크 5종, 타이어 6종 + 폭·편평비·림, 변속기 13종(수동 3–6, 자동 2–10, CVT, DCT), 구동 6종, 실내 6등급, 편의·안전 장비 9계열.
- 시뮬레이션: 기어비 자동 산출 → 0.02s 스텝 종방향 적분(토크컨버터 증배, 하중이동·견인 한계, 변속 시간) → 0-100, 0-400m, 최고속도. 제동거리, 횡가속도, 도시/고속 연비(L/100km·mpg).
- 10개 평가 항목을 **그 시대 기대치 대비**로 정규화 (1950년 0-100 17초는 "보통").

### 1.4 생산 (`src/sim/company.js`, `src/render/factoryRender.js`)
- 공정 5단계 × 시대별 세대: 프레스(수작업 판금 → 단동 → 탠덤 → 트랜스퍼 → 서보/핫스탬핑), 용접(가스·리벳 → 스폿 → 멀티스폿 → 로봇 → 레이저 → 기가캐스팅), 도장(래커 → 에나멜 → 전착 → 로봇 → 수성), 조립(정치식 → 컨베이어 → 린/JIT → 모듈 → 고자동화), 검사(육안 → SPC → TQM → 머신비전 → AI).
- 각 공정이 대당 공수, 결함률, 검출률, 설비비, 방청, 광택을 결정 → 지역 시급과 곱해 **제조원가**, 출고 결함률 → 신뢰성·리콜.
- 공장 건설 12개월, 라인 증설, 공정 교체(1개월 중단), 모델별 금형·지그 비용, 재고 3개월 초과 시 감산, 레이오프가 느린 노무비(가동률 60% 하한).
- 탑뷰 공장 애니메이션: 실제 설계한 차의 평면 실루엣이 프레스 → 용접 로봇 불꽃 → 도장 부스 → 조립 → 검사를 지나간다. 작업자 수는 공수에 비례.

### 1.5 경영·판매·평가
- 시장: 지역 × 세그먼트별 로짓 선택. 경쟁사 8개(시대별 진입·실력 곡선·성향) + 비모델링 업계 평균. 유가 부담이 연비 가중치를 키운다(오일쇼크 때 이코노미 수요 급증).
- 딜러망 커버리지, 브랜드 인지도(광고비 ÷ 시장 규모 + 입소문), 평판(출고 신뢰성 + 언론 평점), 수입 관세·운송비, 규제 위반 시 판매 불가.
- 리콜(1966년 이전은 보증수리 캠페인), 차체 부식 소문, 딜러 이탈.
- 재무: 손익계산서(전년 비교), 재무상태표, 감가상각 20년, 법인세(이월결손금), 신용한도·레버리지 연동 금리, 10년 분할상환 대출, 4개월 현금 부족 시 파산.
- 언론 평가 3개 매체(성향 다름): 점수, 한 줄 평, 장단점.

### 1.6 그래픽
- **강판 텍스처 가공**: 재질별 절차적 텍스처(연강 밀스케일, 아연 스팽글 결정, 보론강 Al-Si 코팅, 헤어라인 알루미늄, 유리섬유, 2×2 트윌 카본). 사용자가 이미지를 올리면 그 텍스처를 쓴다. 텍스처는 차체 윤곽을 따라 **삼각형 메시 아핀 워프**로 변형된다 — 판재가 형상에 맞게 늘어나는 것처럼. 그 위에 도장(공정별 오렌지필, 메탈릭 플레이크), 곡면 음영, 캐릭터 라인 프레스 자국, 패널 갭.
- 시대별 디테일: 화이트월/허브캡 → 스포크 알로이, 크롬 범퍼 → 일체형, 원형 → 각형 → 프로젝터 → LED 램프, 1940s 독립 펜더.
- **엔진**: 1기통 분량의 세그먼트 텍스처(블록 + 헤드 + 커버, 재질·헤드 형식별)를 코드로 생성하거나 업로드받아 **기통 수만큼 타일링**. 측면도(타이밍 벨트, 흡기, 카뷰/인젝터, 터보·슈퍼차저, 인터쿨러, 배기 매니폴드, 컷어웨이 피스톤), 정면 단면(뱅크각대로 실린더 배치, 점화순서대로 움직이는 피스톤·커넥팅로드·크랭크, 연소 플래시, 캠).

## 2. Automation 대비 "그 이상"을 확보하는 계획

Automation은 엔진·차량 설계에 집중하고 경영(Tycoon 모드)은 얕다. MotorWorks는 설계 깊이를 맞추면서 아래 영역에서 앞서는 것을 목표로 한다.

### Phase 2 — 설계 정밀도 (Automation 동급 이상)
1. **엔진**
   - 크랭크 형식(크로스플레인/플랫플레인), 점화순서 선택 → 배기 맥동·사운드·진동 차이.
   - 흡배기 런너 길이·플레넘 체적 → 공진 과급(1D 파동 근사)으로 VE 곡선에 국소 피크.
   - 캠 프로파일을 듀레이션·리프트·LSA 3변수로 분리, 오버랩에 따른 아이들 품질.
   - 로터리, 2행정, 수소, **하이브리드(직병렬)·BEV**: 배터리 화학(납·NiMH·NMC·LFP·전고체), 셀 단가 학습곡선, 모터(유도/영구자석), 인버터(Si→SiC), 충전 인프라 보급률.
   - 엔진 패밀리: 하나의 블록에서 배기량 변형 → 개발비 절감(실제 업계 관행).
2. **차체**
   - 패널 단위 분할(후드, 펜더, 도어, 루프, 트렁크): 패널마다 강판 재질·두께 지정 → **테일러드 블랭크**.
   - 패널별 성형 깊이로 **성형한계도(FLD)** 판정 — 깊게 당긴 패널은 고급 딥드로잉 강판이 필요, 실패 시 주름·파단 스크랩률.
   - 텍스처 매핑을 패널별 UV로 고도화, 성형 시 판두께 감소를 텍스처 늘어남으로 시각화.
   - 2D 패널법(포텐셜 유동)으로 측면 윤곽에서 양력·항력 계산, 스포일러·디퓨저.
   - 2D 간이 FEM 정면/측면 충돌 → NCAP 별점, 크럼플 존 길이를 형상에서 직접 측정.
   - 3/4 뷰 합성 렌더(측면+평면 프로파일 로프트).
3. **섀시**: 서스펜션 하드포인트(롤센터, 캠버 게인), Pacejka 타이어, 가상 테스트 트랙 랩타임, NVH 주파수.

### Phase 3 — 생산 (Automation에 없는 영역)
- **라인 밸런싱**: 공정별 택트타임, 병목 공정 표시, 교대제(1·2·3교대), 잔업.
- 스폿 용접 타점 수, 도장 공정 단계(전처리-전착-실러-중도-상도-클리어), 각 단계 오븐 에너지 비용.
- **공급망**: 1·2차 협력사, 내재화 vs 외주(엔진·변속기·시트·전장), 리드타임, JIT 재고 리스크, 공급사 파산, 반도체 할당.
- **플랫폼 공유**: 여러 모델이 같은 하부 구조를 쓰면 금형·지그 재사용(1990년대 이후 업계 표준).
- 노동: 노조 교섭, 파업, 연금·의료 부채(레거시 코스트), 자동화에 따른 고용 갈등, 숙련도 학습곡선(누적 생산 2배마다 공수 −15%).
- 품질: SPC 관리도 화면, 결함 유형별 파레토, 리콜 원인 추적 → 해당 공정 투자.

### Phase 4 — 회사 경영
- **자본시장**: IPO, 주가(이익·성장·업계 사이클), 배당, 증자, 회사채 등급, 적대적 인수.
- **M&A**: 경쟁사·부품사 인수, 브랜드 포트폴리오(대중/프리미엄/럭셔리 서브브랜드), 합작투자(해외 진출 시 현지 파트너 의무 — 1990–2020 중국형 규제).
- 환율(브레튼우즈 고정환율 → 1971 변동환율, 플라자 합의 1985), 해외 법인 손익, 이전가격.
- **캡티브 파이낸스**: 할부·리스 자회사, 잔존가치 리스크, 금리 인센티브.
- 탄소/연비 크레딧 거래(CAFE, EU CO₂ 함대 평균, ZEV 크레딧).
- 이사회 목표·CEO 평가, 시나리오 모드(망해가는 회사 인수, 신흥국 국민차 프로젝트, EV 스타트업).

### Phase 5 — 판매·딜러·평가
- 지도 기반 딜러 입지(도시 인구·소득), 딜러 개별 수익성과 이탈, 직영 쇼룸 vs 프랜차이즈 vs 온라인 직판(2010s~).
- 트림 레벨·옵션 패키지, 연식 변경(MY) 개선, 플릿(렌터카·관공서·택시) 입찰, 재고 일수와 리베이트.
- 중고차 시장과 **잔존가치**(신뢰성·부식·브랜드) → 신차 수요·리스료에 반영.
- 평가: 잡지 비교 테스트(경쟁차와 나란히), 올해의 차, 소비자 신뢰도 조사(3년 후 결함 데이터), NCAP 별점, 모터스포츠 참가와 브랜드 효과.
- 광고: 매체 믹스(신문·라디오 → TV → 인터넷 → SNS), 시대별 포스터 자동 생성(설계한 차의 렌더 사용).

### Phase 6 — 경쟁사 AI
- 경쟁사가 플레이어와 **같은 설계 엔진**(engine.js / car.js)으로 실제 차를 설계 → 리뷰·비교 화면에서 경쟁차도 렌더·스펙 표시.
- 회사별 전략(원가 리더, 기술 리더, 니치) + 시장 신호에 반응(오일쇼크 → 소형차 개발 착수).

```
index.html            레이아웃·스타일, 스크립트 로드
src/util.js           스플라인, 테이블 보간, 시드 RNG, DOM 헬퍼
src/data/world.js     거시경제·시장·규제·사건 (데이터)
src/data/tech.js      부품·공정 카탈로그 (데이터)
src/sim/engine.js     엔진 물리
src/sim/car.js        차체 해석·차량 성능·원가
src/sim/market.js     수요·경쟁사·리뷰
src/sim/company.js    R&D·공장·판매·재무·월간 스텝

src/ui/*.js           화면
tools/simcheck.js     Node 헤드리스 밸런스 점검
```

원칙
- **데이터 주도**: 새 부품·공정·사건은 카탈로그에 한 줄 추가로 끝나야 한다.
- **시뮬레이션과 렌더 분리**: `sim/`은 DOM 없이 Node에서 돈다 → 밸런스 회귀 테스트(`node tools/simcheck.js`)로 시대별 대표 차량 수치(1946 세단 0-100 ≈ 30s, 1965 V8 ≈ 8s, 1990 1.8 DOHC ≈ 113hp 등)를 고정.
- 저장은 localStorage(시드 RNG로 재현 가능). 다음 단계: 저장 버전 마이그레이션, JSON 내보내기.
