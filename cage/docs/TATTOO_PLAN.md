# 문신 구현 계획

## 목표
선수별 문신을 전신 이미지(레퍼런스)와 같은 모양으로 몸에 붙이고, 팔·몸통이 움직여도 몸을 따라가며, 몸 밖으로 나가지 않고, 부상(멍·피)과 같이 자연스럽게 겹치게 한다.

## 방식: 부위별 데칼(decal)
1. **추출 (도구 `tools/build_tattoo.py`)**: 전신 이미지에서 부위(상완·전완·가슴·복부·종아리)별로 사각 영역을 지정 → 영역 안에서 피부색과 다른 잉크 픽셀만 알파로 뽑아 투명 PNG로 저장. 피부색 기준 색거리 + 부드러운 가장자리. 글자(BROWN PRIDE, MCGREGOR)도 그대로 래스터 이미지로 보존.
2. **부위 좌표로 펴기**: 이미지 속 팔·다리는 비스듬히 놓여 있으므로 부위의 두 관절(어깨–팔꿈치 등)을 찍으면 그 축을 기준으로 (t, w) 좌표(축 방향 0~1, 두께 방향 -1~1)로 회전·보정해 저장한다. 게임의 `limb()`가 이미 같은 (t, w) 좌표를 쓰므로 그대로 얹을 수 있다.
3. **런타임 (`src/Tattoo.js`)**: `detailIn()`(부위 윤곽 안으로만 그리는 클립) 안에서 데칼을 그린다. 그러면 ① 팔이 움직이면 같이 움직이고 ② 몸 밖으로 안 나가고 ③ 외곽선·명암이 그 위에 자연스럽게 덮인다. 몸통 문신은 `torsoFlat`의 (s, w) 좌표로 매핑.
4. **좌우 구분**: 옆모습이라 가까운 팔/먼 팔이 따로 보인다. 데칼 데이터에 `near` / `far` 지정, 먼 팔은 조금 어둡게(0.85) 그린다. 뒤집힘(d)은 부위 프레임이 처리.
5. **데이터**: `assets/cutout/<선수>/tattoo.json` = `[{part:'uarm', side:'near', img:'t_uarm.png', t:[0,1], w:[-1,1], alpha:.9}, …]`. 선수 등록은 기존 `CURATED`에 `tattoo:true`.
6. **부상과의 순서**: 피부 → 문신 → 멍/피. 멍과 피는 문신 위에 덮이도록 기존 `bruises()`를 그 뒤에 그린다.
7. **성능**: 데칼은 로드 시 한 번 캔버스로 만들어 캐시. 프레임당 부위당 `drawImage` 1회.

## 단계
1. 도구 + 가슴·상완 1종(맥그리거 가슴, 알도 어깨)으로 시제품 → 화면 확인
2. 전체 부위(복부·종아리·전완) 확장, 먼 팔 처리
3. 기존 선수(페레이라, 아데산야, 케인 글자 문신 포함) 일괄 적용 + `face_check`와 같은 점검 시트(`tattoo_check`) 추가
4. 성능·부상 겹침 검수

## 위험과 대응
- **옆모습이라 가려지는 부분**: 등 쪽 문신은 안 보이는 쪽이라 생략(레퍼런스에 안 보임).
- **해상도**: 문신 한 부위가 화면에서 작아 글자가 뭉개질 수 있음 → 이미지 2배 업스케일 후 샤프닝, 글자는 굵게.
- **피부색 분리 오차**: 음영 면(저폴리 면)이 잉크로 오인될 수 있음 → 잉크는 어둡고 채도가 낮다는 조건을 같이 걸고, 영역을 사람이 지정해 해결.
- **팔 모양이 레퍼런스와 다름**: 게임 포즈가 달라도 (t, w)로 매핑하므로 늘어남만 있고 어긋나지 않음.
