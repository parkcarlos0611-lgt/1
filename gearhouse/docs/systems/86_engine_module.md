# 86 · 엔진 메시 모듈 (사양에서 엔진을 만든다)

문서 77 §2의 2단계. 유리나 루버 아래로 엔진이 보이는 미드십 차(NSX, F355, EB110, 디아블로)에 넣을 엔진을
차마다 손으로 만들지 않고, 사양 하나로 만든다.

- 파일: `render/car/enginemesh.ts` (`render/car/engine.ts`는 빌더의 엔진 교체 기능이라 이름을 달리했다).
- 시험: `tests/engine.test.ts`.

## API
```ts
addEngine(b: Build, spec: EngineSpec, o: V, opts?: { dir?: 'x'|'-x'|'y'|'-y'; box?: { len, wid, hgt }; detail?: 0|1|2; brace?: boolean })
  → { tris, scale, size: { len, wid, hgt }, min, max }
ENGINES: { nsx, f355, eb110, diablo }
```
- `o`: 크랭크 중심의 벨하우징 쪽 끝(mm, 차의 축). 엔진은 거기서 `dir` 방향으로 풀리 쪽까지 뻗는다.
- `box`: 들어갈 공간. 길이는 크랭크 방향, 폭은 크랭크 중심선 양쪽 합, 높이는 전체. 크면 그대로, 작으면 `o`를
  중심으로 똑같은 비율로 줄인다(`scale`).
- `EngineSpec`: 배열(I, V, flat), 실린더 수, 뱅크 각, 배기량, 터보·슈퍼차저 수, 흡기(`single` 뱅크 사이 큰
  플리넘, `twin` 뱅크마다 하나, `runners` 짧은 플리넘과 드러난 러너), 색(블록, 헤드, 캠 커버, 플리넘, 줄무늬,
  명판, 배기관), 크링클(광택을 낮춘다), 명판 글자(글자는 그리지 않고 밝은 사각형만).
- 부품 이름은 모두 `engine`으로 시작한다(`engineBlock`, `enginePlenum`, ...). 바퀴로 잘못 잡히지 않는다.

## 비례 (경험칙)
- 보어 = 10.8 × (실린더 1개 배기량 cc)^(1/3) (500 cc면 86 mm). 실린더 간격 = 보어 × 1.12 + 4 (78~118).
- 뱅크 축을 따라 데크 2.5 보어, 헤드 1.25 보어, 캠 커버 0.42 보어. 헤드 폭 2.1 보어. V 뱅크는 0.3 간격 엇갈림.
- 결과: NSX 약 520×640×550, F355 550×600×540, EB110 665×490×480, 디아블로 760×510×590 mm (브레이스 포함).

## 부품
블록(크랭크케이스, 뱅크 블록, 밸리, 벨하우징 플랜지), 오일팬, DOHC 헤드와 캠 커버 2개씩(위에 색 줄무늬), 코일,
타이밍 커버, 풀리와 벨트, 배기 헤더·집합관·열 차폐판, 터보(터빈·컴프레서 하우징), 인터쿨러와 부스트 파이프,
플리넘·러너·스로틀 바디·에어박스, 명판, 연료 레일, 냉각 호스, 오일 캡, 스트럿 브레이스(차의 폭 방향).

## 삼각형 예산
| detail | NSX | F355 | EB110 | 디아블로 |
|---|---|---|---|---|
| 2 | 1,062 | 1,166 | 1,490 | 1,198 |
| 1 | 566 | 638 | 762 | 630 |
| 0 | 220 | 242 | 330 | 242 |

시험의 허용 범위: 2는 1,000~1,550, 1은 450~800, 0은 150~350. 넓이가 0인 삼각형은 만들지 않는다.

## 차에 넣는 법 (NSX 예)
가로 배치, 좌석 뒤. 크랭크가 차의 폭 방향이므로 `dir: '-y'`(또는 `'y'`), 브레이스는 자동으로 차의 폭 방향이 된다.
```ts
import { addEngine, ENGINES } from './enginemesh';
// 엔진룸 바닥 위, 뒤 유리 아래. 크랭크 끝은 변속기 쪽(y = +300)
addEngine(b, ENGINES.nsx!, [2980, 300, 360], { dir: '-y', box: { len: 620, wid: 680, hgt: 620 }, detail: 2 });
```
세로 배치(F355, EB110, 디아블로)는 `dir: 'x'`(변속기가 뒤) 또는 `'-x'`(변속기가 앞, 디아블로·EB110식).
가까이 볼 때 2, 게임 크기에서 1, 멀리서 0을 쓴다. 엔진 덮개 유리나 루버는 차 파일이 만든다.

## 남은 것
- 크링클 질감은 광택만 낮췄다. 실제 질감은 라이브 렌더러의 재질로 따로 넣어야 한다.
- 수평대향 엔진의 흡기 배치는 대략적이다. 애니메이션(풀리 회전, 엔진 흔들림)은 문서 77 §2의 다음 단계.
