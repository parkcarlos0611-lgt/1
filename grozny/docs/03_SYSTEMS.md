# 03. 시스템 세부 설계 (초기 수치, 플레이테스트로 조정)

## 1. 부상 시스템
HP 바 대신 **부위 × 상처** 목록으로 관리한다.

**부위:** 머리, 목, 가슴, 복부, 왼팔, 오른팔, 왼다리, 오른다리

| 상처 | 원인 | 효과 | 처치 |
|---|---|---|---|
| 찰과상 | 파편, 유탄 | 출혈 0.1/s | 붕대 |
| 관통상 | 소총탄 | 출혈 0.5~1.5/s, 통증 | 지혈대(팔다리), 압박붕대 |
| 동맥 손상 | 관통상 중 15% | 출혈 4/s, 1~2분 안에 사망 | 지혈대만 유효(팔다리) |
| 골절 | 고속탄, 추락 | 해당 팔: 조준 -60%, 다리: 이동 불가 | 부목 |
| 파편상 | 수류탄, 포격 | 여러 부위 동시, 출혈 합산 | 붕대 여러 개 |
| 화상 | 화재, RPG | 통증, 감염 위험 높음 | 화상 붕대 |
| 동상 | 추위 노출 | 손: 조작 속도 감소, 발: 이동 감소 | 보온, 실내 |
| 감염 | 처치 지연 | 며칠에 걸쳐 열, 사망 가능 | 항생제(희귀) |

- **혈액량** 5000ml. 3000ml 이하 → 의식 저하, 2000ml 이하 → 사망
- **통증** 0~100. 60 이상 → 조준 흔들림, 80 이상 → 쓰러짐. 프로메돌로 감소(지속 시간 제한)
- **머리·목·가슴 관통 시** 즉사 확률 (머리 85%, 목 50%, 가슴 25%)

## 2. 심리 시스템
| 수치 | 범위 | 증가 요인 | 감소 요인 |
|---|---|---|---|
| 공포 | 0~100 | 근처 탄착(제압), 폭발, 아군 사망 목격, 어둠, 고립 | 엄폐, 동료 근처, 시간 경과 |
| 피로 | 0~100 | 수면 부족, 운반, 추위 | 수면, 식사 |
| 트라우마 | 0~100 (영구 누적) | 사망 목격, 민간인 피해, 근접 살해 | 거의 감소하지 않음 |

| 공포 | 상태 | 효과 |
|---|---|---|
| 0~30 | 침착 | 정상 |
| 30~60 | 긴장 | 조준 -15%, 명령 반응 지연 0.5초 |
| 60~85 | 공황 | 조준 -40%, 명령 거부 20%, 맹목 사격 |
| 85+ | 붕괴 | 얼어붙거나 도주, 오인 사격 확률 증가 |

- 트라우마가 높은 대원은 밤 이벤트(악몽, 탈영 시도, 자해 암시는 절제해서 표현)가 생긴다.

## 3. 사격·탄도
- 탄은 **히트스캔이 아닌 투사체 시뮬레이션**(틱당 이동, 속도에 따라 판정). 단순화: 직선 + 확산
- **확산** = 무기 기본값 × 자세(서기 1.0 / 앉기 0.7 / 엎드림 0.5) × 이동 × 공포 × 부상
- **제압:** 탄이 2m 안을 지나가면 공포 +5
- **벽 관통:** 재질별 관통 저항 (석고 10, 나무 20, 벽돌 60, 콘크리트 90). 탄 관통력과 비교
- **탄약 무게:** 5.45mm 탄창 1개 ≈ 0.5kg. 무게 한도를 넘으면 이동속도와 피로에 영향

## 4. 시야·소리
- 시야 원뿔: 주간 110°/40m, 야간 110°/8m(조명탄·화재 근처는 확장)
- 벽·문·연기는 시야 차단. 창문은 시야는 통과, 이동은 불가
- **소리 반경:** 소총 사격 200m, 권총 100m, 달리기 15m, 걷기 5m, 문 부수기 30m
- 플레이어에게 소리는 **방향 표시 + 대략적 거리(근/중/원)**만 보여준다

## 5. AI
- **행동 트리**: 상태 = 순찰 / 경계 / 교전 / 제압당함 / 후퇴 / 부상자 구조
- 적 전투원(챕터 1): 3~5명 소규모 그룹, 건물 위층과 지하실에서 RPG·저격으로 매복, 치고 빠지기
- 아군 분대원: 명령 우선이지만 공포 상태에 따라 무시 가능
- 민간인: 숨기, 도망, 도움 요청. **전투원과 외형으로 구분이 어려운 경우가 있다**(의도된 긴장)

## 6. 시간·환경
- 하루 = 낮 출격(실시간 10~20분) + 밤 이벤트(텍스트·선택지)
- 기온 -5 ~ -15°C. 실내·불 근처가 아니면 체온이 서서히 떨어짐
- 포격: 랜덤 시간에 구역 단위로 발생. 건물 붕괴, 화재

## 7. 거점·관리
- 식량, 물, 탄약, 의약품, 연료 자원
- 대원 카드: 이름, 나이, 출신, 부상, 공포·피로·트라우마, 관계(친한 동료)
- 사망자 기록: "기록" 화면에 남음. 편지 텍스트는 절차적으로 생성(템플릿 + 대원 정보)
