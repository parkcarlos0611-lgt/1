# 06. 고증 메모와 표현 원칙

## 2. 게임에 반영할 "실상" 요소
- 러시아 측: 훈련이 부족한 징집병, 혼성 편성 부대, 부정확한 지도, 무전 혼선, 보급 부족, 오인 사격
- 체첸 측: 소규모 그룹, 지역 지리를 잘 앎, RPG·저격 위주의 기동 방어, 무기·탄약 부족
- 민간인: 그로즈니에 남은 사람 상당수는 떠날 수 없던 노인, 그리고 러시아계 주민. 지하실 피난 생활
- 겨울: 영하의 추위, 난방·물·전기 끊김
- 도시: 소련식 아파트, 철도역, 공장, 광장

## 3. 표현 원칙 (체크리스트)
- [ ] 특정 민족·종교를 집단으로 악마화하지 않는가
- [ ] 폭력이 "재미있는 보상"으로 설계되지 않았는가
- [ ] 민간인 피해 장면이 목적(전쟁의 실상) 없이 소비되지 않는가
- [ ] 실존 인물·부대를 직접 지칭하지 않는가
- [ ] 각 시점의 인물이 사람으로서 동기를 가지고 있는가

## 4. 참고 자료 (조사 예정 목록)
- 전쟁 기자의 르포와 생존자 증언 모음
- 인권 단체(예: 메모리알)의 민간인 피해 보고서
- 군사사 분석 (그로즈니 시가전 교훈 관련 연구)
- 당시 보도 영상·사진 (지형, 복장, 장비 확인용)
- 장비: AK-74, PKM, RPG-7/18/26, SVD, BMP-1/2, T-72/T-80 (게임 데이터 작성 시 제원 확인)
