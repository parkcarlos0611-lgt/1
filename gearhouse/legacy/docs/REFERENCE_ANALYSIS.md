# 레퍼런스 블루프린트 분석 → 비율 규칙 (E1: 1930년대)

사용자가 제공한 1930년대 블루프린트 6장(업라이트 세단·쿠페, 유선형 세단, 고급 투어러 2종, 레이서)을
좌표 격자를 씌워 측정하고, **휠베이스(WB) 기준 비율**로 정규화했다. 실루엣 생성기는 이 비율을 따르되
특정 실존 차량을 복제하지 않는다 (게임 내 디자인은 독자 형상, 실존 브랜드·엠블럼 미사용).
레퍼런스 이미지 자체는 저장소에 넣지 않고 측정값만 기록한다.

## 측정 방법

1. 블루프린트 측면도에 10px 격자 + 좌표 라벨을 씌워 확대 → 앞·뒤 차축 중심, 접지선, 각 형상 기준점 좌표 판독.
2. 실제 휠베이스(시대 표준값)로 mm/px 환산 → 모든 치수를 mm와 WB 비율로 기록.
3. 생성한 픽셀 스프라이트의 외곽을 같은 휠베이스로 맞춘 블루프린트 위에 빨간 선으로 겹쳐 **오버레이 검수**.
4. 어긋나는 항목(지붕 높이, 펜더 앞끝, 창 위치)을 스펙에서 수정 → 재생성.

## 생성기에 반영한 구조 규칙

- **창**: 스플라인 스무딩 대신 `fillet(코너별 반경 mm)`으로 직사각형/사다리꼴을 만든다. 창은 차체에 파인 형태로 표현한다(위·앞 테두리 1px 그림자, 아래 테두리 밝은 창턱).
- **펜더**: 휠 중심 기준 타원호(외곽) + 원호(안쪽, 타이어 반경 + 65~75mm 간격) + 뒷자락(러닝보드까지 직선)으로 조립한다.
- **스플래시 에이프런**: 후드 하단과 펜더 사이, 차체 하단과 러닝보드 사이를 검은 판금으로 채운다. 빈 공간이 보이면 차가 떠 보인다.
- **라디에이터·헤드램프·범퍼**: 차체와 분리된 부품 레이어. 위치는 앞차축 기준 비율로 정한다.
- **시대 파라미터화**: 위 표의 비율을 `eras.json`의 E1 하위 스타일(업라이트 / 고급 / 유선형) 프리셋으로 넣고, 실루엣 생성기(silgen)가 이 범위 안에서 변형을 만든다.
