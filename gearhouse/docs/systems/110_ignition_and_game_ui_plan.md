## 1. 시동 기능
### 1-1. 흐름
```
꺼짐 ──[시동 버튼 길게 / 키 돌림]──▶ 전원(계기 켜짐, 바늘 한 바퀴 점검) ──▶ 크랭킹(스타터 돌아가는 소리, 0.6~1.5초)
   ▲                                                                                     │
   │                                                                         성공 ─▶ 공회전(회전수가 튀었다 내려옴)
   └──[끄기]── 주행 중 ◀── 출발 ◀─────────────────────────────────────────────────────┘
                 │
                 └── 엔진 꺼짐(시동 꺼뜨림: 수동 변속에서 너무 낮은 회전에 클러치를 붙이면) ─▶ 다시 시동
```
- **실내 계기와 연결:** 전원이 켜지면 바늘이 끝까지 올라갔다 내려오는 점검 동작을 하고, 경고등이 잠깐 켜졌다 꺼진다. 959의 다섯 계기 그대로다(문서 109의 계기 작업).
- **소리:** 스타터 모터 소리, 첫 폭발, 공회전으로 이어진다. 엔진 공방의 소리 합성(배열, 실린더 수, 터보)을 그대로 쓴다.
- **차 상태 반영(나중):** 차가 차가우면 크랭킹이 길어진다. 1930년대 클래식은 초크와 크랭크를 쓴다(0.4). 고장(배터리, 점화)은 0.20의 결함 체계와 잇는다.
- **선택:** 설정에서 "자동 시동"(지금처럼 바로 출발)과 "직접 시동"을 고른다. 기본은 직접 시동이다.
- **시동 꺼뜨림:** 수동 변속, 낮은 회전에서 클러치를 급히 붙이면 꺼진다. 처음에는 끄고 시작해서 쉬움 설정에서는 꺼지지 않게 한다.

### 1-2. 만들 것
- 엔진 상태 기계: 꺼짐 / 전원 / 크랭킹 / 공회전 / 주행 / 꺼뜨림
- 주행 물리와 연결: 꺼짐이면 토크 0, 크랭킹은 스타터 토크
- 소리, 계기 점검 동작, 시동 버튼 조작(화면 버튼, 키보드 키, 패드 버튼)

### 1-3. G1 구현 메모 (완료)
- **상태 기계:** `race/ignition.ts` (순수, `tests/ignition.test.ts`). 꺼짐 → 전원(바늘 점검 1.2초, 경고등) → 크랭킹(물 온도로 0.6~1.5초) → 첫 폭발 → 공회전(회전수가 idle의 1.7배까지 튀었다 1.2초에 내려옴) → 작동. 시동 꺼뜨림 뒤에는 전원이 켜진 채 경고등이 켜져 있고, 다시 길게 누르면 바로 크랭킹.
- **물리:** `race/vehicle.ts`의 `engine`. 꺼짐은 토크 없음(굴러가며 기어가 물리면 압축 저항), 크랭킹은 스타터 토크(약 250 rpm), 공회전 제어는 그대로. 만들 때 기본은 작동 중이라 AI 차와 기존 시험은 그대로.
- **조작:** 시동 = `I`/`Enter` 길게, 화면 `시동` 버튼 길게, 패드 `Y`. 꺼짐에서는 0.35초 누른 뒤 크랭킹, 작동 중 새로 누르면 끄기. 클러치 = `F`, 패드 `LB`(수동 변속일 때만).
- **시동 꺼뜨림 규칙:** 수동 변속(자동 변속을 끈 상태)에서만. 클러치를 0.3초 안에 끝까지 떼고 차가 거의 서 있으며 회전수가 idle의 2배 미만일 때, 또는 클러치가 물린 채 회전수가 idle의 0.6배 아래로 0.25초 넘게 끌릴 때. "쉬움" 쪽은 자동 변속(기본)이라 꺼지지 않고, 설정 "시동 꺼짐"으로도 끌 수 있으며 자동 시동에서는 꺼지지 않음.
- **출발 상태:** 시험장(연습)은 직접 시동이면 꺼진 채, 레이스는 내 차도 AI 차처럼 이미 켜진 채(출발 신호를 시동 때문에 놓치지 않게). 자동 시동은 언제나 켜진 채(예전 그대로).
- **계기:** `engine.gaugeSweep`(0..1), `engine.lamps`. 주행 HUD 바늘은 `sweepValue`로 이미 연결. 실내 계기(render/car/interior)는 `InteriorInput`에 `sweep`을 받아 각 바늘에 `sweepValue(v, sweep, min, max)`을 씌우면 됨(`on`은 `engine.ignition`).
- **소리:** 꺼짐 무음, 크랭킹은 스타터 소리(압축 박동), 첫 폭발 한 번, 이후 엔진 소리.

## 2. 게임다운 인터페이스: 카툰 인포그래픽
### 2-1. 지금 문제
- 메뉴, 빌더, 주행 화면이 깔끔하지만 "웹 페이지"처럼 보인다(얇은 글꼴, 흰 패널, 작은 버튼).
- 드리프트 화풍(굵은 외곽선, 2단 음영)과 화면 장식의 결이 다르다.

### 2-2. 목표 스타일
보내 주신 FR Legends 화면의 인터페이스 특징을 기준으로 한다(따라 그리지 않고 원리만 쓴다).
| 요소 | 방식 |
|---|---|
| 글꼴 | 굵고 압축된 제목 글꼴(지금 Oswald 계열을 더 굵게) + 읽기 쉬운 한글 본문. 숫자는 큰 굵은 글꼴 |
| 패널 | 비스듬히 잘린 모서리, 굵은 검은 외곽선, 단색 면 + 살짝 어두운 그림자 면(2단) |
| 색 | 진한 남색·보라 바탕 띠, 강조는 노랑·주황·하늘색. 돈·코인·잠금 같은 상태는 색과 아이콘으로 |
| 아이콘 | 굵은 외곽선의 단순한 그림(엔진, 핸들, 휠, 서스펜션, 스프레이, 렌치). 글자 없이도 읽힘 |
| 버튼 | 크고 두툼한 버튼, 누르면 눌리는 그림자 이동과 짧은 소리 |
| 수치 | 막대와 게이지 그림(출력, 무게, 그립, 최고 속도)을 숫자와 함께 보여 줌. 바뀌면 막대가 늘고 줄어듦 |
| 상단 띠 | 돈, 코인(나중), 슬롯, 뒤로 버튼을 굵은 띠에 |
| 전환 | 패널이 미끄러져 들어오고 나가는 짧은 움직임 |

### 2-3. 화면별 적용
| 화면 | 바뀌는 것 |
|---|---|
| 타이틀 | 큰 로고, 기울어진 메뉴 버튼, 배경의 차 |
| 차고·빌더 | 왼쪽 세로 아이콘 탭(차대, 엔진, 서스펜션, 차체, 부품, 칠, 검사), 부품 라이브러리는 썸네일 카드 격자, 오른쪽 수치는 막대 인포그래픽 |
| 엔진 공방 | 다이노 그래프를 굵은 선의 만화풍 그래프로, 엔진 정보 카드 |
| 주행 화면(HUD) | 아래 3절 |
| 일시정지·결과 | 큰 카드, 순위와 랩타임을 굵은 표로 |

## 3. 주행 조작 장치와 계기 (HUD)
### 3-1. 생김새
| 장치 | 지금 | 바꿀 모습 |
|---|---|---|
| 액셀러레이터 | 녹색 반투명 사각 버튼 | **페달 그림**: 금속 페달판(구멍 뚫린 경주용), 밟는 만큼 아래로 눌리고 옆에 채움 막대 |
| 브레이크 | 붉은 반투명 사각 버튼 | 더 넓은 페달판, 밟는 세기만큼 눌림. 정지 상태에서 길게 누르면 후진(지금 기능 그대로) |
| 핸들 | 원 하나와 스포크 선 | **실제 핸들 그림**: 딥디쉬 3스포크(드리프트), 가죽 테 질감, 위쪽 표시 띠, 돌린 각도만큼 회전. 차의 실내 핸들과 같은 디자인을 쓴다(교체 부품과 연결) |
| 기어 | 글자 버튼 | 기어 레버 그림(수동), 위아래로 밀어 변속. F1 변속기는 패들 그림 |
| 핸드브레이크 | 없음 | 드리프트용 손잡이 그림(당기면 뒷바퀴 잠김) |
| 시동 | 없음 | 시동 버튼(누르고 있으면 크랭킹) |
| 계기판 | 원형 2개(속도, 회전) | **차의 실제 계기 디자인**을 화면에 크게: 타코미터 + 부스트, 속도는 큰 숫자, 기어 숫자. 차마다 계기 디자인이 바뀜(실내 계기와 같은 그림을 씀) |
| 미니맵·랩 정보 | 사각 패널 | 굵은 외곽선 카드, 랩·최고 랩·순위 배지 |

### 3-2. 공통 규칙
- 모든 장치는 같은 카툰 결(굵은 외곽선, 2단 음영, 단색)이다.
- 휴대폰 세로·가로, PC에서 배치를 각각 정한다. 엄지가 닿는 자리, 화면 가림 최소, 차가 가려지지 않게 한다.
- 설정에서 크기와 투명도, 왼손 배치를 바꿀 수 있다.
- 키보드와 패드를 쓰면 터치 장치는 숨긴다.

### 3-3. G3 결과 (주행 HUD)
- **코드:** `ui/hud/logic.ts`(규칙, 순수), `ui/hud/draw.ts`(그림, 규칙으로 그린 SVG 문자열), `ui/hud/hud.ts`(페이지에 붙이기, 매 프레임 자세). 주행 페이지 `ui/drive.page.html`의 표시와 모양, `ui/drive.ts`에서 계기 그리기(`dials`)를 HUD로 바꿈. 외부 그림 파일 없음, 글꼴은 Google Fonts의 Oswald 700.
- **장치:**
  - 가속 페달: 구멍과 홈이 뚫린 금속 페달판(2단 음영, 굵은 외곽선). 밟는 양만큼 아래로 가라앉고 위가 줄어 기울어 보이며, 옆에 초록 채움 막대.
  - 브레이크: 더 넓은 같은 판, 빨간 채움 막대. 정지 상태에서 길게 누르면 후진(그대로).
  - 핸들: 실내와 같은 두 종류. 경량 실내(드리프트)·기본 차는 딥디쉬 3스포크(구멍 뚫린 스포크, 노란 위쪽 띠, 노란 혼 버튼), 그 외 설계는 순정 4스포크(큰 패드). 돌린 만큼 회전.
  - 기어: 수동은 레버 그림. 위로 밀면 한 단 올림, 아래로 당기면 내림(관문을 넘을 때 한 번, 가운데로 돌아오면 다시). F1 변속기는 패들 두 개(왼쪽 −, 오른쪽 +). 설정 "수동 변속 조작"에서 +/− 버튼으로. 자동 변속이면 레버가 회색 "A".
  - 핸드브레이크: 노란 손잡이 레버. 누르는 동안 당겨져 내려오고 받침의 경고등이 켜짐. 기존 Space 핸드브레이크 입력에 연결(뒷바퀴 잠김).
  - 시동 버튼: 둥근 버튼(ENGINE 시동 START). 꺼짐·전원은 노랑(빛나며 깜박), 크랭킹은 주황, 작동은 초록. 길게 눌러 크랭킹(그대로).
  - 계기: 실내 계기(`gaugeSet`)의 타코미터 면을 그대로 그림. 회전 한계의 빨간 띠, 터보 차는 아래쪽 부스트 바늘. 노란 2단 베젤, 경고등 2개, 시프트 램프(한계 85 % 노랑, 한계에서 빨강 깜박). 속도는 큰 숫자 카드, 기어는 노란 배지(자동이면 작은 A). 시동이 꺼지면 바늘은 쉬는 자리, 숫자는 "---", 면은 흐리게. 켜질 때 바늘 점검(sweep)도 따라감.
  - 위쪽 정보: LAP, LAST, BEST 카드(굵은 외곽선, 기울임 글자). 레이스에서는 POS 노란 순위 배지. 미니맵은 굵은 테 카드, 트랙 선에 검은 테. 위 버튼은 파랑(보조).
- **배치:** `body.hud-portrait / hud-landscape / hud-pc`(화면 비율과 터치 버튼 표시로 결정).
  - 가로 휴대폰: 왼쪽 아래 핸들, 그 위에 시동·복귀. 오른쪽 아래 핸드브레이크·브레이크·가속, 레버는 핸드브레이크 위(미니맵 아래). 계기는 가운데 아래.
  - 세로 휴대폰: 아래 줄 핸들 | 핸드브레이크·브레이크·가속, 레버와 시동은 페달 위. 계기는 핸들 위 왼쪽.
  - PC: 터치 장치 없이 오른쪽 아래 큰 계기, 왼쪽 아래 작은 핸들 그림과 각도.
  - 차는 계기·버튼 위로 오도록 기존 `carAim`이 계기 카드까지 재어 맞춤.
- **설정:** 조작 탭에 "화면 버튼 크기"(70~140 %), "불투명도"(35~100 %), "왼손 배치"(좌우 거울: 핸들 오른쪽, 페달 왼쪽), "수동 변속 조작"(레버 / 버튼). `ui/shell/settings.ts` controls에 `hudSize, hudAlpha, leftHand, shifter`.
- **키보드·패드:** 키를 누르거나 패드를 쓰면 터치 장치를 숨기고(`body.hud-keys`, 계기는 PC 배치로), 화면을 다시 만지면 보임.
- **시험:** `tests/hud.test.ts`(레버 관문, 페달 눌림, 바늘 각도·꺼짐·점검, 숫자, 그림 확인). 시동·셸·주행 카메라·실내 시험과 함께 통과, tsc 통과. 실제 주행 페이지를 한 번 띄워 오류 없음 확인.

## 7. 참고 화면 분석 (사용자 제공, `docs/reference/frl_ui/`)
원리만 정리한다. 로고, 글꼴 파일, 그림은 가져오지 않는다.
- **타이틀:** 3D 장면(트랙, 콘, 타이어 벽, 드리프트 중인 차)을 배경으로 그대로 쓴다. 큰 기울어진 로고는 노랑→주황 그라데이션에 굵은 검은 외곽선과 짙은 그림자를 둔다. 왼쪽 아래에는 노란 사각 버튼이 세로로 쌓이고, 버튼마다 흰 아이콘과 굵은 흰 글자에 검은 테를 두른다. 오른쪽 위에는 톱니 설정 아이콘이 있다.
- **모드 선택:** 배경은 검정에 빨간 로고·차 실루엣을 반복한 무늬다. 가운데는 하늘색 판에 굵은 외곽선, 위아래로 남색·보라 사선 줄무늬 띠가 있다. 노란 버튼이 2열로 놓이고, 잠긴 항목은 회색, "BETA" 같은 초록 기울임 배지를 쓴다. 오른쪽 위는 "◀ BACK" 탭이다.
- **목록과 대화상자:** 표 형식 목록에서 선택한 행은 초록으로 칠한다. 대화상자는 검은 반투명 판, 흰 테두리, 초록 "OK" 버튼이다. 아래 버튼은 아이콘 + 글자의 색 구분 버튼이다(노랑 CREATE, 파랑 JOIN, 주황 WATCH).
- **공통:** 모든 글자는 굵고 압축된 기울임 산세리프에 검은 외곽선을 둔다. 버튼은 단색 면, 굵은 검은 테, 아래쪽에 살짝 어두운 띠가 있다. 색은 노랑(주 버튼), 초록(확인, 선택), 파랑(보조), 주황(보기), 회색(잠김)이다.
- **우리 적용:**
  - 같은 원리(굵은 기울임 글자에 외곽선, 단색 버튼에 굵은 테, 3D 장면 배경, 사선 줄무늬 띠, 색으로 역할 구분)를 쓴다.
  - 우리만의 로고(GEARHOUSE)와 색 조합을 정한다. 노랑·주황 계열은 쓰되 남색·하늘 대신 우리 차고·공방 분위기에 맞춘 색을 시안으로 비교한다.
  - 글꼴은 무료 라이선스의 굵은 압축 글꼴을 고르고, 한글은 굵은 고딕을 짝지어 쓴다.
