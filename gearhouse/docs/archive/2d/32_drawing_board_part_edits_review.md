# 검토 32 — 도면 단계에서 문·창·램프·그릴·범퍼·펜더 조절, 도면 품질, 검은 화면 주사선

기획자 아이디어(2026-11-20):
- 길이를 크게 줄이면 문 비율을 자동으로 맞추고 맨 뒤 창을 없앤다.
- 문 길이 조절.
- 도면 단계에서 창 위치, 헤드램프 위치, 그릴 위치와 크기, 범퍼 크기와 유무, 펜더 크기와 유무를 조절한다.
- 차종·시대마다 고칠 수 있는 것이 넓고 다르다.
- 도면의 선과 종이 품질을 높인다.
- 검은 레이저 스캔 화면은 수정을 반영하면 주사선이 위에서 내려오며 바뀐다(초기 컴퓨터 그래픽 느낌). 오른쪽 위에 천천히 도는 정다면체.

## 1. 결론

- 모두 맞는 방향이다. 도면 단계가 "치수만 바꾸는 곳"에서 "차의 짜임을 정하는 곳"이 된다.
- 지금 모델로 대부분 바로 된다. 한 대의 입체 부품 모델을 고친 뒤 모든 보기(도면, 외장 그림, 시험 주행)가 같은 모델에서 나오기 때문이다. 축간·지붕·차체 높이가 이미 이렇게 동작한다.
- 빠진 것은 하나다. 부품들이 "어디에 붙어 있는가"(고정점과 묶음)를 모델이 아직 모른다. 이것을 먼저 넣으면 나머지 조절은 모두 같은 방식으로 붙는다.
- 도면 품질과 검은 화면 주사선·정다면체는 이번에 만들었다(4장).

## 2. 필요한 바탕: 고정점(하드 포인트)과 묶음

지금 1929 세단 모델에서 문은 차체 부품 위의 이음선(seam)이고, 창은 창틀·유리 부품(wframe0~2, glass0~2)이다. 문과 창은 서로 묶여 있지 않다.

| 넣을 것 | 내용 |
|---|---|
| 고정점 | 차 옆면의 세로 기둥 위치: A(앞 유리), B(앞문 뒤), C(뒷문 뒤), D(차체 뒤). 높이 쪽은 벨트 라인, 지붕 아래 선 |
| 묶음 | 부품마다 어느 묶음에 속하는지: 헤드램프(lamp, lampGap, lens, lampStand, lampBar), 그릴(shell, lip, core, cap), 앞 범퍼(bumperF0·1, clamp, iron), 뒤 범퍼, 앞 펜더, 뒤 펜더, 발판, 문 1·2, 창 0·1·2 |
| 붙음 규칙 | 묶음이 무엇에 붙는가: 창은 문 안에, 문은 고정점 사이에, 보닛 앞끝은 그릴 뒤에, 램프대는 펜더나 그릴 옆에, 발판은 앞뒤 펜더 사이에 |

조절은 "고정점이나 묶음을 움직이고, 붙은 것이 따라온다"가 된다. 차마다 부품은 모두 다르지만 고정점과 묶음 규칙은 같은 틀이라, 200종에 한 번 만든 규칙이 그대로 쓰인다.

## 3. 아이디어별 검토

### 3-1. 길이를 줄이면 문 비율을 맞추고 맨 뒤 창을 없앤다

실제로 있던 구분이다. 1920~30년대 세단은 옆창이 셋인 **6라이트**와, 맨 뒤 쪽창이 없는 **4라이트**(짧은 "클로즈 커플드" 세단)로 나뉜다. 1929년 무렵 같은 차종에 두 가지가 다 있었던 예도 흔하다.

| 방식 | 판단 |
|---|---|
| 길이가 문턱 아래로 내려가면 조용히 바꿈 | 비추천. 플레이어가 모르는 사이 차가 바뀐다 |
| **문턱을 넘으면 빨간 선으로 "4라이트로 바꿈"을 함께 그려 보여 주고, 수정을 누르면 반영** (추천) | 지금의 빨간 수정선 흐름과 같다. 체크리스트와 견적에도 미리 보인다 |
| 플레이어가 6라이트 / 4라이트를 직접 고름 | 함께 둔다(같은 버튼) |

문 비율 자동 맞춤 규칙(추천):
1. 객실 길이 = D - A. 문 길이에는 시대별 최소·최대가 있다(예: 1920년대 앞문 750~1050 mm, 뒷문 700~1000 mm).
2. 길이가 줄면 먼저 맨 뒤 쪽창 칸(C~D)이 줄어든다.
3. 쪽창 칸이 최소보다 작아지면 4라이트를 제안한다. 쪽창이 없어지고, 뒷문이 C~D를 차지한다.
4. 더 줄면 2도어(코치)를 제안한다. 주문서에 "4도어"가 있으면 체크리스트가 ×로 바뀐다.

### 3-2. 문 길이 조절

B·C 고정점을 움직이는 손잡이다. 앞문을 늘리면 뒷문이 줄고, 각 문은 시대 범위 안에서만 움직인다. 창은 문 안에서 비율대로 따라간다. 뒷좌석 발 공간(체크리스트)은 C 위치에서 바로 계산된다.

### 3-3. 창 위치

창은 자기 문 안에서만 움직인다. 좌우로는 문 테두리 여유 안에서, 위아래로는 벨트 라인과 지붕선 사이에서. 창 높이를 바꾸면 벨트 라인 몰딩(bead)이 따라간다.

### 3-4. 헤드램프 위치

램프 묶음을 앞뒤·위아래로 옮긴다. 붙는 곳은 시대가 정한다.

| 시대 | 램프가 붙는 곳 | 도면에서 할 수 있는 것 |
|---|---|---|
| 1920년대 | 램프대(바) 위, 펜더 위 지주 | 높이, 간격, 앞뒤 위치 (넓음) |
| 1930년대 중반 | 그릴 옆 · 펜더 위 포드 | 높이, 간격 (보통) |
| 1930년대 말~1940년대 | 펜더 속으로 들어감 | 펜더를 따라서만 (좁음) |

### 3-5. 그릴 위치와 크기

그릴 묶음의 높이·폭을 바꾸면 보닛 앞끝과 라디에이터(섀시 쪽)가 따라온다. 라디에이터보다 작은 그릴은 막는다(냉각 검사: 견적의 성능 줄에 "과열 위험"으로 보이게).

### 3-6. 범퍼 크기와 유무

달기/떼기, 폭, 막대 개수(1~2줄). 범퍼를 떼면 무게와 값이 줄고, 시험 주행 충돌 판정이 나빠진다. 1920년대 초 차는 범퍼가 옵션이던 시절이라 떼기가 자연스럽다.

### 3-7. 펜더 크기와 유무

| 조절 | 따라오는 것 |
|---|---|
| 펜더 크기(바퀴 덮는 정도, 스커트) | 발판 높이, 램프 지주 |
| 펜더 떼기 | 발판도 떼거나 짧은 발판으로. 바퀴가 다 드러나는 스피드스터 · 경주차 꼴 |

펜더를 뗄 수 있는 것은 1920년대와 경주용뿐이다. 1930년대 후반부터는 펜더가 차체와 이어져 떼기를 막는다.

### 3-8. 차종·시대마다 고칠 수 있는 것이 다르다

차마다 "조절표"를 둔다. 각 줄마다 할 수 있는지, 범위가 얼마인지 적는다.

| 조절 | 1920년대 세단 | 1930년대 중반 세단 | 트럭 |
|---|---|---|---|
| 축간 | 넓음 | 보통 | 넓음 |
| 6라이트 / 4라이트 / 2도어 | 모두 | 모두 | 해당 없음 |
| 문 길이 | 넓음 | 보통 | 좁음 |
| 램프 위치 | 넓음 | 보통 | 넓음 |
| 그릴 크기 | 보통 | 넓음 | 보통 |
| 범퍼 유무 | 가능 | 앞뒤 필수 | 가능 |
| 펜더 유무 | 가능 | 불가 | 가능 |

조절표는 시대 · 차종 · 회사 규모(설계 부서가 있으면 범위가 넓어짐)에서 만들어진다. 화면은 조절표에 있는 손잡이만 보여 준다.

## 4. 이번에 만든 것 (도면 품질, 검은 화면)

- **종이**: 종이마다 3~4가지 색조를 순서 디더로 깔았다. 그래서 그라데이션 대신 픽셀아트가 유지된다.
  - 닳은 제도지: 섬유결, 가장자리 바램, 접힌 자국(밝은 쪽과 그늘 쪽), 컵 자국, 얼룩 반점, 끊긴 연필 격자.
  - 깔끔한 제도지: 흰 종이, 50 mm마다 굵은 격자, 테두리 선과 구역 눈금, 표제란이 테두리 모서리에 붙는다.
  - 청사진: 얼룩진 인화지 결, 흰 테두리.
  - 검은 화면: 가운데가 밝은 비네트, 격자는 점과 굵은 선만.
- **선**:
  - 연필: 누르는 힘에 따라 진하고 옅음이 바뀌고, 둘레에 흑연 가루가 묻는다.
  - 잉크: 고른 선.
  - 청사진: 선이 살짝 번진다.
  - 검은 화면: 선이 빛난다(글로).
- **압정**: 그림자 진 황동 압정.
- **검은 화면 주사선**:
  - 바꾸면 화면 전체로 빛나는 주사선이 위에서 내려오고, 그 아래로 새 그림이 나타난다.
  - 수정은 천천히(약 1.2초), 미리보기와 취소는 빠르게 내려온다.
  - 화면 전체에 주사선 줄무늬가 깔린다.
- **정다면체**: 오른쪽 위에 와이어프레임 정이십면체가 천천히 돈다. 뒤쪽 모서리는 점선으로 흐리게 그리고, 아래에 "형상 연산"이라고 적는다.

## 5. 제안하는 진행 순서

1. 모델에 고정점(A~D, 벨트 라인)과 묶음, 붙음 규칙을 넣는다. 1929 세단부터 시작한다.
2. 문 길이, 6라이트 ↔ 4라이트 ↔ 2도어(길이를 줄이면 빨간 선으로 제안).
3. 램프 위치, 그릴 크기, 범퍼 유무·크기, 펜더 유무·크기.
4. 차·시대별 조절표. 화면은 조절표에 있는 손잡이만 보여 준다.
5. 조절 손잡이가 많아지면 도면 옆 조절판을 "차체 / 앞모습 / 바퀴 둘레" 세 탭으로 나눈다.

## 6. 정할 것

1. 길이를 줄일 때 4라이트·2도어를 빨간 선으로 제안하고, 수정을 눌러야 반영할지 (추천). 또는 조용히 자동으로 바꿀지.
2. 조절 범위를 시대 · 차종 · 회사 규모 세 가지로 정할지 (추천).
3. 펜더 떼기를 1920년대와 경주용에만 열지 (추천).
4. 위 진행 순서대로 1~3을 바로 만들지.
