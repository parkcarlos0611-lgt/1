# Design decisions

Each decision is listed with its date. The newest come first.

## 2026-11-25 — 삼각형 예산은 목표, 상한은 따로
- 959 외형 9,352 삼각형(목표 9,200보다 약 150, 1.6% 많음)은 줄이지 않는다. 형태를 깎아 숫자를 맞추지 않는다.
- 이유: 150 삼각형은 차 20대가 달려도 3천 개 정도로 GPU에 무시할 만하다(트랙과 숲이 수십만). 외곽선 hull과 그림자를 더해도 같다. 예산의 목적은 FR Legends 수준의 '깔끔한 면 밀도'를 지키는 것이지 정확한 숫자가 아니다.
- 규칙: 외형 7,400~9,200은 목표, 약 10,000은 상한(넘으면 원인 검토). 차체 껍질 5~6천, 실내 4~5천도 같은 방식이다. 다음 모델링 기준 문서(doc 112)와 자동 검문에 이 목표/상한 구분을 넣는다.

## 2026-11-24 — 1990년대 빌더, 자유도, 실차 수확 (이 대화의 결정 모음)
- **방향(가장 중요):** 자유도가 생명이다. 보이는 부분의 자유도에 집중한다. 차체는 바탕 차가 아니라 실루엣(고르고, 섞고, 끌어 변형)이고, 부품은 미리보기가 있는 수백 종 라이브러리다. 차량을 만든 목적은 부품을 분리해 라이브러리로 쓰기 위해서다.
- **수확 순서:** 실차를 추가한다 → 차체 형상 → 창문 → 장식물 → 엔진. 실차 수백 종이 부담되면 부품만 따온다(문서 107).
- **시대:** 1990년대부터 시작한다. 1930년대 차는 클래식카·리스토어(녹 효과 등)로 쓴다. 출력 상한은 없다(400 km/h급 시판차가 있었다).
- **버전:** 알파 0.10에서 시작해 0.11~0.19, 그다음 0.20(회사).
- **빌더 순서:** 안내는 하되 앞 단계로 돌아갈 수 있다. 서스펜션은 별도 단계(7단계 빌더). 새 방식 빌더에서 다시 정한다.
- **설계 수치:** 엔진 개발 등급(1~5)과 세부(흡기, 압축비, 윤활, 블록, 터보 0~4개), 구조·패널 소재를 상세하게 나눈다(탄소섬유 포함). 실차 6대로 검산한다.
- **호환:** 장착 규격으로 판정한다(장착 / 개조 장착 / 불가). 해결 수단을 보여 준다.
- **차종:** 성능 등급(일반·고성능·스포츠·슈퍼·하이퍼)과 차체 형식(2도어·4도어 등)의 두 축으로 나눈다. 왜건 모양이어도 성능이 스포츠카급이면 스포츠카다. 레이스 클래스는 규정 수치로 자른다.
- **동력계:** Automation 방식(엔진 계열·변형, 부품별 품질, 다이노, 소리, 분해도, 보관함)에 보완을 더한다. 피스톤 왕복을 보는 절단 보기를 둔다. 엔진·부품의 겉 디테일을 실제 게임 수준으로 올리는 일은 나중에 한다(스타일 결정 필요).
- **서스펜션:** 기구학 물리를 유지한다(현실적인 주행에 기여). 회귀 시험을 통과해 기본값이 되었다.
- **제작 공정(1990년대):** 계획으로만 둔다(문서 100). 0.20에서 한다.
- **경기장:** 이번에는 Millbrook만 계획서대로 보강했다(사람 제외). Ashcombe Park(1990년대화)와 Speed Bowl(시험장 시설)은 뒤로 미뤘다.
- **연기·유리:** CS2처럼 몽글몽글하고 차가 뚫는 부피 연기는 V0~V3까지 하고 V4~V6는 미뤘다. 카툰 유리 띠는 시점에 따라 움직이는 반사로 바꿨다. 카툰 그래픽 향상은 상세 계획을 따로 세운다.
- **XJ220:** 지금 모델은 다시 모델링해야 한다. 키트로 옮기지 않았다.
- **모델:** 모양 품질은 Fable이 기준이다(F355 비교에서 사용자가 Fable판을 골랐다).
- **작업 방식:** 동시 작업은 1~2개로 한다. 확인은 사용자가 실제 기기에서 미리보기로 한다(이 환경의 헤드리스 확인은 느리고 애니메이션이 돌지 않는다).
