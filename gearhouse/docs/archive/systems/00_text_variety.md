# 시스템 설계 00 — 글의 다양성 (모든 사건·편지·기사 공통)

기획자 요구: 같은 사건이라도 수백 가지 서로 다른 표현으로 나와서, 반복되는 구성이 느껴지지 않아야 한다. 이 문서의 방식을 모든 시스템의 글에 쓴다.

## 1. 원칙

- 글은 코드에 쓰지 않는다. 전부 `data/text/`의 데이터다.
- 한 사건은 "무슨 일인가(뼈대)"와 "어떻게 말하는가(표현)"를 나눈다. 뼈대는 시스템이 정하고, 표현은 조합으로 만든다.
- 다양성은 문장을 통째로 여러 벌 쓰는 것이 아니라 **작은 조각의 곱**에서 나온다.
- 무작위는 코어의 시드 난수로 뽑는다. 같은 세이브는 같은 글을 다시 보여 준다.

## 2. 조합 구조

한 건의 글은 네 층을 곱해서 만든다.

| 층 | 내용 | 예 (고객 문의 편지) | 가짓수 목표 |
|---|---|---|---|
| 상황 변형 | 같은 사건의 다른 사정 | 광고를 보고 / 친구 차를 보고 / 지나가다 / 예전 차가 망가져서 / 결혼 선물로 | 사건당 6~12 |
| 구성 틀 | 문단 순서와 포함 요소 | 인사 → 계기 → 요구 → 예산 암시 → 맺음. 일부를 빼거나 순서를 바꾼 틀 | 4~8 |
| 문장 조각 | 각 요소를 말하는 문장들. 안에 다시 고를 수 있는 낱말 자리가 있다 | "귀사의 광고를 {신문}에서 보았습니다" / "{신문}에 실린 귀 공방의 차가 눈에 띄어 펜을 듭니다" | 요소당 8~20 |
| 말투 | 쓰는 사람의 직업·나이·성격·교육·기분이 낱말과 문장 끝을 바꾼다 | 은행가의 격식, 농장주의 투박함, 젊은 상속자의 들뜸, 급한 사람의 짧은 문장 | 8~15 |

- 요소가 5개이고 각 12가지 문장이면 문장 조합만 약 25만 가지다. 여기에 상황 8, 틀 6, 말투 10을 곱하면 한 사건 종류에서 수천만 가지가 나온다. 사람이 쓰는 분량은 사건 종류당 문장 조각 약 60~100개다.
- **최근 사용 기록**: 최근에 쓴 조각과 틀은 한동안 뽑지 않는다. 같은 문장이 가까이에서 다시 나오지 않는다.
- **사실 끼워 넣기**: 조각 안의 자리(`{신문}`, `{차 이름}`, `{금액}`, `{이웃 이름}`, `{날씨}`, `{시대 사건}`)에 게임 상태의 실제 값을 넣는다. 그래서 글이 지금 판의 상황과 맞물린다.

## 3. 말투 (화자 특성)

화자마다 다음 값을 갖고, 조각을 고를 때와 낱말 자리를 채울 때 쓴다.

| 특성 | 값 예 | 영향 |
|---|---|---|
| 격식 | 높음 / 보통 / 낮음 | 인사말, 호칭, 문장 길이 |
| 성격 | 꼼꼼함, 성급함, 허세, 수줍음, 인색함, 호탕함 | 강조하는 내용, 덧붙이는 말 |
| 직업 낱말 | 의사, 은행가, 농장주, 배우, 레이서, 상인 | 비유와 관심사("진료 가는 길이 험해서") |
| 기분 | 기대, 걱정, 화남, 고마움 | 맺음말, 느낌표 |
| 지역 | 주(州)별 지명과 말버릇 | 지명, 날씨 언급 |

- 같은 "납기 지연에 대한 항의"도 은행가는 계약 조항을 들고, 농장주는 수확철을 놓쳤다고 쓰고, 상속자는 약혼식 날짜를 들먹인다.

## 4. 시대와 사정의 반영

- 조각마다 쓸 수 있는 조건을 단다: 연도 범위, 경기 상태, 계절, 고객 유형, 회사 평판 수준.
- 대공황이 깊어지면 "지불 능력 상실" 사건의 사정이 달라진다. 예: 은행 파산으로 예금을 잃음, 공장 폐쇄, 주식 폭락 손실, 농산물 값 폭락, 가족 부양, 사업 매각. 사정마다 고객의 제안도 다르다(분할 납부, 인도 연기, 값 인하 요청, 계약 포기, 다른 물건으로 대신 지불).
- 신문 기사와 같은 사실을 가리키게 한다. 그 주 신문에 은행 파산 기사가 났다면 편지에 그 은행 이름이 나온다.

## 5. 표현 매체의 다양성

같은 사건이 여러 모양으로 온다. 글뿐 아니라 보이는 모양도 다르다.

| 매체 | 모양 | 다른 점 |
|---|---|---|
| 편지 | 손글씨 또는 타자, 편지지와 봉투 | 고객 지위에 따라 종이 질과 글씨체가 다르다 |
| 전화 | 짧은 대화 여러 턴 | 끊기는 말, 되묻기 |
| 방문 | 인물 초상화와 대화 | 표정, 차림새 |
| 전보 | 짧은 대문자 문장 | 낱말을 아낀다 |
| 쪽지 | 직원이 받아 적은 메모 | 직원의 말투, 빠진 정보 |
| 신문 기사 | 제목과 본문 | 신문 성격별 문체 |

## 6. 데이터 형식 (안)

```
data/text/ko/inquiry_letter.json
{
  "situations": [ { "id": "saw_ad", "when": { "source": "ad" }, "weight": 3 }, ... ],
  "layouts":    [ ["greet", "reason", "want", "budget_hint", "close"], ["reason", "want", "close"], ... ],
  "parts": {
    "greet":  [ { "t": "삼가 인사 올립니다.", "voice": { "formal": "high" } }, { "t": "안녕하시오.", "voice": { "formal": "low" } }, ... ],
    "reason": [ { "t": "{paper}에 실린 귀 공방의 광고를 보았습니다.", "situation": "saw_ad" }, ... ]
  },
  "words": { "car_praise": ["맵시 있는", "야무진", "점잖은", ...] }
}
```

- 한국어와 영어는 따로 쓴다. 번역이 아니라 각 언어의 조각 집합이다(조사, 어순이 달라서다).
- 한국어 조사(은/는, 이/가, 을/를)는 끼워 넣는 낱말의 받침을 보고 자동으로 맞춘다.

## 7. 품질 관리

- **자동 검사**: 사건 종류마다 1만 건을 만들어 다음을 잰다.
  - 완전히 같은 글의 비율(목표 0.1% 미만)
  - 연속한 두 건이 같은 첫 문장으로 시작하는 비율(목표 2% 미만)
  - 채워지지 않은 자리와 조사 오류(목표 0건)
- **분량 계획**: 수직 슬라이스에서 글이 필요한 사건은 약 40종이다. 종류당 조각 60~100개면 약 3,000개 문장 조각이다. 사건 종류별로 나눠 쓰고, 자동 검사로 반복률이 높은 종류부터 보강한다.
- **쓰는 순서**: 가장 자주 나오는 것부터 쓴다. 고객 문의, 견적 회신, 공급사 회신, 구직 지원, 납품 알림 순이다.

## 8. 결정 (2026-11-19)

1. Claude가 문장 조각을 쓰고, 기획자가 말투와 시대감을 검수한다.
2. 옛 말투는 약간만 쓴다. 기본은 지금의 자연스러운 존댓말이고, 인사말·맺음말·몇몇 낱말에만 시대 느낌을 둔다. 하오체와 어려운 한자어는 격식 높은 화자의 일부 문장에만 쓴다.
