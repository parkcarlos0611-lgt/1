# 4단계 계획: 자료 기반 차량 생성, 경제 밸런스, 상호작용, 장소

> 상태: **계획 보고 단계 — 승인 후 제작.**
> 최우선 원칙 (사용자 지시): **이미지 제작 스타일보다 자료를 항상 우선한다.** 차량 외형 생성 메커니즘 자체를 실측 자료 기준으로 다시 만든다.

## 1. 지적 사항 진단 (코드 확인 결과)

| 지적 | 원인 | 수정 방향 |
|---|---|---|
| 테스트판에서 엔진 레이아웃이 안 보임 | 미리보기 칸이 147×88픽셀로 고정인데 V8(88×104), 직렬6(93×129)이 더 커서 "미리보기 불가"로 처리됨 | 칸 크기에 맞춰 축척 자동 계산 + 별도 **엔진룸·투시 화면** (§4) |
| 차량 하부가 비어 보임 | 차체 생성기(`bodygen`)에는 하부 데이터가 아예 없음 (복제 차량에만 수동으로 있음) | 생성 차량도 플랫폼 데이터에서 프레임·스프링·차축·배기·연료탱크·스플래시 에이프런·러닝보드 받침을 자동 생성 (§2-3) |

| AI 생성 이미지 성향 | 모든 차에 같은 수평 반사띠·디더 그라데이션, 지나치게 매끈한 곡선, 같은 두께의 부품, 대칭적이고 규칙적인 디테일 | §2-4 체크리스트와 자료 대조 검사 |
| 세부 요소가 얇음 | 범퍼·램프·그릴·핸들을 평면 도형 + 1~2픽셀 선으로 그림 | 실제 부품 구조(두께·브래킷·볼트·그림자)를 가진 부품 라이브러리 (§2-2) |
| 너무 쉽게 파산, 창 하나로 게임 종료 | 재고 비용이 즉시 현금에서 빠지고, 대출·경고 단계가 없으며, 현금 −$50,000이면 바로 종료 | §3 |
| 상호작용의 재미 부족 | 숫자·슬라이더 위주, 결과가 즉시 표시 | §4 |
| 장소가 없음 | 모든 것이 사무실 창 안 | §5 |

## 2. 자료 기반 차량 외형 생성 메커니즘 (핵심 재설계)

### 2-1. 실측 템플릿 라이브러리 → 블렌딩
- 생성기는 더 이상 **도형 파라미터**로 차를 만들지 않는다. 지금까지 실측한 복제 차량(1930년대 6종, 1940년대 10종, 이후 추가분)의 윤곽을 **대응점이 맞춰진 템플릿**으로 바꾼다.
- 대응점은 같은 의미의 점끼리 번호를 맞춘다: 범퍼 끝, 그릴 위, 카울, A필러 아래·위, 루프 최고점, C필러, 트렁크 끝, 휠 중심, 펜더 정점.
- 템플릿마다 휠베이스로 정규화한 좌표와 출처(도면·연식·치수)를 기록한다.
- 플레이어가 고르는 것은 "같은 연도대의 실제 차 2~3대 사이의 혼합 비율"과 허용 범위 안의 조정(휠베이스, 지붕 높이, 후드 길이)이다.
- 그래서 어떤 조합이든 실제 차의 비율에서 벗어나지 않는다. 꼬리·루프 형상은 실측 윤곽 그대로라 짓눌린 꼬리가 생기지 않는다.
- 연도 한계는 "그 연도까지 존재한 템플릿만 섞을 수 있다"로 단순하고 정확해진다.

### 2-2. 실제 부품 구조의 부품 라이브러리 (두툼하게)
부품을 평면 실루엣이 아니라 **실제 구조 단위**로 만든다. 레퍼런스 사진에서 두께·단면을 잰다.

| 부품 | 구성 (모두 자료 실측) |
|---|---|
| 범퍼 | 둥근 단면의 바(위 하이라이트·아래 그림자 3~4단), 끝 곡면, 브래킷 2개(프레임까지), 볼트 머리, 오버라이더 |
| 헤드램프 | 버킷(깊이 표현), 크롬 림, 렌즈 굴절 무늬, 스탠천·지지 바, 펜더 매립형은 하우징 |
| 그릴 | 셸 두께, 바 단면(앞면·옆면 2톤), 안쪽 라디에이터 코어가 비침 |
| 휠 | 타이어 사이드월 볼록, 림 단차, 허브캡 돔, 러그 너트, 휠 아치 안쪽 그림자 |
| 문 | 숨은 경첩·노출 경첩, 핸들(손잡이 + 받침), 열쇠 구멍, 문틀 단차 |
| 러닝보드 | 고무 매트 무늬, 크롬 테두리, 받침 브래킷 |
| 펜더 | 두께(옆면 띠), 안쪽 면 그림자, 머드플랩 |

### 2-3. 하부 자동 생성
- 플랫폼(휠베이스·프레임 형식·서스펜션·레이아웃)에서 측면 하부를 자동으로 만든다.
- **구성 요소**: 프레임 레일과 킥업, 판스프링 또는 횡치 스프링, 쇼크, 차축과 디퍼렌셜, 변속기 하단, 추진축 또는 토크튜브, 배기관과 머플러, 연료탱크, 스플래시 에이프런, 바닥판 가장자리.
- 이미 4x4·6x6·1942 세단에서 검증한 기계 정의 방식을 생성 차량 전체에 적용한다. 차체와 하부가 같은 좌표계라 떠 있는 부품이 없다.

### 2-4. "AI 성향" 제거 체크리스트 (자료 대조)
1. 반사띠·그라데이션은 레퍼런스 사진에서 잰 값만 쓴다. 모든 차에 같은 띠를 넣지 않고, 차체 곡률과 재질에 따라 위치·폭을 바꾼다.
2. 디더링은 경계 1~2픽셀에만 쓰고, 넓은 면은 단색 단계로 칠한다(픽셀아트 관습).
3. 선 두께·부품 크기는 실측 mm에서만 나온다. 같은 두께 1픽셀 선의 반복을 금지한다.
4. 디테일 밀도는 실제 차 기준으로 정한다. 없는 장식을 지어내지 않고, 있는 장식은 빠뜨리지 않는다.
5. **검증**: 생성 결과를 원본 도면 위에 겹쳐 윤곽 오차(평균 mm)를 숫자로 기록한다. 기준을 넘으면 실패로 보고 제출하지 않는다.

### 2-5. 자료 요청 (이번 단계에 필요)
| 우선 | 자료 |
|---|---|
| ★★★ | 1930~49 세그먼트별 측면 도면 추가(경차·고급·스포츠·상용) — 템플릿 수가 곧 디자인 자유도 |
| ★★★ | 범퍼·헤드램프·그릴·휠 **클로즈업 사진** (두께·단면 실측용) |
| ★★ | 1930~40년대 **자동차 딜러십** 외관·쇼룸 사진, **공장 조립 라인**, **시험 주행장**(트랙·언덕), 회사 **사무실** 사진 |
| ★ | 1930~40년대 차량 실내(계기판) 사진 — 시험 주행 운전석 화면용 |

## 3. 경제 밸런스와 게임 흐름

| 문제 | 수정 |
|---|---|
| 재고 비용이 즉시 빠져 순식간에 파산 | 재고는 자산으로 장부에 남기고, 보관비는 월 1%만 부담. 판매 예측(지난 3개월 + 시장 추세)을 보여 주고 "예측만큼 생산" 버튼 제공 |
| 대출 없음 | 은행 신용 한도(공장 가치 기반), 이자, 상환 일정 |
| 경고 단계 없음 | 현금이 마이너스가 되면 **경고 → 은행 면담 → 구조조정 선택**(공장 일부 매각, 모델 단종, 합병 제안, 정부 계약 신청) → 6개월 회생 기간. 파산은 그 뒤에만 |
| 창 하나로 종료 | 종료는 별도 장면: 신문 1면 기사, 회사 연표, 판매 그래프, 업적, "이 시점부터 다시" / "샌드박스로 계속" |
| 초반 진입 장벽 | 난이도 3단계(자본·시장 반응), 첫 차는 검증된 기본 설계로 시작하는 선택지, 사무실 비서의 단계별 안내 |
| 전시 | 군납은 전용 계약 화면: 사양 요구(4x4·트럭·엔진) → 입찰 → 생산 |

## 4. 상호작용 요소 (항목마다)

| 화면 | 상호작용 |
|---|---|
| 엔진 설계 | **움직이는 투시도**: 크랭크가 돌고 피스톤·커넥팅로드가 오르내리며, 밸브가 점화 순서대로 열리고 점화 불꽃이 깜박임. 회전수 슬라이더로 속도 조절. 실린더 수·배열·보어·스트로크를 바꾸면 그림이 바로 바뀜 |
| 다이노 테스트 | 시동 → 회전계·토크계 바늘이 움직이고, 토크·출력 곡선이 회전수를 따라 **서서히 그려짐** + 엔진음. 최고점 표시, 이전 시험 결과와 겹쳐 비교 |
| 변속기 | 기어가 맞물려 도는 단면 애니메이션, 단 변경 시 슬리브 이동 |
| 차 디자인 | 턴테이블에서 5뷰 회전(측면 → 정면 → 후면), 바람 시험 연기선(유선형 효과 시각화), 장착 검사 시 엔진이 엔진룸에 들어가는 연출 |
| 시험 주행 | **직접 운전**: 측면 스크롤 주행장, 가속·브레이크·클러치·변속(키보드·터치). 비동기 기어는 회전수를 맞춰야 들어감. 회전계·속도계, 기록 측정(0→60, 최고속, 언덕 등판). 엔진음은 실제 회전수를 따름 |
| 생산 | 조립 라인 애니메이션(생산량에 따라 속도·인원 변화), 완성차가 출고장에 쌓임 |
| 연구 | 실험실 장면에서 진행 막대 대신 시제품이 조금씩 완성 |
| 판매 | 딜러십에 내 차가 전시되고 손님이 둘러봄. 판매되면 차가 나감 |

## 5. 장소 (자유도)
- 회사 소재 도시의 **픽셀 지도**에서 건물을 눌러 이동한다.
- 회사가 커지고 시대가 바뀌면 건물 외관도 바뀐다.

| 장소 | 시대·규모에 따른 변화 |
|---|---|
| 본사 사무실 | 작은 창고 사무실 → 벽돌 본사 → 아르데코 본사. 책상·타자기·전화·지도 |
| 설계실 | 제도대, 클레이 모형(1940s), 엔진 시험대 |
| 공장 | 수작업 조립 → 컨베이어 라인 → 전시 군수 공장(위장 도색) |
| 시험 주행장 | 비포장 언덕길(1930s) → 포장 오벌 트랙 → 군용 험로 |
| 딜러십 | 1930s 거리의 작은 매장(손글씨 간판) → 1940s 유리 쇼룸(네온 간판) → 전후 대형 판매장 |
| 항구·철도역 (확장) | 수출, 부품 수입 |

장소 그림은 §2-4 원칙대로 자료 사진을 우선해 만든다. §2-5 자료가 오면 그 비율과 재질을 따른다.

## 6. 제작 순서 (승인 후)
1. **긴급 수정**: 엔진 미리보기 자동 축척, 경제 밸런스(재고·대출·경고 단계·종료 장면)
2. **엔진 투시 애니메이션 + 다이노 그래프 그리기**
3. **자료 기반 생성기 v2**: 실측 템플릿 대응점화와 블렌딩, 하부 자동 생성, 두툼한 부품 라이브러리, 도면 오버레이 오차 리포트
4. **시험 주행(직접 운전)**
5. 도시 지도 + 장소 4곳 (사무실, 공장, 시험 주행장, 딜러십)
6. 변속기·차 디자인·생산·연구·판매 상호작용
7. 테스트판 갱신 → 보고
