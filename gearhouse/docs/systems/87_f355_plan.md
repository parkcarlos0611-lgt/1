# 87 · 페라리 F355 — 제작 계획과 필요한 자료 (검토 156)

계획만 세운다. 자료가 모이면 NSX와 같은 순서(시트·엔진·물리는 Opus, 차체는 Fable)로 만든다.

## 1. 어떤 F355인가
- **권장: 1994 F355 베를리네타(6단 수동).** 기본형 쿠페이고, 받은 4면도(전장 4250, 휠베이스 2450, 오버행 1032/768, 전고 1170, 전폭 1900, 윤거 1514/1615)와 같은 차다.
- **1997 F1(패들 시프트)은 선택 사양으로 넣는다.** 같은 차체에 변속기만 바꾼다. GTS(타르가)와 스파이더는 지붕이 달라서 하지 않는다.
- 기억하는 제원(만들 때 출처로 다시 확인한다): 3.5 L V8, 실린더당 5밸브, 380 PS/8,250 rpm, 363 Nm/6,000 rpm, 약 1,350 kg(건조 중량), 앞 225/40 ZR18, 뒤 265/40 ZR18, 최고 약 295 km/h, 0→100 약 4.7초.

## 2. 이 차로 새로 들어오는 시스템
| 시스템 | 내용 | 게임에서 |
|---|---|---|
| **F1 자동화 수동(1997)** | 전자유압식 클러치와 변속. 클러치 페달이 없고 패들로 바꾼다. 변속 시간이 수동보다 빠르거나 비슷하다 | 변속 방식(수동, 자동, F1)을 차 사양으로 일반화한다. 변속 시간, 클러치 조작, 다운시프트 블리핑 |
| **가변 댐퍼** | 전자 제어 댐퍼. 컴포트와 스포츠 모드, 속도에 따라 감쇠가 바뀐다 | 서스펜션 모드를 설정에서 바꾸고, 감쇠 계수가 속도·모드에 따라 바뀐다 |
| **평평한 차체 바닥과 뒤 디퓨저** | 앞뒤 다운포스. 페라리 양산차 처음으로 바닥 전체를 덮었다 | XJ220의 그라운드 이펙트를 재사용해 앞뒤 배분을 넣는다 |
| **5밸브 V8 고회전** | 8,250 rpm 최고 출력, 8,500 rpm 레드라인 | 엔진 소리와 출력 곡선. 공용 엔진 모듈에 F355 V8(빨간 주름 도장 흡기)이 이미 있다 |
| 트랙션 컨트롤 | **없음** | NSX(있음)와의 대비 |

## 3. 디자인 포인트
1. **옆 흡기구:** 도어 뒤에서 앞으로 길게 파인 홈이 뒷바퀴 앞 흡기구로 이어진다. 차 옆모습의 핵심이다.
2. **엔진 덮개:** 뒷유리 뒤 루버 판(V자 날개 배열)과 그 아래 빨간 흡기. 4면도 평면에 루버 배열이 보인다. 공용 엔진 모듈로 V8을 넣고 루버 사이로 보이게 한다.
3. **팝업 헤드램프:** 앞 덮개가 올라가는 방식이다. NSX·디아블로와 같은 장치를 쓴다.
4. **앞모습:** 타원형 그릴 안의 말 배지, 양쪽 둥근 안개등과 흡기구.
5. **뒷모습:** 원형 테일램프 한쪽에 2개씩(4개), 가운데 말 배지, 아래 검은 그릴, 배기구.
6. **부드러운 곡면:** 앞 펜더 위로 둥글게 솟은 바퀴 아치, 길게 떨어지는 뒷유리 버팀벽(플라잉 버트레스). EB110처럼 둥근 덩어리 방식이다.
7. **5스포크 별 모양 휠**(4면도에 보인다).

## 4. 지금 가진 자료와 판단
- **F355 4면도(치수 포함):** 해상도가 높고 치수가 다 적혀 있어 좋은 기준이다. 정사영인지, 세로로 눌렸는지는 만들 때 바퀴 지름으로 확인한다.
- **부족한 것:** 실차 사진과 3D 모델 화면이 없다. NSX는 사진과 와이어프레임이 있어서 캐노피와 꼬리를 바로잡을 수 있었다.

## 5. 요청 자료 (중요한 순서)
1. **실차 사진 4~6장:** 앞 3/4, 뒤 3/4, 정측면, 정면, 정후면. 베를리네타면 좋고, 색은 상관없다.
2. **옆 흡기구와 엔진 덮개 클로즈업:** 흡기구가 어디서 시작해 얼마나 깊은지, 루버 배열과 그 사이로 보이는 흡기.
3. **앞뒤 램프 클로즈업:** 팝업 램프(닫힌 모습과 올라간 모습), 앞 그릴과 안개등, 원형 테일램프 4개.
4. **3D 모델 화면이나 와이어프레임(있으면):** 디아블로와 NSX 때처럼 면의 흐름과 패널 경계를 잡는 데 가장 효과가 컸다.
5. **(선택) 실내 사진:** 유리 너머로 보이는 대시보드, 시트, 기어 게이트(크롬 H 패턴).

## 6. 순서
1. 시트(Opus): 4면도와 사진에서 치수, 옆모습, 평면, 흡기구, 엔진 덮개, 부품 위치를 잰다.
2. 물리(Opus): F1 변속기와 변속 방식 일반화, 가변 댐퍼, 디퓨저, 출력 곡선. 테스트를 붙인다.
3. 차체(Fable): 패널별로 만들고, 공용 엔진 모듈의 V8을 루버 아래에 넣는다.
4. 등록: 핸디캡, 주행 페이지, 팝업 램프 연동.

## 7. 정해 주실 것
- 기본형은 1994 수동으로 하고 F1을 선택 사양으로 둘지(권장), 처음부터 F1로 할지.
- 색: 로소 코르사 빨강은 NSX·디아블로와 겹친다. 노랑(지알로 모데나)이나 은색도 가능하다.
