# 2D 시대 계획 보관 (검토 166)

검토 14~67은 2D 그림 중심으로 게임을 만들던 시기의 계획이다. 3D 차(메시, 물리, 실시간 렌더러)로 방향을 바꾸면서, 지금 계획에서 빼고 여기에 보관한다. 지우지는 않는다. 나중에 화면 구성, 경영 게임 장면, 고증 자료를 다시 쓸 때 찾아본다.

| 범위 | 내용 |
|---|---|
| 14~32 | 2D 차량 제작: 차체 고르기, 시트(측면·정면·평면), 도면 화면, 픽셀아트 인터페이스, 하체 그림, 엔진 조달 |
| 33~40 | 세계 구조, 견본 A·B, 판본 1단계(수리 하루) |
| 41~59 | 2D 장소: 공방, 주방, 집 앞, 전화번호부, 손님 방문, 차고 수리, 인도 (스프라이트와 계절 그림) |
| 60~67 | 시트 차의 부품 모델화, 직접 제작 지침, 배치별 지시서, 2D 제작 규칙, 고해상도 차 층 |

- **그대로 두는 것:** `docs/systems/00~13`(시간, 주문, 판매, 재정 같은 게임 체계)은 렌더링 방식과 관계없어 그대로 둔다. `68` 이후는 3D 시대의 계획이다.
- **코드:** 2D 코드(`ui/scenes/*`, 시트 차, 2D 아트)는 그대로 둔다. 게임 본편이 아직 그 코드를 쓴다. 문서만 옮겼다.
- **경로 수정:** 문서를 옮기면서 코드와 문서 안의 경로도 `docs/archive/2d/`로 고쳤다.
