# 시스템 설계 03 — 공급사와 계약

수직 슬라이스(소규모 공방, 미국, 1930~1935) 기준이다. 수치는 시작값이다. 가격은 아직 당시 자료와 대조하지 않았다.

## 1. 목적

- 차를 만들려면 사 와야 하는 것이 있다. 누구에게서, 얼마에, 언제까지, 어떤 품질로 받는지가 차의 원가·품질·납기를 정한다.
- 공급사는 찾아야 보인다. 전화번호부를 뒤지고, 신문 광고를 읽고, 편지를 써서 관계를 만든다.

## 2. 사 오는 것 (슬라이스 범위)

| 분류 | 품목 | 단위 | 비고 |
|---|---|---|---|
| 섀시 | 롤링 섀시(프레임 + 차축 + 서스펜션 + 조향 + 브레이크 + 바퀴) | 대 | 쉬운 길. 자작하면 아래 부품을 따로 산다 |
| 동력 | 엔진, 변속기, 클러치 | 개 | 슬라이스에서는 자체 엔진 개발이 없다 |
| 하체 부품 | 차축, 판스프링, 쇼크, 조향 기어, 브레이크 세트, 휠, 타이어 | 개·세트 | 섀시 자작 때 |
| 자재 | 강판(두께별), 강관·채널, 목재(물푸레나무 뼈대), 유리, 도료, 가죽·천 | 장·미터·통 | 재고로 쌓인다 |
| 전장·소품 | 헤드램프, 테일램프, 계기, 배터리, 경적, 범퍼, 손잡이 | 개 | |

- 모든 품목은 `data/parts/`의 부품 데이터를 가리킨다(무게, 기준 원가, 품질 등급, 신뢰성, 필요 기술).
- 같은 품목도 공급사마다 품질 등급과 값이 다르다.

## 3. 공급사

```
Supplier {
  id, name, town, distance          // 가상 회사 이름. 거리로 연락·배송 시간이 정해진다
  catalog: [{ part, grade, listPrice, minOrder, leadDays }]
  size                              // 동네 가게 / 지역 도매상 / 제조사
  reliability                       // 납기를 지키는 정도
  consistency                       // 품질이 고른 정도
  temper                            // 흥정에 응하는 정도
  health                            // 경영 상태: 대공황에 망할 수 있다
  relation                          // 우리와의 관계 0~100
  known                             // 플레이어가 아는지, 어떻게 알았는지
  contact: { phone, mail, visit }
}
```

| 규모 | 특징 |
|---|---|
| 동네 가게(철물점, 타이어 가게, 유리 가게) | 소량을 바로 판다. 비싸다. 등급이 낮거나 보통이다 |
| 지역 도매상 | 품목이 많다. 중간 값. 최소 주문량이 있다 |
| 제조사(엔진·섀시·강판) | 싸고 좋다. 최소 주문량이 크다. 작은 공방은 상대해 주지 않을 수 있다(평판·거래 실적 조건) |

- 슬라이스에서는 약 12곳을 둔다. 처음에 아는 곳은 동네 가게 2~3곳뿐이다.

## 4. 공급사를 찾는 길

| 길 | 드러나는 것 | 비용 |
|---|---|---|
| 전화번호부(업종별) | 같은 도시의 가게·도매상 이름과 주소. 품목과 값은 모른다 | 없음 |
| 신문·잡지의 공급사 광고 | 이름, 대표 품목, 가끔 가격 | 읽기만 하면 된다 |
| 다른 공급사·직원의 소개 | 이름과 대략의 평 | 관계가 좋아야 한다 |
| 업계 박람회(연 1회 사건) | 제조사 여러 곳 | 여비와 며칠 |
| 고용한 직원의 이전 거래처 | 직원이 알던 공급사 | 없음 |

- 이름만 아는 상태에서는 카탈로그가 비어 있다. **문의**(편지·전화·방문)를 해야 품목·값·납기가 채워진다.

## 5. 거래의 흐름

1. **문의**: 품목과 수량을 적어 보낸다. 연락 수단에 따라 회신이 온다(01 문서 7장).
2. **견적 회신**: 단가, 최소 주문량, 납기, 지불 조건(선불 / 인도 시 / 30일 외상).
3. **흥정**: 다음 중 하나를 내주고 다른 것을 얻는다.

| 내주는 것 | 얻는 것 |
|---|---|
| 수량을 늘림 | 단가 인하 |
| 선불 | 단가 인하 또는 납기 단축 |
| 장기 계약(6~12개월 정기 납품) | 단가 인하, 우선 납품 |
| 납기를 늦춰 줌 | 단가 인하 |
| 웃돈 | 급행 납품, 상급 등급 선별 |

4. **발주**: 주문서가 만들어진다. 선불이면 그 자리에서 돈이 나간다.
5. **납품**: 아침에 도착한다. 도착한 물건마다 실제 품질이 정해진다(등급 평균 ± 공급사의 `consistency`).
6. **검수**: 시간을 써서 검사하면 불량이 드러난다. 검사하지 않으면 제작 중이나 인도 후에 드러난다.
7. **지불**: 조건대로 지불한다. 외상을 늦게 갚으면 관계가 떨어진다.

- 흥정의 성공은 `temper`, 우리와의 `relation`, 주문 규모, 흥정 능력치가 정한다.
- 흥정은 최대 2번 오간다.

## 6. 관계

| 오르는 원인 | 내리는 원인 |
|---|---|
| 제때 지불, 반복 주문, 큰 주문, 직접 방문 | 지불 지연, 잦은 반품, 무리한 흥정, 주문 취소 |

- 관계가 높으면 외상을 주고, 물량이 달릴 때 먼저 주고, 다른 공급사를 소개한다.
- 관계가 낮으면 선불만 받거나 거래를 끊는다.

## 7. 생길 수 있는 사건

모두 `00_text_variety.md`의 방식으로 여러 사정과 표현으로 나온다.

| 사건 | 선택지 |
|---|---|
| 납기 지연 통보 | 기다림 / 다른 곳에서 급히 구함(웃돈) / 주문 취소 |
| 불량 도착 | 반품·교환 요구 / 값을 깎고 받음 / 그냥 씀(품질 하락) |
| 가격 인상 통보(원자재 값 변동) | 받아들임 / 흥정 / 거래처 변경 |
| 공급사 폐업(대공황) | 선불금 손실 가능. 대체 공급사를 찾아야 한다 |
| 공급사의 제안(재고 떨이, 새 품목, 독점 공급) | 수락 / 거절 |
| 경쟁사가 물량을 선점 | 웃돈 / 대체품 |
| 파업·운송 사고 | 지연 |

## 8. 재고와 창고

- 받은 물건은 공방 창고에 쌓인다. 창고 크기에 한도가 있다(공방 확장과 연결).
- 자재는 쓰는 만큼 줄어든다. 차 한 대에 드는 자재량은 설계에서 나온다(차체 면적 → 강판 장수, 뼈대 길이 → 목재).
- 도료·가죽·고무는 오래 두면 품질이 떨어진다.
- 재고가 모자라면 제작이 멈추고 사건이 난다.

## 9. 상태 데이터

```
Supplier[]      // 3장
Quote        { supplierId, lines: [{ part, grade, qty, unitPrice }], leadDays, terms, validUntil, round }
PurchaseOrder{ id, supplierId, lines, placedDate, dueDate, terms, paid, state }
Delivery     { orderId, date, items: [{ part, grade, qty, quality, inspected }] }
Contract     { supplierId, part, grade, qtyPerMonth, unitPrice, months, startDate }
Stock        { [part+grade]: [{ qty, quality, receivedDate }] }
```

## 10. 하루 틱에서 하는 일

1. 아침: 납기가 된 주문의 도착을 굴린다(`reliability`). 도착하면 납품 사건을 낸다. 늦어지면 지연 통보를 낸다.
2. 낮: 기다리는 문의·흥정의 회신 날짜가 되면 회신 사건을 낸다.
3. 저녁: 외상 만기를 확인한다. 정기 계약의 월 납품을 주문으로 만든다.
4. 월초: 공급사마다 `health`를 굴린다(경기에 따라). 원자재 값 변동으로 카탈로그 값을 바꾼다.

## 11. 이벤트

| 이벤트 | 보내는 내용 | 듣는 시스템 |
|---|---|---|
| `supplier_found` | 공급사, 어떻게 알았는지 | UI(주소록) |
| `supplier_quote_received` | 견적 | UI, 시간(정지) |
| `purchase_ordered` | 주문 | 재무 |
| `parts_delivered` | 납품, 품질 | 생산, 재고 |
| `delivery_delayed` | 주문, 새 날짜 | 생산(납기 재계산), 판매 |
| `defect_found` | 물건, 불량 | 생산, 관계 |
| `supplier_closed` | 공급사 | 미디어(기사), 생산 |
| `contract_signed` / `contract_ended` | 계약 | 재무, 시간(만료 알림) |
| `stock_short` | 품목 | 생산(정지), 시간(정지) |

듣는 이벤트: `economy_changed`(원자재 값, 공급사 경영), `order_placed`(필요 부품 계산), `newspaper_published`(공급사 광고로 `supplier_found`).

## 12. 결정이 필요한 것

1. 롤링 섀시 구매와 섀시 자작을 둘 다 둘지(재설계 계획에서 제안한 내용).
2. 검수에 시간을 쓰는 방식(5장 6번)을 넣을지. 넣으면 "믿을 만한 공급사"의 가치가 생긴다.
3. 자재를 장·미터 단위 재고로 다룰지, 차 한 대분 묶음으로 단순화할지. 재고 단위가 세밀하면 현실적이지만 관리가 번거롭다.
