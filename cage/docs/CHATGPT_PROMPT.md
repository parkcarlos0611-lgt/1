# ChatGPT 요청문 — 전신 텍스처 메쉬용 선수 이미지

첨부할 이미지 2장
1. `assets/fighters/kane/reference_full.png` (구도·포즈·스케일 기준 전신 이미지)
2. `assets/fighters/kane/part_sheet.png` (부위별로 분리한 모습: 이 부위 구성이 게임에서 쓰입니다)

## 프롬프트 (그대로 복사해서 사용)

```
첨부한 이미지 1(reference_full.png)은 2D 격투 게임에 쓸 "전신 텍스처 메쉬 원본"입니다.
첨부한 이미지 2(part_sheet.png)는 이 전신 이미지를 게임 엔진에서 어떻게 부위별로 잘라 쓰는지 보여주는 시트입니다.

[목표]
이미지 1과 "완전히 같은 구도·포즈·스케일·카메라"로, 아래 선수의 외형만 바꾼 전신 이미지를 1장 만들어 주세요.
(나중에 이 이미지를 이미지 2처럼 12개 부위로 기계적으로 잘라 쓰므로, 포즈가 달라지면 안 됩니다.)

[선수 정보]
- 이름/별명: {선수 이름}
- 체형: 키 {cm}, 체중 {kg}, 리치 {cm}, 근육량 {마른/보통/근육질/매우 근육질}
- 피부색: {예: 밝은 / 황갈색 / 올리브 / 갈색 / 어두운 갈색}
- 머리: {삭발 / 짧은 스포츠머리 / 곱슬 / 장발 묶음 ...}, 수염: {없음 / 짧은 수염 ...}
- 문신: {위치와 내용, 없으면 "없음"}
- 트렁크: 색 {검정/금색/...} + 로고 {UFC 벨트, 측면 로고 등}
- 글러브: 검정 4온스 MMA 글러브 + 손목 스트랩(빨강). 스트랩 색만 빨강 유지.

[절대 고정할 것: 포즈·구도]
1. 순수 옆모습(좌→우 방향), 선수가 오른쪽을 바라봄. 오소독스(왼발이 앞) 스탠스는 이미지 1과 동일.
2. 이미지 1과 같은 포즈: 양손 가드(앞손 턱 앞, 뒷손 턱 옆), 팔꿈치 몸통에 붙임, 무릎 살짝 굽힘, 발은 어깨너비 두 배로 벌림.
3. 카메라는 정측면 고정, 원근 왜곡·3/4 시점·과장된 단축 금지. 이미지 1과 같은 정도의 약한 3/4만 허용.
4. 화면 비율 1312×1199(약 1.09:1). 인물의 머리 꼭대기가 위에서 약 1.2%, 발바닥이 아래에서 약 3% 지점에 오게(이미지 1과 동일).
   인물의 좌우 폭도 이미지 1과 같은 위치(왼발 끝 약 20%, 오른발 끝 약 76%)에 맞추세요.
5. 선수의 체형(키, 어깨 폭, 허벅지 두께 등)은 달라져도 되지만 관절 위치(어깨·팔꿈치·손목·고관절·무릎·발목)의 대략적인 높이는 이미지 1과 비슷하게 유지.

[그림 스타일: 이미지 1과 동일]
- 깔끔한 플랫/세미리얼리스틱 일러스트, 면 분할 음영(저폴리 느낌), 얇은 갈색 외곽선, 부드러운 그라데이션.
- 배경은 순백(#FFFFFF) 단색. 그림자, 바닥선, 반사, 글자, 워터마크 전부 금지.

[부위 분리를 위해 꼭 지킬 것]
- 앞팔(가드)과 몸통이 겹치는 이미지 1의 배치를 유지: 가까운 쪽 팔이 가슴 앞을 가로지르고, 먼 쪽 팔은 몸통 뒤에서 글러브만 턱 옆에 보임.
- 두 다리는 서로 겹치지 않게 충분히 벌린 이미지 1의 간격 유지(앞다리·뒷다리가 분리되어 보여야 함).
- 트렁크는 허벅지 중간까지 내려오는 길이, 양쪽 다리 통이 따로 보이게.
- 글러브·스트랩은 손목 위치에서 선명하게 분리되어 보이게.
- 맨발, 5개 발가락이 보이게(앞발은 옆모습, 이미지 1과 동일).
- 얼굴은 무표정에 가까운 집중한 표정. 상처·멍·피·땀 표현 금지(게임 안에서 부위별로 따로 올립니다).
- 인물 외곽선은 깨끗하게(배경과 경계가 또렷하게). 반투명 번짐 금지.

[출력]
- PNG, 1312×1199, 배경 순백.
- 같은 선수의 변형을 요청하면(예: 다른 트렁크색) 포즈를 절대 바꾸지 말고 색/디테일만 바꿔 주세요.
```

## 이어서 요청하면 좋은 보조 이미지 (선택)

1. **부위별 개별 이미지 직접 생성** (전신 이미지가 잘 안 맞을 때)
```
위 선수의 전신 이미지를 기준으로, 다음 12개 부위를 각각 "배경 순백, 가려진 부분은 자연스럽게 이어 그려서 완전한 형태로" 따로 그려 주세요:
머리(+목), 몸통(팔 없이 가슴·복부 전체), 골반(벨트+트렁크 허리), 가까운 팔 상박, 가까운 팔 하박+글러브, 먼 팔 상박, 먼 팔 하박+글러브,
앞다리 허벅지(트렁크 다리 통 포함), 앞다리 정강이, 뒷다리 허벅지(트렁크 다리 통 포함), 뒷다리 정강이, 발(옆모습).
각 부위는 관절 쪽 끝이 둥글게 이어지도록 여유 있게 그리고, 서로 같은 스케일(전신 이미지 기준)로 한 장의 시트에 라벨 없이 배치.
```
2. **피격 상처 텍스처** (머리용): 눈가 붓기, 눈썹 찢김, 입술 터짐, 코피, 광대 멍을 각각 투명 배경 PNG 오버레이로 (머리 이미지와 같은 크기·위치).

## 적용 방법 (개발용)
```
python3 tools/slice_fighter.py 새선수.png assets/fighters/<이름> --sheet
```
그 뒤 선수 look에 `tex:'<이름>'`을 지정하면 그 선수는 해당 텍스처 세트를 사용합니다. (새 이미지의 인물 bbox가 기준과 다르면 슬라이서가 자동으로 크기·위치를 맞춥니다.)
