# E1 조립 테스트 — 프롭 무작위 조합 1930년대 차량 20대

실행: `node tools/pixel/samplesAsm.mjs` → `samples/e1_assembly_test.png`, `data/e1_assembly_test.json` (시드 1~20 고정, 재현 가능)

## 1. 절차
1. 시드로 연도(1930~1939), 디자인 언어(박스/유선), 차종(4도어 세단/2도어 쿠페), 슬라이더 9개를 무작위 결정
2. 휠을 먼저 고름 → 타이어 규격 코드가 차체 비율(휠 반경·펜더 간격)을 결정
3. `clampParams()`가 연도·스타일 한계로 슬라이더와 선택지(꼬리·펜더·그릴)를 보정
4. 슬롯 9개(휠, 헤드램프, 범퍼, 후드 벤트, 트림, 스페어, 트렁크, 마스코트, 루프)마다 **연도 + 차체 조건을 통과한 후보 중에서만** 선택
5. 선택한 프롭의 파라미터를 차량 축척(12.5mm/px)에서 **네이티브로 다시 그림** (프롭 시트 이미지를 축소해 붙이지 않음 → 픽셀아트 품질 유지)
6. 디자인 점수 = 시대 적합도 40 + 스타일 조화 35 + 비율 25

## 2. 슬롯 호환 규칙 (예)
| 슬롯 | 규칙 |
|---|---|
| 헤드램프 | 드럼·총알·물방울형은 분리형 펜더에서만(램프 바·스템 필요). 펜더 포드·매립형은 폰툰·스커트 펜더에서만 |
| 스페어 | 사이드마운트는 분리·밸런스 펜더에서만. 후면 노출·커버는 박스형 + 업라이트·트렁크 꼬리에서만. 트렁크 내장은 업라이트 꼬리 제외 |
| 트렁크 | 러기지 랙은 업라이트 꼬리, 트렁크 박스는 업라이트·트렁크, 일체형은 트렁크·버슬 꼬리 |
| 후드 벤트 | 세로 루버·벤트 도어는 박스형, 래핑 루버는 유선형 |
| 루프 | 천 인서트·인조가죽·랜도는 박스형, 일체형 강판 지붕은 1935년 이후 |
| 연도 | 모든 프롭은 등장~퇴장 연도 범위가 있음 (예: 와이어 휠 32 ~1934, 휠커버 1936~) |

## 4. 테스트 중 발견해 고친 문제
| 문제 | 수정 |
|---|---|
| 쿠페가 픽업처럼 보임 (짧은 캐빈 + 평평하고 긴 데크) | 쿠페는 루프 뒤에서 꼬리까지 경사 데크(터틀 데크) |
| 헤드램프 버킷이 허공에 뜸 | 펜더 크라운까지 내려오는 램프 스템 추가 |
| 유선형 버슬 꼬리에 세로 스페어가 솟음 | 후면 스페어는 박스형 + 업라이트·트렁크 꼬리로 제한 |
| 밸런스 펜더 앞끝이 뾰족함 | 앞끝 모서리 R 80mm |

## 5. 2차: 떠 있는 요소 연결 시스템 + 남은 과제 수행

### 5-1. 고립 요소 자동 연결 (`gen/anchor.mjs`, `buildCar`·`buildFront` 공통 후처리)
1. 렌더 결과에서 그림자를 뺀 픽셀로 8방향 연결 덩어리를 찾는다.
2. 차체 픽셀을 가장 많이 가진 덩어리를 본체로 보고, 휠은 차축으로 지지된다고 본다.
3. 나머지 덩어리는 아래 → 옆 → 위 순으로 가장 짧은 지지 경로를 찾아 브래킷(검은 철제, 큰 부품은 2px)을 그린다. 연쇄 지지도 허용(최대 4회).
4. 결과를 `anchorLog`(브래킷 수·방향·길이, 미해결 수)로 남겨 검증에 쓴다.
- 결과: 조립 20대에서 고립 요소 36개를 연결, 미해결 0. 레퍼런스 차량은 쿠페 1건 외에는 이미 연결 상태.

### 5-2. 정면·후면 조립 (`assembleViews`)
- 측면에서 고른 프롭(램프·범퍼·스페어·타이어·펜더 색)을 정면·후면에도 똑같이 적용.
- 그릴 슬롯 추가(연도별 12종 중 선택). 그해 스타일에 맞는 그릴이 없으면 스타일 조건만 완화하고 연도는 지킨다.
- 결과: `samples/e1_assembly_3view.png` (8대 × 측면·정면·후면)

### 5-3. 스타일 조화 점수 확장
- 9개 슬롯 전체의 스타일 태그(박스/유선) 일치율 55% + 성격 태그(경제·패밀리·고급·스포츠) 일관성 45%.
- 차량 성격(character), 원가(cost), 위신(prestige)을 함께 산출.

### 5-4. 시장 연결 (`gen/market.mjs`)
| 세그먼트 | 가중치 (가격 / 최신성 / 디자인 / 위신 / 실용) | 선호 태그 |
|---|---|---|
| 경제 | 0.45 / 0.15 / 0.10 / 0 / 0.30 | economy, box |
| 패밀리 | 0.25 / 0.20 / 0.15 / 0.10 / 0.30 | family, stream |
| 고급 | 0 / 0.15 / 0.30 / 0.45 / 0.10 | luxury |
| 스포츠 | 0.10 / 0.25 / 0.40 / 0.20 / 0.05 | sport, stream |

예: #12(1930 세단, 경제형 부품) 경제 95 / 고급 51. #20(1936 유선형 쿠페, 고급 부품) 경제 51 / 고급 71.

## 6. 이후 과제
- 조립 차량은 현재 측면만 그림 → 정면·후면 조립 (그릴·범퍼·램프 프롭은 이미 정면 스프라이트가 있음)
- 디자인 점수의 "스타일 조화"가 휠·후드 벤트 태그만 사용 → 램프·범퍼·트림 태그까지 확장
- 시장 시뮬레이션과 연결 (세그먼트별 선호 태그로 매력도 계산)
