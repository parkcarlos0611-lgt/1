# 77 · 시험 차량(티렐 P34, EB110, XJ220)과 엔진·변속기·서스펜션·구동축 3D 구현 — 검토 (검토 121)

기획자 요청 두 가지를 검토한다. 구현은 결정 뒤에 한다.
1. 6륜 시험용으로 티렐 P34, 또는 1990년대 기술 시험용으로 부가티 EB110이나 재규어 XJ220 중 무엇이 나은가.
2. 엔진, 변속기, 서스펜션, 구동축을 3D로 구현하는 방안.

## 1. 세 차의 실제 사양과 시험할 것

| | 티렐 P34 (1976) | 부가티 EB110 GT (1991) | 재규어 XJ220 (1992) |
|---|---|---|---|
| 바퀴 | 6개. 앞 10인치 4개가 모두 조향 | 4개 | 4개 |
| 구동 | **뒤 2륜만** (6륜 구동이 아님) | **상시 4륜**. 센터 디퍼렌셜, 앞뒤 약 27:73 | 후륜 |
| 엔진 | 코스워스 DFV 3.0 V8 자연흡기, 약 470마력 | 3.5 V12, 터보 4개, 약 553마력 (SS 약 603) | 3.5 V6, 터보 2개, 약 542마력 |
| 변속기 | 휴랜드 5단 | 6단 수동 | 5단 수동 |
| 차체 | 알루미늄 모노코크, 약 575 kg | 탄소섬유 모노코크(아에로스파시알), 약 1,620 kg | 알루미늄 허니콤, 약 1,470 kg |
| 공력 | 날개, 앞바퀴 작게 해 전면 면적 줄임 | 능동 리어 윙 | 차체 하부 벤투리(그라운드 이펙트) |
| 기록 | 1976 스웨덴 GP 1·2위 | 약 342 km/h | 약 341 km/h (1992, 나르도) |

(수치는 공개된 일반 자료 기준이며, 넣을 때 레퍼런스 시트로 다시 확인한다.)

### 각 차로 시험할 수 있는 것
- **P34**
  - 바퀴 수를 일반화한다(지금은 4륜이 코드 곳곳에 고정되어 있다: 물리, 타이어 링, 메시의 바퀴 찾기, 렌더러).
  - 두 차축 동시 조향의 기하, 작은 바퀴의 접지면과 타이어 열, 공력 다운포스를 시험한다.
  - **6륜 구동은 시험할 수 없다.** P34는 뒤 2륜 구동이다.
- **EB110**
  - 상시 4륜 구동: 센터 디퍼렌셜(토크 배분, 점성 커플링). 지금은 오픈 디퍼렌셜 하나뿐이다.
  - 터보 4개: 부스트 지연(터보 랙), 웨이스트게이트.
  - 탄소 모노코크: 노드·빔 변형에 매우 단단하고 부러지는 재질을 처음 쓴다.
  - 능동 리어 윙: 속도에 따라 다운포스가 바뀐다.
  - 6단 싱크로 변속기.
- **XJ220**
  - 트윈 터보, 그라운드 이펙트(지면 높이에 따라 다운포스가 바뀐다), 후륜 대출력.
  - EB110과 많이 겹치고, 새로 시험할 것은 그라운드 이펙트 정도다.

### 무엇이 나은가 — 권장: EB110 먼저
- EB110 한 대로 새 시스템이 가장 많이 들어온다(4륜 구동과 센터 디퍼렌셜, 터보, 공력, 탄소 구조). 지금의 4륜
  구조 위에서 바로 만들 수 있다.
- XJ220은 EB110의 일부(터보, 공력)를 반복한다. 비교 대상(후륜 대 4륜)으로 두 번째에 넣으면 좋다.
- P34는 바퀴 수 일반화가 먼저 필요하다. 그 작업은 아래 2절의 구동계 일반화와 같이 하는 것이 맞다.
- **진짜 6륜 구동을 시험하려면 다른 차가 낫다.** 게임 시대에 맞는 차는 메르세데스-벤츠 G4(W31, 1934~39, 6×4:
  뒤 4륜 구동)다. 6×6을 원하면 1930년대 군용 6×6 트럭이 있다. 둘 다 노드·빔 차체(사다리 프레임)와 리프 스프링
  보기 서스펜션 시험에도 좋다.
- **제안 순서**
  1. EB110: 4륜 구동, 터보, 공력
  2. 구동계와 바퀴 수 일반화
  3. G4 6×4: 다축 구동. 또는 P34: 다축 조향
  4. XJ220: 비교용

## 2. 엔진·변속기·서스펜션·구동축 3D 구현 방안

### 물리: 구동계를 부품의 그래프로
- 지금은 엔진 관성, 클러치, 기어비, 디퍼렌셜 하나, 바퀴 순서로 고정된 식이다.
- 이것을 관성(엔진 플라이휠, 변속기, 프로펠러 샤프트, 디퍼렌셜, 바퀴)과 연결(클러치 마찰, 기어비, 비틀림 스프링인
  샤프트, 디퍼렌셜의 종류: 오픈, LSD, 잠금, 점성)의 그래프로 바꾼다. 1 ms 스텝에서 그대로 적분할 수 있다
  (샤프트의 비틀림 진동은 10~20 Hz).
- 얻는 것
  - **구동 방식:** 4륜, 6×4, 6×6을 같은 코드로 만든다.
  - **구동계 거동:** 샤프트 와인드업과 덜컹임(스너치), 크래시 박스의 더블 클러치, 싱크로 시간이 생긴다.
  - **엔진:** 실린더별 점화 토크 맥동(진동과 소리 동기화), 엔진 마운트의 흔들림, 터보 랙이 생긴다.
- 연결: 빌더의 엔진과 변속기 데이터(형식, 실린더 수, 기어비)가 그대로 입력이 된다. 플레이어가 설계하거나 산
  부품이 주행에 그대로 나타나서 경영 게임과 바로 이어진다.

### 3D 모델: 사양에서 부품 메시를 만든다
- 엔진 블록(실린더 수와 배열: 직렬, V, 수평대향), 헤드, 매니폴드, 팬과 풀리, 플라이휠 하우징, 변속기, 프로펠러
  샤프트와 유니버설 조인트, 디퍼렌셜과 리어 액슬 하우징, 하프 샤프트, 리프 스프링, 댐퍼, 조향 링키지(드래그 링크,
  타이 로드), 브레이크 드럼.
- 지금 차 메시처럼 코드로 만들어 차종별 사양에서 자동으로 배치한다. 차 한 대에 1~2만 삼각형이 더 들고, 가까이
  볼 때만 그린다(LOD).

### 애니메이션: 물리 상태를 그대로
- 크랭크와 팬, 풀리가 엔진 회전수로 돈다. 엔진은 토크 반력으로 마운트 위에서 흔들린다.
- 프로펠러 샤프트가 변속기 출력 속도로 돌고, 액슬이 오르내리면 각도가 바뀐다(유니버설 조인트).
- 액슬 하우징이 빔 액슬의 상하, 롤, 와인드업을 따라 움직인다(이미 물리에 있다).
- 리프 스프링은 행정만큼 휜다(정점 셰이더로 호를 바꾼다). 댐퍼가 늘고 준다.
- 조향 링키지가 조향각을 따른다.

### 보기
- 투시(엑스레이)나 절개 보기: 차체를 반투명하게 하거나 감춘다. 아래에서 보는 카메라.
- 주행 페이지, 빌더, 차고에 넣는다.

### 변형과의 연결
- 엔진과 변속기 노드에 마운트 빔을 단다. 큰 충돌에서 엔진이 밀리고, 마운트가 끊기고, 프로펠러 샤프트가 휜다.
- 그러면 수리할 부품 목록이 차고로 이어진다.

### 단계 제안
1. 구동계 그래프와 바퀴 수 일반화. 지금 차들은 결과가 같아야 한다(회귀 테스트).
2. 사양에서 부품 메시 만들기: 엔진, 변속기, 샤프트, 액슬, 스프링.
3. 물리 상태를 애니메이션에 연결한다.
4. 투시·절개 보기를 넣는다.
5. 빌더와 차고에 연결하고, 변형과 수리로 잇는다.
6. 시험 차량을 넣는다: EB110 → G4 6×4 또는 P34 → XJ220.

### 비용
- 물리: 구동계 그래프는 관성 수십 개라 지금 비용의 10~20 % 정도 늘어난다.
- 그래픽: 가까이 볼 때만 삼각형이 늘어난다. 투시 보기는 반투명 패스가 하나 더 든다.
