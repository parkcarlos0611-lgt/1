# 검토 26 — 설계 도면 화면: 회사 규모별 도면, 요구 체크리스트, 선으로 구상, 빨간 수정선과 지우개

기획자 아이디어(2026-11-20):
- 회사 규모에 따라 도면 화면이 다르다: 약간 닳은 제도지 → 깔끔한 제도지 → 레이저 스캔 청사진(청색 바탕, 흰 선) → 레이저 스캔 검은 바탕, 흰 선.
- 설계 단계에서 고객 요구조건이 체크리스트로 뜬다(차체 높이, 원하는 차체 스타일 등).
- 도면 단계에서는 휠 디자인, 외장까지 설계할 수 없다. 요소가 검은 선 / 흰 선으로만 보이고, 해상도를 조금 낮춰 구상 단계임을 표현한다.
- 제도지 단계: 부품이나 요소를 바꾸면 바뀐 부품을 빨간색으로 먼저 겹쳐 그리고, "수정"을 누르면 검은 부품을 지우개로 지운 뒤 다시 그린다. 제도 샤프로 사각사각 그리는 효과.

## 1. 지금 상태

- **화면은 없다.** 도면은 계획에만 있다.
  - 검토 14: 요구서 → 도면(하체, 배치, 차체) → 부품표 → 주문 → 조립 → 차체 → 결합 → 시험 → 수정 → 인도.
  - 04 차량 프로젝트: 설계 단계, 설계 공수, 숨은 설계 결함.
  - 02 주문: 요구서와 상담으로 드러나는 숨은 요구.
- **이번 아이디어가 붙을 기반은 이미 있다.**
  - 한 대의 입체 부품 모델(render/car/model.ts): 부품마다 위치와 옆·앞·뒤·위 윤곽을 가진다. 도면은 이 윤곽을 선으로만 그리면 된다.
  - 부품별 그림이 따로 있어(부품 점검표), 바뀐 부품 하나만 빨간 선으로 다시 그리는 것이 구조상 쉽다.
  - 맞춤 검사(fitcheck)와 비율 검사: 요구조건 체크리스트의 판정에 쓸 수 있다.

## 2. 아이디어 검토 — 모두 맞는 방향이다

| 아이디어 | 판단 | 이유와 보완 |
|---|---|---|
| 규모별 도면 4종 | 좋다 | 회사 성장이 화면에서 바로 보인다. 다만 시대도 맞아야 한다(아래 2-1) |
| 요구 체크리스트 | 좋다 | 이미 계획된 "요구서 대조표"를 도면 옆에 실시간으로 띄우는 것. 상담으로 드러난 숨은 요구는 나중에 줄이 추가된다 |
| 도면에선 선만, 외장·휠 디자인 없음 | 좋다 | 단계 구분이 분명해지고, 픽셀 그림 작업량도 줄어든다. 외장은 다음 단계(목업·차체 설계)로 |
| 해상도 낮추기 | 좋다, 조절 필요 | 너무 낮추면 치수를 읽을 수 없다. 선은 1px, 격자는 원래 축척 그대로, 그림만 2배 픽셀로 거칠게 하는 정도를 권한다 |
| 빨간 겹침 → 수정 → 지우개 → 다시 그림 | 매우 좋다 | "바꾸기 전과 후"를 한 화면에서 비교하는 실용 기능이기도 하다. 수정 버튼을 누르기 전에 수치 변화(무게, 원가, 체크리스트)를 보여 주면 결정 도구가 된다 |
| 샤프 사각사각 효과 | 좋다 | 선을 순서대로 따라 그리는 애니메이션 + 짧은 긁는 소리. 빨리 감기 가능해야 한다(여러 번 고치면 지루함) |

### 2-1. 도면 4종과 시대

레이저 스캔 청사진은 실제로는 훨씬 뒤 시대다(청사진 인화는 1930년대에도 있었지만, 레이저 스캔·검은 바탕 화면은 1980년대 이후). 그래서 **규모 + 시대** 두 조건으로 여는 것을 권한다.

| 도면 | 여는 조건 | 모습 |
|---|---|---|
| 닳은 제도지 | 소규모 공방 | 누런 종이, 접힌 자국과 얼룩, 연필(회흑색) 선, 손글씨 치수 |
| 깔끔한 제도지 | 설계실이 있는 제작소 | 흰 켄트지, 잉크선, 자로 그은 치수선, 표제란 |
| 청사진 (청색 바탕 흰 선) | 중견 이상 + 설계 부서, 1930년대부터 가능 | 시안 바탕, 흰 선, 약간 번진 선 (인화 청사진) |
| 검은 바탕 흰 선 (스캔·화면) | 대기업 + 시대 1980년대 이후 | 검은 화면, 흰·하늘색 선, 격자 |

1930~35 슬라이스에서는 앞의 두 장(필요하면 청사진까지)만 쓴다.

### 2-2. 수정 흐름 (제도지 단계)

1. 부품이나 치수를 바꾼다 → 바뀐 부품만 **빨간 선**으로 원래 선 위에 겹쳐 그린다(사각사각). 옆 체크리스트와 수치가 "바뀌면 이렇게 된다"로 미리 바뀐다.
2. "수정"을 누른다 → 원래 검은 선을 **지우개**로 문질러 지운다(지운 자국이 연하게 남는다: 닳은 제도지 느낌). 빨간 선이 검은 선으로 다시 그려진다.
3. "취소"를 누르면 빨간 선만 지운다.
- 청사진·검은 화면 단계에서는 지우개 대신 선이 깜빡이며 바뀐다(회사가 커지면 도구가 바뀌는 연출).
- 지운 자국이 많이 남으면 "새 도면에 깨끗이 옮겨 그리기"(공수 소모)로 정리한다. 설계 결함 확률과도 이을 수 있다(고친 곳이 많은 도면은 실수가 남기 쉽다).

### 2-3. 도면에 보이는 것 / 보이지 않는 것

| 보인다 (선) | 보이지 않는다 (다음 단계) |
|---|---|
| 차체 외곽과 큰 패널 경계 | 도장색, 명암, 반사 |
| 프레임, 차축, 바퀴(원과 축만) | 휠 디자인(살, 캡) |
| 엔진·변속기·탱크·라디에이터의 자리(상자) | 엔진 외관 |
| 치수선: 전장, 축간, 전고, 지상고, 앞뒤 오버행 | 램프·그릴·범퍼의 세부 모양 |
| 사람 실루엣(자리, 머리 공간) | 실내 |

입체 부품 모델의 윤곽에서 "외곽선만" 뽑아 그리면 되므로 차마다 따로 그릴 필요가 없다.

## 3. 요구 체크리스트

| 줄 | 판정 방법 (모델에서 바로 계산) |
|---|---|
| 차체 스타일 (세단, 투어링, 쿠페 …) | 고른 차체 형식 |
| 차체 높이 / 머리 공간 | 지붕 높이 - 좌석 높이 |
| 지상고 | 가장 낮은 부품 높이 (fitcheck) |
| 자리 수 / 발 공간 | 객실 길이와 좌석 배치 |
| 짐 공간 | 뒤 오버행, 트렁크 |
| 속도·힘 | 엔진 선택 (계산 물리) |
| 값 / 날짜 | 부품표 원가, 공수 |

각 줄에 ○ / △ / × 를 실시간으로 표시. 숨은 요구는 상담으로 드러나면 줄이 생긴다.

## 4. 도면 다음 단계 안내

| 순서 | 단계 | 화면 | 하는 일 |

| 1 | 요구서 | 고객 편지와 체크리스트 | 요구 확인, 상담으로 숨은 요구 찾기 |
| 2 | **도면 (선)** | 규모별 도면 | 하체·배치·차체 외곽과 치수. 빨간 수정선 |
| 3 | 부품표·견적 | 도면 옆 표 | 원가, 공수, 예상 성능, 체크리스트 대조 |
| 4 | 외장 설계 | 픽셀 그림(지금의 차 렌더러) | 휠 디자인, 그릴·램프·범퍼 고르기, 색, 몰딩 — 도면에서 정한 외곽 안에서 |

| 7 | 제작 | 공정 장면 | 섀시 조립 → 목골조 → 판금 → 도장 → 결합 |

## 5. 제안하는 진행 순서

1. 도면 화면 1차: 닳은 제도지 한 종, 1929 세단의 입체 모델에서 외곽선만 뽑아 옆·위 보기, 치수선, 해상도 낮춤.
2. 요구 체크리스트(3장)를 모델 계산과 연결.
3. 빨간 수정선 → 수정 → 지우개 → 다시 그리기, 샤프 효과(애니메이션 + 소리).
4. 나머지 도면 3종(깔끔한 제도지, 청사진, 검은 화면)은 같은 그리기에 종이·선 색만 바꾼다.
5. 외장 설계 단계(4번)로 연결.

## 6. 정할 것

1. 도면 4종을 규모 + 시대 조건으로 여는 것 (추천).
2. 해상도 낮춤 정도: 그림만 2배 픽셀, 선과 치수는 읽을 수 있게 (추천).
3. 도면 단계에서 바꿀 수 있는 범위: 차체 형식, 비례(전장·축간·높이·오버행), 섀시 형식, 부품 자리. 외장은 다음 단계 (추천).
4. 위 진행 순서대로 도면 화면 1차 데모를 만들지.
