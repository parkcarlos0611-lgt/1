# 99 · 설계 수치 계산과 부품 호환·차종 분류 (검토 177)

문서 98(부품 빌더)의 후속이다. 두 가지를 정리한다.
- 1부: 빌더가 설계에서 수치(무게, 출력, 최고 속도, 0→100)를 어떻게 계산하는지(`race/design.ts`). 지금 식의 한계와 고칠 계획도 함께 적는다.
- 2부: 부품 호환을 장착 규격으로 정하는 방식과, 차종을 결과 수치로 분류하는 방식의 구체안.

이 문서는 계획이다. 구현은 검토를 받은 뒤 한다.

---

## 1부. 설계 수치는 어떻게 계산하나

### 1-1. 흐름
```
Design(선택값) ─┬─ 엔진 식 ──────── 출력·토크 곡선
                ├─ 무게 식 ──────── 총무게, 앞뒤 배분
                ├─ 공기 식 ──────── 공기 저항 면적(cdA), 다운포스
                ├─ 타이어·기어 ──── 바퀴 반경, 기어비, 종감속
                └─ 장비 ────────── ABS·TCS·LSD·4WD·댐퍼 → 물리 기능
                       ↓
                 RaceSpec(물리 사양) ─→ 빌더의 간이 계산(최고 속도, 0→100)
                                     └→ 주행 페이지의 실제 시뮬레이션(측정값)
```
- 빌더 오른쪽 수치는 **간이 계산**이다. 순간적으로 다시 계산한다.
- **시험 주행**의 측정값은 실제 물리(타이어 미끄러짐, 변속, 공기)로 낸다. 둘은 NSX·F355에서 1~3 % 안으로 맞는다.

### 1-2. 엔진: 출력
**식:** 출력(hp) = 배기량(L) × 출력 회전수(천 rpm) × 밸브 계수 × VTEC × 피스톤 속도 손실 × 과급 배수

| 항목 | 값 | 근거 |
|---|---|---|
| 출력 회전수 | 레드라인 × (2밸브 0.84, 3밸브 0.865, 4밸브 0.8875, 5밸브 0.97) | NSX 8,000 → 7,100, F355 8,500 → 8,250. 밸브가 많으면 고회전까지 숨을 쉰다 |
| 밸브 계수 (hp/L/천 rpm) | 2밸브 11.3, 3밸브 11.9, 4밸브 12.37, 5밸브 13.0 | 평균 유효 압력(BMEP)과 같은 뜻이다. 12.4는 약 12.5 bar다 |
| VTEC | × 1.03 | NSX의 고속 캠 |
| 피스톤 속도 손실 | 평균 피스톤 속도가 21 m/s를 넘으면 1 m/s당 2.5 % 감소, 최대 40 % | 행정은 보어/행정 1.12로 배기량에서 구한다. F355가 정점에서 21 m/s다 |
| 과급 배수 | 1 + 0.65 × 부스트(터보 1개 0.8 bar, 2개 1.0 bar) | 인터쿨러 달린 엔진은 부스트의 약 65 %만큼 출력이 는다 |

- **NSX 검산:** 2.977 × 7.1 × 12.37 × 1.03 × 1.0(18.8 m/s, 손실 없음) = 269 hp. 실차는 270이다.
- **F355 검산:** 3.496 × 8.25 × 13.0 × 1.0(21.0 m/s) = 375 hp. 실차는 375다.

**토크:**
- 출력 정점의 토크 = 출력 ÷ 회전 속도.
- 최대 토크 = 그 값 × 비율. 자연흡기는 밸브 수에 따라 1.12~1.22배이고 출력 회전수의 0.73 지점에 온다. 터보는 1.2배이고 0.6 지점에 온다.
- VTEC은 NSX처럼 저속 캠과 고속 캠 두 곡선이고, 출력 회전수의 0.817 지점에서 바뀐다.

### 1-3. 무게와 앞뒤 배분
**식:** 총무게 = 차대 구조 + 엔진 + 변속기 + 바퀴 + 장비 + 나머지 + 운전자 75 kg

| 부품 | 무게 | 놓이는 곳(앞 차축에서) |
|---|---|---|
| 차대 구조 | 강철 약 320 kg, 알루미늄은 0.6배. 휠베이스와 폭에 비례해 늘고 준다 | 휠베이스 중앙 |
| 엔진 | V6 95 / V8 115 / V12 150 kg + 1 L당 35 kg + 터보 1개당 22 kg + 밸브(2밸브 -8 ~ 5밸브 +6) + VTEC 4 | 뒤 차축 0.75 m 앞(미드십) |
| 변속기 | 5단 52, 6단 60, F1 +10, LSD +4 | 뒤 차축 |
| 4륜구동 | +65(앞 디퍼렌셜 30, 센터와 축 35) | 앞 차축과 터널 |
| 바퀴(타이어 포함) | 폭(mm) × 림(in) × 0.0055 kg | 각 차축 |
| ABS, TCS, 스티어링, 댐퍼, 윙, 디퓨저 | 9, 3, 7~9, 5, 14, 9 | 각자 자리 |
| 나머지(내장, 유리, 서스펜션, 유체, 배선) | 실차 공차중량 − 위 부품들. 차가 커지면 크기^0.3으로 는다 | 실차 앞 배분이 나오도록 거꾸로 구한 자리 |

- 앞뒤 배분은 각 무게 × 자리의 합을 무게중심으로 계산해서 낸다.
- 예: NSX를 강철로 바꾸면 +128 kg(1,440 → 1,568)이고, 0→100은 5.7 → 6.2 s가 된다.
- 예: NSX에 V12 6.0 L를 얹으면 +157 kg이고, 앞 배분은 0.42 → 0.41이 된다.

### 1-4. 공기
- **cdA:** 바탕 차의 cdA × 폭 비율 × 코·꼬리 형태 계수. 뾰족한 코 0.985, 덕테일 1.01, 원형 램프 꼬리 1.005.
- **윙:** 다운포스 면적 0.3 m²(뒤에 작용), 저항 +0.05 m².
- **디퓨저:** 다운포스 0.13 m²(앞뒤 반씩), 저항 +0.01 m². F355의 바닥 덮개와 같다.

### 1-5. 기어와 최고 속도
- **기어비:** 5단은 NSX, 6단은 F355의 비율이다.
- **종감속:** "자동(0)"이면 출력과 공기·구름 저항이 만나는 속도에서 최고단이 출력 정점 회전에 오도록 고른다(2.8~4.8).
- **최고 속도:** 기어마다 속도를 올려 가며 "구동력 ≥ 공기 저항 + 구름 저항"인 가장 높은 속도를 찾는다. 레드라인을 넘으면 거기서 멈춘다(기어가 짧으면 회전 제한에 걸린다).
- **0→100:** 0.005초 간격으로 계산한다. 출발 회전 수, 구동 바퀴의 접지력(가속할 때 뒤로 쏠리는 하중 반영), 변속 중 동력이 끊기는 시간, 바퀴와 엔진의 회전 관성을 넣는다.

### 1-7. 다른 실차로 검산해 보니 (식을 만들 때 쓰지 않은 차)
| 차 | 실제 출력 | 계산 | 오차 | 원인 |

| 디아블로 5.7 V12 | 492 hp / 7,000 | 457 / 6,480 | -7 % | 대배기량 V12의 고회전 특성이 4밸브 평균보다 좋다 |
| EB110 3.5 V12 5밸브 쿼드터보 | 553 / 8,000 | 601 / 8,000 | +9 % | 터보가 최대 2개라서 2개로 넣었다. 부스트가 실차보다 높게 잡힌다 |

### 1-8. 고칠 것 (계산식 2차)
| # | 고칠 것 | 방법 | 검산 차 |
|---|---|---|---|
| F1 | 엔진 개발 등급 | 선택값을 더한다. "양산 / 고성능 / 경주"로 BMEP와 출력 회전 비율을 올린다. 대신 원가, 신뢰성, 저속 토크, 연비가 나빠진다 | 맥라렌 F1, 디아블로 |
| F2 | 압축비, 흡기 방식 | 고성능 등급의 세부로 둔다(개별 스로틀, 가변 흡기). 처음에는 등급 하나로 묶어도 된다 | 맥라렌 F1 |
| F3 | 터보 수와 부스트 | 터보 0~4개, 부스트를 슬라이더로 바꿀 수 있게 한다. 부스트가 높으면 노킹 위험이 커지고 압축비를 내려야 한다 | EB110(4개), XJ220 |
| F4 | 소재 | 강철 / 알루미늄 / **탄소섬유**(구조 0.45배, 값 매우 비쌈) | 맥라렌 F1(1,140 kg) |
| F5 | 2밸브 토크 오류 | 2밸브의 최대 토크가 4밸브보다 크게 나온다. 비율 대신 밸브별 저속 BMEP로 바꾼다 | — |
| F6 | 무게중심 높이 | 지금은 바탕 값으로 고정이다. 엔진 높이(V12 > V8)와 차 높이로 계산한다 | — |
| F7 | 엔진 길이 | 무게뿐 아니라 치수도 낸다. 2부의 장착 검사에 쓴다 | — |
| F8 | 공기 | 차 높이·폭으로 앞면적을 계산한다. 윙 크기와 각도를 선택값으로 둔다 | 맥라렌 F1(Cd 0.32), 디아블로 |
- **검산 기준:** NSX·F355는 ±3 %, 위 4대는 ±7 % 안에 들어와야 한다. 이 6대를 테스트에 고정한다.

## 2부. 부품 호환: 장착 규격으로 정한다

### 2-1. 원칙
- 부품에 "스포츠카용", "슈퍼카용" 같은 딱지를 붙이지 않는다. **부품끼리 물리적으로 맞물리는지**로 정한다.
- 맞물리면 붙는다. 조금 안 맞으면 **개조 비용**을 물린다. 구조적으로 안 되면 막는다.

### 2-2. 차대 계열 (플랫폼 패밀리)
| 계열 | 예 | 엔진 자리 | 지금 |
|---|---|---|---|
| 미드십 모노코크 | NSX, F355, EB110, 디아블로, XJ220 | 운전석 뒤, 가로 또는 세로 | 키트에 있다 |
| 앞 엔진 모노코크 | (1990년대 GT, 프런트 미드십) | 앞 차축 뒤 | 없다. 나중에 추가 |
| 사다리 프레임·분리 펜더 | 1930년대 차(리스토어용) | 앞 | 없다. 1930년대 계열로 추가 |

- **같은 계열 안:** 차체 패널(코, 꼬리, 캐빈, 데크), 휠, 장비가 모두 맞는다. 지금 NSX·F355 72조합이 모두 닫히는 것이 이 경우다.
- **다른 계열끼리:** 차체 패널은 맞지 않는다(선 체계가 다르다). 기계 부품(엔진, 변속기, 장비)은 장착 규격만 맞으면 옮길 수 있다.

### 2-3. 장착 규격 (데이터)
```
차대.엔진룸 = { 길이, 폭, 높이, 엔진 방향(가로/세로), 변속기 위치 }
차대.휠아치 = { 앞: {반경, 안쪽 폭}, 뒤: {...} }
차대.마운트 = { 엔진: '미드-세로' | '미드-가로' | '앞-세로', 최대 토크 }   ← 이보다 센 엔진은 보강 필요
엔진.치수   = { 길이, 폭, 높이 }   ← 배열·배기량·터보로 계산(1부 F7)
변속기.한계 = { 최대 토크 }
타이어.치수 = { 지름, 폭 }
```

### 2-4. 판정 세 단계
| 판정 | 조건(예) | 결과 |
|---|---|---|
| ✅ 장착 | 엔진이 엔진룸 안, 타이어가 아치 안, 토크가 마운트·변속기 한계 안 | 그대로 |
| ⚠️ 개조 장착 | 엔진이 엔진룸보다 조금 크다(10 % 안). 토크가 한계를 넘는다. 타이어가 아치보다 조금 넓다 | 개조 부품의 비용·무게·제작 시간이 든다. 신뢰성이 내려간다. 펜더 확장 같은 외관 변화도 생긴다 |
| ⛔ 불가 | 엔진룸보다 훨씬 크다. 엔진 방향이 다르다(앞 엔진 자리에 미드십 배치 등). 계열이 다른 차체 패널 | 선택 목록에서 회색으로 보이고 이유를 표시한다 |

- **해결 수단도 함께 보여 준다.** 예: "V12는 엔진룸보다 180 mm 깁니다 → 휠베이스 +180 mm 또는 개조 장착(비용 +12 %)."
- 지금 넣고 있는 "타이어가 펜더 밖으로 나옴" 경고가 이 체계의 첫 항목이다.

### 2-5. 시대와 리스토어
- 1930년대 차는 사다리 프레임 계열이다. 1990년대 엔진을 넣는 것(레스토모드)은 "개조 장착"으로 허용한다.
- 대신 **원형 보존 점수**가 떨어진다. 클래식 수집가는 원형을 높이 쳐 주고, 레스토모드 구매자층은 따로 둔다.

## 3부. 차종 분류: 결과 수치로 계산한다

### 3-1. 원칙
- 차종을 처음에 고르지 않는다. 완성된 설계의 수치로 **여러 차종에 대한 소속 비율**을 계산한다.
- 시장(손님)은 이 비율을 쓴다. 레이스는 규정 수치를 쓴다(3-4).

### 3-2. 기준 수치
| 수치 | 뜻 |
|---|---|
| 출력 대 무게(hp/t) | 가속 성능의 핵심 |
| 최고 속도 | 손님이 가장 먼저 보는 숫자 |
| 판매 가격 | 원가 + 이윤(B5에서 계산) |
| 좌석, 짐 공간, 승차감 | 일상 사용성(GT와 슈퍼카를 가른다) |
| 엔진 배치, 차 높이 | 형태 |

### 3-3. 1990년대 차종과 계산 (제안값)
소속 정도는 0~1 사이의 부드러운 곡선(S자)으로 낸다. 경계 근처에서는 두 차종에 반씩 속한다.

| 차종 | 중심 조건 |
|---|---|
| 스포츠카 | 150~230 hp/t, 최고 230~280 km/h, 중간 가격 |
| GT | 일상성이 높고(좌석, 짐, 승차감) 앞 엔진, 200~300 hp/t |
| 슈퍼카 | 230~330 hp/t, 최고 280~330 km/h, 미드십, 높은 가격 |
| 하이퍼카 | 330 hp/t 이상 또는 최고 340 km/h 이상, 매우 높은 가격 |

| 차 | hp/t (운전자 포함) | 최고 속도 | 계산 예 |
|---|---|---|---|
| NSX | 187 | 274 | 스포츠카 0.75 · 슈퍼카 0.25 |
| F355 | 246 | 299 | 슈퍼카 0.65 · 스포츠카 0.35 |
| 디아블로 | 298 | 325 | 슈퍼카 0.8 · 하이퍼카 0.2 |
| 맥라렌 F1 | 516 | 386 | 하이퍼카 1.0 |
- 위 비율은 곡선 모양을 보여 주는 예시다. 실제 계수는 구현할 때 이 4대가 위처럼 나오도록 맞춘다.

**시장에서 쓰는 법:**
- 차종마다 손님층(수요, 예산, 중시하는 수치)이 있다. 한 차의 수요는 "차종 비율 × 그 손님층이 이 차를 좋아하는 정도"의 합이다.
- 경계에 있는 차는 두 손님층에서 조금씩 팔린다. 한쪽에서 1등이 되기는 어렵다. 실제 시장과 같다.
- 신문·잡지 기사가 차종 이름을 붙인다("일상용 슈퍼카"). 이름은 비율이 가장 높은 차종에서 나온다.

### 3-4. 레이스 클래스: 규정 수치로 자른다
- 규정은 수치 조건이다. 차종 이름과 상관없다. 경계가 애매한 차는 생기지 않는다.
- 예(게임 고유 규정):

| 클래스 | 조건 |
|---|---|
| 양산 GT | 시판 25대 이상, 무게/출력 4.0 kg/hp 이상, 원래 차체 |
| GT2 | 무게/출력 3.0 이상, 흡기 제한 장치, 윙 크기 제한 |
| GT1 | 무게/출력 2.4 이상, 개조 자유도 높음 |
| 오픈 | 제한 없음(최고 속도 시험 등) |

- 규정에 걸리는 차는 **흡기 제한, 무게 추가, 출력 제한**으로 맞춘다. 빌더에 "클래스 맞춤" 버튼을 둔다.
- 규정은 시즌마다 바뀔 수 있다. 신문 이벤트로 알린다.
