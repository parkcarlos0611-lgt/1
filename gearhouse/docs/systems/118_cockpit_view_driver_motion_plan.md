# 118 · 운전석 시점과 운전자 동작 (계획)

> 2026-11-25. D1~D4 구현(맨 아래 "D1~D4 결과"). D5(마디 모양 다듬기, 몸 기울기)는 남음.
> - 사용자 요청: 운전자 시점을 제대로 구현하고, 더미 운전자가 핸들을 양쪽으로 돌리고, 변속하고, 페달을 밟는 동작을 넣는다.
> - 근거: 실내(문서 109 S4 결과), 주행 카메라(`ui/drivecam.ts`), 주행 HUD(문서 110 §3).

## 1. 지금 상태
| 항목 | 지금 | 문제 |
|---|---|---|
| 운전석 카메라 | `carEyes()`가 `seat` 부품 뒤쪽 위 약 840 mm에 눈을 둔다. 차에 붙어서 그대로 따라간다 | 운전자 머리와 위치가 맞지 않을 수 있다. 머리 흔들림, 시선 이동, 가까운 물체 처리(가까운 면 잘림, 외곽선 굵기)가 없다 |
| 운전자 | 헬멧, 몸, 팔·다리가 곧은 관, 손은 핸들 위, 발은 페달 위에 고정(672 삼각형) | 뼈가 없다. 어깨·팔꿈치가 딱딱하다 |
| 핸들 | 뼈(`steer`)에 달려 있다 | 팔이 따라가지 않아서 주행에서는 꺼 두었다 |
| 계기 바늘 | 뼈 8개, 지연 포함, 주행과 연결됨 | — |
| 렌더러의 뼈 | 부품을 축 하나로 돌리는 방식(`DialRig`, 바늘·핸들) | 팔·다리처럼 여러 마디가 이어진 회전은 없다 |
| 변속 레버·페달·사이드 브레이크 | 형상은 있다 | 움직이지 않는다 |

## 2. 목표
1. **운전석 시점:** 운전자의 눈 위치에서 본다.
   - 대시, 계기, 핸들, 운전자 손이 보인다.
   - 차의 움직임에 맞춰 머리가 자연스럽게 흔들린다.
2. **운전자 동작:** 밖에서 볼 때(유리 너머)와 운전석 시점 모두에서 보인다.
   - 핸들 돌리기, 변속하기, 페달 밟기, 사이드 브레이크 당기기
   - 몸 기울기, 코너 쪽 머리 돌리기
3. **스타일:** 피부를 늘이는 방식이 아니라, 굳은 마디를 이어 붙이고 관절은 공 모양으로 감추는 로우폴리 방식이다(FR Legends 결).

## 3. 운전석 시점 (D1)
| 항목 | 방법 |
|---|---|
| 눈 위치 | 운전자 뼈대의 머리 마디에서 헬멧 눈 위치. 운전자가 없는 차는 지금처럼 `carEyes` |
| 시야각 | 기본 세로 60°(가로 약 90°, 16:9). 설정 "운전석 시야" 50~75° |
| 가까운 면 | 0.05 m. 대시가 잘리지 않게 한다 |
| 머리 흔들림 | 옆 G에 따라 기울기, 제동·가속에 따라 앞뒤 끄덕임, 노면 진동. 스프링·감쇠로 늦게 따라간다. 설정 "머리 움직임"(끔, 약하게, 보통) |
| 시선 | 미끄러지는 방향과 요 속도로 머리를 조금 돌린다(최대 약 15°). 드리프트 중 진행 방향을 본다 |
| 감추는 것 | 운전석 시점에서는 운전자 헬멧과 머리를 그리지 않는다. 팔·손·다리는 그린다 |
| 외곽선 | 카메라 가까이 있는 실내는 외곽선이 화면 픽셀 기준이라 지나치게 굵어질 수 있다. 실내 부품의 선 굵기를 거리로 줄인다 |
| 유리 | 앞유리 안쪽에서 보는 반사 띠(카툰 유리)를 약하게 둔다 |
| 백미러 | 이번에는 하지 않는다(장면을 한 번 더 그려야 함). 나중 항목 |
| HUD | 운전석 시점에서는 핸들 그림 HUD를 끌 수 있다(실제 핸들이 보임). 계기 HUD는 설정을 따른다 |

## 4. 운전자 뼈대 (D2)
- 마디: 골반(시트에 고정), 상체, 머리, 양팔(위팔, 아래팔, 손), 양다리(허벅지, 정강이, 발). 모두 13마디다.
- 마디는 굳은 부품이다. 관절에는 공을 두어 이음매를 감춘다. 지금 관 모양 팔·다리를 이렇게 바꾼다(모양 다듬기는 D5).
- 렌더러 일반화: 축 하나로 돌던 뼈(`DialRig`)를 **마디마다 4×4 행렬**로 넓힌다. 바늘·핸들도 같은 틀에 넣는다.
  - 차 한 대에 행렬 약 32개(운전자 13 + 바늘 8 + 핸들 + 레버·페달 5 + 여유)
  - 상대 차는 멀리 있으면 운전자를 쉬는 자세로 둔다(가까운 2~3대만 움직임)
- 입력: 주행 상태에서 핸들 각도, 가속·제동·클러치, 기어와 변속 순간, 사이드 브레이크를 받는다. 바늘이 쓰는 `inputFromVehicle`를 넓힌다.

## 5. 동작 (D3·D4)
### 5-1. 핸들과 팔 (D3)
- 손은 핸들 림의 9시·3시 자리를 잡고, 핸들과 함께 돈다. 팔은 두 마디 IK(이미 있는 `joint()`)로 어깨에서 손까지 잇고, 팔꿈치는 아래 바깥으로 굽힌다.
- **±120°까지:** 두 손이 림을 잡은 채 돈다(팔이 엇갈림).
- **그 너머(드리프트의 빠른 반대 조향):** 한 손을 떼고 다른 손으로 돌리거나, 두 손을 펴서 핸들이 손안에서 돌게 둔다. FR 결로는 **두 손을 살짝 떼고 핸들이 미끄러져 도는** 쪽이 읽기 쉽다(제안).
- 핸들 뼈를 주행에서 다시 켠다. 바퀴 조향각 × 조향비(599 약 15:1 [~])로 핸들 각을 만든다.

### 5-2. 변속, 페달, 사이드 브레이크 (D4)
| 동작 | 방법 |
|---|---|
| 변속(수동 H 패턴) | 변속 순간에 오른손(왼쪽 핸들 차)이 레버로 간다(0.12 s) → 레버가 H 패턴 길을 따라 새 단으로 간다(0.15 s) → 손이 핸들로 돌아온다(0.15 s). 레버 손잡이도 같은 길로 움직인다 |
| 클러치 | 변속 때 왼발이 클러치를 밟았다 뗀다. 출발할 때도 밟는다 |
| 가속·제동 | 오른발이 가속 페달을 입력만큼 누른다. 제동이 들어오면 발이 브레이크 페달로 옮겨 간다(0.1 s) |
| 힐앤토 | 제동 중 시프트 다운 때 오른발 뒤꿈치로 가속을 살짝 누른다(엔진 회전 올리기와 맞춤). 선택 사항 |
| 사이드 브레이크 | 오른손이 레버를 잡고 당긴다. 드리프트 진입 때 보인다 |
| 시동 | 직접 시동(문서 110 G1)일 때 손이 열쇠·단추로 간다. 선택 사항 |
- 핸들 위치는 차의 실내 기준점(`CabinAnchors`)을 따른다. 오른쪽 핸들 차는 거울상으로 처리하고, 레버를 잡는 손이 바뀐다. 599 실내가 왼쪽 핸들인지는 STATUS의 확인 대기 항목이다.

### 5-3. 몸 (D5)
- 옆 G에 따라 상체를 바깥으로 기울이고(최대 약 8°), 머리는 반대로 조금 세운다.
- 제동 때 앞으로, 가속 때 뒤로 살짝 움직인다.
- 코너에서 머리를 안쪽으로 돌린다(§3 시선과 같은 값).

## 7. 위험
- **팔이 핸들·대시를 뚫음:** 큰 각도와 레버로 가는 길에서 생기기 쉽다. 손 길에 거쳐 가는 점을 두어 피한다.
- **멀미:** 머리 흔들림이 크면 휴대폰에서 어지럽다. 기본은 "약하게"로 둔다.
- **성능:** 차마다 행렬 32개는 가볍다. 다만 상대 8대가 모두 움직이면 CPU 쪽 IK 계산이 늘어서 가까운 차만 움직인다.
- **새 차:** BNR33(문서 117)처럼 실내가 다른 차는 실내 기준점만 맞추면 같은 뼈대와 동작을 쓴다.

## 8. 검토받을 것
1. 큰 각도 반대 조향: 핸들이 손안에서 미끄러지는 방식으로 할지, 손을 바꿔 잡는 방식으로 할지
2. 운전석 시점에서 헬멧·머리를 감출지(제안: 감춤)
3. 머리 흔들림 기본값(제안: 약하게)
4. 힐앤토와 시동 손동작을 넣을지
5. 순서: D1 먼저(운전석 시점만 빠르게) → D2~D4 → D5

## 9. 결정 (2026-11-25, 사용자)
- 운전자 모델은 **약간 카툰 결로 깔끔하게** 만든다(D5에서 반영. 둥근 헬멧, 단순한 몸통과 굵은 팔다리, 공 관절).
1. ±120°를 넘는 조향은 **손을 바꿔 잡는다**(미끄러지기 아님). 빠른 반대 조향 때 손이 림 위로 번갈아 옮겨 간다.
2. 운전석 시점에서는 헬멧과 머리를 감춘다.
3. 머리 흔들림 기본은 **아주 약하게**(설정 단계에 "아주 약하게"를 더하고 기본으로).
4. 힐앤토와 시동 손동작을 넣는다.
- 수동 변속 동작: 구현할 수 있다(D4의 H 패턴 레버 길, 클러치 발, 손 이동). 오른쪽 핸들 차는 왼손으로 변속한다.
- 순서: 번호판 시험 → BNR33 → D 계획.

## D1~D4 결과 (2026-11-25)
그림: `docs/reference/d_cockpit.png` (위: 599 운전석 시점, 아래: 앞 유리 너머. 왼쪽은 핸들 왼쪽 70°에 오른손이 레버 3단, 오른쪽은 핸들 오른쪽 70°에 두 손이 림 위).

**D1 운전석 시점** (`ui/drivecam.ts`, `ui/drive.ts`)
- 눈: 운전자 머리 마디의 눈 자리(헬멧 안, 머리 중심 앞 95 mm). 뼈대가 있는 차는 `carEyes`의 seat가 이 눈이다. 차체의 롤·피치를 렌더러와 같은 식으로 따라간다(`meshToWorld`).
- 시야: 설정 "운전석 시야" 50~75°, 기본 60°(세로). 세로 화면은 예전처럼 가로 62° 이상이 되게 넓힌다. 가까운 면 0.05 m.
- 머리: G에 따라 기울기(옆 G), 끄덕임(앞뒤 G), 노면 진동(바퀴 이동 속도), 스프링·감쇠로 늦게 따라감. 미끄러지는 방향과 요 속도로 최대 15° 돌아봄. 설정 "머리 움직임": 끔·**아주 약하게(기본)**·약하게·보통. 카메라는 머리의 돌림과 끄덕임을 받고, 차체 피치의 85 %만 따른다(머리가 수평을 조금 잡음). 화면 롤은 렌더러에 없어서 넣지 않았다.
- 감춤: 운전석 시점에서는 머리 마디(헬멧·목)의 행렬을 0으로 접어 그리지 않는다. 팔·손·다리는 그린다.
- 선 굵기: 렌더러에 `LiveView.inkNear`(운전석 시점 2.2 m). 그 안에서는 외곽선(뒤집힌 껍질)과 그린 선이 거리에 비례해 가늘어지고, 눈 앞에서 1/3까지.
- HUD: PC 배치의 핸들 그림(`#hwheel`)을 운전석 시점에서 숨긴다(설정 "운전석 시점에서도 화면 핸들 그림 보이기", 기본 끔). 터치 핸들은 그대로.

**D2 뼈대** (`render/car/interior/rig.ts`, `parts.ts` driver)
- 마디는 **15개**다(골반, 상체, 머리, 팔 3×2, 다리 3×2. §4의 "13마디"는 같은 목록을 잘못 센 것). 팔꿈치·무릎·발목에 공 관절(6각, 공 하나 36삼각형), 어깨·엉덩이는 몸통 안에 묻힌다.
- 렌더러의 실내 뼈를 마디마다 3×4 행렬로 넓혔다: 0 실내, 바늘 7~8개, 핸들, 운전자 15, 레버·사이드 브레이크·클러치·브레이크·가속 5 = 최대 30(셰이더 칸 54 안). `DialRig.cabin`(뼈대 자료), `poseCabin`(모든 뼈의 행렬과 눈), `LiveCar.cabin`(행렬을 그대로 받음). 바늘과 핸들은 같은 계산을 그대로 쓴다(`poseDials`가 모든 뼈를 먼저 단위 행렬로 채움).
- 헬멧의 그린 선도 머리 뼈를 따라간다(`MeshLine.bone`, 렌더러의 실내 선 묶음).
- 입력: `inputFromVehicle`이 핸들 각(`sw`), 차가 마지막으로 받은 조작(`Vehicle.ctl`: 가속·제동·클러치·사이드 브레이크), 기어·후진·단 수·F1 패들 여부, 시동 모터, 차체 가속도·속도·요 속도를 넘긴다.
- 움직이는 차: 내 차와 가장 가까운 상대 3대. 나머지는 바늘만 움직이고 운전자와 핸들은 쉬는 자세.

**D3 팔과 핸들**
- 손은 림의 9시·3시(수평에서 6° 위)를 잡는다. 예전 그림의 10시·2시(18°)에서 바꿨다.
- 핸들 뼈를 주행에서 다시 켰다. 핸들 각은 차의 `sw`(바퀴 조향각 × 조향비).
- 팔: 어깨에서 손까지 두 마디 IK(위팔 325, 아래팔 300 mm), 팔꿈치는 아래 바깥. 손이 팔 길이보다 멀면 상체가 앞으로 숙이고(최대 약 17°) 조금 돈다(최대 약 17°).
- 손 바꿔 잡기: 손이 자기 자리에서 120°를 넘으면 림에서 살짝 떼고(55 mm) 온 길을 되돌아 자기 자리 너머 40°를 다시 잡는다. 한 번에 한 손. 빠르게 돌 때는 0.2 s보다 빨리(최소 0.1 s). 핸들이 0.6 s 멈춰 있으면 자기 자리에서 8° 넘게 벗어난 손이 제자리로 다시 잡는다.

**D4 변속, 페달, 사이드 브레이크, 시동**
| 동작 | 결과 |

| H 패턴 | 1·2단 왼쪽 면, 3·4단 가운데, 5·6단 오른쪽. 후진은 홀수 단이면 맨 윗단 옆 뒤, 짝수 단이면 1단 왼쪽 앞. 길은 중립 선으로 → 옆으로 → 새 단(`leverPath`). 레버는 옆 7°, 앞뒤 11° 기운다 |

**그림 평가**

## 눈높이 고침 (2026-11-25, 실기기 의견 "운전석 시점이 너무 낮고 창문과 멀다")
그림: `docs/reference/d_cockpit_v2.png` (위 두 줄: 599·N33 운전석 시점 전/후, 아래: N33 옆 유리와 앞 유리 너머의 머리).

**원인:** 카메라 오프셋이 아니라 운전자와 자리였다.
- 운전자 상체가 짧았다(엉덩이 점에서 어깨 392, 목 468 mm를 등판 기울기로). 눈이 엉덩이 점 위 595 mm로 실제(약 620~680)보다 낮았다.
- 머리가 기울어진 상체 선 위에 그대로 얹혀 있어서 눈이 엉덩이 점보다 뒤에 있었다.
- N33은 자리가 뒤에 있어서 다리가 97 %, 팔이 94 % 펴져 있었다. 핸들 림 윗부분(눈에서 -3°)이 앞 유리 아랫단(-6°)보다 위에 있어서 림이 길을 가렸다.
