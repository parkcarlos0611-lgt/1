# 검토 34 — 차 시트 다시 추리기, 프레임과 하부 구동부, 시간 흐름, 사람 스프라이트

기획자 결정과 아이디어(2026-11-20):
- 기존 시트는 해상도가 낮고 뿌연 안개가 낀 것이 많다. 200종을 한꺼번에 넣는 것도 부담이다. 안개 없는 시트 중 **미국에서 생산된 스포츠·고급 차**만 추리고, 게임에 필요한 차(배달차, 견인용 플랫베드 등)는 고화질·안개 없는 시트를 새로 만들어 채운다.
- 차량 프레임과 하부 구동부를 구현한다. 1차판의 프레임 제작·변형 방식은 참고만 하고, 반영할 것이 있는지 본다.
- 시간: 평소에는 하루 60초. 작업 중에는 실제 시간의 20배(하루 1.2시간). 상담은 실제 시간과 같게.
- 손작업과 능력치: 검토 33의 추천안(결과는 손, 기술은 도구의 너그러움).
- 사람 스프라이트는 외부 제작 사이트를 쓴다. 배경과 집 안은 품질을 본 뒤 참고 이미지를 줄지 정한다.
- 견본 B(부식 수리)부터 만든다.

## 3. 프레임과 하부 구동부

### 3-1. 1차판에서 가져올 것

1차판(legacy/tools/pixel/gen/v3/platform.mjs, frame.mjs)은 프레임을 **숫자 몇 개와 옆·위 그림**으로 다뤘다. 입체 부품도, 휘거나 상하는 것도 없었고, 동력계는 차체 기준의 고정 거리로 놓았다.

| 가져온다 | 이유 |
|---|---|
| 프레임 형식 5종과 시대: 채널 사다리(1900~), X자 보강 사다리(1932~), 상자형 레일 + X자(1937~), 중앙 관 + 바닥판(1934~), 일체형(1934~, 연구 필요) | 시대 고증과 진행 단계가 이미 맞춰져 있다 |
| 강재 등급 3종(연강, 중탄소강, 고장력강): 강성 계수, 값 계수 | 단순하고 효과가 크다 |
| 매개변수: 레일 깊이·폭·두께, 가로대 수(3~8), 가로대 형식(채널·관), 킥업(0~260 mm), 드롭(0~120 mm, 1932~), 앞 좁힘(0.6~0.95), 접합(리벳, 1936~ 용접), 거싯, 차체 고정점 수(6~14) | 도면 화면의 "섀시" 쪽 손잡이가 된다 |
| 무게·강성·강도 여유 공식(platformStats): 단면 × 길이, 강성 ∝ 깊이^0.8 × 두께^0.5 × 가로대 | 성능 계산(시제품 ②)과 견적에 바로 쓰인다 |
| 약한 곳(frameZones): 앞 뿔, 가운데(드롭이 약하게), 뒤 킥업(킥업이 약하게), 비틀림 | 고장·수리 의뢰의 재료(킥업에 금 감 등) |
| 가로대 자리 목록(stations): 앞, 뒤, 변속기, 스프링 걸이, 가운데, 킥업, 엔진, 좌석 | 가로대를 실제 부품으로 놓는 순서 |
| 프레임이 차체를 정하는 규칙: 축간·폭이 차체의 범위 안, 엔진이 보닛 안에 | 자유 조합(삼륜차에 V8)의 판정 |
| 섀시 형식표(sim/chassis.mjs): 서스펜션 종류, 스프링 아래 무게, 완충기, 조향 | 시험 주행 물리(physics/rig.ts)의 입력 |

| 가져오지 않는다 | 이유 |
|---|---|
| 픽셀 띠로 그리는 방식 | 새 모델은 부품의 입체 윤곽에서 그린다 |
| 고정 거리 배치(엔진 = 앞 + 300 등) | 붙는 점(마운트)으로 잇는다 |
| 쓰이지 않던 강성 입력, ±10% 보정값 | 다시 검증하기 전에는 넣지 않는다 |

### 3-2. 새 방식

| 단계 | 내용 |
|---|---|
| 1. 프레임 생성기 | 매개변수 → 입체 부품(레일 좌우, 가로대들, X자, 거싯, 스프링 걸이, 엔진·차체 마운트). 레일 옆모습은 1차판의 railZ(앞 아치, 드롭, 킥업)를 따른다 |
| 2. 붙는 점 | 부품마다 붙는 점: 엔진 마운트 4, 변속기 마운트, 스프링 걸이 앞뒤, 차체 고정점, 탱크 받침, 배기 걸이. "무엇에 무엇이 붙었나"를 기록 |
| 3. 구동계 잇기 | 엔진 → 클러치 → 변속기 → 추진축(토크 튜브 또는 홋치키스 + 유니버설 조인트) → 차동기 → 차축. 각도와 길이는 붙는 점 사이에서 계산. 축간을 바꾸면 추진축이 늘고 탱크·배기가 따라간다 |
| 4. 하부 부품 그림 | 엔진, 변속기, 차축, 스프링, 완충기, 탱크, 프레임은 부품 그림(약 60장, 검토 25)에서 만든다. 섀시 시트는 배치 참고용 |
| 5. 계산과 연결 | 프레임 무게·강성·강도 → 견적, 시험 주행(스프링 위 무게, 비틀림), 고장(킥업 균열), 수리 의뢰(휜 프레임 바로잡기) |
| 6. 화면 | 도면의 "섀시" 쪽에서 매개변수를 바꾸면 빨간 선으로. 차고에서는 하부를 보는 장면(차를 들어 올린 옆모습) |

손상과 변형(새로 넣는 것): 사고로 휜 레일, 녹슨 가로대, 킥업 균열. 수리 미니게임으로 펴기, 덧대기(피시 플레이트), 리벳 다시 치기.

## 4. 시간 흐름 (기획자 안 검토)

기획자 안: 평소 하루 = 60초. 작업 중 = 실제 시간의 20배(하루 1.2시간). 상담 = 실제 시간.

| 상태 | 게임 시간 흐름 | 실제 1분 동안 | 판단 |
|---|---|---|---|
| 평소(집 앞, 공방) | 하루 60초 = 1440배 | 하루 | 길게 기다리는 일을 빨리 넘기기에 좋다. 다만 손님이 오고 걷는 것은 이 속도로 보면 순간이동 같다 → 아래 1 |
| 작업(긁기, 칠하기, 조립) | 20배 | 20분 | 손작업 한 번(실제 3~6분)이 게임 1~2시간. 공정 길이와 잘 맞는다 |
| 상담, 전화 | 1배(사실상 멈춤) | 1분 | 맞다. 선택지를 읽는 동안 날이 지나면 어색하다 |

다듬을 점 (추천):
1. **사건이 생기면 느려진다.** 손님 차가 들어오고, 걸어오고, 배달차가 서는 동안은 1배 또는 60배로 내린다. 끝나면 다시 하루 60초. 이렇게 하지 않으면 하루 60초에서는 사람이 1초에 몇 미터씩 움직인다.
2. **움직임과 시계를 떼어 놓는다.** 걷기·비·김 같은 움직임은 늘 실제 시간으로 그리고, 시계만 상태에 따라 빠르게 흐른다.
3. **밤.** 하루 60초면 밤에도 25초쯤 걸린다. 침대에서 자면 아침으로 넘기고, 밤에 할 일이 없으면 저절로 빨리 넘긴다.
4. **작업 시간의 공정함.** 실제로 오래 붙잡고 있으면 게임 시간을 많이 쓴다. 그래서 도구 업그레이드(큰 스프레이건, 전동 솔)가 곧 "시간을 아끼는 것"이 되어 성장의 의미가 생긴다.
5. **코어에 시계가 필요하다.** 지금 core/sim은 하루 단위(아침·낮·저녁)로만 돈다. 분 단위 시계를 두고, 시간이 정해진 사건(배달 도착, 손님 방문)을 그 시계에 맞춰 일으켜야 한다.

결론: 좋은 안이다. 1~3을 더하기를 추천한다. 견본 B에서는 작업 상태의 20배를 이미 쓰고 있다(화면 위 시계).

추천:

- 받은 스프라이트는 게임 팔레트에 맞추고 외곽선을 정리하는 도구를 하나 만든다(색 줄이기, 테두리 색 통일).
- 배경·집 안: 이번 견본 B의 차고 배경처럼 규칙으로 먼저 그려 보고, 품질이 모자라면 참고 이미지를 받는다는 안에 찬성한다. 집 앞 장면(견본 A)이 그 판단 자리다.

## 6. 견본 B (부식 수리) — 만든 것

ui/scenes/bodywork.ts, 단독 페이지(ui/bodywork.ts).

- 1929 세단의 옆모습(입체 부품 모델에서 그림) 아래쪽 판에 녹 6군데가 생긴다(깊이가 다른 얼룩).
- 칠한 픽셀마다 층: 원래 칠, 녹 깊이, 녹이 먹어 들어간 깊이(파임), 메운 납, 마스킹 테이프, 새 칠(색과 두께).
- 도구 4개:
  - 철수세미: 새 칠 → 솟은 납 → 원래 칠 → 녹 순서로 벗긴다. 녹을 벗기면 파임이 드러난다. 유리·크롬을 문지르면 긁힌다.
  - 납 메움(플럭스 + 납): 맨 철판에만 붙는다. 파인 곳에 빨리 차고, 넘치면 솟는다. 녹 위에 올리면 약하게 붙는다.
  - 마스킹 테이프: 끌어서 띠로 붙인다. 붙인 곳에는 칠이 닿지 않는다. 끌 때 "찌익" 소리, 길수록 높아진다. "테이프 떼기".
  - 스프레이건: 부드럽게 두께가 쌓인다. 한곳에 오래 두면 흘러내린다. 가까운 유리·크롬·타이어에 칠이 묻는다.
  - 색: 원래 색, 검정, 적갈색, 크림. 원래 색이 아니면 감점.
- 검사: 보이는 녹, 칠 밑에 숨은 녹, 메우지 않은 파임, 메움 굴곡, 칠 안 된 맨 철판, 얇은 칠, 흘러내림, 다른 색, 녹 없던 곳까지 벗김, 녹 위의 납, 유리·크롬·타이어에 묻은 칠, 긁힘, 떼지 않은 테이프 → 손님 만족 점수와 "반년 안에 들뜨거나 다시 녹슬 확률".
- 소리: 긁는 소리(움직이는 빠르기에 따라), 스프레이 쉿 소리, 테이프 찌익.
- 시계: 작업 상태라 실제 시간의 20배(오전 8:00부터).
