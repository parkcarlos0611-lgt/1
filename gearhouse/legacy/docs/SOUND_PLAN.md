# 사운드 계획: 새 기능 효과음, 기존 효과음 강화, 배경음악 강화

> 원칙: 모든 소리는 브라우저에서 직접 합성하는 오리지널 (녹음 파일·외부 음원 없음). 장소마다 공간감(잔향)을 다르게 하고, 시대마다 기계·장비 소리가 달라진다.

## 1. 공통 기반 (먼저 만든다)
| 항목 | 내용 |
|---|---|
| 믹서 | 음악·효과음·환경음 3개 버스, 각 버스에 컴프레서, 마스터 리미터. 효과음이 나면 음악을 살짝 낮춤(더킹) |
| 공간 잔향 | 합성 임펄스 응답 4종: 사무실(작은 방, 0.4초), 공장(큰 홀, 2.5초), 쇼룸(유리·돌, 1.2초), 야외(잔향 없음 + 먼 반사) |
| 소리 재료 | 잡음(백·분홍·갈색), 금속 공명(여러 비정수배 배음), 나무 두드림, 기어 이빨 펄스, 공기 분사 → 조합해 효과음 생성 |
| 변화 | 같은 효과음이라도 매번 음높이·길이·세기를 조금씩 바꿔 반복감 제거 |

## 2. 새 기능 효과음
| 기능 | 효과음 (시대 차이) |
|---|---|
| **조립 과정** | 리벳 박기(연속 타격 + 금속 울림), 판금 망치, 체인 호이스트 래칫 딸깍 + 체인 짤랑, 엔진이 내려앉는 쿵, 렌치(1930s 수동 래칫 → 1940s 공압 렌치), 용접 지직거림(불꽃과 동기), 프레스 쾅(낮은 충격 + 플라이휠 윙윙 + 공기 빠짐), 도장 분사 쉬익, 건조 오븐 웅웅, 바디 드롭 덜컹, 타이어 공기 주입, 첫 시동, 검사 도장 쾅 |
| **엔진 투시 애니메이션** | 화면 속 피스톤 움직임에 맞춘 점화 퍽 소리(저회전에서 하나하나 들림), 밸브 똑딱, 크랭크 회전음 |
| **다이노 테스트** | 롤러 웅웅, 회전계 바늘 틱, 그래프를 그리는 펜 긁는 소리, 최고 출력 지점 벨 |
| **시험 주행** | 단마다 기어 소리(비동기 기어 1단·후진 윙~), 회전수가 안 맞으면 **기어 갈리는 소리**, 클러치, 바이어스 타이어 끽 소리, 노면(콘크리트 이음매 툭툭, 자갈 사각), 속도에 따라 커지는 바람 소리, 브레이크 끽, 스톱워치 딸깍 |
| **장소 환경음** | 사무실: 타자기·벽시계·다이얼 전화벨 / 공장: 기계 소음·교대 벨·증기 호각 / 딜러십: 문 종소리·손님 웅성거림·금전등록기 / 시험장: 바람·멀리 지나가는 차·새 / 도시 지도: 거리 소음·전차 종 |
| **UI** | 지도 핀 선택, 창 열 때 종이 바스락, 승인 도장, 재무 장부 넘김, 전보 수신 신호 |
| **경영 사건** | 경고(은행 종), 은행 면담(무거운 문), 전쟁 발발(라디오 뉴스 신호), 종전(교회 종), 출시(박수 + 플래시 펑) |

## 3. 기존 효과음 강화
| 소리 | 지금 | 강화 |
|---|---|---|
| 엔진음 | 점화 펄스 + 필터 + 잡음 | 실린더별 연소 편차(불규칙 털털거림), 감속 시 배기 팝, 고부하 흡기 굉음, L헤드의 기계 덜걱거림, V형 엔진은 뱅크별 좌우 분리, 시대별 머플러 공명, 공회전의 불규칙한 리듬 |
| 경적 | 톱니파 음높이 변화 / 사각파 2음 | 클랙슨: 모터가 진동판을 긁는 거친 음 + 덜덜 떨림 / 전기 경적: 2음 화음 + 배음 |
| 스타터 | 잡음 덩어리 4번 | 솔레노이드 딸깍 → 6V(1930~40s) 느리고 힘겨운 크랭킹, 배터리 전압 처짐 → 시동이 걸리는 순간 |
| 버튼 | 짧은 삑 | 시대 질감: 타자기 키, 금속 스위치, 종이 넘김 |
| 전보·금전등록기 | 사인파 | 실제 장치 구조 반영(전신 키 딸깍 + 신호음, 등록기 벨 + 서랍 열림) |

## 4. 배경음악 강화
| 항목 | 강화 |
|---|---|
| 악기 | 지금(피아노·베이스·브러시·리드) + 뮤트 트럼펫, 클라리넷, 색소폰 섹션 화음(1940s), 비브라폰, 리듬 기타 스트럼(1930s 4비트), 밴조(1930년대 초), 하이햇·킥(1940s), 현악 패드(성공 장면) |
| 곡 형식 | 32마디 AABA, 인트로·엔딩, 조바꿈, 솔로 악기 순환 → 같은 곡도 길게 들어도 덜 반복적 |
| 작곡 품질 | 모티프 반복·변형(같은 리듬을 다른 음높이로), 화음 진행에 맞춘 성부 진행, 셸 보이싱, 사람이 연주한 듯한 타이밍·세기 흔들림 |
| 장소별 곡 | 도시 지도(산책 스윙), 공장(쇠 두드림이 섞인 작업 리듬), 딜러십(가벼운 스윙), 시험장(빠른 드라이빙 템포), 조립 과정(진행에 맞춰 쌓이는 곡), 사무실·설계실(기존 개선) |
| 시대 변화 | 1930s 래그타임·스트라이드·초기 스윙 → 1940s 빅밴드·부기우기, 전시엔 감상적 발라드, 1946~49 비밥 느낌 |
| 경영 반응 | 자금이 늘면 장조·밝은 편성, 위기엔 단조·느리게. 장면 전환은 마디 단위로 부드럽게 교차 |
| 음색 | 옛 라디오·레코드 질감(대역 제한, 약한 잡음·지글거림)은 설정에서 강도 조절 |

## 5. 제작 순서
사운드는 4단계 제작과 함께 진행한다: 공통 기반 → 기존 효과음 강화 → 기능을 만들 때마다 해당 효과음 → 배경음악 확장(악기·형식 → 장소별 곡 → 시대·경영 반응).
