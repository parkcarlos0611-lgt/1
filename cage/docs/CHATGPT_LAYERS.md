# ChatGPT로 마네킹 위에 올릴 피부·신체·얼굴 레이어 만들기

## 원리
마네킹(물리 뼈대 + 흰 몸)은 그대로 두고, 그 위에 **투명 PNG 레이어**를 겹칩니다. 레이어는 부위별로 따로 만들어야 관절을 따라 움직입니다.
레이어 종류(아래에서 위 순서): ① 피부(전신 색·근육 음영) → ② 신체 디테일(근육 윤곽, 혈관, 문신) → ③ 얼굴(눈·코·입·귀·헤어·수염) → ④ 의상·장비(트렁크, 글러브) → ⑤ 피해(멍·상처·땀, 게임이 부위별로 합성).

## 1단계: 정렬용 템플릿을 ChatGPT에 첨부
`docs/mannequin_template.png`(옆모습 차렷, 1380px) — 이 윤곽을 **그대로 따라** 그리게 하는 것이 핵심입니다. 윤곽·비율·포즈를 바꾸면 게임의 부위 위치와 어긋납니다.

## 2단계: 레이어별 요청문 (그대로 복사, `{}`만 채움)
**A. 피부+신체 레이어**
```
첨부한 마네킹 템플릿(옆모습, 오른쪽을 봄)의 윤곽과 비율을 1픽셀도 바꾸지 말고, 같은 캔버스(900×1500)에 그 위에 입힐 "피부와 근육 음영" 레이어만 그려 주세요.
선수: {이름}, 키 {cm}, 체중 {kg}, 체형 {마른/근육질/뱃살}, 피부색 {색 코드}.
- 투명 배경 PNG. 마네킹 윤곽 밖은 완전 투명.
- 얼굴 이목구비·머리카락·옷·글러브는 그리지 말 것(맨 머리, 맨몸, 맨발 상태). 문신 제외.
- 근육 윤곽(삼각근, 흉근, 복근, 광배, 대퇴사두, 종아리)은 템플릿의 선 위치에 맞춰 면 분할 음영으로.
- 얇은 갈색 외곽선, 그림자는 아래/뒤쪽에.
```
**B. 얼굴(머리) 레이어**
```
템플릿의 머리(옆모습, 오른쪽을 봄) 위치와 크기에 맞춰, 같은 캔버스에 "얼굴과 머리카락만" 투명 PNG로 그려 주세요.
선수: {이름}, 피부색 {코드}, 머리 {스타일/색}, 수염 {종류}, 눈·코·입·턱·광대·눈썹 특징 {설명 또는 사진 첨부}.
머리 윤곽을 템플릿 윤곽 안에 정확히 맞추고, 몸·목 아래는 투명. 무표정, 상처·땀 없음.
```
**C. 문신·트렁크·글러브 레이어(각각 따로)**
```
같은 캔버스·같은 정렬로 "{문신 | 트렁크 | 글러브}"만 투명 PNG로. 문신은 {위치·도안}, 트렁크는 {색·로고}, 글러브는 검정 4온스+빨간 스트랩. 나머지 신체는 투명.
```
**C-2. 부위 시트(권장)**: 한 장 대신 머리/몸통/위팔/아래팔/주먹/허벅지/종아리/발을 각각 템플릿에서 잘라 같은 크기로 요청하면 정렬이 훨씬 정확합니다.

## 3단계: 검수 체크(실패 원인 대부분)
1. 투명 배경인가(흰 배경이면 겹치지 않음) 2. 윤곽이 템플릿과 일치하는가(겹쳐서 확인) 3. 캔버스 크기·좌우 방향 동일 4. 레이어별로 다른 정보가 섞이지 않았는가(피부 레이어에 눈이 있으면 안 됨).
ChatGPT가 윤곽을 자주 바꾸므로 **마네킹 윤곽선 PNG를 먼저 만들어 주고 "이 선 안쪽만 칠하라"**고 하는 방식이 가장 안정적입니다.

## 4단계: 게임에 적용(구현 필요)
- 레이어를 부위별로 자르고(슬라이서) 각 마네킹 부위 윤곽으로 클리핑해, 관절을 따라 이동·회전하며 그립니다.
- 피해(멍·붓기·상처)는 레이어 위에 부위별로 합성합니다.
- 선수마다 `look.tex`에 폴더를 지정해 로드합니다.
