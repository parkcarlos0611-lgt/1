# R34 기준 차: 캐릭터 라인 v1

## 정해진 것 (2026-11-24)
- 엔진: **three.js** (TypeScript + Vite, Capacitor로 모바일 포장)
- 모델링: **Blender(bpy) 스크립트** → glb. 이 환경에서 Blender 5.3 설치와 CPU 렌더 확인 완료
- 게임 기본 화풍: **데포르메**. 실차 비율 버전도 같은 데이터에서 함께 생성
- 기준 차: **일반 GT-R 차체**. Z-tune 보닛·범퍼·펜더는 교체 부품으로 따로 만든다

## 자료
- 4면 선화 도면(Z-tune, 1500×756 px)과 사진 7장, outlines 일반 사양 도면 2장(해상도가 낮아 비율 확인용)
- 도면과 사진은 제3자 자료라서 **저장소에 올리지 않는다.** 겹쳐 본 확인 그림도 저장소 밖에만 둔다

## 데이터와 도구
- `model/r34/ref_lines.py`: 도면에서 손으로 읽은 캐릭터 라인 약 25개. 차의 왼쪽 반만 두고, 오른쪽은 대칭으로 만든다
- `model/common/deform.py`: 데포르메 표와 변환
  - 길이: 앞 오버행, 휠베이스, 뒤 오버행 구간마다 직선 비율. 구간 안에서는 평면이 평면으로 남는다
  - 폭·높이: 단순 비율. 벨트라인 위 유리 부분에만 추가 비율
  - 휠아치: 바퀴 중심 기준으로 바퀴와 함께 키운다. 아치가 늘어나 찌그러지지 않는다
- `model/common/draw_lines.py`, `model/r34/build_lines.py`: 확인 그림(옆, 정면, 후면, 위, 3/4)을 만든다

## 알려진 한계 (v1)
- 헤드라이트와 앞범퍼 주변의 선은 대략이다. 정면 도면 확대본을 보고 다듬어야 한다
- 앞 펜더의 Z-tune 덕트, 보닛 루버는 아직 넣지 않았다. 교체 부품 단계에서 넣는다
- 숄더 라인의 y값(폭 방향)은 평면도와 정면도를 보고 추정한 값이다
- 다음 단계(차체 면 붙이기)로 가기 전에 이 선을 승인받는다

## 차체 v1 (Blender)
- `model/r34/build_body.py`: 캐릭터 라인 사이를 평면으로 채운 첫 차체. 실차 비율과 데포르메를 한 번에 만든다
  - 실행: bpy 모듈이 있는 파이썬으로 `python build_body.py <출력 폴더>`
  - 결과: `assets/r34/r34_real.glb`, `r34_chibi.glb`, 확인 그림 `review/r34_body_v1.png`
- 삼각형: 바퀴 포함 실차 936개, 데포르메 892개
- 구조: 옆벽 4줄(바닥, 옆 주름선, 윗옆면, 숄더) + 윗면(숄더 → 중간 → 중심) + 캐빈(5개 지점)
- 휠아치: 아치 아래 줄을 아치 원 위로 올려 다각형 립을 만든다
- 아직 없는 것: 헤드라이트, 그릴, 범퍼 개구부, 테일램프, 리어윙, 미러, 필러, 패널 분리, 실내, 휠 디자인
- 알려진 문제: A필러 옆 삼각면이 유리 대신 차체 색, 바퀴 위 틈으로 바닥이 보임, 뒤쪽이 단순한 상자
