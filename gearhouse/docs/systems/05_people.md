# 시스템 설계 05 — 창업자와 직원

수직 슬라이스(소규모 공방, 미국, 1930~1935) 기준이다. 수치는 시작값이다. 가족·유언·승계는 4단계로 미뤘고, 여기서는 그때 필요한 자리만 남긴다.

## 1. 목적

- 회사는 사람으로 돌아간다. 차의 품질, 설계 속도, 상담 성공이 모두 사람의 능력에서 나온다.
- 사람은 다 보이지 않는다. 뽑을 때는 일부만 알고, 같이 일하면서 알게 된다.

## 2. 사람의 공통 데이터

창업자, 직원, 지원자, 고객, 공급사 담당자가 같은 바탕을 쓴다.

```
Person {
  id, name: { given, family }, born, sex, hometown
  portrait: { face, hair, facialHair, clothes, seed }   // 부위 조합, 나이에 따라 바뀐다
  skills: { 설계, 판금, 용접, 기계, 목공, 도장, 내장, 판매, 관리 }   // 0~100
  potential: { [skill]: 상한 }                          // 숨은 값
  traits: [성격 특성 2~3개]                             // 일부는 숨은 값
  voice: { formal, mood, ... }                          // 글의 말투(00 문서)
  health, fatigue
  lifespan                                              // 숨은 값
}
```

### 이름

- 국가별 이름 데이터에서 조합한다. 미국은 성 약 1,000개 × 이름 약 1,000개(남녀 각각)에 출생 연도별 빈도 가중치를 둔다. 이민 배경(영국계, 독일계, 이탈리아계, 폴란드계, 아일랜드계 등)에 따라 성과 이름의 묶음이 달라진다.
- 중간 이름 머리글자를 넣으면 조합이 더 늘어난다.
- 이름 데이터는 공개 통계(미국 인구조사 성씨 빈도, 사회보장국 출생 이름 통계)를 바탕으로 만든다. 출처는 `docs/asset_sources.md`에 적는다.

### 초상화

- 얼굴형, 눈, 코, 입, 머리 모양, 수염, 옷, 모자를 부위별로 조합한다.
- 나이대(20대~80대)에 따라 주름, 흰머리, 머리숱이 바뀐다.
- 옷은 직업과 시대를 따른다(작업복, 양복, 중절모).

## 3. 창업자

게임 시작 때 만든다.

| 항목 | 정하는 방법 |
|---|---|
| 이름 | 직접 입력 또는 무작위 |
| 나이 | 22~45세 중 선택 |
| 출신 배경 | 선택. 초기 능력과 시작 조건을 바꾼다 |
| 초상화 | 부위 선택 또는 무작위 |
| 수명 | 숨은 값. 80%는 Beta(5,3)을 49~99세로 환산한 나이까지 산다. 20%는 그 전의 무작위 시점에 사망한다 |

출신 배경(슬라이스):

| 배경 | 강한 능력 | 시작 조건 |
|---|---|---|
| 기계공 | 기계, 용접 | 공구가 좋다. 동네 정비 손님이 조금 있다 |
| 마차 장인 | 목공, 판금, 도장 | 차체 품질이 좋다. 엔진은 모른다 |
| 레이서 | 기계, 판매(이름값) | 레이스 인맥. 성능 평판이 조금 있다 |
| 상인 | 판매, 관리 | 자금이 더 많다. 손기술이 낮다 |
| 엔지니어 | 설계 | 도면이 빠르고 설계 결함이 적다. 자금이 적다 |

- 나이가 젊으면 능력은 낮지만 잠재력을 채울 시간이 길다. 나이가 많으면 능력이 높지만 남은 시간이 짧다.

## 4. 직원 뽑기

### 구인 경로

| 경로 | 비용 | 지원자 | 걸리는 시간 |
|---|---|---|---|
| 신문 구인란 | 광고비 | 수가 많다. 질이 고르지 않다 | 게재 후 1~2주 동안 온다 |
| 지인·직원 추천 | 없음 | 1~2명. 추천자와 성향이 비슷하다 | 며칠 |
| 가게 앞 구인 쪽지 | 없음 | 동네 사람. 수가 적다 | 느리다 |
| 직업학교 | 없음 | 젊고 능력이 낮지만 잠재력이 있다. 급여가 싸다 | 졸업철 |
| 다른 업체에서 데려오기 | 웃돈 | 능력이 높다. 그 업체와 사이가 나빠진다 | 협상 |

- 대공황이 깊어지면 지원자가 크게 늘고 희망 급여가 내려간다. 문 닫은 공장의 숙련공이 지원한다.

### 지원자가 보이는 정도

| 단계 | 드는 것 | 드러나는 것 |
|---|---|---|
| 지원서(편지) | 없음 | 이름, 나이, 경력 글. 능력은 "경력 몇 년" 같은 말로만 |
| 면접 | 창업자 1~2시간 | 능력 2~3개가 범위로(예: 판금 55~75). 성격 특성 1개 |
| 실기 시험 | 반나절, 자재 조금 | 시험한 능력 1개가 정확한 값으로 |
| 이전 고용주에게 문의 | 편지 왕복 | 근무 태도, 그만둔 이유 |
| 수습 기간(4주) | 급여 | 나머지 능력이 차츰 드러난다 |

- 잠재력과 숨은 성격은 함께 일해야 드러난다. 드러나는 속도는 창업자의 관리 능력이 정한다.
- 지원서 글은 과장될 수 있다(성격 특성 "허풍").

### 고용 조건

- 주급, 근무 요일, 수습 여부를 정한다. 지원자가 수락·흥정·거절한다.
- 급여 시작값: 견습 주 $12~$18, 일반공 $20~$28, 숙련공 $28~$40. (자동차 숙련공 임금은 자료를 찾지 못한 값이다.)

## 5. 일하기

- 직원은 근무일마다 정해진 시간(기본 9시간)을 낸다. 작업 배정표에서 공정이나 프로젝트에 배정한다.
- 배정하지 않으면 자기 능력이 가장 높은 열린 공정을 스스로 맡는다.
- 능력이 낮은 공정을 맡기면 느리고 품질이 낮지만 경험은 쌓인다.

### 성격 특성 (예)

| 특성 | 효과 |
|---|---|
| 꼼꼼함 | 품질 +, 속도 − |
| 손이 빠름 | 속도 +, 품질 조금 − |
| 가르치기 좋아함 | 같이 일하는 사람의 성장 + |
| 고집 | 지시와 다른 방식으로 할 때가 있다. 가끔 더 낫다 |
| 술 | 월요일 결근 사건 |
| 야심 | 성장이 빠르다. 승진이 없으면 떠난다 |
| 충직 | 어려울 때 남는다. 급여 지연을 참는다 |
| 허풍 | 지원서가 과장된다 |
| 손재주 | 한 능력의 잠재력이 매우 높다 |

## 6. 성장, 만족, 떠남

- **성장**: 공정을 한 시간만큼 그 능력의 경험이 쌓인다. 잠재력에 가까울수록 느려진다. 20~35세가 가장 빠르고 50세부터 손기술이 조금씩 내려간다.
- **만족도**(0~100): 급여 대 시세, 일의 맞음, 야근, 작업장 상태, 회사 평판, 동료가 정한다.
- 만족도가 낮으면 급여 인상 요구 → 사직 통보(2주 전) 순으로 사건이 난다.
- 다른 업체의 제안을 받는 사건도 있다. 능력이 드러난 숙련공일수록 자주 받는다.
- **해고**: 그 자리에서 할 수 있다. 남은 직원의 만족도와 구인 평판에 영향을 준다. 대공황 때의 해고는 지역 신문에 날 수 있다.
- **은퇴와 병**: 나이와 건강에 따라 병가, 은퇴 사건이 난다.

## 7. 승진과 조직 (슬라이스에서는 싹만)

- 직원 3명부터 **작업반장**을 정할 수 있다. 반장은 창업자가 없을 때 배정을 맡고, 관리 능력이 다른 직원의 효율을 바꾼다.
- 부서, 임원, 대량 채용은 3단계 이후다. 이때 초기 직원을 요직에 앉히는 선택이 생긴다.

## 8. 사건 (글은 00 문서 방식)

| 사건 | 선택지 |
|---|---|
| 지원서 도착 | 면접 / 거절 / 보류 |
| 급여 인상 요구 | 올려 줌 / 일부만 / 거절 |
| 사직 통보 | 붙잡음(조건 제시) / 보냄 |
| 다툼 | 한쪽 편 / 중재 / 내버려 둠 |
| 다침(작업장 사고) | 치료비 부담 / 유급 휴가 / 아무것도 안 함 |
| 좋은 제안("이렇게 하면 더 빨리 됩니다") | 받아들임(공수 감소, 가끔 품질 위험) / 거절 |
| 가족 일(결혼, 출산, 장례) | 휴가와 축의금 / 휴가만 / 거절 |
| 급여를 못 줄 때 | 사정을 말함 / 일부 지급 / 해고 |

## 9. 상태 데이터

```
Employee { personId, hiredDate, wage, daysOff, role, known: { skills: {[s]: [lo, hi]}, traits: [...] },
           satisfaction, xp: {[skill]: n}, assignedTo }
Applicant{ personId, via, letter, askWage, revealed, expires }
JobAd    { medium, cost, startDate, weeks, wanted: [skill] }
```

## 10. 하루 틱에서 하는 일

1. 근무일이면 직원마다 시간을 배정대로 넣는다(`hours_spent`).
2. 구인 경로마다 지원자 도착을 굴린다.
3. 저녁: 경험을 올리고, 드러난 정보 범위를 좁힌다.
4. 주말: 급여를 지급한다. 만족도를 다시 계산하고 사건을 굴린다.
5. 생일: 나이를 올리고 초상화 나이대를 바꾼다. 건강을 굴린다.

## 11. 이벤트

| 이벤트 | 보내는 내용 | 듣는 시스템 |
|---|---|---|
| `founder_created` | 창업자 | 전부(시작 조건) |
| `job_ad_placed` | 구인 광고 | 재무, 미디어(구인란에 실림) |
| `applicant_arrived` | 지원자 | UI, 시간(알림) |
| `employee_hired` / `employee_left` / `employee_fired` | 직원, 이유 | 생산, 재무, 평판, 공급(이전 거래처 소개) |
| `skill_revealed` | 직원, 능력, 범위 | UI |
| `skill_grew` | 직원, 능력 | 일지 |
| `wage_paid` / `wage_missed` | 금액 | 재무, 만족도 |
| `person_died` | 사람, 원인 | 승계(4단계), 미디어(부고) |

듣는 이벤트: `economy_changed`(지원자 수, 시세), `reputation_changed`(지원자 질), `build_step_done`(경험), `newspaper_published`(구인란).

## 12. 결정 (2026-11-19)

1. 능력은 9가지다(설계, 판금, 용접, 기계, 목공, 도장, 내장, 판매, 관리).
2. 창업자의 시작 나이는 플레이어가 고른다(22~45세).
3. 수직 슬라이스에서는 창업자 사망 판정을 끈다. 승계 단계(4단계)에서 켠다.
