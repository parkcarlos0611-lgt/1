# 테스트판 2차 계획: 화면·한국어·그릴 수정·배경음악·시대별 엔진/차량 사운드

> 상태: **계획 보고 단계 — 승인 후 제작.**

## 1. 지적 사항 진단

| 지적 | 원인 (코드 확인) | 수정 |
|---|---|---|
| 타이틀 차가 뒤로 감, 바퀴가 안 돎 | 차 스프라이트는 앞이 왼쪽인데 왼→오로 이동. 차 한 장을 통째로 미끄러뜨림 | 오른→왼(앞 방향)으로 주행. 휠 생성기의 회전값(`rot`)으로 **바퀴 8프레임**을 미리 만들어 이동 거리에 맞춰 돌림(미끄러짐 없이 둘레 = 이동 거리). 차체 미세 상하 흔들림 1px, 배기 연기 픽셀 |
| 화면이 작고 잘림 | 정수 배율만 쓰고 여백(32px)을 빼서 작음. 휴대폰·앱 화면에서 안전 영역·주소창 높이를 반영하지 않아 잘림 | 화면 비율(16:9)을 유지한 채 **꽉 채우는 배율**(정수 배율이 가능하면 정수, 아니면 소수 배율). `visualViewport` 크기와 안전 영역 기준, 회전·리사이즈 대응. 설정에 "정수 배율(선명)/꽉 채움" 선택 |
| 30년대 박스 세단 그릴이 펜더 위로 튀어나옴 | 차체 생성기의 플랫 그릴 셸이 펜더 높이 아래(바닥+150mm)까지 내려오고, 펜더보다 **앞 레이어**에 그려짐 | 그릴 셸을 펜더 **뒤 레이어**로, 아래 끝을 펜더 윗선에서 자름. 같은 규칙을 다른 그릴 모양·연도에 일괄 적용하고, 1930~39 생성 차량 40대를 뽑아 겹침 자동 검사(펜더 위 픽셀에 그릴 태그가 있으면 실패) |
| 한국어 없음 | 3×5 영문 픽셀 폰트만 있음 | §2 |

## 2. 한국어
- **폰트**: 픽셀아트용 한글 오픈 폰트(SIL OFL, 상업 사용 가능)를 페이지에 내장. 11px 크기를 기본으로, 안티앨리어싱 없이 픽셀 버퍼에 찍어 지금 UI와 같은 질감을 유지. 라이선스 문구를 설정 화면과 저장소에 표기.
- **문자열 표**: 모든 화면 문구를 키로 분리(`ko`·`en`), 설정에서 언어 전환. 기본값은 브라우저 언어(한국어 브라우저 → 한국어).
- **레이아웃**: 한글은 영문 3×5보다 높으므로 버튼·목록 줄 간격을 언어별로 계산. 숫자·단위는 그대로(예: 90HP → 90마력 선택 가능).

## 3. 배경음악 (잔잔한 타이쿤 스타일)
- **방식**: 음원 파일 없이 브라우저 오디오 합성으로 직접 연주하는 **오리지널 곡**. 저작권 문제 없음, 용량 거의 없음.
- **악기 (합성)**: 업라이트 피아노(삼각파 + 빠른 감쇠 + 약한 해머 잡음), 콘트라베이스 피치카토, 브러시 스네어(필터 잡음), 클라리넷/뮤트 트럼펫 느낌의 리드(필터 사각파 + 비브라토), 옛 라디오 질감(대역 제한 + 약한 잡음, 끄기 가능).
- **곡 구성**: 시대별 4곡.
  | 곡 | 시대·장면 | 분위기 |
  |---|---|---|
  | 사무실 1930s | 본사 화면 1930~39 | 느린 스윙·래그타임 피아노, 72~84 BPM |
  | 사무실 1940s | 본사 화면 1940~49 | 부드러운 빅밴드 리듬 섹션, 전시엔 단조 변주 |
  | 설계실 | 엔진·차 디자인 | 더 잔잔한 피아노 솔로 |
  | 타이틀 | 메인 메뉴 | 짧은 팡파르 → 루프 |
- 코드 진행은 시대 대중음악 관습(ii–V–I, 턴어라운드)을 따르되 멜로디는 규칙 기반으로 새로 생성(고정 시드 → 매번 같은 곡). 60~90초 루프, 반복 시 변주.
- **조작**: 첫 클릭 후 재생(브라우저 자동재생 정책), 음악·효과음 볼륨 따로, 음소거 버튼 상단 바에.

## 4. 시대별 고유 엔진·차량 사운드 계획 (전 시대 공통 설계)

### 4-1. 원리: 엔진 데이터에서 소리를 만든다
엔진 설계값이 그대로 소리가 된다. 같은 엔진은 같은 소리, 설계를 바꾸면 소리도 바뀐다.

| 엔진 데이터 | 소리 요소 |
|---|---|
| rpm, 실린더 수 | 점화 주파수 = rpm/60 × 실린더/2 (기본음) |
| 배열·점화 간격 | 펄스 간격 패턴: 직렬6·V12 고른 간격(매끈한 윙), 크로스플레인 V8 불균일 간격(특유의 우르릉), 직렬4 2차 진동(거친 웅) |
| 밸브 기구 | 사이드밸브: 둔하고 조용한 기계음 / OHV: 태핏 똑딱 / OHC·DOHC: 고회전 금속성 |
| 배기량·보어 | 펄스 크기·저음 비중 |
| 흡기(기화기 수·크기) | 흡기 쉭 소리, 스로틀 열림 |
| 배기·머플러(시대) | 배기 공명 필터. 1930s 단순 머플러 → 거칠고 큼, 1970s 촉매 → 둔탁·조용 |
| 부하·rpm | 부하 시 음량·잡음 증가, 감속 시 팝 |

### 4-2. 시대 특징 사운드
| 시대 | 엔진 | 차량·주변 |
|---|---|---|
| 1930s | 사이드밸브 직렬4·6 저회전 털털거림, 플랫헤드 V8 우르릉, 고급 V12·V16 매끈한 윙 | 6V 스타터의 느린 크랭킹, 클랙슨 "아-우-가" 경적, 비동기 기어 갈리는 소리, 포장·자갈길 타이어 |
| 1940s | 군용 4기통 고회전 윙윙, 6x6 거버너 직렬6 웅웅, 전후 V8 | 전기 트럼펫 경적, 유체 커플링 자동의 미끄러지는 변속, 군용 체인·캔버스 펄럭임 |
| 1950s | 고압축 OHV V8 크고 깊은 소리, 듀얼 배기 | 12V 스타터(빠른 크랭킹), 크롬 문 닫힘 |
| 1960s | 다중 기화기 머슬 V8, 소형 공랭 수평대향의 독특한 소리 | 4단 수동 변속, 레디얼 타이어 소음 |
| 1970s | 배기가스 규제로 둔해진 V8, 소형 4기통 | 촉매 머플러, 안전벨트 경고음 |
| 1980s | 연료분사의 안정된 공회전, 터보 휘슬·블로오프 | 전자음 차임 |
| 1990s | DOHC 고회전, 가변 밸브 전환음 | 정숙한 실내, ABS 작동음 |

### 4-3. 게임 안 쓰임
- 엔진 설계: **다이노 테스트** 버튼 → 공회전에서 레드라인까지 회전을 올리는 소리.
- 차 디자인: **시험 주행** 버튼 → 출발, 변속(기어비대로), 최고속.
- 타이틀: 지나가는 차의 엔진음(차가 다가왔다 멀어지는 음량·도플러).
- 출시·판매: 시대별 짧은 효과음(타자기, 전신, 금전등록기).

### 4-4. 구현 방식
브라우저 오디오: 실린더 펄스 생성기(점화 순서·뱅크각 반영) + 공명 필터(배기관 길이) + 흡기·기계 잡음 + 부하 엔벨로프. 엔진마다 rpm 구간별 짧은 소리를 미리 만들어 부드럽게 섞음 → 휴대폰에서도 가볍게. 테스트판에서는 1930~40년대 엔진(사이드밸브 I4·I6·V8·V12, OHV I6)과 1930~40년대 차량 효과음만 먼저 만든다.

## 5. 테스트판 2차 제작 순서 (승인 후)
1. 화면 꽉 채움·잘림 수정, 타이틀 차 전진 + 바퀴 회전
2. 박스 세단 그릴 레이어 수정 + 1930년대 생성 차량 겹침 자동 검사
3. 한국어 (폰트 내장, 문자열 표, 언어 전환)
4. 배경음악 4곡 + 볼륨·음소거
5. 1930~40년대 엔진 사운드(다이노·시험 주행·타이틀 지나가는 차) + 효과음
6. 헤드리스 브라우저로 화면별 스크린샷 검사 → 페이지 갱신 → 보고
