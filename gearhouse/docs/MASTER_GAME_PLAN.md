# GEARHOUSE 본격 게임 시스템 구상안 (마스터 계획서)

> 상태: **계획 보고 단계 → 보고 후 1단계부터 착수.**
> 참고 게임: *Automation*(엔진·차체 설계 깊이, 실제 개발 순서), *GearCity*(경영·딜러·경쟁사·연표), *Car Mechanic Simulator*(부품 단위 조립 상호작용), *Game Dev Tycoon*(출시 행사·리뷰 점수 연출).
> 구조와 검증된 흐름만 참고한다. 명칭·UI·수치·그림은 모두 이 프로젝트 고유로 만든다.
> 원칙: ① 자료(실측·사진)가 항상 그림 스타일보다 우선 ② 실제 개발 순서와 공정 ③ 높은 설계 자유도 ④ 모든 단계에 손으로 만지는 상호작용과 보상 연출 ⑤ 결과는 장소·인쇄물·숫자로 사실적으로 남는다.

## 1. 차량 개발 파이프라인 (실제 순서)
각 단계는 **설계실 장소**의 다른 자리(제도대, 엔진 시험실, 목업실, 시험장)에서 일어나고, 단계마다 기간·비용·담당 인력이 든다. 앞 단계로 돌아가 수정하면 뒤 단계 비용이 다시 든다(실제 개발처럼).

| 단계 | 내용 | 결과물·연출 |
|---|---|---|
| 1 기획서 | 목표 세그먼트·가격·연간 생산량·시장(국가). 시장 조사 보고서(경쟁차 표) | 타자기로 찍히는 기획서 문서 |
| 2 플랫폼(섀시) | 프레임 형식(래더·X멤버·페리미터·유니바디), 강재 등급·두께, 휠베이스·트레드, 앞뒤 서스펜션, 브레이크, 타이어 규격, 조향 | 제도대 위 **프레임 청사진**. 무게·강성·원가 계산, 강성 부족 부위가 붉게 표시 |
| 3 엔진 | §2 엔진 설계기 (패밀리 → 변형) | 엔진 시험실: 조립 애니메이션, 다이노, 내구 시험 |
| 4 구동계 | 변속기 형식·단수·기어비, 종감속, 차동 | 기어 맞물림 단면 |
| 5 차체 설계 | §3 파라메트릭 차체 설계기 (측면·정면·후면·평면) | **청사진**: 수정할 때마다 새 청사진이 스캔되어 나오는 장면 (광원 막대가 지나가며 선이 인쇄됨) |
| 6 목업 | 1930년대 목재 목업, 1940년대 실물 크기 클레이 모형. 조명 아래 360° 회전, 경영진 품평회 | 목업실 장면, 품평 점수와 수정 요청 |
| 7 상세 설계 | 실내(좌석·계기판), 편의 장비, 안전 장비, 트림 등급, 도장 옵션 | 계기판·실내 단면 미리보기 |
| 8 시제품·시험 | 시제품 제작(조립 9단계 연출), **시험장 직접 운전**, 내구 주행, 결함 발견과 수정 | 결함 리포트(신뢰성↑ vs 출시 지연) |
| 9 생산 준비 | 공장 라인 배치, 강판·자재 조달, 설비(프레스 금형) 제작 | 도색 안 된 프레임이 라인에 걸리는 장면 |

## 2. 엔진 설계기 (부품 단위)
| 부품 그룹 | 설계 항목 (시대 해금) | 영향 |
|---|---|---|
| 블록 | 배열(직렬 3~8, V6~V16, 수평대향), 뱅크각, 재질(주철·알루미늄), 실린더 간격, 최대 보어·스트로크 | 길이·폭·무게·진동·원가 |
| 헤드 | 사이드밸브 / F헤드 / OHV / SOHC / DOHC, 실린더당 밸브 수, 연소실 형상, 재질 | 체적효율 상한, 회전 한계, 압축비 한계 |
| 하체 | 크랭크(주조·단조, 메인 베어링 수), 커넥팅로드(재질), 피스톤(주철·알루미늄) | 회전 한계, 신뢰성, 진동 |
| 밸브계 | 캠 프로파일(토크형 ↔ 고회전형), 밸브 스프링 강도 | 토크 곡선 모양, 밸브 서징 |
| 흡기 | 기화기 형식(업드래프트·다운드래프트·사이드), 개수·구경, 흡기 매니폴드 | 고회전 출력, 연비 |
| 연료·점화 | 압축비(시대 옥탄 한계), 점화 시기 | 출력·노킹·신뢰성 |
| 배기 | 매니폴드, 단일·듀얼, 머플러 | 출력, 소음(사운드에 반영) |
| 냉각·윤활 | 라디에이터 크기, 오일 용량 | 신뢰성, 무게 |
| 공정 등급 | 부품 그룹마다 −3~+3 | 원가·개발기간 ↔ 성능·신뢰성 |

- **엔진 그림**: 설계값으로 블록·헤드·크랭크·피스톤·매니폴드·기화기·발전기·팬을 **부품별 스프라이트로 조립**한다. 외관, 투시도, 분해도 3가지로 보여 준다. 투시도는 점화 순서대로 움직인다.
- **시험**: 다이노(곡선이 그려짐), 내구 시험(시간 가속, 고장 부품 표시), 엔진음.
- **엔진 조립 연출**: 블록 → 크랭크 → 피스톤 → 헤드 → 매니폴드 → 보기류.

## 3. 파라메트릭 차체 설계기 (가장 큰 작업)
**혼합 대신 직접 설계.** 실측 차량은 허용 범위와 시작 프리셋으로만 쓴다.

### 3-1. 설계 계층 (아래에서 위로)
| 계층 | 조절 (모두 mm, 실측 범위 + 시대 한계) |
|---|---|
| 프레임·섀시 | §1-2에서 설계한 플랫폼 그대로. 차체는 프레임 위에 얹힌다 |
| 차체 구조 | 목골조+강판 / 전강철 / 일체형, 강판 등급·두께(성형 한계 → 곡률 한계) |
| 측면 윤곽 | **제어점 편집**: 범퍼선, 후드선, 카울, 앞유리 기울기, 루프선, C필러, 트렁크·꼬리, 로커선. 점을 끌어 옮기고 곡률 손잡이를 조절. 각 점은 실측 범위 밖으로 못 나감 |
| 펜더 | 분리형(앞·뒤 모양 곡선), 밸런스형, 반폰툰, 폰툰. 앞펜더 꼬리 길이, 크라운 높이, 스커트 |
| 캐빈·창 | 문 개수·문 길이·경첩 형식, A·B·C 필러 위치와 두께, 창 개수·위아래 선, 환기창, 앞유리(1장·2분할), 뒷창 크기, 지붕 형식(고정·컨버터블·랜도) |
| 정면 | 그릴(모양·패턴·크기·높이), **헤드램프 좌우 대칭 배치**(간격·높이·형식: 스탠천·포드·펜더 매립, 크기), 범퍼(바 수·가드·높이), 보조등, 후드 장식, 번호판 |
| 후면 | 트렁크/뒤 스페어, 테일램프(대칭 배치), 뒷창, 범퍼, 번호판, 연료 주입구 |
| 장식 | 몰딩·스피어·핀스트라이프·루버·엠블럼을 측면·정면에 배치 (그리드 스냅, 좌우 대칭 복사) |
| 도장 | 단색·투톤·펜더색·핀스트라이프 색, 시대 색표 |

### 3-2. 편집 기능 (실용)
- **대칭 모드**: 정면·후면의 램프·범퍼 가드·보조등을 한쪽에 놓으면 반대쪽에 거울 배치.
- **편집 보조**: 그리드 스냅, 실행 취소·다시 실행, 수치 직접 입력, 부품 복사.
- **비교**: 실측 범위 표시선, 경쟁차 실루엣을 겹쳐 보기.
- **5뷰 동기화**: 측면에서 바꾼 높이·길이가 정면·후면·평면에 즉시 반영. 폭·높이가 어긋나면 자동 경고.
- **기존 모델에서 시작**: 연식 변경(페이스리프트)용으로 지난 모델을 불러와 일부만 수정.

### 3-3. 질리지 않게
- **시대 유행 지수**: 해마다 인기 형태(그릴 모양·펜더 형식·투톤 등)가 바뀌어 같은 디자인의 평가가 달라짐.
- **디자이너 인력**: 숙련도가 허용 곡률·부품 수·개발기간에 영향, 각자 성향(보수·전위).
- **영감 스케치**: 디자이너가 가끔 콘셉트 스케치를 가져옴(새 부품·형태 해금).
- **도전 과제 기획서**: 예) "1936년, $600 이하 4도어로 연비 25mpg".
- **콘셉트카**: 판매하지 않는 쇼카로 평판을 올린다.
- **부품 카탈로그**: 해마다 새 프롭 추가(이미 224종 + 1940년대 배치 예정).

### 3-4. 청사진·목업 연출
- **청사진**: 설계 변경 → 제도대 위 청사진 롤이 스캐너를 통과하며 선이 한 줄씩 인쇄되는 장면. 치수선·주석 포함.
- **목업**: 실물 크기 목재·클레이 모형이 목업실 조명 아래 놓이고, 360° 회전과 품평회 의견 말풍선이 나옴.

### 3-5. 품질 (v2 렌더 품질 향상 동시 진행)
- **부품 라이브러리**: 두툼한 실부품으로 바꾼다. 범퍼 단면·브래킷·볼트, 램프 버킷·크롬 림, 그릴 셸·바 단면, 교차 스포크 휠, 경첩·핸들.
- **명암 v2**: 곡률 기반 반사띠, 디더는 경계에만, 재질별 명암 곡선.
- **하부 자동 생성**: 프레임·서스펜션·구동계·배기·탱크가 섀시 설계값에서 나온다.

## 5. 장소 (도시 지도에서 이동)
| 장소 | 그래픽·상호작용 |
|---|---|
| 회사 전경 | 공장동·사무동·급수탑·굴뚝, **출고 야적장에 줄지어 선 신차**(실제 재고 수에 비례), 직원 주차장. 규모·시대에 따라 확장 |
| 본사 사무실 | 책상·타자기·전화·지도. 비서 안내, 보고서 서류 |
| 설계실 | 제도대(청사진), 목업실, 엔진 시험실 |
| 공장 내부 | 라인, 프레스, 도장 부스. 기계·인원 클릭 시 정보 |
| 시험장 | 직선로·뱅크 오벌·비포장 언덕. 직접 운전 |
| 딜러십 | 지역별 매장(1930s 상가 → 1940s 쇼룸 → 1949 스트림라인), 진열된 내 차, 손님 |
| 행사장 | §7 발표회 장소들 |
| 재고 방치 | 야적장·쇼룸에 오래 팔리지 않은 차에 **먼지가 쌓이고 색이 바래는 표시**, 가격 인하 필요 |

## 6. 신차 발표회와 언론
| 규모 | 장소 | 비용·효과 |
|---|---|---|
| 소 | 딜러 쇼룸 | 지역 신문 단신 |
| 중 | 호텔 연회장 | 지역·전국 신문 |
| 대 | 본사 대강당·전용 행사장 | 잡지 표지 기회 |
| 특대 | 자동차 박람회·만국박람회 부스 | 해외 시장 인지도 |
- **연출**: 커튼이 걷히며 차가 공개되고 플래시가 터진다. 그 장면이 **흑백 신문 사진**(디더 흑백 + 망점 질감)으로 인쇄된다.
- **신문 기사**: 헤드라인, 사진, 본문은 제원·가격과 기자 한마디.
- **잡지**: 로드 테스트 기사(측정값 표, 장단점, 별점). 매체마다 성향이 다르다(스포츠지·가정지·업계지).

## 7. 출시 후 평가와 판매
- **판매**: 월별·지역별·세그먼트별 판매량, 경쟁차 대비 점유율 그래프, 딜러 재고.
- **전문가 평가**: 출시 리뷰 + 연례 비교 시험, 수상(올해의 차 등 가상 상).

## 12. A단계 재정비 — 실측 렌더를 설계기의 바탕으로

**지적:**
- v3 설계기가 기존 실측 렌더(측면 14대, 정면·후면 5세트, 군용)를 쓰지 않고 도형부터 새로 그려 품질이 떨어졌다.
- 정면 앞유리 아래 양옆이 비는 문제(예전 군용차와 같은 문제)가 다시 생겼다.

**바로 고친 것:** 정면·후면에서 차체 옆면(카울·문)이 벨트라인부터 문턱까지 전폭으로 내려가도록 수정했다. 펜더는 그 앞에 그려진다.

**원칙:** 기존 실측 렌더는 삭제하지 않고 설계기의 **바탕 차체**로 쓴다. 새 도형은 실측 자료가 없는 곳에만 쓴다.

| 순서 | 내용 |
|---|---|
| 1 | **바탕 차량 선택**: 설계를 시작할 때 시대에 맞는 실측 차체 14대 중 하나를 고른다(연도로 잠금). 측면은 실측 사양 그대로 출발한다 |
| 2 | **치수 조절 = 구간 변형**: 휠베이스, 앞뒤 오버행, 지붕·벨트·후드 높이, 전폭을 실측 사양의 구간 변형으로 적용한다(캐빈 고정 원칙 유지). 기존 warpSpec을 오버행·후드·벨트까지 확장한다 |
| 3 | **부품 교체 = 실측 부품 라이브러리**: 그릴, 헤드램프, 범퍼, 테일램프, 휠, 스페어를 실측 차에서 부품 단위로 떼어 라이브러리로 만든다. 다른 실측 차의 부품을 같은 기준점(그릴 중심, 펜더 정점, 범퍼 높이)에 맞춰 바탕 차에 끼운다 |
| 4 | **정면·후면도 실측 바탕**: 실측 정면·후면이 있는 차(1930 세단, 1934 타운카, 1934 에어플로형, 1937 유선형, 군용)는 그대로 쓰고 같은 치수 변형을 적용한다. 정면·후면이 없는 1940년대 8대는 받은 정면·후면 사진 16장으로 **실측 정면·후면을 새로 제작**한다 |
| 5 | **v3 매개변수 체계 유지**: 조작 항목, 시대 한계, 대칭 배치, 청사진 스캔은 그대로 두고 그리는 쪽만 실측 바탕으로 바꾼다. 실측 바탕이 없는 조합에만 v3 도형을 쓴다 |
| 6 | **품질**: 범퍼 단면·브래킷, 램프 버킷·크롬 림, 그릴 바 단면을 실측 부품 기준으로 다듬는다 |

**진행 결과 (12장 1차):** 바탕 차량 14대 선택, 구간 변형(앞·뒤 오버행, 휠베이스, 차체 높이, 지붕 높이, 전폭), 부품 교체(휠, 헤드램프, 그릴, 범퍼, 테일램프)를 테스트판에 반영했다. 실측 정면·후면 5세트는 치수에 맞춰 다시 맞추고, 1940년대 8대의 정면·후면은 측면 실측 높이와 정면·후면 사진으로 만들었다. 자유 설계(v3)는 선택 항목으로 남겼다.

### 13-1. 실측 기반 프레임·플랫폼
- **바탕 프레임**: 바탕 차량마다 실제 프레임 형식과 치수를 기본값으로 둔다. 1930년대 초는 채널 단면 래더와 뒤차축 위 킥업, 1930년대 중반부터 X멤버, 1940년대 박스 단면 레일. 휠베이스를 바꾸면 사이드 레일이 늘어난다.
- **모노코크(유니바디)**: 연구로 해금한다(1930년대 중반 실차 사례 기준). 바닥판, 사이드실, 터널, A·B·C 필러, 루프 레일, 앞 격벽을 부재 단위로 표시하고, 무게·강성·금형비·수리비가 프레임식과 달라진다.
- **설계 화면**: 평면도와 측면도를 함께 보여 준다. 도색 안 된 강재 색에 리벳·용접 표시를 넣고 청사진 스캔을 쓴다. 조절 항목은 레일 단면 높이·두께, 강재 등급, 크로스멤버 수, 킥업 높이다.
- **생산 연결**: 조립 1단계에서 설계한 프레임이 그대로 나온다. 모노코크는 프레임 단계와 차체 얹기 단계 대신 용접 지그에서 차체가 짜이는 장면으로 바뀐다.
- **필요 자료**: 1930~49년 프레임 평면도(래더·X멤버), 초기 모노코크 절개도.

### 13-2. 실측 차체 형상 조절
- **조절점**: 실측 윤곽 위에 지붕 앞끝, 지붕 정점, 뒷창 경사, 트렁크 길이·높이(패스트백 경사), 앞코·그릴 경사, 앞펜더 꼬리 길이·정점, 벨트선 기울기, 앞유리 경사를 둔다.
- **변형 방식**: 각 조절점 주변만 부드럽게 변형하고 캐빈 문짝은 고정한다. 범위는 같은 시대 실측 차들 사이로 제한한다.
- **조작**: 측면 미리보기에서 끌기와 수치 입력을 모두 지원하고, 실행 취소를 넣는다. 정면·후면은 같은 높이를 공유해 자동으로 따라간다.

### 13-3. 부품 장착 연출
- **설계 화면**: 그릴·램프·범퍼·장식·휠을 바꾸면 화면 전체를 다시 스캔하지 않는다. 바뀐 부품만 다음 순서로 연출한다.
  1. 옛 부품이 떨어진다.
  2. 새 부품이 장착 위치로 내려와 맞물린다.
  3. 볼트 조임 반짝임 2~3번.
  4. 크롬에 빛이 한 번 훑고 지나간다.
  5. 효과음(렌치, 래칫, 쿵)과 장식 장착 시 작은 '딸깍'.
- **조립 화면**: 8단계 마감에서 그릴, 헤드램프, 범퍼, 장식, 휠캡을 하나씩 단다.
- **구현 기반**: 부품이 사양에 따로 들어 있어서, 부품을 뺀 차체와 부품을 따로 그려 겹치는 방식으로 만든다.

**진행 결과 (13장 1차, 3 → 2 → 1 순서):**
- **13-3 장착 연출:** 설계 화면에서 그릴, 램프, 범퍼, 가드, 장식, 안개등, 휠을 바꾸면 그 부품만 연출한다. 옛 부품이 떨어지고, 새 부품이 내려와 맞물리고, 볼트 반짝임과 크롬 빛이 지나가며, 쿵·래칫·딸깍 소리가 난다. 조립 8단계에서는 범퍼 → 램프 → 그릴·크롬 순서로 하나씩 단다.
- **13-2 형상 조절:** 형상 탭을 추가했다. 실측 윤곽 위 조절점 7개(앞유리 윗선, 지붕 정점, 뒷창 윗선, 트렁크 높이, 앞코 경사, 앞펜더 꼬리, 앞펜더 높이)를 끌거나 슬라이더로 움직이며, 바탕 차마다 범위가 정해져 있다. 되돌리기·다시하기는 모든 탭에 적용된다.
- **13-1 프레임·플랫폼:** 프레임 탭을 추가했다.
  - 바탕 차마다 실제 형식을 기본값으로 둔다: 채널 래더, 래더 + X멤버, 박스 레일 + X멤버, 일체형 차체(연구 해금).
  - 조절 항목: 레일 높이·두께, 크로스멤버 수, 킥업, 강재 등급(연강, 중탄소강, 고장력강).
  - 이 값으로 무게·강성·강도 여유·원가를 계산해 성능(무게), 승차감(강성), 신뢰성(강도 부족 시 균열), 원가, 현대성에 반영한다.
  - 조립 장면은 설계한 프레임(도색 안 된 강재)을 쓰고, 일체형 차체는 지그 용접 → 서스펜션 장착 → … 순서로 진행한다.
- **13-1 보강 (7차 자료):** 일체형 차체를 1934년 셸 사진 기준으로 다시 그렸다(격벽, 뿔 레일, 문·창 개구부, 일체 휠하우스, 평평한 리브 바닥). 조립 장면도 셸 → 서스펜션 → 파워트레인 → 펜더·보닛 결합 순서로 바뀐다. 1938년 하부 사진으로 '중앙 튜브 플랫폼' 형식을 추가했다.

**그림:**
1. **외관**: 설계값대로 부품 스프라이트를 조립한다. 블록 길이는 실린더 수×보어 간격, 헤드는 평평한 SV·로커 커버 OHV·캠 커버 OHC, 기화기 개수와 위치(업드래프트는 아래, 다운드래프트는 위), 매니폴드, 발전기, 팬·물펌프, 배전기, 오일 필터, 스타터.
2. **투시도**: 기존 절개도를 부품 설계에 맞춰 점화 순서대로 움직인다.
3. **분해도**: 부품을 위아래로 띄워 이름표를 단다.

**엔진 시험실:**

**글꼴**
- 지금은 UI에 쓰는 한글 548자만 들어 있다.
- 갈무리7에는 한글 11,172자가 모두 있으므로 전체를 따로 굽는다(약 130KB). 이름을 처음 입력할 때만 불러온다.

**표시와 번역**
- 직접 입력한 이름은 번역하지 않는다. 텍스트 함수에 '원문 그대로' 표시를 추가해, 예를 들어 'STANDARD 8'이 '표준 8'로 바뀌지 않게 한다.
- 이름은 목록, 생산·시장 화면, 신문 기사, 신차 발표회(F단계), 차 옆면 크롬 엠블럼(작은 픽셀 글씨, 선택 사항)에 쓴다.

**상표 관련**
- 게임이 만드는 기본 이름과 추천 이름에는 실존 상표를 쓰지 않는다.
- 플레이어가 직접 입력한 이름은 막지 않는다.

**저장**: 이름은 이미 각 객체의 name 필드에 있어 저장 형식은 그대로 쓴다. 새 필드(트림 이름, 색 이름, 플랫폼 이름)만 기본값과 함께 추가한다.

**제작 순서**
1. 입력칸 위젯 + 숨은 입력창 + 한글 전체 글꼴 지연 로드
2. 모델·엔진·변속기·회사 이름
3. 트림·색·플랫폼·차체 이름
4. 이름 추천
5. 엠블럼 표시

**16장 진행 결과 (이름 짓기 1~4):** 이름 입력칸(숨은 입력창으로 한글 조합·모바일 키보드 지원, Enter 확정, Esc 취소)과 주사위 추천 버튼을 넣었다. 대상은 회사(새 게임, 메뉴), 모델, 플랫폼, 차체 스타일, 트림 이름 4개, 색 이름, 엔진, 변속기다. 한글 11,172자 글꼴은 처음 필요할 때 불러온다(177KB). 입력한 이름은 번역하지 않는다. 엠블럼 표시(5)는 남았다.

**버튼 클릭 문제 수정:**
- 탭(터치)이 프레임에 반영되기 전에 손가락이 떨어지면 좌표가 지워져 클릭이 사라지던 문제 → 프레임이 처리할 때까지 탭 위치를 유지한다.
- 터치 스크롤·확대 동작이 캔버스 입력을 가로채던 문제 → 캔버스에 touch-action none과 포인터 캡처를 적용했다.
- 스크롤 영역에서 3픽셀만 흔들려도 스와이프로 처리해 클릭이 무시되던 문제 → 6픽셀로 완화했다.

## 17. 그릴·범퍼·헤드램프 자유 이동 계획 (좌우 대칭 유지)

**지금:** 정면 부품은 '어느 차의 부품을 쓸지'만 고르고, 위치는 바탕 차의 장착점에 고정된다.

| 부품 | 움직일 수 있는 것 | 대칭 규칙 | 한계 |
|---|---|---|---|
| 헤드램프 | 좌우 간격, 높이, 크기 | 한쪽을 끌면 반대쪽이 중심선 기준으로 거울처럼 따라온다 | 펜더·후드 윤곽 안, 범퍼 위, 시대별 최소 높이, 그릴과 겹치면 붉게 표시 |
| 그릴 | 높이 위치, 폭, 높이 | 항상 중심선에 놓이고 폭은 양쪽으로 같이 늘어난다 | 후드 폭·높이 안, 라디에이터를 가릴 수 없는 최소 면적(냉각 성능에 반영) |
| 범퍼 | 높이, 폭, 앞으로 나온 길이(측면에서), 가드 간격 | 폭·가드는 대칭 | 프레임 혼(브래킷) 높이 ±범위, 타이어 폭 바깥으로 최소 돌출 |
| 테일램프·안개등 | 간격, 높이 | 거울 대칭 | 차체 윤곽 안 |

- **조작**: 정면·후면 미리보기에서 부품을 직접 끈다. 끄는 동안 중심선과 대칭 안내선이 보이고, 놓으면 부품 장착 연출이 나온다. 슬라이더로도 같은 값을 넣을 수 있고 되돌리기가 된다.
- **3면 일치**: 높이는 측면과 같은 값을 쓴다. 정면에서 램프 높이를 바꾸면 측면 램프도 같이 움직인다. 범퍼 돌출은 전장에 반영된다.
- **게임 반영**: 그릴 면적 → 냉각 여유(엔진 신뢰성), 램프 높이·간격 → 시대별 규정·디자인 점수, 범퍼 높이 → 안전·디자인 점수.
- **순서**: ① 정면 부품 위치 값(오프셋) 추가와 한계 계산 ② 끌기 + 대칭 안내선 ③ 측면·후면 연동 ④ 점수 반영.

## 18. 프레임 제작 단계 구체화 계획

**지적:** 프레임이 너무 가늘고 실제 같지 않다. 프레임 단계에서 차체 형상(바탕 차량)까지 정하는 것이 섞여 있다. 프레임 위에 차체를 맞춰 만드는 방식과 모노코크 방식이 갈라져야 한다.

**1) 단계 분리**

| 지금 | 바꾸는 것 |
|---|---|
| 플랫폼 단계에서 바탕 차량(차체 형상)·휠베이스·프레임을 한꺼번에 선택 | **플랫폼 단계는 구조만**: 구조 방식, 휠베이스, 트레드, 프레임 치수, 서스펜션, 브레이크. 차체 형상(바탕 차체)은 **차체 단계**에서 고른다 |
| 차체가 프레임을 정함 | **프레임이 차체를 제한**: 휠베이스·트레드·프레임 높이·엔진룸 길이에 맞는 바탕 차체만 차체 단계에서 고를 수 있고, 맞지 않으면 차체를 늘리거나 줄여 맞춘다 |

**2) 구조 방식에 따른 분기**

| 방식 | 개발 흐름 | 특징 |
|---|---|---|
| 프레임 위 차체(바디 온 프레임) | 프레임 설계 → 차체는 프레임에 **맞춰** 제작(마운트 위치, 바닥 높이) → 같은 프레임에 다른 차체를 얹어 파생 모델(세단·쿠페·픽업)을 싸게 추가 | 무겁지만 차체 변경이 쉽고 금형비가 낮다 |
| 중앙 튜브 플랫폼 | 플랫폼 설계 → 차체를 볼트로 결합 | 가볍고 단단, 차체 교체 가능 |
| 모노코크 | **프레임 단계가 없고** 차체 단계에서 셸 구조(사이드실, 필러, 바닥, 격벽 두께)를 함께 설계 → 차체와 구조가 한 번에 확정 | 가볍고 단단하지만 금형비가 크고 파생 모델이 어렵다. 차체를 바꾸면 구조도 다시 |

**3) 프레임 제작 단계 구체화 (프레임 방식)**
1. **사이드 레일**: 단면(채널, 박스, 더블 드롭), 높이·폭·두께, 앞쪽 좁아짐, 뒤차축 킥업, 앞차축 위 아치를 정한다.
2. **크로스멤버**: 개수와 위치(앞, 엔진 받침, 변속기 받침, 중앙, 뒤 스프링 행거, 뒤 끝), 형식(관, 채널, X멤버, K멤버).
3. **장착부**: 스프링 행거, 엔진 마운트, 차체 마운트 위치, 범퍼 혼. 차체 마운트 위치가 차체 단계의 제약이 된다.
4. **결합 방식**: 리벳(1930년대) ↔ 용접(1930년대 후반~), 강재 등급.
5. **검사**: 굽힘·비틀림 하중을 걸어 약한 구간을 붉게 표시하고, 보강판을 덧대거나 단면을 키운다.

**4) 그림을 실제처럼**
- 지금은 30~45mm/px로 레일이 1~2픽셀이다. 프레임 전용 화면에서는 **12~15mm/px**로 크게 그린다.
- 레일 단면 두께(채널의 위·아래 플랜지와 웹), 리벳 줄, 크로스멤버의 거싯(삼각 보강판), 스프링 행거, 엔진 마운트 브래킷, 범퍼 혼, 킥업 곡선을 그린다.
- 평면도·측면도·단면도 3가지와 도색 전 강재 질감을 쓴다.
- 조립 장면 1단계도 같은 그림을 쓰고, 레일 → 크로스멤버 → 리벳·용접 → 행거 순서로 만들어진다.

**5) 제작 순서**
1. 플랫폼 단계에서 차체 형상 선택 분리, 차체 단계에서 프레임에 맞는 바탕 차체 선택
2. 프레임 상세 설계(레일·크로스멤버·장착부)와 큰 그림
3. 하중 검사와 보강
4. 구조 방식별 개발 흐름 분기(파생 모델, 모노코크의 셸 설계)
5. 조립 장면 연동

**필요 자료:** 1930~40년대 프레임 평면도·측면도(리벳·크로스멤버·행거가 보이는 것), 더블 드롭 프레임 사진, 차체 마운트 위치 도면.

**18장(프레임 단계) 진행 결과:** 플랫폼 단계는 구조·휠베이스·전폭·프레임만 정하고, 차체 셸은 차체 단계에서 프레임에 맞는 것만 고른다. 래더 프레임은 레일 높이·폭·두께, 앞쪽 좁아짐, 킥업, 더블 드롭, 크로스멤버 수·형식, 리벳/용접, 킥업 보강판, 차체 마운트 수를 설계하고 평면·측면·단면을 크게 그린다. 하중 검사는 앞 혼, 중앙, 뒤 킥업, 비틀림 구간별 여유를 보여 주고 약한 구간을 붉게 표시한다. 출시한 모델의 플랫폼을 재사용하면 플랫폼 단계가 즉시·$500, 금형비가 30% 줄어든다. 모노코크는 플랫폼 단계가 즉시 끝나고 차체 단계에 셸 탭(패널 두께, 사이드실 깊이, 격벽 보강)이 생기며 차체 단계가 +1개월·+$6,000이다. 조립 장면은 레일 → 크로스멤버 → 행거·마운트 순으로 만들어진다.

**17장(부품 자유 이동) 진행 결과:** 정면·후면 미리보기에서 헤드램프, 그릴(높이·폭), 범퍼(높이·폭), 테일램프를 핸들로 끌거나 슬라이더로 옮긴다. 반대쪽 핸들이 거울처럼 따라오고 중심선이 표시된다. 높이와 램프 크기는 측면과 공유한다. 램프가 그릴과 겹치면 경고와 디자인 감점, 그릴 면적이 85% 밑으로 줄면 신뢰성이 떨어진다. 범퍼 앞뒤 돌출(전장 반영)은 아직 없다.

**D단계 1차 진행 결과:**
- **목업실**: 목업 단계에서 들어간다. 턴테이블 위 모형이 돌아가며(회전·정지·수동 회전), 조명을 스포트라이트/자연광으로 바꾸고, 품평이 나오면 경영진 의견이 말풍선으로 뜬다.
- **시험장 직접 주행**: 시제품 단계에서 들어간다. 가속·브레이크를 누르고 있으면(화면 버튼 또는 방향키) 설계한 엔진 토크 곡선·기어·종감속·무게·공기저항·브레이크 형식으로 차가 달린다. 구간은 정지 출발 60마일, 12% 언덕, 험로, 고속 직선, 제동 시험이다. 엔진음이 회전수에 맞춰 나고, 끝나면 측정값(0-60, 최고 속도, 언덕, 흔들림, 제동 거리) 보고서가 프로젝트에 기록된다.

**E단계 1차 진행 결과:**
- **도시 지도**(새 탭): 강, 도로, 철도와 기차, 연도에 따라 늘어나는 시가지. 공장 전경, 본사 사무실, 시내 딜러십, 시험장을 눌러 이동한다.
- **공장 전경**: 벽돌 공장동(공장 능력에 따라 톱날 지붕 동 수와 굴뚝이 늘어남), 사무동과 회사 간판, 급수탑, 생산 중일 때 나는 굴뚝 연기와 불 켜진 창, 지나가는 화물차. 출고 야적장에는 실제 재고 20대당 차 1대가 모델별 스프라이트로 줄지어 선다.
- **공장 내부**: 프레스 → 프레임 → 섀시 → 차체 얹기 → 도장 부스 → 마감 → 검사 7개 공정. 컨베이어 속도와 작업자 수가 가동률을 따른다. 라인 위 차는 도장 부스 전까지 맨 강판, 부스 안에서 프라이머, 이후 도장색이다. 공정에 마우스를 올리면 설명이 나오고, 공장 확장을 여기서 할 수 있다.
- **딜러십**: 연도에 따라 1930년대 상가(차양), 1936년 이후 쇼룸(큰 유리), 1947년 이후 유선형 쇼룸. 유리 안에 내 차가 진열되고 판매량에 따라 행인이 늘어난다. 옆 야적장에 재고가 서 있고 모델별 가격 5% 인하 버튼이 있다.
- **재고 먼지**: 재고가 판매량의 1.5배를 넘는 달마다 '방치 개월'이 늘고, 6개월이면 완전히 먼지를 뒤집어쓴다(야적장·딜러십 차가 회색으로 바래고 얼룩이 생김). 방치된 재고는 최대 15% 덜 팔리고, 6개월째에 전보가 온다. 가격을 내리거나 재고가 줄면 회복된다.

## 19. 방향 전환 — 차량·엔진·부품 디테일, 물리 엔진, 후면 시점 실제 트랙 주행 (E·F 보류)

**결정:** E단계(장소)와 F단계(발표회·언론)는 품질 부족으로 보류한다. 도시 탭과 장소 화면은 테스트판에서 숨기고 코드는 남긴다. 재고 먼지 규칙만 유지한다.

### 19-1. 디테일 업그레이드
| 대상 | 지금 | 목표 |

| 차량 | 25mm/px 측면, 부품이 얇음 | 확대 보기(12mm/px), 범퍼·램프·그릴·휠을 실측 단면으로, 실내(좌석·핸들·계기판)와 하부(배기·연료탱크·구동축) 표시 |

### 19-2. 물리 엔진
- **엔진**: 지금의 토크 곡선 모델에 회전 관성, 스로틀 응답, 냉각수 온도, 연료 소모를 더한다.
- **구동·타이어**: 바이어스 타이어 접지력(약 0.6~0.75g), 폭·공기압, 구동륜 슬립.
- **서스펜션**: 차축별 스프링 상수·감쇠·스프링 아래 무게로 승차 진동수, 롤, 피치(가속 시 뒤 앉음, 제동 시 앞 숙임), 요철 응답을 계산한다. 일체 차축과 독립식의 차이, 무게 배분에 따른 언더스티어·오버스티어가 나온다.
- **제동**: 드럼 크기와 형식에 따른 제동력, 열에 의한 페이드.
- **검증**: 실제 차 3~4대의 공개 시험 수치(0-60, 최고 속도, 제동 거리)와 비교한다.

### 19-3. 후면 시점 트랙 주행
- 차 **후면 그림**을 화면 아래 가운데에 두고 도로가 원근으로 다가오는 방식(구간 투영)이다.
- 조작: 가속, 브레이크, 좌우 조향. 차체가 롤·피치로 기울고 바퀴가 요철을 탄다.
- 트랙: 실제 1930~40년대 코스의 평면 형상과 고저를 구간 데이터로 옮긴다(뱅크 오벌, 도로 서킷, 시험장).

## 21. 엔진 설계 재구성 — 단계별 제작 화면과 그림 품질 (Automation 흐름 참고)

**지적:** 그림 품질이 크게 부족하다. 한 화면에서 모든 과정이 진행된다. 빠진 기능(내구 시험, 분해도, 조립 연출)은 제외한다.

**1) 단계별 제작 (한 단계 = 한 화면, 엔진이 그 단계만큼만 그려짐)**
Automation은 패밀리 → 하체 → 상부 → 연료계 → 배기 → 시험 탭을 순서대로 넘기며, 고를 때마다 엔진 모형에 부품이 붙는다. 같은 흐름을 쓴다.

| 단계 | 정하는 것 | 화면에 보이는 것 |
|---|---|---|
| 1 블록 | 배열, 재질, 패밀리 최대 보어·스트로크, 메인 베어링 | 빈 블록만: 실린더 구멍, 물 통로, 베어링 받침 |
| 2 헤드 | 밸브 형식, 연소실, 헤드 재질 | 블록 위에 헤드가 얹히고 캠·밸브 자리가 보임 |
| 3 하체 | 보어, 스트로크, 크랭크, 커넥팅로드, 피스톤, 카운터웨이트, 댐퍼 | 크랭크·로드·피스톤이 블록 안에 들어가 돌아감 |
| 4 상부 | 압축비, 캠, 밸브 스프링, 태핏 | 캠과 밸브가 움직이고 행정별 색이 나옴 |
| 5 연료계 | 기화기 형식·개수·구경, 매니폴드, 혼합비, 진각, 회전수 제한 | 흡기 매니폴드와 기화기가 붙음 |
| 6 배기 | 매니폴드, 단일·듀얼, 관 굵기, 머플러 | 배기 매니폴드와 관이 붙음 |
| 7 냉각·윤활 | 냉각 방식, 라디에이터, 윤활 방식, 오일 용량 | 팬·물펌프 또는 호스, 오일 팬, 필터가 붙음 |
| 8 시험·확정 | 시험대(스로틀), 통계 전체, 패밀리·변형 개발 시작 | 완성된 엔진이 시험대 위에서 돌아감 |

- 이전·다음 버튼과 단계 막대로 이동한다. 아직 정하지 않은 단계의 부품은 그려지지 않고, 그 단계에 달린 통계는 '-'로 둔다.
- 기존 엔진의 변형을 만들 때는 1·2단계(패밀리)가 잠긴 채 3단계부터 시작한다.
- 변속기 화면도 같은 방식(형식 → 단수·기어비 → 확정)으로 나눈다.

**2) 그림 품질**
- **크게**: 엔진 그림 칸을 지금의 약 150×74에서 화면 오른쪽 전체(약 270×170)로 넓힌다. 통계는 접을 수 있는 옆 칸으로 옮긴다.
- **그리는 방식 교체**: 지금은 단색 사각형을 바로 찍는다. 차량 그림과 같은 방식(재질별 5단계 명암 + 자동 윤곽선 + 둥근 부품 디더링)으로 바꾼다. 고정 부품은 미리 그려 두고, 움직이는 부품(피스톤, 로드, 크랭크, 밸브, 체인)만 매 프레임 그린다.
- **부품 형상**: 피스톤(링 홈, 스커트, 핀 보스), 커넥팅로드(I단면, 대단부 캡과 볼트), 크랭크(저널 필렛, 웹, 카운터웨이트 부채꼴), 밸브(튤립 머리, 스템, 코일 스프링, 리테이너), 캠 로브, 타이밍 기어 이와 체인 링크, 헤드 개스킷 선, 주물 리브와 볼트 머리, 오일 표면과 방울, 냉각수 통로.

3. 변속기 화면 단계 분리
4. 이후 19장의 2단계(서스펜션·물리), 3단계(후면 시점 주행)

**21장 진행 결과 (1~3):** 엔진 그림을 재질별 명암·자동 윤곽선·단면 빗금 방식(engdraw.mjs)으로 새로 그렸다. 엔진 탭은 8단계 화면(단계 막대, 뒤로/다음, 큰 그림 칸, 단계별로 쌓이는 부품, 정해지지 않은 수치는 '-')으로 바뀌었다. 변속기 탭은 3단계(형식 → 단수·기어비 → 시험·확정)로 나누었고, 단계마다 변속기 단면 그림(gbdraw.mjs)에 케이스·축 → 기어 쌍·싱크로·포크 → 변속 레버·오일·물린 기어 강조가 차례로 붙는다. 시험 단을 고르면 그 기어가 금색으로 표시되고, 고른 엔진의 최고 회전 기준 단별 속도가 나온다.

## 22. 엔진 외관 — 앞쪽 보기 정리와 벨트 구동 움직임 (계획, 승인 대기)

**지적:** 외관 보기에서 엔진 앞의 세로 막대가 떠 있다. 이것은 냉각 팬을 옆에서 본 날개(가운데 흰 점은 팬 허브)인데, 물펌프와 잇는 축·풀리가 없고 벨트가 1픽셀보다 가늘어 점선처럼 끊겨 떠 보인다. 아래 회색 공은 크랭크 풀리다. 또 옆에서 본 그림인데 풀리를 원으로 그려 시점이 맞지 않는다.

**1) 옆 보기(외관) 바로잡기**
- 팬을 물펌프 축 끝에 붙인다: 펌프 몸체 → 축 → 팬 풀리 → 팬 허브 → 날개 순서로 이어 그린다.
- 풀리(크랭크, 물펌프·팬, 발전기)는 옆에서 본 모습, 곧 V홈이 있는 얇은 원판 옆면으로 그린다.
- 벨트는 최소 2픽셀 두께로 그려 끊기지 않게 한다.
- 열사이펀 냉각(물펌프 없음)은 팬과 발전기만 벨트로 돈다.

**2) 새 보기: 정면 (4번째 보기 버튼)**
- 엔진을 앞에서 본 그림이다. 크랭크 풀리·댐퍼, 물펌프와 팬 풀리, 발전기 풀리를 원으로 그리고, 벨트는 풀리들을 감싸는 경로(접선 + 호)로 계산해 그린다.
- 블록·헤드·밸브 커버·매니폴드의 정면 윤곽도 함께 그려, 벨트가 엔진 어디에 붙는지 보이게 한다.

**3) 벨트가 도는 모습**
- 벨트 속도 = 크랭크 각속도 × 크랭크 풀리 반지름. 벨트 표면 무늬(이음 자국)가 경로를 따라 이 속도로 흐른다.
- 각 풀리는 (크랭크 풀리 반지름 ÷ 자기 반지름) 배로 돈다. 살·볼트 구멍이 돌아 회전이 보이고, 발전기는 작아서 더 빨리 돈다.
- 팬 날개 4장이 물펌프와 같은 속도로 돈다. 회전이 빨라지면 날개가 흐린 원판처럼 보이게 바꿔, 거꾸로 도는 것처럼 보이는 현상을 막는다.
- 피스톤과 같은 크랭크 각(th)을 쓰므로 단면 보기, 시험대 회전수와 맞물려 움직인다. 정지 시에는 멈춘다.
- 옆 보기에서도 벨트 무늬가 흐르고 풀리 옆면의 반짝임이 돈다.

**4) 언제 보이나**: 7단계(냉각·윤활)부터, 8단계 시험대, 차 개발의 엔진 단계 미리보기.

**5) 고칠 파일**: engdraw.mjs(옆 보기 수정, drawFrontPix 추가), main.mjs(정면 보기 버튼).

**22장 진행 결과:** 외관 보기에서 팬을 물펌프 축에 붙이고 풀리를 옆면(V홈 원판)으로, 벨트를 2픽셀 이상으로 그렸다. 4번째 '정면' 보기에 풀리 3개와 계산된 벨트 경로, 크랭크 속도에 맞춰 흐르는 벨트 무늬, 크기에 반비례해 도는 풀리, 4장 팬을 넣었다. 빨라지면 흐림으로 바뀐다.

**19-2 진행 결과 (섀시 설계와 물리):** 차 개발 4단계 이름을 '섀시'로 바꾸고 변속기·종감속 아래에 앞·뒤 서스펜션(일체 차축 판스프링, 횡치 판스프링, 코일·위시본, 토션바·위시본 / 구동 차축 판스프링·횡치·코일, 스윙 액슬), 스프링 강성, 쇼크(마찰식, 레버식, 통형)와 감쇠, 안티롤 바, 브레이크(기계식·유압식, 드럼 지름·폭, 앞 제동 배분), 타이어(연도별 바이어스 규격, 공기압), 조향 기어와 기어비를 넣었다(sim/chassis.mjs).
- 계산: 승차 진동수, 롤(도/G), 제동 시 앞 숙임·가속 시 뒤 앉음, 횡 접지(G)와 언더·오버스티어, 60-0 MPH 제동 거리, 반복 제동 페이드 횟수, 조향 회전수, 스프링 아래 무게. 타이어 반지름과 구름 저항은 성능 계산에, 승차감·접지·제동은 편의성·성능 점수에, 페이드·오버스티어·떨림은 시제품 결함 후보에 반영한다.
- 범위 확인: 유압 드럼 60-0 약 200~225ft, 기계식 약 255ft, 판스프링 일체 차축 1.3~1.7Hz, 독립식 1.2Hz 안팎, 횡 접지 0.61~0.67G (1935~49년 도로 시험 수치 범위 안).
- 그림(chassdraw.mjs): 앞 차축 정면·뒤 차축 후면(왼쪽 바퀴 밑으로 요철이 지나가며 차축·바퀴가 움직임), 드럼 브레이크(작동할 때 슈가 벌어지고 드럼이 돎, 페이드가 이른 설계는 달아오른 색), 타이어 단면(공기압에 따라 옆면이 부풀고 접지면이 넓어짐).

**19-3 진행 결과 (후면 시점 트랙 주행):** 시제품 단계의 '트랙 주행'을 후면 시점으로 바꿨다(drive3d.mjs).
- 트랙 3개: 1번 시험 도로(언덕 10%, 험로, 여러 굽이), 2번 경사 오벌(22도 뱅크), 3번 도로 서킷. 각 트랙은 이름을 직접 지을 수 있고, 짓지 않으면 '1번 트랙'처럼 표시된다. 미니맵과 트랙 선택 화면에 평면 형상을 그린다.
- 도로는 2m 조각을 지평선 쪽으로 투영해 그리고(굽이, 고저, 연석, 중앙선, 험로 자갈, 나무·표지 기둥, 출발선), 하늘의 먼 언덕은 차의 방향에 따라 돈다.
- 차는 후면 그림이 화면 아래에 있고, 횡가속에 따라 차체가 기울고(롤), 제동·가속 때 앞뒤로 숙고 앉으며, 험로와 노면 이탈 때 승차 진동수·제어력에 따라 흔들린다.
- 물리: 엔진 토크·기어·종감속·공기 저항·구름 저항·경사(성능 보고서와 같은 식), 코너링은 섀시 횡 접지·뱅크 각, 언더스티어는 바깥으로 밀리며 감속, 오버스티어는 뒤가 돌아 스핀, 제동은 섀시 감속도와 드럼 온도(260도 넘으면 페이드).
- 조작: 방향키(위 가속, 아래 브레이크, 좌우 조향), 화면 버튼, 자동 가속.
- 결과: 최고 랩, 랩 기록, 최고 속도, 최대 횡가속, 구간별 최저 코너 속도, 브레이크 최고 온도·페이드, 스핀·이탈, 험로 흔들림. 트랙별 최고 랩은 프로젝트에 남고, 페이드·스핀·흔들림은 시제품 결함 발견에 반영된다.
