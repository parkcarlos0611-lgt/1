# 검토 16 — 보이기만 하는 차: 차종, 업체 라인업, 무작위 생성

기획자 지시(2026-11-19)에 대한 검토다. 적용한 것은 없다. 맨 끝의 결정 사항에 답을 받으면 시작한다.

같은 날 정한 것: 차는 A 방식(1차 판 방식, `render/car/flat.ts`)으로 그린다.

지시:
- 경쟁사 차, 길 위의 차처럼 보이기만 하는 차에도 차종을 준다.
- 큰 업체의 특정 차종 라인업이 길에서 자주 보이는 식으로 시스템과 이을 수 있는지 본다.
- 같은 A 방식으로 무작위 생성하는 것을 검토한다.

## 1. 결론

된다. 보이기만 하는 차를 플레이어의 차와 같은 데이터(뼈대 + 11자리 부품 + 치수 + 칠)로 만들면, 그리기·차종·수치가 모두 한 체계에서 나온다. 무작위는 "아무 조합"이 아니라 "업체의 집안 모양 안에서의 조합"으로 해야 어색한 차가 나오지 않는다.

## 2. 차 한 대가 만들어지는 길

```
업체(집안 모양) → 모델(차종, 뼈대, 값대, 출시·단종 해) → 연식 변경(그릴·등 바꿈) → 한 대(칠, 낡음)
```

| 층 | 정하는 것 | 예 |
|---|---|---|
| 업체 | 집안 모양: 쓰는 그릴 계열, 전조등 모양, 범퍼, 장식 줄, 즐겨 쓰는 칠 색. 값대와 규모 | 대중차 대형 업체: 세로 살 그릴, 검정·짙은 청색, 값 싼 쪽 |
| 모델 | 차종(목록표의 차종 구분), 뼈대 하나, 차체 변형(세단·쿠페·픽업), 값, 출시와 단종 해 | 1934~1936년 대중 세단 |
| 연식 변경 | 1~2년마다 그릴·등·장식을 바꾸고, 4~7년마다 뼈대를 바꾼다 | 1935년형은 그릴만 다름 |
| 한 대 | 칠 색(그 해에 흔한 색에서), 흰 띠 타이어 유무, 낡은 정도(색 바램, 녹, 찌그러짐) | 검정, 3년 된 차 |

- 무작위가 들어가는 곳은 모델을 만들 때(업체 안의 부품 조합, 치수를 차종 범위 안에서 조금)와 한 대를 만들 때(칠, 낡음)다. 같은 모델은 언제 보아도 같은 모양이다.
- 같은 씨앗이면 같은 업체·같은 모델이 나온다. 저장에는 씨앗과 모델 목록만 넣는다.

## 3. 시스템과의 연결

### 3-1. 길 위에 얼마나 보이나

| 방식 | 내용 |
|---|---|
| 간단(1차) | 업체 규모 × 모델의 값대 × 그 해 경기로 가중치를 매겨 뽑는다 |
| 대수 기반(2차) | 모델마다 해마다 팔린 대수를 두고, 해가 갈수록 일부가 폐차된다. 길에 보이는 차는 "지금 굴러다니는 대수"에 비례한다 |

대수 기반이면 이런 일이 저절로 생긴다.
- 큰 업체의 대중 세단이 길의 절반을 채운다.
- 불황 해(1932~1933)에는 새 차가 드물고 낡은 차가 많다.
- 망한 업체의 차도 몇 해 동안은 길에 남는다.
- 고급차는 드물게, 은행가 손님 동네에서는 조금 더 보인다.

### 3-2. 이미 있는 시스템과

| 시스템 | 연결 |
|---|---|
| 동네 등록부의 경쟁사 10곳 | 각자 라인업을 갖는다. 등록부에서 "어려움"이면 신차가 줄고, "파산"이면 단종되어 길에서 서서히 사라진다 |
| 신문 | "경쟁사 신형" 기사가 실제 새 모델의 출시와 같은 날 난다. 기사 그림에 그 차를 그린다. 자동차 등록 기사의 숫자가 길의 대수와 맞는다 |
| 손님 | 손님이 지금 타는 차가 정해진다(바꾸려는 낡은 차). 편지에 "지금 타는 ○○가 낡아서"가 들어가고, 그 차가 상담 장면에 서 있다 |
| 판매 | 손님이 기대하는 값을 경쟁 모델의 값이 정한다(계획 12의 묶음 E) |
| 플레이어가 판 차 | 판 차도 길에 보인다. 손님이 몰고 다니는 모습이 신뢰·인지도 연출이 된다 |
| 배달 컷신, 공방 앞, 품평회 | 배경의 차를 이 방식으로 채운다. 품평회에는 경쟁사의 그 해 신형이 나란히 선다 |
| 잡지 | 시승기의 주인공이 경쟁 모델이다 |

### 3-3. 플레이어에게 주는 것

- 길을 보면 무엇이 잘 팔리는지 보인다. 플레이어가 자기 설계의 방향을 정할 단서가 된다.
- 손님의 "옆집 차보다 낫게"를 실제 옆집 차와 견줄 수 있다.

## 4. 그리기와 성능

| 항목 | 값 |
|---|---|
| 한 대 그리기 | 측면 약 75 ms(지금 견본). 모델·칠·낡음 조합마다 한 번 그려 두고 다시 쓴다 |
| 동시에 보이는 차 | 장면당 10~30대면 그려 둔 그림을 쓰므로 부담이 없다 |
| 탑뷰 | 평면 그림이 따로 필요하다. 뼈대마다 평면 윤곽을 함께 따야 한다(참고 시트에 평면이 있다) |
| 정면 | 배달 컷신에 필요하다. 같은 이유로 뼈대마다 정면을 따야 한다 |

## 5. 필요한 것과 한계

| 항목 | 내용 |
|---|---|
| 뼈대 수 | 업체 10곳 × 시기마다 2~4 모델이면 슬라이스(1930~1935)에 뼈대 15~25개가 필요하다. 지금 참고 차 중 미국 1930~1935년은 8대뿐이다. 기획자가 추가로 만들 1930년대 초 차와 상용차로 채운다. 다른 나라 차의 뼈대를 미국 업체의 모델로 쓰는 것도 된다(이름과 집안 모양을 새로 주므로) |
| 1920년대 차 | 1930년 길에는 1920년대 차가 많았다. 뼈대가 하나도 없다. 몇 종(대중 투어링, 세단, 트럭)이 있으면 초반 길이 실제에 가까워진다 |
| 부품 조합의 어색함 | 부품마다 "맞는 차급과 시기" 표시를 두고, 업체의 집안 모양 안에서만 고른다. 처음에는 사람이 업체마다 조합을 손으로 정하고, 무작위는 칠과 낡음에만 쓰는 것이 안전하다 |
| 실제 차와 닮음 | 뼈대가 실제 차에서 왔으므로 닮은 모델이 나온다. 이름과 로고는 지운다(이미 정한 규칙) |
| 수치 | 보이기만 하는 차도 무게·출력·값을 갖게 하면 경쟁·판매와 바로 이어진다. 구동계 계산(계획 14의 B)이 들어온 뒤 붙인다 |

## 6. 넣는 순서 제안

1. 견본 3종 마무리(A 방식). 부품을 11자리로 나누는 일을 이때 함께 한다
2. 업체·모델 데이터 틀과 간단 가중치 방식, 경쟁사 10곳에 손으로 정한 라인업
3. 신문 기사·손님의 지금 차와 연결
4. 대수 기반 방식, 판 차가 길에 보이기
5. 평면·정면 윤곽(탑뷰 주행, 배달 컷신과 함께)

## 7. 결정이 필요한 것

1. 업체마다 "집안 모양"을 두고 그 안에서만 조합할지. (추천: 그렇게)
2. 무작위의 범위: 처음에는 모델의 모양은 손으로 정하고 칠과 낡음만 무작위로 할지, 모델 모양까지 무작위로 만들지. (추천: 처음에는 칠과 낡음만. 뼈대가 쌓이면 모양으로 넓힌다)
3. 길의 차 수를 간단 가중치로 시작하고 대수 기반으로 넘어갈지. (추천: 그렇게)
4. 플레이어가 판 차가 길에 보이게 할지. (추천: 그렇게)
5. 1920년대 차 몇 종의 참고 시트를 만들어 주실 수 있는지. (대중 투어링, 세단, 쿠페, 1톤 트럭 정도)
