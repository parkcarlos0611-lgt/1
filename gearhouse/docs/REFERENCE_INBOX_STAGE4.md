# 4단계 자료 수신함 (제작 전 수집 단계)

> 사용자 지시: **모든 사진 자료를 받은 뒤 제작 시작.** 이 문서는 받은 자료의 판독 메모와 남은 요청 목록이다. 이미지 원본은 저장소에 넣지 않는다.

→ 휠 생성기 보강: 스포크 교차 패턴(X), 림 깊이, 이중 스포크, 목재 쐐기 스포크 + 클램프, 스포크 도색, 스트랩 스페어.

### 주의: 이 4장은 AI로 만든 홍보용 인포그래픽으로 보임
- **근거**: 같은 워터마크, 스튜디오 렌더 질감, 카드끼리 같은 차의 제원이 다름(예: 1930 V16 토크 300 lb-ft vs 446 Nm), 사실 오류(1930 V16을 "L-Head"로 표기 — 실제는 45° OHV).
- **원칙(자료 우선, AI 성향 배제)**:
  - 이 이미지의 **형태·비율은 템플릿 실측에 쓰지 않는다**. 같은 차의 도면이나 실제 사진을 찾아 대체한다.
  - **제원은 아래 표처럼 1차 출처로 교차 확인한 값만** 쓴다.
  - 배색·장비 구성(사이드마운트, 화이트월, 트렁크 랙)은 참고만 한다.
