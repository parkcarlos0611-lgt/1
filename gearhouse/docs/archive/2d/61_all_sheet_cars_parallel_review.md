# 검토 61 — 시트의 차 전부를 병렬로 넣을 수 있나 (자원을 너무 쓰지 않고)

기획자 결정(2026-11-21):
- 순서는 추천대로: 부품 틀 → 부품 빌더 → 시민 차 → 손님 차 다양화.
- 부품 빌더는 메인 화면에 둔다. Automation식 부품 미리보기 라이브러리, 인터페이스 그림 향상, 전화번호부 메모장 포함.
- 차는 한꺼번에 병렬로 많이 확보하면 좋겠다 → 시트 명단을 파악하고 가능한지 검토.

## 명단
docs/reference/sheet_inventory_2026_11_21.md: 시트 22장, 서로 다른 차 **39대**.
- 세단 20대
- 밴 · 픽업 12대
- 트럭 5대
- 장비 차 2대

## 결론: 가능하다. 단, "사람이 한 대씩"이 아니라 "틀 4개 + 자동 변환 + 묶음 검수"로

### 왜 1929 세단처럼 하면 안 되나
- 1929 세단은 부품 상자와 윤곽을 보기마다 손으로 맞췄다. 39대를 같은 방식으로 하면 품이 너무 크다.
- 에이전트 39개를 동시에 돌리는 것도 자원 낭비다. 대부분의 일은 기계적인 이미지 처리라 스크립트로 된다.

### 방법
1. **틀 4개**(갈래별 표준 부품 목록, 이름 · 갈래 · 붙는 점 · 소재):
   - 세단(1929 세단에서 뽑음)
   - 밴 · 픽업(앞부분은 세단과 같고, 뒤는 짐칸 또는 상자)
   - 트럭(큰 캡, 차대, 짐칸 · 탱크, 뒷바퀴 2겹 · 6바퀴)
   - 장비 차: 지금은 트럭 틀 + 장비 덩어리 하나(NPC용)
2. **자동 변환 도구**(한 번 만들어 모든 차에 씀):
   - 시트에서 차 두 대 × 여섯 보기를 잘라 낸다(투명 바탕이라 쉽다).
   - 옆 · 앞 · 위 보기의 실루엣과 바퀴(원 찾기)로 축간 거리 · 길이 · 높이 · 폭을 잰다.
   - 틀의 부품 상자를 그 치수에 맞춰 놓는다.
   - 부품 윤곽은 색 · 경계로 나눈다: 유리(밝은 회청색), 바퀴, 펜더(검은 에나멜), 차체 칠, 크롬. 틀의 위치 정보로 어느 부품인지 정한다.
   - 결과: 부품 모델 JSON + 확인 그림(부품별 색칠, 원본과 겹쳐 보기, 점수).
3. **병렬은 프로세스로**: 변환은 이미지 처리라 시트 22장을 CPU 프로세스로 동시에 돌린다(몇 분, 에이전트 비용 없음).
4. **검수만 묶어서 맡김**:
   - 점수가 낮은 차만 고친다.
   - 에이전트는 많아야 3~4개, 각자 갈래 하나(세단 / 밴 · 픽업 / 트럭)를 맡는다. 확인 그림을 보고 틀린 부품 상자와 윤곽만 고친다.

### 품질 단계
- **A(손님 차 · 가까이 보기)**: 녹 수리 장면(5 mm/px)까지 견딘다. 세단 중 자주 오는 6대만 손질한다(Ford A, Chevrolet AB, Plymouth U, Ford T, Essex, Pontiac).
- **B(시민 차 · 집 앞 · 차고)**: 자동 변환 + 검수. 집 앞(27 mm/px), 차고(15 mm/px)에서 깨끗하면 된다. 나머지 33대.
- 시트 해상도(옆모습 400~470 px)는 B에 충분하다. A의 녹 수리 장면에서는 칠 질감을 게임이 새로 칠하므로(소재 층) 윤곽만 맞으면 된다.

### 순서와 대략의 품
1. 세단 틀 + 변환 도구 + 첫 2대(Ford A Town Sedan, Chevrolet AB)로 도구를 확인한다. 가장 큰 일이다.
2. 세단 20대 일괄 변환 + 검수(에이전트 1~2개).
3. 밴 · 픽업 틀 → 12대, 트럭 틀 → 5대(에이전트 1~2개).
4. 그 사이 나는 부품 빌더(메인 화면)를 만든다. 변환된 차를 바로 빌더에서 본다. Automation식 큰 미리보기, 부품 라이브러리, 인터페이스 그림 향상, 전화번호부 메모장 포함.
5. 시민 차(GPU에서 여러 대), 손님 차 다양화.

### 위험
- 자동 부품 나누기가 틀리는 곳: 칠과 같은 색의 부품(카울과 차체, 보닛 옆판), 검은 펜더와 검은 발판 · 바퀴. 틀의 위치 정보로 대부분 풀리지만, 남는 것은 검수에서 고친다.
- 겹치는 시트(Ford T · A, Ford B · Dodge KC, Mack BM)는 첫 시트만 쓴다.
- 이 22장에 없는 트럭 3대(MacDonald 저상, Packard · Autocar 덤프)는 시트를 확인해야 한다.

## 정할 것
- 이 방식(틀 4개 + 자동 변환 + 갈래별 검수 3~4개)으로 진행할지.
- A등급 6대 고르기(위 추천 그대로인지).
