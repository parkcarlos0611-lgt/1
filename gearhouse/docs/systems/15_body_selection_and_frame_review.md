# 검토 15 — 차체 고르기와 프레임 설계 (Automation 조사와 제안)

기획자 지시(2026-11-19)에 대한 검토다. 적용한 것은 없다.

지시:
- 제공 이미지는 자료다. 1차 판에서 도면을 분석해 만든 것처럼 400px 규격으로 다시 짓는다.
- 로고만 지우고, 그릴과 그 차 특유의 디자인은 그대로 둔다.
- Automation처럼 "시대 / 차종 / 차체 A, 범퍼 A, 그릴 A"를 고른 뒤 윤곽선으로 치수를 조절하는 방식을 검토한다. Automation이 실제로 그런지, 프레임 설계를 어떻게 하는지 조사한다.

조사의 한계: 공식 포럼과 위키는 이 세션의 네트워크에서 열리지 않았다. 검색 결과의 요약과 내가 아는 내용을 함께 썼다. 내 지식에서 온 부분은 "(기억)"으로 표시했다.

## 1. Automation은 실제로 어떻게 하는가

### 1-1. 차체

| 단계 | 방식 |
|---|---|
| 연도 | 차종을 시작할 연도를 정한다. 연도에 따라 고를 수 있는 차체가 열린다 |
| 차체 고르기 | 미리 만들어 둔 차체 목록에서 고른다. 한 차체에는 묶음으로 변형(세단, 쿠페, 왜건, 컨버터블 등)이 딸려 있고, 크기(축간거리)가 다른 판이 따로 있다. 차체는 모두 합쳐 1,000개가 넘는다 |
| 축간거리 | 자유롭게 늘이지 못한다. 차체마다 정해져 있고, 다른 길이를 원하면 다른 크기의 차체를 고른다 (기억) |
| 모핑 | 차체의 정해진 부분(지붕선, 보닛, 트렁크, 펜더 등)을 끌어서 모양을 바꾼다. 차체마다 되는 부분이 다르고 범위가 정해져 있다. 무리하면 면이 겹치거나 찢어진다 |
| 모핑과 수치 | 모핑은 대체로 겉모양만 바꾼다. 플레이어들은 짐칸, 공기 저항 같은 수치가 모핑에 따라 바뀌지 않는다고 말한다 |
| 부착물 | 그릴, 전조등, 미등, 범퍼, 손잡이, 통풍구, 번호판을 목록에서 골라 차체 표면 아무 데나 붙이고 크기와 각도를 바꾼다. 붙이면 표면 굴곡을 따라 휜다 |

즉 "차체는 목록에서 고르고, 범퍼·그릴·등은 따로 골라 붙인다"는 맞다. 다만 두 가지가 지시하신 생각과 다르다.
- 범퍼·그릴은 "자리에 끼우는 부품"이 아니라 "아무 데나 붙이는 장식"이다. 자유롭지만 성능과는 거의 무관하다.
- 치수 조절(모핑)은 겉모양용이다. 치수가 설계 수치를 바꾸는 구조가 아니다.

### 1-2. 프레임과 하체

프레임을 그리지 않는다. 전부 목록에서 고른다.

| 고르는 것 | 선택지 |
|---|---|
| 섀시 형식 | 사다리꼴 프레임, 모노코크, 스페이스 프레임, 세미 스페이스 프레임, 경트럭 모노코크 |
| 섀시 재료 | 강철, 아연도금 강철, 내식 강철, 알루미늄, 탄소섬유 등 (기억) |
| 차체 판 재료 | 강철, 처리 강철, 알루미늄, 유리섬유, 탄소섬유 (기억) |
| 엔진 자리 | 앞 세로, 앞 가로, 가운데, 뒤 (연도에 따라 열린다) |
| 앞·뒤 현가 | 판스프링 일체차축, 코일 일체차축, 더블 위시본, 맥퍼슨, 토션 빔, 세미 트레일링 암, 멀티링크, 푸시로드 (기억) |

- 형식마다 무게, 강성, 안전, 생산 난이도, 개발 기간이 다르다.
- 엔진룸 크기는 차체가 정한다. 엔진의 크기가 엔진룸을 넘으면 맞지 않는다. 조금 넘는 것은 허용되고 그만큼 개발 시간이 더 든다(채움 비율).
- 프레임 자체를 설계하는 기능은 없다. 포럼에 "왜 프레임의 뼈대를 고칠 수 없느냐"는 질문이 있을 정도다.

### 1-3. 엔진 (기억)

"계열"과 "변형"으로 나눈다. 계열은 블록 형식·재료·최대 보어와 행정·밸브 형식이고, 변형은 보어·행정·압축비·캠·연료 장치·배기다. 1차 판의 엔진 모형이 이 구분을 이미 따르고 있다.

## 2. 우리 게임에 맞춘 방식 (제안)

Automation에서 가져올 것: 연도와 차종으로 좁혀 고르기, 차체와 부품을 따로 고르기, 엔진룸에 엔진이 들어가야 한다는 제약, 프레임을 목록에서 고르기.
다르게 할 것: 2D이므로 부품은 정해진 자리에 끼운다. 치수가 수치를 바꾼다. 프레임과 부품 배치가 도면에 보인다.

### 2-1. 고르는 순서

```
시대 → 차종 → 차체 뼈대 → 자리별 부품 → 윤곽선으로 치수 조절
```

| 단계 | 내용 | 예 |
|---|---|---|
| 시대 | 그해까지 나온 것만 보인다 | 1930~1934 |
| 차종 | 승용(대중 세단, 고급 세단, 쿠페, 컨버터블, 왜건), 스포츠, 경주, 상용(배달차, 트럭, 택시) | 스포츠 |
| 차체 뼈대 | 객실·보닛·꼬리의 큰 윤곽. 참고 이미지 한 종이 뼈대 하나가 된다 | 로드스터 뼈대 A |
| 자리별 부품 | 그릴, 앞 펜더, 뒤 펜더, 범퍼 앞·뒤, 전조등, 미등, 바퀴, 지붕, 발판, 예비 바퀴 자리 | 그릴 C, 범퍼 A |
| 치수 조절 | 윤곽선의 손잡이를 끌어 앞 돌출, 보닛, 객실, 뒤 돌출, 지붕 높이, 허리선을 바꾼다 | 보닛 +200 mm |

- 지금 시제품이 이미 이 구조다. 치수 조절 6가지(앞 돌출, 보닛, 객실, 뒤 돌출, 차체 높이, 유리 높이)와 부품 자리 6가지(그릴, 전조등, 미등, 범퍼 앞·뒤, 바퀴)가 있고, 기준 차마다 기준점 8개가 있어 다른 차의 부품을 가져다 끼운다. 여기에 시대·차종으로 좁히는 단계와 자리 5가지(펜더 앞·뒤, 지붕, 발판, 예비 바퀴)를 더하면 된다.
- 다른 차의 부품이 맞으려면 크기가 비슷해야 한다. 부품마다 "맞는 차급"을 적어 두고, 조금 다른 것은 자리에 맞춰 늘인다.
- 치수 조절은 수치를 바꾼다: 보닛 길이 → 들어가는 엔진, 객실 길이 → 자리 수와 발 공간, 뒤 돌출 → 짐칸, 지붕 높이 → 머리 공간과 공기 저항, 전체 → 무게와 판금 공수. Automation과 다른 점이고, 이 게임에서 설계가 뜻을 갖는 지점이다.
- 3층째(패널의 점을 직접 고치기)는 그대로 둔다. 손으로 짓는 공방의 재미다.

### 2-2. 프레임과 하체

목록에서 고르고, 고른 것이 측면도와 하부도에 그려진다. 1930년대에 실제로 있던 것으로 한다(아래는 기억에 따른 것이고 연도는 확인이 필요하다).

| 고르는 것 | 선택지 |
|---|---|
| 프레임 형식 | 곧은 사다리꼴, 낮춘 사다리꼴(이중 굴곡), X자 보강 사다리꼴, 등뼈 관 프레임, 바닥판 프레임, 일체 차체(뒤 시기) |
| 구동 방식 | 앞 엔진 뒷바퀴, 앞 엔진 앞바퀴, 뒤 엔진 뒷바퀴 |
| 앞 현가 | 일체차축 + 판스프링, 가로 판스프링, 독립(위시본 + 코일, 토션 바) |
| 뒤 현가 | 일체차축 + 판스프링, 스윙 액슬, 드 디옹 |
| 제동 | 기계식(줄·막대), 유압식 |
| 치수 | 축간거리, 윤거, 지상고는 범위 안에서 숫자로 정한다 |

- 엔진, 변속기, 뒤차축, 연료 탱크, 라디에이터, 예비 바퀴는 형식이 정해 주는 자리에 놓이고 앞뒤로 조금 옮길 수 있다(지난 검토의 추천과 같다).
- 엔진룸 제약은 Automation의 "채움 비율"을 가져온다. 조금 넘으면 들어가되 조립 공수가 늘고 정비가 어려워진다. 많이 넘으면 보닛을 늘여야 한다.
- 소규모 공방은 프레임을 직접 짓기 어렵다. "사 온 섀시"는 이 표에서 이미 정해진 한 줄을 고르는 것이고, "자체 섀시"에서 표 전체가 열린다.

### 2-3. 참고 이미지 200종을 400px 에셋으로 다시 짓기

| 항목 | 방식 |
|---|---|
| 측면 | 그림에서 패널 윤곽을 따서 지금의 그리기 방식(패널 → 음영 → 반사 → 이음새)으로 다시 그린다. 원본 그림은 대조용이다 |
| 뼈대와 부품으로 나누기 | 한 차를 뼈대 1개와 자리별 부품으로 나눠 저장한다. 200종이면 뼈대 200개, 부품은 자리마다 겹치는 것을 묶어 수십 종씩이 된다 |
| 치수 | 차 이름으로 찾은 제원에 맞춘다. 그림에서 잰 비율과 견줘 크게 다르면 표시한다 |
| 로고 | 배지와 글씨만 민무늬로 바꾼다. 그릴과 특유의 모양은 그대로 둔다 |
| 평면·정면 | 측면과 같은 뼈대·부품 구분으로 딴다. 탑뷰 주행과 컷신에 쓴다. 측면을 먼저 하고 뒤에 한다 |
| 하부 | 윤곽을 따지 않는다. 2-2의 프레임 형식별 그림을 따로 그린다 |

그릴과 특유의 디자인을 그대로 두는 것에 대해 한 가지만 적는다. 일부 회사는 그릴의 모양 자체를 상표로 등록해 두었다. 배지를 지워도 모양으로 문제가 될 수 있는 경우가 있다. 법률 판단은 내가 할 수 없으니, 출시 전에 이름난 그릴 몇 가지만 따로 확인하는 것을 권한다. 지금 단계의 제작은 지시대로 그대로 둔다.

품이 드는 곳:
- 윤곽 따기가 가장 큰 일이다. 지금 기준 차 한 대가 패널 약 47개다. 200종을 손으로만 하기는 어렵다.
- 그림에서 색 덩어리와 경계를 찾아 윤곽 초안을 만들어 주는 보조 도구를 먼저 만들고, 사람이 다듬는 방식으로 간다. 이 도구가 얼마나 잘 되는지는 견본 몇 종으로 해 봐야 안다.
- 순서는 슬라이스에 필요한 것(미국, 1930~1935, 차종이 섞이게 12종쯤)부터다.

## 3. 결정이 필요한 것

1. 2-1의 순서(시대 → 차종 → 차체 뼈대 → 자리별 부품 → 치수 조절)로 갈지.
2. 부품을 "정해진 자리에 끼우는" 방식으로 할지, Automation처럼 "아무 데나 붙이는" 방식으로 할지. (추천: 정해진 자리. 2D에서 자유 부착은 어색한 차가 쉽게 나오고 400px 그리기와 맞추기 어렵다)
3. 치수 조절이 수치(엔진룸, 자리, 짐칸, 무게)를 바꾸게 할지. (추천: 바꾼다)
4. 프레임은 2-2처럼 목록에서 고르고 도면에 그려지는 방식으로 할지. (추천: 그렇게)
5. 자리를 11가지(지금 6 + 펜더 앞·뒤, 지붕, 발판, 예비 바퀴)로 할지.
6. 윤곽 따기를 보조 도구 + 다듬기로 하고, 견본 3종으로 먼저 품질과 품을 재 볼지. (추천: 그렇게)
