# 시스템 설계 07 — 재무와 경제

수직 슬라이스(소규모 공방, 미국, 1930~1935) 기준이다. 수치는 시작값이고, 경제 지표는 당시 통계와 대조해 확정한다(아직 대조하지 않았다).

## 1. 목적

- 돈은 장부로 본다. 숫자판이 아니라 현금 출납부, 영수증, 은행 통지서다.
- 바깥 세상(대공황)이 수요, 값, 사람, 은행을 흔든다. 플레이어는 신문으로 그 흐름을 읽는다.

## 2. 재무 (슬라이스: 최소)

### 돈이 들어오는 곳

| 항목 | 때 |
|---|---|
| 계약금 | 주문 시 |
| 잔금 | 인도 시 |
| 재고 차 판매 | 판매 시 |
| 수리·잔일(동네 손님) | 가끔. 창업자 배경이 기계공이면 더 자주 |
| 대출 | 승인 시 |

### 돈이 나가는 곳

| 항목 | 주기 | 시작값 |
|---|---|---|
| 직원 급여 | 주 | 05 문서 |
| 창업자 생활비 | 주 | $15~$25 |
| 공방 임대료 | 월 | $20~$40 (자가이면 없음) |
| 전기·난방·전화 | 월 | $8~$15 |
| 부품·자재 | 발주 조건대로 | 03 문서 |
| 광고비 | 게재 시 | 06 문서 |
| 공구·설비 | 구입 시 | |
| 대출 이자와 원금 | 월 | |
| 세금 | 연 | 단순화: 이익의 일정 비율 |

- 시작값은 당시 자료와 대조하지 않은 값이다.

### 장부

- **현금 출납부**: 날짜별 들어온 돈과 나간 돈. 책상 서랍의 장부를 펼쳐 본다.
- **월말 결산서**: 그달의 수입, 지출, 남은 현금, 받을 돈(잔금), 줄 돈(외상, 대출).
- **차별 손익**: 차 한 대마다 견적 원가, 실제 원가, 판매가, 이익.
- **현금 예측**: 앞으로 8주의 예정 수입과 지출. 현금이 바닥나는 주가 보이면 경고 사건을 낸다.

### 은행

- 동네 은행 1~2곳이 있다. 은행마다 건전성(숨은 값)이 있어 대공황 때 파산할 수 있다.
- 예금을 넣은 은행이 파산하면 예금 일부를 잃는다(1933년 이전에는 예금 보험이 없다).
- **대출 신청**: 금액, 기간, 담보(공방, 설비, 주문서)를 적어 낸다. 은행원 면담 사건이 난다.

| 승인을 정하는 것 | 영향 |
|---|---|
| 장부 상태(최근 6개월 손익) | 크다 |
| 담보 | 크다 |
| 받아 둔 주문 | 보통 |
| 지역 평판 | 보통 |
| 경기 | 대공황이 깊으면 은행이 돈을 조인다 |

- 이자는 연 6~8%에서 시작한다(대조하지 않은 값). 연체하면 독촉 → 담보 압류 순으로 사건이 난다.
- 다른 돈줄: 지인에게 빌리기(이자가 낮고 관계가 걸린다), 고객에게 계약금을 더 받기, 설비 팔기.

### 파산

- 현금이 음수이고 4주 안에 메울 수단이 없으면 파산 절차 사건이 난다.
- 선택지: 설비 매각, 직원 정리, 빚 조정 협상, 동업자 받기(지분을 내줌, 뒤 단계의 이사회 씨앗), 폐업.
- 폐업하면 게임이 끝난다. 샌드박스 설정에서는 끌 수 있다.

## 3. 경제 (슬라이스: 대공황 한 줄기)

### 지표

월 단위로 움직이는 값이다. 실제 1930~1935년의 흐름을 바탕 곡선으로 두고, 판마다 작은 흔들림을 더한다.

| 지표 | 쓰이는 곳 | 실제 흐름(대략, 대조 필요) |
|---|---|---|
| 경기 지수 | 전체 수요 배수 | 1929년 정점에서 1933년 초 바닥, 이후 느린 회복 |
| 실업률 | 지원자 수, 희망 급여 | 1930년 약 9% → 1933년 약 25% → 1935년 약 20% |
| 임금 지수 | 급여 시세 | 1930 → 1933년 약 30% 하락 |
| 물가 지수 | 생활비, 값 전반 | 1930 → 1933년 약 25% 하락 |
| 강재·고무·목재 값 | 공급사 가격 | 물가보다 크게 출렁인다 |
| 은행 위험 | 은행 파산 확률 | 1930년 말, 1931년, 1933년 초에 파산이 몰렸다 |
| 신차 판매 | 가상 경쟁사 상태, 수요 | 1929년 약 450만 대 → 1932년 약 110만 대 |

- 지표는 `data/economy/us_1930_1945.json`의 월별 표로 둔다. 다른 국가와 시대는 표를 더하면 된다.
- 표의 값은 공개 통계로 채우고 출처를 적는다.

### 수요

고객 유형별 수요 배수를 따로 둔다.

| 유형 | 대공황의 영향 |
|---|---|
| 부유층 사치(코치빌드, 로드스터) | 1930~1932년에 크게 준다. 그래도 남은 부자는 산다. 눈에 띄는 사치를 꺼리는 분위기가 생긴다 |
| 전문직 실용(의사, 변호사의 튼튼한 차) | 조금 준다 |
| 상용(배달차, 소형 트럭, 삼륜차) | 덜 준다. 값에 매우 민감해진다 |
| 레이서·취미 | 준다. 값싼 개조 수요가 생긴다 |

- 이 변화가 회사 진화의 첫 갈래(프리미엄 대 초저가 상용)를 고민하게 만든다.

### 지역

- 슬라이스의 무대는 가상의 소도시와 그 둘레다. 인구, 평균 소득, 도로 상태(포장 비율), 주요 산업을 갖는다.
- 주요 산업이 무너지면(공장 폐쇄 기사) 그 지역 수요가 더 내려간다.
- 도로 상태는 고객이 원하는 차에 영향을 준다(험한 길 → 높은 지상고, 튼튼한 하체).

### 가상 경쟁사 (슬라이스: 배경으로만)

- 경쟁사 AI는 3단계다. 슬라이스에서는 이름과 차 몇 대만 가진 배경으로 둔다.
- 하는 일: 잡지의 신차 소개와 값 비교에 나오고, 신문에 폐업 기사가 나고, 문 닫으면 숙련공과 중고 설비가 시장에 나온다.

## 4. 경제가 다른 시스템에 닿는 곳

| 닿는 곳 | 어떻게 |
|---|---|
| 판매 | 유형별 수요 배수, 고객 예산, 지불 불능 확률 |
| 공급 | 원자재 값, 공급사 폐업 확률 |
| 인사 | 지원자 수와 질, 급여 시세 |
| 재무 | 은행 파산, 대출 승인, 이자 |
| 미디어 | 경제 기사의 재료. 기사가 변화를 미리 알린다 |

- 변화는 먼저 신문에 조짐이 나오고, 몇 주 뒤에 수치로 닥친다. 읽은 사람이 대비할 수 있다.

## 5. 상태 데이터

```
Ledger   { entries: [{ date, kind, amount, ref, note }], cash }
Loan     { bankId, principal, rate, months, startDate, collateral, missed }
Bank     { id, name, health, deposits, failed }
Economy  { month, indices: { activity, unemployment, wage, price, steel, rubber, lumber, bankRisk, carSales } }
Region   { id, population, income, roads, industries: [{ name, health }] }
Forecast { weeks: [{ in, out, cash }] }
```

## 6. 하루 틱에서 하는 일

1. 그날의 수입과 지출을 장부에 적는다.
2. 주말: 급여와 생활비를 낸다. 현금 예측을 다시 계산한다.
3. 월초: 경제 지표를 다음 달 값으로 옮기고 `economy_changed`를 낸다. 임대료, 공과금, 대출 상환을 낸다. 은행 파산을 굴린다.
4. 월말: 결산서를 만든다.
5. 현금 예측이 음수가 되는 주가 있으면 경고 사건을 낸다.

## 7. 이벤트

| 이벤트 | 보내는 내용 | 듣는 시스템 |
|---|---|---|
| `money_in` / `money_out` | 금액, 종류, 근거 | 장부, UI |
| `month_closed` | 결산서 | UI, 시간(알림) |
| `cash_warning` | 바닥나는 주 | 시간(정지) |
| `loan_taken` / `loan_missed` / `loan_repaid` | 대출 | 평판(신뢰), 은행 |
| `bank_failed` | 은행 | 미디어(기사), 판매(고객 지불 불능), 재무(예금 손실) |
| `economy_changed` | 지표 | 판매, 공급, 인사, 미디어 |
| `bankruptcy_started` | 사유 | 시간(정지), UI |

듣는 이벤트: `order_placed`(계약금), `car_delivered`(잔금), `purchase_ordered`, `wage_paid`, `ad_placed`.

## 8. 결정이 필요한 것

1. 은행 파산으로 예금을 잃는 사건을 넣을지. 시대감은 매우 크지만 한 번에 판이 기울 수 있다. 제안: 넣되, 신문에 그 은행의 불안 기사가 2~3주 먼저 나오게 한다.
2. 창업자 개인 돈과 회사 돈을 슬라이스에서 나눌지. 제안: 슬라이스에서는 하나로 두고 생활비만 뺀다. 나누는 것은 4단계(개인 생활)에서 한다.
3. 세금을 슬라이스에 넣을지. 제안: 연 1회 단순 비율로만 넣는다.
