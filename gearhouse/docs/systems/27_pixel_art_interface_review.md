# 검토 27 — 인터페이스 전체를 고급 픽셀아트로 만드는 것이 계획에 있었는가

## 1. 결론

- **1차판에는 있었고, 실제로 만들었다.** 480×270 픽셀 버퍼를 정수 배율로 키우고, 창·버튼·슬라이더·선택기·그래프·커서까지 모두 픽셀로 직접 그렸다(legacy/docs/STAGE3_PLAN.md). 재질은 호두나무 책상, 크림색 제도지, 황동 베벨, 옥스블러드 에나멜 제목판, 리벳. 한글은 픽셀 폰트 Galmuri7(SIL OFL)을 구워 넣었고(legacy/game/font_ko.mjs), 픽셀 UI용 텍스트 입력칸(숨은 HTML 입력으로 한글 조합)과 황동 스크롤바도 계획·구현했다.
- **2차 재설계에는 "시대 소품형 UI"로만 남았다.** REBOOT_PLAN 7장의 폴더 설명이 "시대 소품형 UI 컴포넌트, 창 관리자"이고, 6장은 UI 품질 기준(누름 영역 44pt/48dp, 글자 넘침, 창 겹침 자동 검사)이다. "모든 UI를 고급 픽셀아트로" 라는 결정은 명시돼 있지 않다.
- **지금 화면(책상, 시험 주행장)은 HTML·CSS다.** 시스템 글꼴, CSS 색. 계획 12에서 "화면 1차는 배치와 조작만 보고, 그림은 자료가 오면 바꾼다"고 정했기 때문이다. 즉 픽셀 UI는 미뤄진 상태이지 폐기된 것은 아니다.

## 2. 지금 만드는 것과의 관계

- 차·부품 그림은 이미 고급 픽셀아트(외곽선, 단계 명암, 디더)로 가고 있다. UI가 HTML 그대로면 화면 안에서 화풍이 갈라진다.
- 도면 화면(검토 26)의 닳은 제도지, 청사진, 빨간 수정선, 지우개는 픽셀 UI와 잘 맞는다. 도면을 첫 픽셀 UI 화면으로 삼기 좋다.

## 3. 픽셀 UI로 갈 때 걸리는 점과 해법

| 걸리는 점 | 해법 |
|---|---|
| 글이 많은 화면(신문, 편지, 장부)의 가독성 | 제목·숫자·버튼은 작은 픽셀 폰트, 긴 본문은 큰 픽셀 폰트(Galmuri11 / 14 등)를 2배 이상으로. 확대해서 읽는 신문 보기 |
| 휴대폰 누름 영역 44pt | 픽셀 버튼을 정수 배율로 키워 44pt 이상. 품질 기준 자동 검사는 그대로 |
| 여러 화면 비율 | 1차판처럼 픽셀 버퍼 + 꽉 채우는 배율, UI는 안전 영역 안 |
| 한글 입력 | 1차판의 숨은 입력칸 방식 |
| 작업량 | 공통 부품(9조각 창틀, 버튼, 탭, 목록, 슬라이더, 스크롤바)을 한 벌 만들고 모든 화면이 쓴다. 재질 4종(나무 책상, 제도지, 황동, 에나멜) |
| 접근성·번역 | 글자를 그림에 굽지 않고 폰트로 찍는다. 문자열 표 유지 |

## 4. 제안

1. 결정으로 명시: "인터페이스 전체를 시대 소품형 고급 픽셀아트로. 1차판의 픽셀 UI 방식(픽셀 버퍼, Galmuri, 황동·나무·제도지 재질)을 이어받는다."
2. 공통 픽셀 UI 부품 한 벌을 먼저 만든다(창틀, 버튼, 탭, 목록, 슬라이더, 입력칸, 스크롤바).
3. 첫 적용 화면은 도면 화면(검토 26). 다음이 책상 화면(지금 HTML)을 픽셀로 옮기기.
4. 회사 규모·시대에 따라 UI 재질도 바뀐다(도면 4종과 같은 생각): 공방은 나무와 종이, 커지면 황동·에나멜, 뒤 시대는 철제 사무가구.

## 5. 정할 것

1. 인터페이스 전체를 고급 픽셀아트로 하는 것을 결정으로 명시할지 (추천).
2. 긴 본문을 픽셀 폰트로 할지, 본문만 고운 글꼴로 둘지 (추천: 픽셀 폰트, 큰 크기).
3. 첫 픽셀 UI 화면을 도면 화면으로 할지 (추천).
