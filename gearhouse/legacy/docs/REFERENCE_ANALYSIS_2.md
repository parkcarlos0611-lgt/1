## 2. 패턴화 결과

### 2-1. 범퍼 (지적 1: 공 모양 끝 + 가는 선)

| 구분 | 패턴 | 치수 (R1·R3·R5 실측) |
|---|---|---|
| 경차·소형 앞 | **크롬 바 2단**, 차 폭보다 넓음, 바 끝이 뒤로 말림. 가운데와 양끝에 클램프. 스프링강 브래킷이 프레임 혼으로 연결 | 바 높이 40–45mm, 바 중심 간격 약 90mm, 바 중심 높이 450–550mm. 측면에서는 말린 끝 약 110–170mm와 클램프, 브래킷만 보임 |
| 경차·소형 뒤 | **좌우 분리 범퍼렛** (C자로 말림) + 브래킷 | 높이 약 440mm, 스페어 캐리어 아래 |
| 고급 | 단일 두꺼운 바 + 오버라이더, 또는 2단 바 + 중앙 엠블럼 바 | 바 높이 60–80mm |
| 스포츠·레이싱 | 없음, 또는 짧은 너프 바 | — |
| 상용 | 단일 바 또는 없음 (트럭은 프레임 앞 크로스멤버 노출) | — |

### 2-2. 차체 하부 (지적 2: 비어 보임)

측면에서 실제로 보이는 구성 (R1·R2·R5·R6 공통):
- **앞**: 프레임 혼 (레일 앞끝이 아래로 휨), 라디에이터 아래 검은 스플래시 에이프런, 앞 스프링 끝(측면에서 보면 단면)·섀클, 레버식 쇼크업소버와 링크, 래디어스 로드(앞차축에서 뒤로 비스듬히)
- **가운데**: 러닝보드 약 85mm (고무 상판 + 알루미늄 엣지 몰딩), 그 위 차체 하단까지 검은 에이프런 약 150mm (보드와 에이프런을 합친 검은 띠가 약 240mm). **보드 아래로는 지면이 보이는 게 맞다.**
- **뒤**: 프레임 킥업과 뒤 혼, 뒤 스프링 단면, 스페어 캐리어 브래킷, 범퍼렛 브래킷, 머플러와 테일파이프, 테일램프·번호판 브래킷
- 상용(R5): 프레임 레일이 차체 아래로 **완전히 노출**, 적재함 아래 크로스멤버, 뒤 듀얼 타이어, 스페어 캐리어

### 2-3. 창문 (지적 3)

| 항목 | 패턴 (R1 실측) |
|---|---|
| 도어창 | 높이 약 355–378mm, 모서리 R 35–40mm, 창 하단 ≈ 후드 상단 높이 (벨트라인 연속) |
| 쿼터창 | 뒤 아래 모서리 **R 80–90mm**(큰 곡률), 위 모서리 R 약 60mm |
| 창 위 루프 띠 | 드립레일 + 차양 포함 약 185–200mm (지붕이 두툼해 보이는 이유) |
| B필러 | 약 75–80mm |
| 창틀 | 경제형은 차체색 리빌(안쪽으로 파인 그림자), 고급형은 크롬 프레임 |
| 유리 묘사 | 위쪽에 하늘 반사, 아래로 갈수록 어두운 실내. 스티어링 휠, 시트 등받이 실루엣. 강한 사선 반사는 현대적이라 제거 |
| 앞유리(정면) | 굵은 프레임, 상단 힌지 개폐식, 와이퍼 1개 |

### 2-4. 장식

| 장식 | 패턴 |
|---|---|
| 라디에이터 셸 | 크롬 셸 + 세로 미세 그릴 + 중앙 스파인, 상단 캡 + 마스코트 (상표 없는 일반 형상) |
| 헤드램프 | 크롬 버킷이 펜더 사이 램프 바 위에 장착. 지름 약 230–250mm, 중심 ±420mm, 라디에이터와 간격이 있음 |
| 카울 램프 | 카울 측면 상단의 작은 크롬 램프 |
| 후드 루버 | 경차·소형은 세로 슬롯 약 20개 (길이 약 386mm, 간격 약 25–28mm), 고급은 루버 그룹 또는 벤트 도어, 유선형은 가로 래핑 |
| 몰딩 | 벨트 리빌 몰딩이 후드·카울·차체로 연속, 드립레일, 펜더 비드 |
| 투톤 | 경차는 지붕·펜더 검정 + 차체 색, 고급은 펜더 대비색 (R7) |
| 휠 | 와이어 휠 뒤로 브레이크 드럼이 보이고 큰 허브캡, 타이어 트레드가 실루엣에 드러남 |

## 3. 생성기 반영 (이번 차수)

| 변경 | 내용 |
|---|---|
| **디테일 축척 12.5mm/px** | 25mm/px에서는 범퍼 바가 1~2px라 표현할 수 없음. 디자인 스튜디오·쇼룸·테스트 트랙은 12.5mm/px, 목록·지도는 25mm/px 유지 |
| 범퍼 어셈블리 (`bumperSets`) | 말린 끝 2단 바 + 클램프 + 스프링강 브래킷 → 프레임 혼 |
| 하부 레이어 (`under`) | 프레임 혼·레일, 스플래시 에이프런, 스프링 단면, 쇼크·링크, 래디어스 로드, 뒤 킥업, 머플러·테일파이프 (차체와 바퀴 뒤에 그림) |
| 러닝보드·에이프런 | 실측 두께로 수정 (보드 81mm, 에이프런 146mm) |
| 창문 | 실측 크기·곡률, 드립레일, 리빌 프레임, 시대 유리 (하늘 반사에서 어두운 실내로 그라데이션) |
| 장식 | 카울 램프, 마스코트 캡, 램프 스템, 스페어 캐리어, 번호판·테일램프 브래킷, 럼블 핸들, 루버 간격 실측 |
| 휠 | 스포크 뒤 브레이크 드럼, 림 웰, 큰 허브, 타이어 트레드 블록 |
| 음영 | 디더링 그라데이션. 단계가 바뀌는 경계에만 좁게 디더를 넣어 면은 깨끗하게 유지 |
| 정면 | 헤드램프 크롬 링 + 렌즈 그라데이션 + 하이라이트, 위치·크기 실측, 말린 끝 범퍼 바, 시대 유리 |
