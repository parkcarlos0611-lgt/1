# 58. 차고 수리 (프리알파 4단계)

## 흐름
1. 합의한 손님 차는 길가에 서 있다. 차를 누르면 **차를 차고에 넣는다**(차고문이 닫혀 있으면 먼저 연다). 차고 칸이 차 있으면 못 넣는다.
2. 차고: 차가 바닥에 실제 크기(1 m = 67 px)로 서 있다. 남은 손상(녹, 찌그러짐, 깨진 램프, 찢어진 지붕)이 차에 보인다. 칠 밑에 숨은 녹은 안 보인다.
3. 오른쪽 작업 카드:
   - **차체 작업**(녹 · 칠): 녹 수리 장면(프로토타입 B)을 손님 차 색과 이 일의 녹으로 연다. 숨은 녹은 칠이 멀쩡해 보이고 군데군데 부풀었을 뿐이다. 철수세미로 칠을 뚫어야 드러난다. **검사**한 뒤 **이대로 끝**을 누르면 결과(만족, 재발 확률, 부품별 숨은 녹 · 파인 곳 · 맨 철판)가 남는다. **나가기**를 누르면 작업한 상태를 두고 나온다(같은 세션 안에서 이어서 할 수 있다).
   - **찌그러짐 펴기 · 램프 유리 갈기 · 지붕 천 갈기**: 버튼 하나로 처리한다. 손상 정도에 따라 시간(시계가 그만큼 간다)과 재료비(장부에 기록)가 든다.
   - **작업을 끝낸다**: `repair.finish`. 차체 작업을 안 했거나 안 고친 곳이 있으면 만족이 크게 깎이고 재발 확률이 높다.
4. 끝난 차는 손님이 찾으러 올 때까지 차고 칸에 있다(5단계: 인도와 대금).

## 시간
- 차체 작업 장면 안에서는 작업 시간이 20배로 흐른다. 나오거나 끝낼 때 그 시간만큼 바깥 시계를 앞으로 돌린다.
- 판금 · 교체 작업은 데이터의 작업 시간(손상 정도로 보간)에 맞춰 시계를 돌린다.

## 아직 남은 것
- 차고 배경은 아직 임시 그림이다. 공방 · 차고 새 레퍼런스로 다시 만든다.
- 찌그러짐 펴기는 손으로 하는 장면이 없다(망치와 돌리). 지금은 버튼이다.
- 차체 작업 도중 상태는 저장되지 않는다. 게임을 다시 열면 처음부터 한다.
- 차가 길에서 차고로 들어가는 움직임은 없다. 화면이 넘어가며 바로 들어가 있다.
